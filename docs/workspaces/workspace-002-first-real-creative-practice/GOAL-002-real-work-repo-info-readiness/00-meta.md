# GOAL-002 · 获取并审视真实作品仓信息

## 概述

本子目标承接 Root `GOAL-001-first-real-creative-practice` 的 S1 信息就绪阶段，负责与真实作品仓/作品方形成可追溯的信息收集闭环：先定义对方需要提供的最小信息，再接收提交，逐项审视完整性、歧义和与 VP-002 固定终点的兼容性；发现缺失或不清楚时，形成明确的补充/澄清清单并再次审视，直到获得足以核对 Root I-001～I-005 的信息。

本目标只处理 D1 所需的事实发现与就绪判断，不预先创建未来方法 Goal，不代替作品仓的创作目标或状态源，也不把未有证据的信息写成已确认事实。完成本目标只表示已形成可供 Root 核对的 D1 信息包；不自动改变 Root 状态，也不自动关闭 Root 信息项。

## 成功标准

- [x] 已形成一份面向真实作品仓/作品方的首轮信息请求，逐项说明所需内容、最低清晰度和可接受证据形式。
- [ ] 每轮作品仓提交均有来源和日期记录；已收到内容与尚未收到内容明确区分，未经核对的陈述不作为验证事实。
- [ ] 每轮审视均记录缺失、歧义、相互矛盾或超出范围的内容，并形成可执行的补充/澄清请求；不以猜测替代确认。
- [ ] 重复“提交→审视→补充/澄清→再审视”，直到 Root I-001～I-005 各自有可核对证据，且没有影响 D1 的未决冲突。
- [ ] 形成一份映射 Root I-001～I-005 的信息就绪包并交回 Root；若作品方当前下一阶段不符合 VP-002 已冻结的终点，则记录阻塞并回流 `/vision`，不得扩张“大纲”语义或要求作品适配预设流程。

## 父目标与门禁关系

- 父目标：`GOAL-001-first-real-creative-practice`。
- 本目标是 Root S1 的信息收集切片；不取代 Root 的 I-001～I-005，已核对的信息状态通过 Root D-003/E-003 同步，不以子目标记录替代 Root 门禁。
- 当前 I-003 的收集通过 VP-002 D1 有界探索完成，不要求作品方预先虚构答案；探索不等于验收或方法响应。若发现最终边界不符合 VP-002 已冻结的“包含故事线规划、足以进入其下一创作阶段的大纲”，本目标停止扩大收集范围并记录回流 `/vision` 的事实。

## 台账布局

本目标使用平铺的 `01-decision/`、`02-execution/`、`03-audit/` 和 `attachments/`。新增决定、事实和正式审计意见分别写入对应 ledger 目录；当前不把任何未发生的作品仓提交写成执行事实。
