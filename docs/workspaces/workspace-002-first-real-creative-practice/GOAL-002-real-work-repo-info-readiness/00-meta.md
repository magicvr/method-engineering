# GOAL-002 · 获取并审视真实作品仓信息

## 概述

本子目标承接 Root `GOAL-001-first-real-creative-practice` 的 S1 信息就绪阶段，负责与真实作品仓/作品方形成可追溯的信息收集与探索闭环：先定义需要固定的最小事实，再接收提交，逐项审视完整性、歧义和与 VP-002 固定终点的兼容性；对尚不存在的接受边界，不要求预先给出答案，而是在 D1 内形成候选、作品证据和后续进入条件。

本目标只处理 D1 所需的事实发现、接受边界探索与就绪判断，不预先创建未来方法 Goal，不代替作品仓的创作目标或状态源，也不把未有证据的信息写成已确认事实。完成本目标表示已形成可供 Root 核对的事实包、候选边界和证据；不自动改变 Root 状态，也不把候选写成已经验证的接受标准。

## 成功标准

- [x] 已形成一份面向真实作品仓/作品方的首轮信息请求，逐项说明所需内容、最低清晰度和可接受证据形式。
- [ ] 每轮作品仓提交均有来源和日期记录；已收到内容与尚未收到内容明确区分，未经核对的陈述不作为验证事实。
- [ ] 每轮审视均记录缺失、歧义、相互矛盾或超出范围的内容，并形成可执行的补充/澄清请求；不以猜测替代确认。
- [ ] 重复“提交→审视→补充/澄清→再审视”，直到 Root I-001、I-002、I-004、I-005 各自有可核对证据，且没有影响 D1 的未决冲突。
- [ ] 在真实推进中形成最低接受条件候选、对应作品证据、下一阶段候选及进入条件，并交由 book_green 判断；若候选方向不符合 VP-002 已冻结的终点，则记录阻塞并回流 `/vision`，不得扩张“大纲”语义或要求作品适配预设流程。

### D1 探索目标（原 I-003）

原 `I-003` 仅作为历史追踪标签保留。当前目标是：在 VP-002 的实践中形成最低接受条件候选、对应作品证据、下一阶段候选及进入条件。它由本目标 P4 承载，影响 Root S1 退出和后续验收，但不构成本目标 P4 或 GOAL-003 P2 的启动门禁。VP-002 v0.3.0 允许 GOAL-003 在 D1 内提供有限前置方法分析输入，但 P4 仍是接受边界探索的权威承载目标。

## 父目标与门禁关系

- 父目标：`GOAL-001-first-real-creative-practice`。
- 本目标是 Root S1 的事实与 D1 探索切片；不取代 Root 的 I-001、I-002、I-004、I-005，已核对的信息状态通过 Root D-003/E-003 同步，不以子目标记录替代 Root 的 S1 退出判断。
- D1 探索不要求作品方预先虚构答案；探索不等于验收或方法响应。若发现形成中的边界不符合 VP-002 已冻结的“包含故事线规划、足以进入其下一创作阶段的大纲”，本目标停止扩大范围并记录回流 `/vision` 的事实。

## 台账布局

本目标使用平铺的 `01-decision/`、`02-execution/`、`03-audit/` 和 `attachments/`。新增决定、事实和正式审计意见分别写入对应 ledger 目录；当前不把任何未发生的作品仓提交写成执行事实。
