# D-009 · 保留 D1 创作边界探索并解除其对局部方法需求的统一门禁

## 决定

GOAL-002 P4 继续承载原 I-003 对应的 D1 探索，但其职责限定为作品自身的范围、终点、最低接受条件、下一阶段和对应作品证据。P4 不定义方法验收条件，不要求作品方产生、比较或验证候选方法，也不整理 Method Engineering 的工程证据。

D1 探索的未完成状态只影响 Root S1 退出和 VP-002 的最终关门，不统一阻止一个已经足够具体且局部有界的方法需求进入澄清、构建、交付和正常使用。GOAL-003 的当前需求澄清不再向 P4 提供“D1 前置方法分析”输入；任何后续方法响应由 Method Engineering 按其自身责任边界处理。

## 理由与影响

此前为解除 I-003 的启动死锁，P4 被允许吸收 GOAL-003 的候选方法材料。这把作品大纲的创作边界和方法工程的设计责任绑定在一起，容易要求作品方共同承担本仓工作。现在保留 D1 作为作品自身的真实探索目标，同时解除其对局部方法需求的统一门禁，可以同时维护作品接受责任和需求驱动的方法工程闭环。

本决定不改变 VP-002 的最终大纲终点、四周投入上限或 book_green 对作品边界的判断权；不表示 D1 已完成，也不表示任何方法需求已完成响应。
