# D-008 · 承接 VP-002 的 D1 前置分析输入但保留 P4 权威

## 决定

GOAL-002 P4 继续是原 I-003/D1 接受边界探索的权威承载目标。根据 VP-002 v0.3.0，P4 可以吸收 GOAL-003 在 D1 内形成的问题、边界、候选和证据设计，但这些内容只作为探索输入，不自动成为接受条件、作品标准或 D2 方法响应。

## 影响

GOAL-003 P2 不再等待 P4 先形成答案；P4 仍必须独立形成候选接受条件、对应作品证据、下一阶段候选和进入条件，并交由 book_green 判断。Root S1 的退出条件不变。
