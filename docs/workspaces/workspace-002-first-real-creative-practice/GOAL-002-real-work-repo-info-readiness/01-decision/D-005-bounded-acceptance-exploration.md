# D-005 · I-003 转入 VP-002 D1 有界接受条件定义探索

- **日期**：2026-09-19
- **状态**：accepted
- **决策来源**：用户选择经 `/vision` 重新对齐的有界探索，不要求 book_green 为未知内容虚构门禁答案。

## 决定

1. I-003 不再通过补问要求 book_green 预先给出其尚不具备依据的最终接受标准或下一阶段；改在 VP-002 D1 内开展有界定义探索。
2. 探索只收集和形成三类结果：最低接受条件候选及其作品证据、下一阶段候选及进入条件、由 book_green 确认的范围/终点/接受边界。
3. 探索不是验收，不是 D2 方法响应，也不自动创建未来方法 Goal；在 book_green 确认前，I-003 保持 `required/collecting`，Root S1 不退出。
4. 探索受已确认的四周总投入上限约束；到期不自动延长，无法形成可接受边界时停止并重新判断范围、投入或 VP 对齐。

## 退出条件

只有在探索产出被 book_green 确认，并且结果仍落在 VP-002 的“包含故事线规划、足以进入下一创作阶段的大纲”终点内，GOAL-002 才能形成 P5 信息交接；否则记录缺口并回流 `/vision`。
