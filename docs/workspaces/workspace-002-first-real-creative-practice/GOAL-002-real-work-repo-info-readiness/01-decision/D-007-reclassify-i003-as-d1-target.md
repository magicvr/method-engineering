# D-007 · 将 I-003 重分类为 D1 探索目标

## 决策

GOAL-002 的 P4 不再被表述为“补齐一个既有的 Root required 信息项”，而是承载 VP-002 D1 的探索目标：从真实推进中逐步形成最低接受条件候选、对应作品证据、下一阶段候选及其进入条件。

原 `I-003` 编号保留为历史追踪标签，但不再作为 GOAL-002 P4 或 GOAL-003 P2 的前置信息门禁。P4 的退出仍需要候选边界、证据和 book_green 的判断；这属于探索目标的退出条件，而不是探索启动条件。

## 理由与范围

- VP-002 在起点没有现成的接受边界；要求先验证它会形成循环依赖。
- 该未知仍需被认真记录、限制投入并以真实证据推进，不能被删除或假定完成。
- 本次重分类只解除同一 D1 探索体系内的启动死锁，不改变 VP-002 的方向级终点、四周投入上限或后续接受责任。

## 后续

GOAL-002 继续执行 P4 探索；形成的结果交回 Root 进行 S1 退出判断。GOAL-003 可并行贡献其候选边界与方法分析，但不得把候选分析写成已验证的作品接受标准。
