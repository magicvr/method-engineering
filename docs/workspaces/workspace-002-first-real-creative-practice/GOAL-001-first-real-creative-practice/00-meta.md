# GOAL-001 · 支持首个真实作品完成故事线规划大纲

## 概述

本 Root 承接 [`VP-002-first-real-creative-practice`](../../../vision/plans/VP-002-first-real-creative-practice.md)，目标是在 book_green 这一已提交但仍在核对的真实作品仓中，从作品真实状态出发，按 VP-001 已建立的需求驱动运行机制，支持作品方完成并接受一份包含故事线规划、足以进入其下一创作阶段的有界大纲成果。

book_green 已提交首轮真实作品信息；GOAL-002 的 P2/P3 已完成，当前在 P4 承载 VP-002 D1 的创作接受边界探索中。原 I-003 不再作为一项必须先验证的 P-005 输入，而是该实践需要形成的探索目标；其候选边界、作品证据和 book_green 判断仍是 Root S1 退出与后续 VP-002 关门所需的结果，但不构成所有局部方法响应的统一门禁。维护者已接收一条关于“元规则”环节的需求信号并保持直属 `GOAL-003-outline-meta-rule-boundary-exploration` 为 `active`；该信号已澄清为「最小背景世界模型构造方法」，GOAL-003 P3 已形成可交付响应，尚未向 book_green 交付或发生真实使用。本 Root 不把作品仓自身的创作目标、方法运行记录和本仓 Goal 状态合并，也不把未知写成已经发生的作品事实。

## 成功标准

- [ ] 真实作品仓、当前版本与创作状态已确认；本次范围、排除项、固定终点、接受责任、实际责任边界和投入限额已通过 D1。
- [ ] 至少一条来自真实作品推进、已被接受的方法需求，按 VP-001 机制完成响应、验证、交付、实际使用与反馈闭环。
- [ ] 方法响应实际支持作品推进到包含故事线规划的大纲成果，而非只形成上游文档交付。
- [ ] 作品方已评阅并接受大纲，影响本次边界的反馈已完成修订或明确处置。
- [ ] 结项证据区分作品问题、方法问题与运行机制问题，并将结论限定于本作品、本大纲阶段和本次条件。

### D1 创作接受边界探索目标（原 I-003）

原 `I-003` 编号保留在历史决策、执行和审计记录中，但不再作为当前 P-005 信息项。其当前权威承载目标是 `GOAL-002-real-work-repo-info-readiness` 的 P4：在 VP-002 的真实实践中形成作品自身的最低接受条件候选、对应作品证据、下一阶段候选及进入条件。

该探索目标影响 Root S1 的退出和 VP-002 的后续验收，但不阻断 D1 探索本身，也不阻断已经足够具体的局部方法需求响应。GOAL-003 P3 已完成、P4 未开始，不要求 D1 先完成。只有探索产出形成并经 book_green 判断后，才可据此作 S1 退出或后续阶段放行判断。
