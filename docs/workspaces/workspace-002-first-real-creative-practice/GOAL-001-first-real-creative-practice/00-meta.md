# GOAL-001 · 支持首个真实作品完成故事线规划大纲

## 概述

本 Root 承接 [`VP-002-first-real-creative-practice`](../../../vision/plans/VP-002-first-real-creative-practice.md)，目标是在一个尚待确认的真实作品仓中，从作品真实状态出发，按 VP-001 已建立的需求驱动运行机制，支持作品方完成并接受一份包含故事线规划、足以进入其下一创作阶段的有界大纲成果。

真实作品仓尚未确定，因此本目标当前保持 `draft`。本 Root 不预先创建未来方法 Goal，不把作品仓自身的创作目标、方法运行记录和本仓 Goal 状态合并，也不把未知写成已经发生的作品事实。

## 成功标准

- [ ] 真实作品仓、当前版本与创作状态已确认；本次范围、排除项、固定终点、接受责任和投入限额已通过 D1。
- [ ] 至少一条来自真实作品推进、已被接受的方法需求，按 VP-001 机制完成响应、验证、交付、实际使用与反馈闭环。
- [ ] 方法响应实际支持作品推进到包含故事线规划的大纲成果，而非只形成上游文档交付。
- [ ] 作品方已评阅并接受大纲，影响本次边界的反馈已完成修订或明确处置。
- [ ] 结项证据区分作品问题、方法问题与运行机制问题，并将结论限定于本作品、本大纲阶段和本次条件。

## 纲领路线图（P-001）

| 阶段 | 名称 | 状态 | 退出条件 |
|------|------|------|----------|
| **S1** | 启动边界与信息就绪 | 未开始 | I-001～I-005 已有证据或合规决策；作品方、起点、范围、固定终点、接受条件、协作责任和投入限额明确；若作品方下一阶段不符合 VP-002 固定终点，则回流 `/vision` 修订 VP，不扩张「大纲」语义。 |
| **S2** | 真实需求驱动的方法响应与实际使用 | 未开始 | 至少一条真实、已接受的方法需求完成响应、验证、交付、实际使用和反馈处理；独立方法工程边界需要时再创建子目标。 |
| **S3** | 大纲接受与有界结项 | 未开始 | 作品方接受包含故事线规划的大纲，范围内承诺已处置，必要 Goal/runtime work item/信息项已完成或合法退出，形成 VP-002 关门核对证据。 |

阶段按 S1→S2→S3 串行；同一阶段内只有存在独立范围、依赖、交付证据或并行价值的真实需求才创建平铺子目标。
