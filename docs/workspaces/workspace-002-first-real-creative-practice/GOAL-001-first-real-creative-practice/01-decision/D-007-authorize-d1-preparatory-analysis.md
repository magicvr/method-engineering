# D-007 · 接受 VP-002 对 D1 有限前置方法分析的边界修订

## 决定

维护者选择通过 `/vision` 修订 VP-002，而不是把 GOAL-003 的 P2 工作退回草稿或缩减为纯问题描述。VP-002 已更新为 `0.3.0`：D1 可以对真实推进中暴露、且具有独立边界的方法问题进行有限前置方法分析。

该授权只覆盖问题/职责/边界分析、候选草案、实质取舍、最小操作链和后续证据设计。它不授权在 D1 内宣称最终方法、方法工程响应、真实试用、交付、实际使用或作品方接受，也不改变 VP-002 已冻结的方向级终点。

## 理由与影响

I-003 所指向的接受边界此前尚不存在；把它作为 GOAL-003 P2 的前置门禁会使“探索该边界”的目标无法开始。本决定保留 D1 的信息探索性质，同时允许在探索中产生必要的前置方法材料，使 GOAL-003 可以继续收敛而不越过 D2/S2 的真实响应边界。

因此 Root 进入 `active`、S1 标记为进行中；S1 仍须等待 D1 候选边界、作品证据和 book_green 判断后才能退出。GOAL-003 的 P2 可继续，P3 仍待 D1 边界确认并进入 D2/S2。

## 依据

- [`VP-002-first-real-creative-practice.md`](../../../../vision/plans/VP-002-first-real-creative-practice.md) v0.3.0 的「D1 内的有限前置方法分析」与方向级阶段结构。
- 用户对“将 I-003 从门禁改为 VP-002 要探索的目标，并允许方案 1”的明确裁决。
