# D-003 · 按 VP-002 重新对齐 I-003 的有界探索路径

- **日期**：2026-09-19
- **状态**：accepted
- **决策来源**：用户明确选择转入需经 `/vision` 重新对齐的有界探索，不要求作品仓强行虚构未知答案。

## 决定

1. 采用 VP-002 重新对齐后的 D1 路径：作品方无法在实践开始前合理给出最低接受条件或下一阶段时，可在 D1 内开展有界接受条件定义探索。
2. 探索只形成最低接受条件候选、对应作品证据、下一阶段候选及进入条件；候选不等于验收，只有 book_green 确认边界后 I-003 才能关闭。
3. 探索受 book_green 已确认的四周总投入上限约束，到期不自动延长；不自动扩展范围、不自动进入 S2 方法响应，也不改变 VP-002 的方向级终点。
4. 若四周内无法形成 book_green 可接受的边界，停止并重新判断范围、投入或 VP 对齐，不用猜测填补 I-003。

## 影响

- Root S1 仍未通过，但允许在 S1 内执行上述信息探索。
- GOAL-002 进入有界探索阶段；它不再向作品仓索取事先不存在的最终答案。
- Root 与 GOAL-002 均继续把 I-003 标为 `required/collecting`，不得将探索过程写成已验证的接受条件。
