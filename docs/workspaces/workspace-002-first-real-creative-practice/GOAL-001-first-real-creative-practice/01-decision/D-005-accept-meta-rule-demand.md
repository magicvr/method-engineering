# D-005 · 接受元规则环节需求并建立 draft 子目标

## 决策

维护者选择方案 A：接受 book_green 关于小说大纲构建中“元规则”环节的真实方法需求，并在 Root 下建立直属 `draft` 子目标 `GOAL-003-outline-meta-rule-boundary-exploration`。

## 范围

本次接受范围仅包括：澄清该环节的职责与问题边界，识别必要信息/假设/未知，比较有依据的候选方法，设计有限试用和证据观察，并列出由 book_green 决定的事项。该接受不冻结最终“元规则”，不要求固定模板或工具，不授权整套创作流程重设计。

## 阶段门禁

建立 `draft` 子目标不是 Root S1 通过，也不是 S2 方法响应授权。Root I-003 继续为 `required/collecting`；在其按治理要求解除前，GOAL-003 不得进入方法分析、实际试用或验证执行。四周投入上限、book_green 的最终接受责任和 VP-002 固定终点继续有效。

## 理由

提报已满足 D-004 三类最小信息，且具有独立的方法工程边界和可核对交付物。建立 draft 目标能够追踪真实需求，同时保持 Root 信息门禁和“候选不等于验证”的事实边界。
