# D-002 · 在 D1 探索中开放 P2 候选分析

## 决策

GOAL-003 从 `draft` 转为 `active`，开始 P2“候选边界与方法分析”。P2 的工作属于 VP-002 D1 探索的一部分，可以在接受边界尚未形成时进行；其产出是候选问题定义、职责边界、候选方法及后续试用设计，不是已经被 book_green 接受的方法响应。

原 Root I-003 不再作为 P2 的启动门禁。GOAL-003 仍须遵守四周投入上限、真实作品范围和后续 G-001 试用证据要求；P3 不能在没有可定位真实作品证据时宣称验证结论。

## 理由

如果当前问题本身是“如何形成可接受的大纲边界”，就不能要求该边界先存在才允许分析。先形成候选并明确反证条件，才能让 book_green 在真实实践中判断其是否有用。

## 未选方案

- 等待 I-003 先变成 verified 再开始 P2：会把本目标需要探索的对象错误地当作输入。
- 依据附件直接冻结“元规则”：附件只作为参考，不是权威，也不构成验证。

## 后续

先完成职责/边界和候选方法分析，再决定是否进入有界试用；所有候选保持暂定，直到真实作品证据和 book_green 判断出现。
