# D-003 · 提议具体判断驱动的局部设定规约

## 提案

GOAL-003 P2 暂以“具体判断驱动的局部设定规约”作为第一候选路径，暂不把它等同于最终“元规则”，也不假设它必须成为独立创作环节。

其最小操作链为：当前判断 → 相关设定及依据 → 缺失前提/冲突/推论分支 → 对当前判断的影响 → 暂定处理 → 停止与重开条件。

## 理由

该路径不要求 VP-002 在起点已经拥有完整世界或接受标准，能直接暴露“它帮助了哪一个判断、增加了多少成本、在哪里失效”。“参考框架与偏离描述”作为按需技术保留；“嵌入世界模型、不设独立环节”作为成本基线和合法退出路径。

## 状态与未决事项

本提案尚未被 book_green 接受，也没有真实作品试用证据。以下仍待验证：规约是否真的有用、是否值得独立表达、局部处理是否会漏掉跨场景影响，以及“元规则”称谓是否应保留。

## 复审条件

第一次真实试用后，若规约只复述已有判断、增加负担、导致无界推演、误把可能性当必然性，或妨碍有意保留的模糊性，应缩减、改名、嵌回世界模型或否定该候选。
