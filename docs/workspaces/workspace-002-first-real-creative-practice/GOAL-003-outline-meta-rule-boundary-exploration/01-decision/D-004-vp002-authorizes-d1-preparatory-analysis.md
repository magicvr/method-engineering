# D-004 · 按 VP-002 修订确认 D1 前置分析授权边界

## 决定

在维护者选择方案 1 后，VP-002 v0.3.0 明确：GOAL-003 可以在 D1 接受边界探索尚未完成时继续进行有限前置方法分析。P2 的工作稿可以包含问题、职责边界、候选路径、取舍、最小操作链和试用/证据设计。

## 不包含的授权

本决定不接受 [`D-003-propose-local-setting-judgment-protocol.md`](D-003-propose-local-setting-judgment-protocol.md) 中的候选方法为最终方法；也不授权 D1 内的真实试用、方法响应交付、实际使用、验证结论或 book_green 接受。P3 仍须等待 D1 边界确认并进入 D2/S2 的相应真实运行阶段。
