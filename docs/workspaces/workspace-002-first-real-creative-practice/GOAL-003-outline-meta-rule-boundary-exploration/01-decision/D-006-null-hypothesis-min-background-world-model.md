# D-006 · 采纳独立元规则层暂不成立的工作零假设，并先定义最小背景世界模型

## 决定

GOAL-003 的 P2 采纳如下工作零假设，并按此主导需求澄清。该零假设是可证伪的澄清策略，不是已验证结论，也不是 P3 方法定稿。

1. **独立元规则层暂不成立。** 不再要求 book_green 定义「元规则」。该称谓仅保留为历史工作标签（见 G-002），不作为必须先填的独立创作环节。
2. **先形成「最小背景世界模型」的工作定义。** 其充分性边界为：能够形成稳定世界默认状态，并支持作品序列进入主题选择。此处「主题选择」是 book_green 已提交序列中的下一格，不是本目标 P3，也不是 Root S2。
3. **再做残余职责分析。** 分类规则为：
   - 世界事实归世界模型；
   - 世界模型的继承、构造、推论、维护和停止规则，优先归其构造方法；
   - 只有无法由二者承载、却必须作为后续创作前置约束持续存在的职责，才建立独立元规则候选。
4. 工作定义与残余分析由 Method Engineering 根据已有创作事实、目标和限制完成；不把定义「元规则」、设计候选方法、比较路径或整理工程证据转交给作品仓。

工作定义与第一轮残余分析见 [`attachments/p2-minimum-background-world-model.md`](../attachments/p2-minimum-background-world-model.md)。

## 理由

继续向作品仓索要「元规则是什么」会把方法工程问题抛回需求方，等价于本目标失败。作品仓已给出的序列把「元规则」放在「世界模型（背景）」之前，但附件材料实际讨论的是如何从参考态得到可继承的世界默认，而不是一个已被界定的独立层。

从含义更清楚的下一格起步，用残余必要性检验独立层是否仍需要，可以在空仓筹备、尚无具体情节判断的条件下推进 G-001，而不提前构建猜测性方法。将继承/构造/推论/维护/停止优先归入世界模型构造方法，是为了避免把「如何得到世界」误写成必须单独立层的「元规则」。

本决定不改变 D-005 的澄清授权，不进入 P3，不冻结六步主线为线性流程，不替 book_green 作创作判断，也不声称独立元规则层已被证伪或方法已经交付。

## 未选方案

| 方案 | 未选理由 |
|------|----------|
| 继续要求 book_green 定义「元规则」 | 对方正因该空位向本仓提报；再抛回即职责倒置，且违反 D-005。 |
| 直接冻结「元规则 = 世界模型（背景层）」 | 过强。附件已区分构造协议与世界状态；同一关系应作为待检验假设，用残余分析判定，而不是先写成定义。 |
| 在 P2 直接构建完整世界观方法并转入 P3 | 违反 D-005：事实不足时不构建猜测性方法。本拍只形成足以做残余检验的工作定义。 |
| 以 D-003 的「先找一个真实创作判断」作为本拍主路径 | 当前作品为空仓筹备，序列停在进入主题选择之前，没有可用的具体情节判断；该路径可在后续出现真实判断时再启用，不能解开当前死锁。 |

## 影响

- G-001 的澄清问题改写为：最小背景世界模型如何构成、何时够用到可以进入主题选择，以及进入该格之前是否仍有无法由世界模型及其构造方法承载的独立元规则职责。
- G-002 不因本决定关闭；独立层按零假设暂不建立，称谓是否保留等到残余分析出现独立候选、或 P2 判断需求边界时再定。
- 既有 `meta-rule-preliminary-exploration.md` 与 `p2-candidate-boundary-analysis.md` 仍只作内部参考。其中「现实参考态 / 显式差异 / 有界传播」可被工作定义吸收为待检验构造线索，不升格为规则。

## 后续

1. 以工作定义为准完成进入主题选择前的残余职责分析（本拍同步形成）。
2. 若独立元规则候选仍为空，记录零假设未被证伪；再判断「最小背景世界模型及其构造方法」是否已构成可进入 P3 的有界方法需求。该判断另作决策，不由本条自动放行。
3. 若后续阶段出现既非世界事实、亦非构造方法、却必须作为前置约束持续存在的职责，再建立独立元规则候选，并复核本零假设。
