# D-007 · 确认有界方法需求、退出 P2、在本目标内进入 P3，暂不派生子目标

## 决定

1. **「最小背景世界模型及其构造方法」已构成可进入 P3 的有界方法需求。** GOAL-003 P2 退出。问题类型是方法/工具，不是创作对象问题，也不是运行机制问题。
2. **本拍不开启新的直属 GOAL-003 子目标，也不在 Root 下另建兄弟方法响应 Goal。** 本条已澄清需求的方法响应由 GOAL-003 自身的 P3/P4 承载。这是对本目标澄清例外的后续使用，不改变「未来新信号仍先澄清、方法响应另行建立」的一般规则。
3. **P3 在本目标内启动。** 工作定义仍不是交付方法；P3 必须把它操作化并做 Method Engineering 内部验证后，才形成可交付响应。P4（交付、正常使用、反馈）仍未开始。

### 有界需求陈述

为 book_green 当前空仓筹备状态、在作品序列进入主题选择之前，由 Method Engineering 研究、设计、构建并内部验证一份可交付方法：

- **对象**：最小背景世界模型（世界事实与默认状态）；
- **方法**：其构造方法，至少覆盖继承、构造、推论、维护、停止；
- **充分性**：形成稳定世界默认状态，并支持进入主题选择；
- **非目标**：独立元规则层、完整世界观栏目模板、前景细化、主题选定、叙事窗口、故事线、普遍创作方法体系；不要求 book_green 定义「元规则」或设计、比较该方法。

### P3 阶段计划

| 步骤 | 工作 | 退出 |
|------|------|------|
| P3.1 | 将 P2 工作定义操作化为可执行构造步骤与最小记录形态 | 有一份 Method Engineering 可据以执行的步骤和记录形态；仍标明待检验处 |
| P3.2 | 内部验证：用有界例子或纸面走查，检验能否达到充分性边界、停止规则是否可执行 | 记录帮助、成本、失效方式；不把内部验证写成作品仓使用或接受 |
| P3.3 | 形成可交付响应 | 交付物边界清楚，可进入 P4；未交付前不把方法写成已使用 |

P3 三步顺序执行；不因本决定预先拆成子目标。若实施中出现独立范围、并行价值或单独审计门禁，再另作决策决定是否派生。

## 理由

P2 已具备进入方法响应所需的最小界定：

| 界定项 | 当前内容 |
|--------|----------|
| 创作情境 | 空仓筹备；作品序列在进入主题选择前需要稳定背景默认 |
| 可核查问题 | 如何构造并维护最小背景世界模型，使其达到充分性边界 |
| 目标 | 稳定世界默认，并支持进入主题选择 |
| 限制 | 独立元规则层暂不成立；不写完整世界；不冻结六步为线性流程；不把方法工程任务转交作品仓 |
| 残余 | 进入主题选择前的独立元规则候选为空；零假设未被证伪 |

参考切片粒度、必要后果与可能后果的操作化，属于 P3 要把工作定义做成可执行方法时解决的设计问题，不是继续停在 P2 的理由。

暂不派生子目标，是因为当前 P3 是**单一、顺序、最小**的方法切片：操作化 → 内部验证 → 形成交付。它没有独立并行的第二产物，也不需要与本目标澄清记录分开的第二套五件套。P-001 禁止为形式完整而机械拆目标。GOAL-003 路线图已为这条需求预留 P3/P4；把同一需求再建成子目标或 Root 兄弟目标，会把澄清与响应拆成两套状态，却不增加可验证边界。

## 未选方案

| 方案 | 未选理由 |
|------|----------|
| 事实仍不足，继续留在 P2 | 情境、问题、目标、限制已齐。再留在 P2 会把本应在 P3 完成的操作化伪装成需求澄清。 |
| 新开直属 GOAL-003 的方法响应子目标 | 当前无独立范围、并行交付或单独审计必要；为 P3 再套一套五件套是机械拆分。若后续出现上述条件，可再开。 |
| 在 Root 下新开兄弟方法响应 Goal | 同一已澄清需求会被拆成两个 Root 直属节点，澄清台账与方法响应脱节。VP-002「在工作区 Root 下创建方法响应 Goal」的一般规则，由本目标作为该需求载体、进入自身 P3 来满足。 |
| 把 `p2-minimum-background-world-model.md` 直接当作 P3 交付 | 该文件是澄清用工作定义，尚未操作化，也无内部验证。 |

## 影响

- G-001 在本决定下 `verified`：P2 所需的最小界定已形成，P3 启动门禁解除。
- G-002 仍为 non-blocking / open：P3 交付对象不使用「元规则」作为独立层名；历史称谓是否保留不影响 P3 启动。
- 新增 G-003：P3 退出所需的操作化步骤、最小记录形态与内部验证结论，由 Method Engineering 在 P3 收集，不向 book_green 索取方法设计。
- 本目标由「仅澄清」进入「本条需求的方法响应」；不表示 Root S1 退出，不表示 P4 已开始，也不表示方法已被作品使用或接受。
- 独立元规则层零假设仍成立；P3 若发现无法由世界模型及其构造方法承载的持续前置约束，须回流残余分析，不得在 P3 静默恢复独立层。

## 后续
