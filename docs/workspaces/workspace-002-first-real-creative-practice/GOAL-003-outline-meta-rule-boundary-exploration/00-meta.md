# GOAL-003 · 界定小说大纲构建中的元规则环节

## 概述

本目标承接 book_green 已提交并经维护者选择 A 接受的真实方法需求。需求聚焦于当前大纲构建探索主线中的“元规则”工作性称谓：需要澄清该环节可能解决的问题、承担的职责、与世界模型/主题/叙事窗口/故事线的边界，以及如何通过有限试用判断候选方法是否有用。

本目标不把“元规则”写成已确认的最终概念，不替 book_green 选择最终方法，不把当前六步主线冻结为线性流程，也不扩展为整套创作流程重设计。目标现为 `active`，P2 在 VP-002 D1 接受边界探索中开始；VP-002 v0.3.0 已明确允许这类有限前置方法分析，但不等于 Root S1 已退出，也不等于 D2/S2 方法响应、真实试用或作品验收已获授权。

## 成功标准（暂定）

- [ ] 形成一份职责、问题范围、边界和相邻环节区分的分析，并明确“元规则”称谓是否仍然适用。
- [ ] 登记影响候选设计与试用的必要信息、关键假设和未决问题，不把假设写成已验证事实。
- [ ] 形成有依据的候选方法或候选定义及实质取舍；不为形式凑出弱方案，也不宣称已有方案普遍有效。
- [ ] 形成有界试用建议，明确所需真实作品证据、观察现象、修订/缩减/否定条件。
- [ ] 将仍需由 book_green 决定的事项单独列出，并由其对候选边界、试用结果和继续方向作出判断。

## 纲领路线图（P-001）

| 阶段 | 名称 | 状态 | 退出条件 |
|------|------|------|----------|

| **P2** | 候选边界与方法分析 | 进行中 | 在 D1 接受边界探索尚未完成时，完成职责/边界分析、必要信息登记、候选方法及取舍；不得把候选分析写成 book_green 已接受的作品标准或 S2 方法响应。 |
| **P3** | 有界试用与证据收集 | 未开始 | 在 D1 边界确认并进入 D2/S2 后，book_green 使用候选内容处理至少一个可定位的真实大纲片段或创作判断，并记录可观察证据及结果分类。 |

阶段按 P1→P2→P3→P4 串行。P2 已在 D1 探索范围内开放；P3 的真实试用和验证仍需要可定位的真实作品证据、明确的有界试用范围及相应参与判断。四周投入上限、book_green 的接受责任和 Root S1 的退出条件继续有效，但不把尚未形成的 D1 目标当作 P2 的前置输入。

### 与 D1 探索目标的关系

Root 原 `I-003` 已重分类为 VP-002 D1 的探索目标，由 `GOAL-002-real-work-repo-info-readiness` 的 P4 承载。GOAL-003 的 P2 是该探索目标允许吸收的一项独立方法分析，不替代 GOAL-002，也不要求 D1 目标先完成。

## 父目标与门禁关系

- 父目标：`GOAL-001-first-real-creative-practice`。
- 本目标是 Root 下的直属需求目标，现已进入 `active`；它不改变 Root S1 状态，不把 D1 探索目标写成已完成，也不替代 GOAL-002 的 P4/P5 交接。
- 本目标的 P2 候选分析可以在 D1 探索目标未完成时开始；实际试用、验证和作品接受仍须满足各自证据与参与条件。若四周投入上限内无法形成可接受边界，按 VP-002 记录停止或回流 `/vision`。

## 审计模式

当前按 `self` 规划后续阶段审视：范围可逆，且本目标不修改治理协议、生产发布或安全门禁。若后续候选方法影响范围扩大、出现证据冲突或维护者要求第二视角，再单独按治理要求决定是否引入 independent/cross。

## 台账布局

本目标使用平铺的 `01-decision/`、`02-execution/`、`03-audit/` 和 `attachments/`。新增决定、事实和正式审计意见分别写入对应 ledger 目录；当前已记录 P2 工作稿和 D1 前置分析授权，但没有把候选方法定稿、D2 方法响应、真实试用、验证或 book_green 接受写成已发生事实。
