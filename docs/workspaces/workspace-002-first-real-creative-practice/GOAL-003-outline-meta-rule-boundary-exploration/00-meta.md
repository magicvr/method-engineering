# GOAL-003 · 界定小说大纲构建中的元规则环节

## 概述

本目标承接 book_green 已提交并经维护者选择 A 接受的真实方法需求。需求聚焦于当前大纲构建探索主线中的“元规则”工作性称谓：需要澄清该环节可能解决的问题、承担的职责、与世界模型/主题/叙事窗口/故事线的边界，以及如何通过有限试用判断候选方法是否有用。

本目标不把“元规则”写成已确认的最终概念，不替 book_green 选择最终方法，不把当前六步主线冻结为线性流程，也不扩展为整套创作流程重设计。目标当前为 `draft`；建立目标不等于 Root S1 已退出，也不授权立即开始 S2 方法响应。

## 成功标准（暂定）

- [ ] 形成一份职责、问题范围、边界和相邻环节区分的分析，并明确“元规则”称谓是否仍然适用。
- [ ] 登记影响候选设计与试用的必要信息、关键假设和未决问题，不把假设写成已验证事实。
- [ ] 形成有依据的候选方法或候选定义及实质取舍；不为形式凑出弱方案，也不宣称已有方案普遍有效。
- [ ] 形成有界试用建议，明确所需真实作品证据、观察现象、修订/缩减/否定条件。
- [ ] 将仍需由 book_green 决定的事项单独列出，并由其对候选边界、试用结果和继续方向作出判断。

## 父目标与门禁关系

- 父目标：`GOAL-001-first-real-creative-practice`。
- 本目标是 Root 下的直属需求目标，但当前只建立 `draft` 目标结构；它不改变 Root S1 状态、不关闭 Root I-003，也不替代 GOAL-002 的 P4/P5 信息就绪交接。
- 本目标的实际方法响应、试用和验证必须在 Root I-003/S1 门禁按治理要求解除后开始；若四周投入上限内无法形成可接受边界，按 VP-002 记录停止或回流 `/vision`。

## 审计模式

当前按 `self` 规划后续阶段审视：范围可逆，且本目标不修改治理协议、生产发布或安全门禁。若后续候选方法影响范围扩大、出现证据冲突或维护者要求第二视角，再单独按治理要求决定是否引入 independent/cross。

## 台账布局

本目标使用平铺的 `01-decision/`、`02-execution/`、`03-audit/` 和 `attachments/`。新增决定、事实和正式审计意见分别写入对应 ledger 目录；当前没有把方法分析、试用或验证写成已发生事实。
