# P2 工作定义 · 最小背景世界模型与残余职责分析

> 本文是 GOAL-003 P2 的澄清产物，依据 [`D-006-null-hypothesis-min-background-world-model.md`](../01-decision/D-006-null-hypothesis-min-background-world-model.md)。
> 它是 Method Engineering 的工作定义与第一轮残余分析，不是冻结方法、不是 P3 交付、不是 book_green 的创作决定。
> 文中「主题选择」指作品仓已提交序列中「世界模型（背景）」的下一格，不是本目标 P3，也不是 Root S2。

## 1. 工作零假设

**独立元规则层暂不成立。**

P2 不再把「先定义元规则」当作进入后续工作的前提，也不再要求 book_green 回答「元规则是什么」。零假设可被后续残余分析或真实创作前置约束证伪；未被证伪前，不建立独立元规则层。

## 2. 最小背景世界模型 · 工作定义

### 2.1 对象

最小背景世界模型是作品序列中「世界模型（背景）」这一格的最小可用形态。它保存当前故事尚未按主题细化之前的**世界事实**与**默认状态**，供后续主题选择、前景细化、叙事窗口和故事线作为已成立的世界约束来使用。

它不是主题、前景世界模型、叙事窗口或故事线，也不因历史上被放在「元规则」之后或之前而自动获得独立元规则层的地位。

### 2.2 充分性边界（停止条件）

当且仅当同时满足下列两项，即视为达到最小可用，并停止继续扩展背景层：

1. **稳定世界默认状态**：对当前作品将会涉及、但尚未逐条声明的事实，参与者能够依据同一组默认作出不互相冲突的判断；已知冲突已被标记或处理到不影响主题选择；未知被保留为未知，不伪装成已定事实。
2. **足以进入主题选择**：创作者能够基于该默认世界，判断作品要观察、讨论或呈现什么。不要求主题已经选定，不要求前景已经细化。

未达到上述边界时，继续补的是参考切片、显式差异或有界推论，而不是新开一个名为「元规则」的层。

达到边界后不再要求：完整地理 / 历史 / 政治 / 种族等字段模板、按主题展开的前景细节、无界社会推演、全世界模拟，或规定读者何时获知某项事实。

### 2.3 内容：世界事实

背景世界模型只保存世界事实，至少包括：

| 内容 | 含义 | 当前最小取用 |
|------|------|----------------|
| 现实参考切片 | 足以使未声明事实获得稳定默认判断的一组现实上下文 | 按当前作品实际需要取用时代、地域、技术、制度等；不预先固定字段清单 |
| 显式差异 | 相对参考切片必须声明的偏离 | 只登记会改变默认判断的部分 |
| 当前默认世界状态 | 继承与有界推论之后、主题细化之前仍然成立的世界事实 | 未被覆盖的部分默认继承参考切片；未知保持未知 |

这些内容归世界模型。它们回答「在这个世界里什么成立」，不回答「如何得到这些事实」或「故事怎样让读者看见它们」。

### 2.4 构造方法：继承、构造、推论、维护、停止

下列规则优先归**背景世界模型的构造方法**，不单独立为元规则层：

| 类 | 最小工作含义 |
|----|----------------|
| 继承 | 未被显式差异覆盖的部分，默认继承参考切片；不把常识逐条写成设定。 |
| 构造 | 如何选择参考切片、登记显式差异、形成当前默认世界状态；只收集对充分性边界有贡献的信息。 |
| 推论 | 区分必要后果与可能后果；不把惯例、类型偏好或概率写成必然；推论结果若成为世界事实，写入世界模型，而不是另建规则层。 |
| 维护 | 新增或修改设定时如何覆盖默认、暴露冲突、保留未知；主题、叙事需要或情节方便不得直接篡改已成立的世界事实。若必须改世界，走世界模型修订，而不是用后一层覆盖前一层。 |
| 停止 | 达到 §2.2 即停止扩展；记录重开条件（例如新的显式差异、原默认被证伪、主题选择暴露背景不足）。 |

附件 [`meta-rule-preliminary-exploration.md`](meta-rule-preliminary-exploration.md) 中的「现实参考态 / 显式差异 / 有界闭包」可作为上述构造方法的待检验线索，尤其可用于继承、构造与推论。它们不是本工作定义的必要公式，也尚未被真实创作试用证实。

### 2.5 本定义明确不包含

- 规定所有小说必须填写的世界观栏目；
- 生成情节、选定主题、安排故事线；
- 管理角色已知事实或读者已知事实；
- 把本文件当作已验证方法或要求 book_green 按此填写完整世界。

## 3. 进入主题选择前的残余职责分析

分析材料：D-006 分类规则、§2 工作定义、book_green 范围序列，以及 `meta-rule-preliminary-exploration.md` 中被当作「元规则候选职责」的条目。分析范围仅限**进入主题选择之前**。不把附件中的 xxx 阶段索引解释为本仓目标治理阶段。

### 3.1 分类

| 候选职责或原则 | 归宿 | 理由 |
|----------------|------|------|
| 世界模型从哪里继承默认事实 | 构造方法 · 继承 | 是如何得到默认状态，不是独立于世界的前置约束。 |
| 哪些事实必须作为差异被显式声明 | 构造方法 · 构造 | 决定写入世界模型的内容边界。 |
| 差异如何覆盖已有默认事实 | 构造方法 · 构造 / 维护 | 覆盖规则服务于世界状态的形成与修订。 |
| 差异产生的必要后果是否已被处理 | 构造方法 · 推论 | 推论产物仍是世界事实；停止深度由充分性边界约束。 |
| 世界模型何时拥有足够信息以支持下一步创作 | 构造方法 · 停止 | 「下一步」在本范围中即主题选择；已写入 §2.2。 |
| 锚定原则、最小差异原则、一致性传播原则 | 构造方法 | 三条都是如何从参考态得到当前默认世界，不是另类对象。 |
| 世界事实 ≠ 角色已知 ≠ 读者已知 | 与叙事窗口的接口 | 后两项不属于背景世界模型，也不构成进入主题选择前的独立规则层。 |
| 主题不得直接篡改世界事实 | 构造方法 · 维护，以及与主题的接口 | 维护的是世界模型已成立事实，不需要独立元规则层来保存。 |
| 剧情必须服从已成立的世界约束 | 与故事线的接口 | 发生在更后的序列格；当前前置约束就是世界模型本身。 |
| 必须按地理 / 历史 / 政治等栏目填完整世界 | 不采用 | 与最小充分性冲突；那是内容模板，不是本拍所需对象。 |
| 参与者必须共享同一组未声明事实的默认 | 世界模型（内容） | 这正是背景世界模型存在的理由，不是它之上的另一层。 |
| 允许有意保留荒诞、寓言或模糊，不强制闭包 | 构造方法 · 停止 / 推论 | 属于何时不把可能性写成必然、何时停止传播。 |

### 3.2 第一轮结论

在进入主题选择之前，**未发现**无法由「世界事实 ∪ 世界模型构造方法」承载、却必须作为后续创作前置约束持续存在的职责。

因此：

- 独立元规则候选清单当前为空；
- 工作零假设「独立元规则层暂不成立」**未被证伪**；
- 「元规则」在本阶段不作为必须先完成的独立环节；
- 原需求信号在 P2 中被澄清为：需要一份足以进入主题选择的最小背景世界模型，以及得到它的构造方法。

本结论只覆盖进入主题选择前。若主题选择、前景细化、叙事窗口或故事线阶段出现新的、既非世界事实亦非构造方法的持续前置约束，应重开残余分析，而不是把本轮空清单外推为「永远不需要元规则」。

### 3.3 仍待确认（不阻断本轮工作定义）

- 参考切片在空仓筹备状态下要细到什么粒度，才能使默认判断对参与者稳定——待后续有真实作品上下文时检验，不在本拍向 book_green 索取「元规则」定义。
- 「必要后果」与「可能后果」的操作化边界，以及停止规则会不会在真实判断中失效——属构造方法的后续检验，不是独立层是否存在的前提。
- 「最小背景世界模型及其构造方法」是否已经构成可进入 P3 的有界方法需求——由后续决策判断，本文不自动放行。

## 4. 与相邻对象的接口（仅澄清，不重设计六步）

| 对象 | 本工作定义如何交接 |
|------|----------------------|
| 主题 | 背景世界模型提供可选择主题的默认世界；主题决定随后重点观察哪些世界部分，但不改写已成立事实。 |
| 世界模型（前景） | 主题选定后，只细化与主题相关的世界部分；前景不得另建第二套与背景冲突的事实。 |
| 叙事窗口 | 使用世界事实，但决定谁在何时知道什么、读者何时获知。 |
| 故事线 | 在已成立世界约束内安排事件；需要改世界时回流修订世界模型。 |

这些接口不恢复独立元规则层。book_green 的六步序列仍只是作品范围陈述，不因本文被冻结为必须线性执行的流水线。
