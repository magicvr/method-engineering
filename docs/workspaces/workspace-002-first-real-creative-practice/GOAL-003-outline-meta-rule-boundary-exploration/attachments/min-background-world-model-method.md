# 最小背景世界模型构造方法

> 这是 GOAL-003 P3.3 的**可交付响应**（v1.1.1，响应 A-008 recommended）。供作品仓在正常创作中使用：进入主题选择前，形成一份最小背景世界默认。
> 它还没有被作品仓使用，也不是普遍有效证明。使用后请只反馈实际现象、影响和预期；不必设计或比较方法。
> 「主题选择」指作品序列里「世界模型（背景）」的下一格。
> **不要**另建「元规则」层。本方法就是背景世界模型的构造与维护办法。
> v1.1.0 及更早版本不再作为使用文本。

内部操作稿与走查仍分别见 [`p3-1-min-background-world-model-procedure.md`](p3-1-min-background-world-model-procedure.md)、[`p3-2-bounded-walkthrough.md`](p3-2-bounded-walkthrough.md)。使用以**本文**为准。

## 1. 做什么、不做什么

一次构造产出**一份**背景世界模型记录。

构造**过程中**允许状态为 `collecting`。一次构造**结束**时，合法终态只有两种：

| 终态 | 含义 |
|------|------|
| `sufficient-for-theme-selection` | 已形成稳定默认，可以开始下一步主题选择，停止扩展 |
| `not-yet-sufficient` | 还不能开始主题选择；记下缺的是参考切片、显式差异，还是推不出且会阻塞主题选择的未知。然后停。不要编造世界事实，不要新开一层 |

**做：** 给未声明事实一个可共享的默认；只写会改变该默认的偏离；必要且必须写明的推论才显式化。

**不做：** 选定主题、细化前景、安排谁何时知道什么、生成情节；填写地理/历史/政治/种族/经济/魔法体系等栏目表；把「选主题需要知道」写成世界事实。

### 显式记录与模型语义

**显式记录**（文本载体）记为：

$$
\text{显式记录} = R + D + W
$$

（外加 P、U、C 作为纪律栏目，不是第三套世界事实。）

**模型语义**不只等于写下来的那几行。经 D 覆盖后的 R 默认，以及由继承规则成立、即使未写入 W 的事实，仍然属于世界模型。W 只是其中为维持共享解释而必须显式写出的必要推论。没写进 W，不等于「不属于这个世界」。

- **R**：参考切片。未声明事实从哪里继承默认。
- **D**：当前工作世界模型明确采用的、相对于 R 的偏离。分两种身份，不得混称：
  - **已确认 D**：作者确认成立的世界事实；
  - **暂定 D**：当前工作默认，尚未获作者确认。**严禁**把暂定 D 说成已成立世界事实。
- **W**：需要写明的必要推论。不是全部世界事实。未被 D 覆盖的部分继承 R，**不抄进 W**。W 的确定性不得高于它所依据的 D：依据含暂定 D 时，该 W 只是暂定必要推论。

另外只记录：**P** 可能（不是事实）、**U** 未知、**C** 冲突。

## 2. 先选记录形态

**短记录**（D 为空时必须用这个，不要填空表）：

```text
# 最小背景世界模型（短记录）
- 作品 / 范围：
- 本遍目的：进入主题选择前的背景默认
- 过程状态：collecting（可选）
- 终态：not-yet-sufficient | sufficient-for-theme-selection
- R 参考切片：（一句）
- D：无
- Q1 当前所需共享默认是否稳定：yes / no。一句。
- Q2 是否已足以开始主题选择、无需先补新的背景世界事实：yes / no。一句。
- 重开条件：
```

若 R 也写不出，不要硬用短记录充作充分。把「R 尚未定位」写入 U（可在短记录下加一行 U），终态为 `not-yet-sufficient`。

**全记录**（有 D 时用）：

```text
# 最小背景世界模型
- 作品 / 范围：
- 本遍目的：进入主题选择前的背景默认
- 过程状态：collecting（构造未结束时）
- 终态：not-yet-sufficient | sufficient-for-theme-selection（构造结束时必填其一）

## R 参考切片
- 定位陈述：
- 写入原因：（若省略，哪个默认会翻）
- 本遍刻意未展开的相关维度（如有）：（不是完整性清单，不要据此补栏目）

## 继承规则
未被 D 覆盖的部分，默认继承 R。常识不写入 W。未写入 W 的继承事实仍属于世界模型。

## D 显式差异
| id | 陈述 | 覆盖 R 的哪条默认 | 身份（已确认 / 暂定） |
|----|------|-------------------|------------------------|
|    |      |                   |                        |

## W 需要写明的必要推论
（不是全部世界事实。显式记录 = R + D + W。D 不重复写入 W。）
| id | 陈述 | 依据（D-id 或 D-id 集合） | 确定性（确认 / 随暂定 D-n） |
|----|------|---------------------------|------------------------------|
|    |      |                           |                              |

## P 可能后果（不是世界事实）
| id | 陈述 | 为何不是必然 |
|----|------|--------------|
|    |      |              |

## U 未知
| id | 问题 | 为何本遍不决定 | 是否使主题选择实质分叉且无法在未知下开始 |
|----|------|----------------|------------------------------------------|
|    |      |                |                                          |

## C 冲突
| id | 双方 | 状态（open / resolved） | 处理 |
|----|------|-------------------------|------|
|    |      |                         |      |

## 充分性核对
- Q1：yes / no。一句。
- Q2：yes / no。一句。

## 停止与重开
- 终态：
- 重开条件：
```

## 3. 步骤

按顺序做。D 为空则第 5 步整步跳过。出现冲突时先做第 6 步。

### 第 1 步 · 框定本遍

写下作品/范围，并写明：本遍只为进入主题选择前的背景默认。

不要：另建「元规则」节；写完整世界；把「作品以后可能涉及的一切」列入本遍。

### 第 2 步 · 定位 R

问：如果不再多写设定，未声明事实应继承哪一段现实（或已声明的参考世界）？

只写拿掉就会让大默认翻掉的维度（时代、地域、技术、制度等按需要取用）。不要为写全而补栏目。

空仓允许很粗，例如：「未特别声明则继承当代地球常识。」

检查：另一个人只看这句 R，会不会把大默认放到互相冲突的时代/世界类型上。会，就收紧 R，或把分歧记入 U/C。

### 第 3 步 · 登记 D

只登记当前工作模型明确采用的、会改变 R 默认的偏离。每条必须标明身份：**已确认**或**暂定**。没有偏离：D=无，改用短记录，跳到第 4、7 步。

暂定 D：

- 是当前工作默认，不是已成立世界事实；
- 必须能在记录中被看见（身份栏为「暂定」）；
- 由其推出的 W 只能标「随暂定 D-n」，不得升格为已确认事实。

### 第 4 步 · 继承

确认规则：未被 D 覆盖的部分继承 R。不要把「人要吃饭、建筑有门」写入 W。这些仍是世界模型里的事实，只是不必显式抄写。

### 第 5 步 · 有界推论（两道门）

对每条 D，或对产生某个直接后果所需的**最小 D 集合** \(D^*\)，列出 \(R + D^*\) 的一阶候选句子。对每个候选 x：**先推论，再决定写不写进 W**。

**推论门：** \(R + D^* \models x\) 是否成立？
承认 R 与该 \(D^*\) 的同时，若能合理否认 x 而不与 \(D^*\) 矛盾，就是推不出。
只推直接后果。类型惯例、概率、叙事方便、主题偏好，不能单独证明推出。

**深度限制：** 严格禁止拿已经写入的 W 再去推出下一条 W。有界靠的是「不递归用 W」，不是「每次只许一条 D」。联合前提是合法的；用 W 滚雪球不合法。

推不出时：

- 本遍已经问到，且该未知的不同答案会使主题选择空间**实质分叉**，并且不知道答案就**无法开始**主题选择 → 写入 **U**，禁止写入 W，且第 7 步 **Q2 必须为 no**。去向只能是：补 D（或最小 D 集合），或缩小本遍已暴露范围。缩小范围只有在被移出的事项对缩小后的主题选择确实不再构成前置背景问题时才合法；不得仅为使 Q2 通过而删除已经暴露的阻塞项。**禁止**用「书面声明暂不决定仍进入」把 Q2 改成 yes。
- 本遍已经问到，但主题选择对该未知**不敏感**（不知道答案仍能开始主题选择） → 写入 **U**（deferred）。这依据的是「客观上不阻塞」，不是执行者有豁免权。
- 否则记 **P**，或不记。

**物化门（仅当已推出）：** 若不把 x 写进 W，本遍已暴露、且不同解释会改变主题选择判断的默认会不会不稳？

- 会 → 写入 W，依据填写 D-id 或 D-id 集合。\(D^*\) 中若有暂定 D，确定性标「随暂定 D-n」。
- 不会 → 不写 W（推出了，但本遍不必显式化；它仍属于模型语义）。

推完该 \(D^*\) 的直接必然后果就停。不要为「社会还会怎样」展开。

**禁止：** 因为选主题需要一个答案，就把推不出的句子写入 W。

### 第 6 步 · 覆盖与冲突

**覆盖不是冲突。** D 对其**声明覆盖**的那条 R 默认进行替换，这正是 D 的职责，**不写入 C**。

只有下列情形才登记为 C：

- D 与 R 中**未被该 D 声明覆盖**的前提不能同时成立；
- D 与另一条 D、D 与 W、或 W 与 W 出现不可同时成立的陈述。

C 的处理只能是：改 R、改 D、撤回 W，或保持 open。
open 且影响 Q1/Q2 时，本遍不能标 `sufficient-for-theme-selection`。
禁止用主题、叙事或情节直接改已成立或已确认的事实。修订暂定 D 时，所有依据它的 W 一并改暂定、撤回或重推。

### 第 7 步 · 两问停止

只评估**截至本遍已经暴露**的背景问题。不保证作品以后会涉及的一切。

**Q1** 当前所需共享默认是否稳定：对这些已暴露、且不同解释足以改变主题选择判断的问题，依据 R + 继承 + D + W 能否得到不互相冲突的默认？未决定事项是否仍在 U，没有被当成事实？暂定 D 是否仍标明暂定、没有被洗成已确认事实？

**Q2** 当前共享默认是否已经足以让下一步主题选择**开始**，而无需先补充新的背景世界事实？
不要求已经选定主题，也不要求判断作品要观察、讨论或呈现什么。

若存在这样的 U：其不同答案会使主题选择实质分叉，且不知道答案就无法开始主题选择，则 **Q2 = no**。不允许用书面豁免改写这一判定。
仅当主题选择对该 U 不敏感时，才可在 U 未决的情况下让 Q2 = yes。

| Q1 | Q2 | 终态 |
|----|----|------|
| yes | yes | `sufficient-for-theme-selection`。停止。写下重开条件。 |
| 任一 no | | `not-yet-sufficient`。只处理导致不充分的 R、D、C 或阻塞性 U；必要时补充/修订 R、D 或最小 D 集合，解决冲突，或把推不出且阻塞主题选择的项保持在 U。不得把 U 改成 W。 |

重开条件至少预写：

- 出现**属于当前范围、且可能改变已有共享默认或主题选择能否开始**的新 D（局部前景设定若不动已有默认、也不迫使主题选择重新开始，不自动重开）；
- R 被证伪；
- 主题选择暴露必须先补的背景世界事实。

## 4. 已知边界（使用前请读）

- Method Engineering 内部用两例纸面走查过：当代现实且 D=无可以通过；「极少数人自然寿命约 3000 年」可以把「非通例」写入 W，把「公开或隐藏」留在 U。v1.1.0 收紧了：若「公开或隐藏」会使主题选择实质分叉且无法在未知下开始，则 Q2 必须为 no，不能靠书面暂缓通过。
- 这**不**证明在真实作品里有用、负担可接受，或应当成为所有小说的步骤。
- 失效方式：把想到的社会后果都当成「已暴露」；用「选主题需要答案」写 W；把粗 R 理解成要填全地球；把暂定 D 当成已确认事实；把合法覆盖当成冲突；用已有 W 递归推 W。

## 5. 使用后如何反馈

在正常创作中用这份方法即可。请反馈：

- 实际发生了什么（做了哪一遍、停在哪种终态）；
- 对当前判断的影响（有帮助 / 过重 / 误导 / 无差别）；
- 预期是否达到。

不必提交候选方法、验收方案或根因诊断。
