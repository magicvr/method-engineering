# P3.1 · 最小背景世界模型构造步骤与最小记录形态

> 依据 [`D-008-p3-1-operationalize-procedure.md`](../01-decision/D-008-p3-1-operationalize-procedure.md)。
> 本文是 Method Engineering 可据以执行的操作稿，不是 P3.2 内部验证结论，不是 P3.3 交付，不是作品仓使用或接受证据。
> 「主题选择」指作品仓序列中「世界模型（背景）」的下一格，不是本目标 P3。
> 独立元规则层按工作零假设暂不成立；执行中不得新开该层。

工作定义仍以 [`p2-minimum-background-world-model.md`](p2-minimum-background-world-model.md) 为准。本文只把它写成动作、判断和记录位置。

## 0. 一次构造在做什么

一次构造产出**一份**最小背景世界模型记录，使参与者共享同一组世界默认，并足以进入主题选择。

输入可以很少，包括空仓。输出有两种合法结果：

- `sufficient-for-theme-selection`：两问停止条件都满足，停止扩展；
- `not-yet-sufficient`：还不能进入主题选择；记录缺的是 R、D 还是必要推论，然后停止本遍，不发明独立层。

不要产出：主题、前景细节、叙事窗口、故事线、完整世界观栏目表、「元规则」文档。

## 1. 记录形态（先建表，再填）

只维护下列栏目。没有内容的栏目写「无」，不要删掉类型。

```text
# 最小背景世界模型
- 作品 / 范围：
- 本遍目的：进入主题选择前的背景默认
- 状态：collecting | not-yet-sufficient | sufficient-for-theme-selection

## R 参考切片
- 定位陈述：（一句：未声明事实从哪里继承默认）
- 写入本切片的原因：（若省略，哪个默认会翻）
- 未写入的维度：（明确「不在本遍取用」）

## 继承规则（常驻，不枚举）
未被 D 覆盖的部分，默认继承 R。常识不写入 W。

## D 显式差异
| id | 陈述 | 覆盖 R 的哪条默认 | 来源（作者设定 / 既有笔记 / 暂定假设） |
|----|------|-------------------|----------------------------------------|
|    |      |                   |                                        |

## W 已成立世界事实
| id | 陈述 | 来源（D / inferred-necessary） | 依据 |
|----|------|--------------------------------|------|
|    |      |                                |      |

## P 可能后果（不是世界事实）
| id | 陈述 | 为何不是必然 |
|----|------|--------------|
|    |      |              |

## U 未知
| id | 问题 | 为何本遍不决定 |
|----|------|----------------|
|    |      |                |

## C 冲突
| id | 双方 | 状态（open / resolved） | 处理 |
|----|------|-------------------------|------|
|    |      |                         |      |

## 充分性核对
- Q1 稳定共享默认：yes / no。一句证据或缺口。
- Q2 足以进入主题选择：yes / no。一句证据或缺口。

## 停止与重开
- 本遍结果：
- 重开条件：
```

约束：

- W **不**抄继承常识。继承只写在「继承规则」。
- D 条目不要重复写进 W，除非该差异还推出了额外的必要事实。
- P 不得在后续步骤被当成已成立事实使用。
- 来源是「暂定假设」的 D，必须能在 C 或 U 中被看见；不得写成已验证世界事实。

## 2. 可执行步骤

按顺序做。每步只写本步要求的栏目。出现冲突时先做第 6 步，再决定是回到第 3、第 4 还是第 5 步。

### 第 1 步 · 框定本遍

写下作品/范围，以及「本遍只为进入主题选择」。

禁止：另建「元规则」节；把本遍写成写完整世界。

### 第 2 步 · 定位参考切片 R

问一句：

> 如果不再多写设定，未声明的世界事实应该继承哪一段现实（或已声明的参考世界）？

只写入会改变默认判断的定位。启发式：若拿掉某维度后，参与者会选到互相冲突的时代 / 地域 / 技术 / 制度默认，才写入该维度。不要为「写全」而补地理、历史、种族、经济栏目。

空仓允许很粗的 R，例如「未特别声明则继承当代地球常识」。若连这一句都无法写，把「R 尚未定位」记入 U，状态定为 `not-yet-sufficient`，结束本遍。

检查：另一个参与者只看 R，会不会对未声明事实选出冲突的大默认。会，就收紧 R 或把分歧记入 U/C；不会，进入第 3 步。

### 第 3 步 · 登记显式差异 D

只登记会改变 R 默认的偏离。每条写清：陈述、覆盖哪条默认、来源。

没有偏离则 D 表填「无」，进入第 4 步。这是合法最小形态。

来源是暂定假设的，同时在 U 留一条「该差异尚未从作者设定确认」。

### 第 4 步 · 应用继承

在记录里确认常驻规则已写上。不要把继承结果逐条抄进 W。

若某条常识即将被 D 覆盖，应出现在 D，而不是先写入 W 再删。

### 第 5 步 · 有界推论

对**每一条** D 问：

> 承认这条 D、其余仍继承 R 时，还有哪些句子必须为真，参与者才能共享默认，并且作者能进入主题选择？

把候选句子分成三类，**先分类再写入**：

| 分类 | 写入 | 判定 |
|------|------|------|
| 必要 | W，来源 `inferred-necessary` | 承认 D 同时否认该句，会与 D 直接矛盾；或使主题选择所依赖的默认无法共享。 |
| 可能 | P | 承认或否认都不破 D；只是常见、有趣、或类型上更可能。 |
| 未知 | U | 此刻无法判断，且本遍不必判断。 |

操作化测试（待 P3.2 检验）：

1. **反例测试**：能否在承认 D 的同时，合理否认该句？能，则不是必要。
2. **共享测试**：两个参与者对该句一正一反，是否仍能对「主题选择要靠的默认」达成一致？能，则不是必要。
3. **一阶限制**：只推 D+R 的直接后果。若必须经过另一条未判定句子，先给那条分类；中间任何一条是 P 或 U，末端不得写入 W。
4. **禁例**：类型惯例、概率、叙事方便、主题偏好，不能单独把句子升格为必要。

推完一条 D 的直接必要后果后即停，不要为「社会还会怎样」继续展开。被停掉的有趣分支写入 P 或 U。

### 第 6 步 · 冲突与维护

检查新写入的 D/W 是否与已有 R/D/W 冲突。

- 有冲突：写入 C。处理只能是修订 R、修订 D、撤回该条 W，或把冲突保持为 `open`。
- `open` 且影响 Q1/Q2：本遍不能标 `sufficient-for-theme-selection`。
- 禁止：用主题、叙事窗口或情节需要直接改写已成立事实。必须改世界时，回到第 2～5 步修订记录。

### 第 7 步 · 充分性两问（停止）

两问都必须回答，并写一句证据或缺口：

**Q1 · 稳定共享默认**
对当前作品将会涉及、但未逐条声明的事实，参与者能否依据 R + 继承规则 + D + W，作出不互相冲突的默认判断？已知且影响主题选择的冲突是否已处理或标为 open？未知是否仍标为未知？

**Q2 · 足以进入主题选择**
作者能否基于这份默认世界，判断作品要观察、讨论或呈现什么？不要求主题已选定，不要求前景已写。

判定：

| Q1 | Q2 | 本遍状态 | 下一步 |
|----|----|----------|--------|
| yes | yes | `sufficient-for-theme-selection` | 停止扩展。写下重开条件。 |
| 任一为 no | | `not-yet-sufficient` | 只回到第 2、3 或 5 步，补 R、D 或必要推论。不新开层，不填栏目表。 |

重开条件至少预写三类：出现新的 D；R 被证伪；主题选择暴露背景不足。

## 3. 本方法明确不做

- 选定主题、细化前景、安排谁在何时知道什么、生成情节；
- 要求填写地理 / 历史 / 政治 / 种族 / 经济 / 魔法体系等固定栏目；
- 把 P 或 U 写成 W；
- 把内部走查当成作品仓已使用或已接受；
- 向作品仓索取「元规则」定义或方法设计。

## 4. 仍待 P3.2 检验

- 空仓下 R 粗到什么程度，Q1 仍能成立。
- 第 5 步四条测试是否能把「必要 / 可能」分开，且不会无界展开。
- 两问停止是否会过早停（默认其实不共享）或过晚停（开始写前景）。
- 这份记录形态会不会比直接在设定旁写几句更有帮助；若只增加负担，应缩减栏目，而不是加层。
