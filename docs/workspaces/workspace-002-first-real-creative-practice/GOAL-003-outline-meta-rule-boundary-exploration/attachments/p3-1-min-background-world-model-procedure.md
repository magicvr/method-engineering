# P3.1 · 最小背景世界模型构造步骤与最小记录形态

> 依据 [`D-008-p3-1-operationalize-procedure.md`](../01-decision/D-008-p3-1-operationalize-procedure.md)，并经 [`D-009-respond-a002-p3-1-procedure.md`](../01-decision/D-009-respond-a002-p3-1-procedure.md) 修订第 5 步与第 7 步。
> 本文是 Method Engineering 可据以执行的操作稿，不是 P3.2 内部验证结论，不是 P3.3 交付，不是作品仓使用或接受证据。
> 「主题选择」指作品仓序列中「世界模型（背景）」的下一格，不是本目标 P3。
> 独立元规则层按工作零假设暂不成立；执行中不得新开该层。

工作定义仍以 [`p2-minimum-background-world-model.md`](p2-minimum-background-world-model.md) 为准。本文只把它写成动作、判断和记录位置。

当前工作世界模型为：

$$
\text{背景世界模型} \approx R + D + W
$$

其中 $D$ 覆盖 $R$ 的偏离；$W$ 只承载**由 $R+D$ 必然推出、且本遍需要显式物化**的推论。未覆盖部分继承 $R$，不写入 $W$。

## 0. 一次构造在做什么

一次构造产出**一份**最小背景世界模型记录，使参与者对**本遍已经暴露、且其不同解释足以改变主题选择判断**的背景问题共享默认，并足以进入主题选择。

输入可以很少，包括空仓。输出有两种合法结果：

- `sufficient-for-theme-selection`：两问停止条件都满足，停止扩展；
- `not-yet-sufficient`：还不能进入主题选择；记录缺的是 R、D，还是本遍已暴露、无法由 $R+D$ 推出、因而留在 U 的事项。然后停止本遍，不发明独立层，也不把下游「需要知道」写成世界事实。

不要产出：主题、前景细节、叙事窗口、故事线、完整世界观栏目表、「元规则」文档。

## 1. 记录形态（先建表，再填）

只维护下列栏目。没有内容的栏目写「无」，不要删掉类型。

```text
# 最小背景世界模型
- 作品 / 范围：
- 本遍目的：进入主题选择前的背景默认
- 状态：collecting | not-yet-sufficient | sufficient-for-theme-selection

## R 参考切片
- 定位陈述：（一句：未声明事实从哪里继承默认）
- 写入本切片的原因：（若省略，哪个默认会翻）
- 未写入的维度：（明确「不在本遍取用」）

## 继承规则（常驻，不枚举）
未被 D 覆盖的部分，默认继承 R。常识不写入 W。

## D 显式差异
| id | 陈述 | 覆盖 R 的哪条默认 | 来源（作者设定 / 既有笔记 / 暂定假设） |
|----|------|-------------------|----------------------------------------|
|    |      |                   |                                        |

## W 显式物化的必要推论
（不是全部世界事实。当前工作世界模型 = R + D 覆盖 + W。D 本身同样是已成立世界事实，不重复登记于 W。）
| id | 陈述 | 来源 | 依据（D-id） | 确定性 |
|----|------|------|--------------|--------|
|    |      | inferred-necessary | D-n | 确认 / 随暂定 D-n |

## P 可能后果（不是世界事实）
| id | 陈述 | 为何不是必然 |
|----|------|--------------|
|    |      |              |

## U 未知
| id | 问题 | 为何本遍不决定 | 是否足以改变主题选择判断 |
|----|------|----------------|--------------------------|
|    |      |                |                          |

## C 冲突
| id | 双方 | 状态（open / resolved） | 处理 |
|----|------|-------------------------|------|
|    |      |                         |      |

## 充分性核对
- Q1 当前所需共享默认是否稳定：yes / no。一句证据或缺口。
- Q2 足以进入主题选择：yes / no。一句证据或缺口。

## 停止与重开
- 本遍结果：
- 重开条件：
```

约束：

- W **不是**全部世界事实集合，只是本遍需要显式物化的必要推论。
- D 本身属于当前工作世界模型，**不**重复写进 W。
- 继承常识不抄进 W。
- P 不得在后续步骤被当成已成立事实使用。
- 写入 W 必须同时满足第 5 步的**推论条件**与**物化条件**。
- W 的确定性不得高于其依据中的 D。依据含「暂定假设」的 D 时，该 W 只能标「随暂定 D-n」，不得当作作者已确认事实。
- 来源是暂定假设的 D，必须能在 U 中被看见；不得写成已验证世界事实。
- 对主题选择很重要、但无法由 $R+D$ 必然推出的事项，一律进 U，禁止写入 W。

## 2. 可执行步骤

按顺序做。每步只写本步要求的栏目。出现冲突时先做第 6 步，再决定是回到第 3、第 4 还是第 5 步。

### 第 1 步 · 框定本遍

写下作品/范围，以及「本遍只为进入主题选择」。

禁止：另建「元规则」节；把本遍写成写完整世界；把「作品以后可能涉及的一切」列入本遍范围。

### 第 2 步 · 定位参考切片 R

问一句：

> 如果不再多写设定，未声明的世界事实应该继承哪一段现实（或已声明的参考世界）？

只写入会改变默认判断的定位。启发式：若拿掉某维度后，参与者会选到互相冲突的时代 / 地域 / 技术 / 制度默认，才写入该维度。不要为「写全」而补地理、历史、种族、经济栏目。

空仓允许很粗的 R，例如「未特别声明则继承当代地球常识」。若连这一句都无法写，把「R 尚未定位」记入 U，状态定为 `not-yet-sufficient`，结束本遍。

检查：另一个参与者只看 R，会不会对**本遍定位所依赖的大默认**选出冲突答案。会，就收紧 R 或把分歧记入 U/C；不会，进入第 3 步。

### 第 3 步 · 登记显式差异 D

只登记会改变 R 默认的偏离。每条写清：陈述、覆盖哪条默认、来源。

没有偏离则 D 表填「无」，进入第 4 步。这是合法最小形态。

来源是暂定假设的，同时在 U 留一条「该差异尚未从作者设定确认」，并在该 D 的来源栏标明暂定。

### 第 4 步 · 应用继承

在记录里确认常驻规则已写上。不要把继承结果逐条抄进 W。

若某条常识即将被 D 覆盖，应出现在 D，而不是先写入 W 再删。

### 第 5 步 · 有界推论（两道门）

对**每一条** D，只列出 $R+D$ 的一阶候选句子。对每个候选 $x$，**先过推论门，再过物化门**。不得用「主题选择需要知道」代替推论。

#### 5.1 推论条件（真值）

问：$R + D \models x$ 是否成立？

| 测试 | 用法 |
|------|------|
| 反例测试 | 承认 $R$ 与该条 $D$ 的同时，能否合理否认 $x$ 而不与 $D$ 矛盾？能，则推不出。 |
| 一阶限制 | 只推 $D+R$ 的直接后果。若必须经过另一条未判定句子，先给那条分类；中间任何一条是 P 或 U，末端不得视为推出。 |
| 禁例 | 类型惯例、概率、叙事方便、主题偏好，不能单独证明推出。 |

推不出时：

- 若该事项**本遍已经暴露**，且其不同解释足以改变主题选择判断 → 写入 U，**禁止写入 W**。这通常使 Q2 为 no，直到作者增加新 D，或明确「暂不决定仍进入主题选择」。
- 否则写入 P（常见/有趣但非必然），或不记录。

#### 5.2 物化条件（是否写入 W）

仅当推论条件已成立时，才问：若不把 $x$ 显式写入 W，本遍已经暴露、且其不同解释足以改变主题选择判断的共享默认是否会不稳定？

- 是 → 写入 W，来源 `inferred-necessary`，依据引用 D-id。若该 D 为暂定假设，确定性标「随暂定 D-n」。
- 否 → 不写入 W。它已被 $R+D$ 推出，但本遍不必物化。

#### 5.3 分类表

| 分类 | 写入 | 判定 |
|------|------|------|
| 必要且须物化 | W | 推论条件成立，且物化条件成立 |
| 推出但不物化 | 不写 W | 推论条件成立，隐式默认已够 |
| 可能 | P | 承认或否认都不破 D |
| 未知 | U | 推不出，或此刻无法判断；重要但推不出的必须在此 |

推完一条 D 的直接必然后果后即停，不要为「社会还会怎样」继续展开。

**禁止**：因为下游工作流需要共享答案，就把未由 $R+D$ 推出的句子写入 W。

### 第 6 步 · 冲突与维护

检查新写入的 D/W 是否与已有 R/D/W 冲突。

- 有冲突：写入 C。处理只能是修订 R、修订 D、撤回该条 W，或把冲突保持为 `open`。
- `open` 且影响 Q1/Q2：本遍不能标 `sufficient-for-theme-selection`。
- 禁止：用主题、叙事窗口或情节需要直接改写已成立事实。必须改世界时，回到第 2～5 步修订记录。
- 修订或撤回一条暂定 D 时，所有依据该 D 的 W 一并改为暂定、撤回或重推。

### 第 7 步 · 充分性两问（停止）

两问都必须回答，并写一句证据或缺口。评估范围限于**截至本遍已经暴露**的背景问题，不保证「作品以后将会涉及的一切」。

**Q1 · 当前所需共享默认是否稳定**
对截至本遍已经暴露、且其不同解释足以改变主题选择判断的背景问题，参与者能否依据 R + 继承规则 + D + W 作出不互相冲突的默认判断？未决定事项是否仍明确留在 U，而没有被偷偷当成事实？

**Q2 · 足以进入主题选择**
作者能否基于这份默认世界，判断作品要观察、讨论或呈现什么？不要求主题已选定，不要求前景已写。若 U 中存在本遍已暴露、且必须先有共享默认才能选主题的事项，而作者又未明确「暂不决定仍进入主题选择」，则 Q2 为 no。

判定：

| Q1 | Q2 | 本遍状态 | 下一步 |
|----|----|----------|--------|
| yes | yes | `sufficient-for-theme-selection` | 停止扩展。写下重开条件。 |
| 任一为 no | | `not-yet-sufficient` | 只回到第 2、3 或 5 步，补 R、D，或把推不出的重要事项留在 U。不把 U 改写成 W，不新开层，不填栏目表。 |

重开条件至少预写三类：出现新的 D；R 被证伪；主题选择暴露背景不足。

## 3. 本方法明确不做

- 选定主题、细化前景、安排谁在何时知道什么、生成情节；
- 要求填写地理 / 历史 / 政治 / 种族 / 经济 / 魔法体系等固定栏目；
- 把 P 或 U 写成 W；
- 用「主题选择需要知道」替作者创造世界事实；
- 把内部走查当成作品仓已使用或已接受；
- 向作品仓索取「元规则」定义或方法设计。

## 4. 仍待 P3.2 检验

- 空仓下 R 粗到什么程度，收敛后的 Q1 仍能成立。
- 第 5 步两道门是否能分开「推出且物化 / 推出但不物化 / 重要但推不出而入 U」，且不会无界展开。
- 两问停止是否会过早停或过晚停；Q1 是否仍被执行成「未来作品可能涉及的一切」。
- 暂定 D 派生的 W 是否被误当成已确认事实。
- 这份记录形态会不会比直接在设定旁写几句更有帮助；若只增加负担，应缩减栏目，而不是加层。
