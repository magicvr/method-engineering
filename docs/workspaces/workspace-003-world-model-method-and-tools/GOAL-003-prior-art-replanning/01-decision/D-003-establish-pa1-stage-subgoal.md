# D-003 · 建立 PA1 阶段子目标

## 决定

按 P-001 渐进拆分原则，建立 [GOAL-004-pa1-baseline-and-source-plan](../GOAL-004-pa1-baseline-and-source-plan/00-meta.md) 作为本目标的第一个阶段子目标，只承载 PA1：需求/H 基线固定、约束迁移矩阵、五类来源/访问方案、资源与停止规则，以及 Root I-007 的阶段退出证据。

## 理由

PA1 已启动但仍有独立证据与概率性用户裁决点。将它从 PA2～PA5 中隔离，可避免把来源识别误写为理论吸收，并使访问权限、费用或范围扩张在合适治理节点由用户裁决。后续 PA2～PA5 暂不预建，待 PA1 完成后按实际结果渐进立项。

## 边界

GOAL-003 继续持有 PA1～PA5 纲领路线图和 Root 门禁引用；GOAL-004 只执行 PA1。PA1 完成并由阶段审计确认后，先把 GOAL-004 置 done，再由 GOAL-003 决定是否进入 PA2。GOAL-004 不关闭 I-008～I-010，不形成理论适用性、缺口或 R2-W 路线结论。

## 被拒替代

- 不拆子目标、继续在 GOAL-003 混写：会使阶段证据与后续映射混杂，增加错写风险和上下文污染。
- 一次性建立 PA1～PA5 全部子目标：后续范围依赖 PA1 结果，违反渐进拆分。
