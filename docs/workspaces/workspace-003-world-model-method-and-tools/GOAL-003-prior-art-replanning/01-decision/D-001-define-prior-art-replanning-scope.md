# D-001 · prior-art 调查与路线重规划范围

依据用户 2026-10-04 书面任务包及 [Root D-021](../../GOAL-001-world-model-method-and-tools/01-decision/D-021-prior-art-driven-implementation-reframe.md)，建立本目标承接 R2-PA。旧 H 路线不再是前置。

## Scope / 非目标

只调查、吸收、映射必要需求、判断缺口并交接后续方法路线；不建立普遍世界理论、不完成旧预登记/运行 H、不形成最终工作版或工具/交付。本目标通过 Root 服务既定 VP 意图，不修改上层边界。PA1～PA5 纲领与完成检查点唯一写在 [meta](../00-meta.md)。

## 来源与比较方法（待 PA1 固定）

从已冻结需求 §10/§13、R1 通用契约与旧 H 局部主张开始，先核实原始来源/版本/定位再抽取要素；记录前提、输入/输出、适用限制、差异/反例与证据链，逐项比较而不是比较整理论“总优劣”。来源登记五类线索为待核实检索入口，不是选定理论或充分综述。本轮本地需求原文快照已提取；历史提交级一致性仍待核对。

## 证据等级与处置

1. 经核实的原始来源/版本/定位支持“理论内容是什么”；不自动支持“适合本需求”。
2. 直接有界实践/验证支持相应适用范围；不得从局部结果外推普遍有效。
3. 用户需求/裁决支持必要性和授权边界，不证明理论有效性。
4. 二手解释仅作线索或辅助交叉检查；AI 建议、候选书目及未核实材料只作 unverified，不能关闭门禁。

- **inherit**：来源与适用依据已核对，保留要素语义，无需实质改变而纳入。
- **adapt**：保留可追溯来源，显式记录有限改造、理由、差异风险及验证安排。
- **not-applicable**：有已核实的范围/前提与必要需求不匹配依据；不是声称理论错误或不存在。
- **unresolved**：来源、解释、适用性或比较证据尚不足；不得作吸收已验证或缺口已确证。

分类对象是要素或局部主张，不给整理论贴总标签；同一理论的不同要素可以分别处置。

## 门禁、停止与原创闸门

Root I-007～I-010 唯一权威，分别约束 PA1/PA2-PA3/PA3/PA5、R2-W 或原创启动。未核实来源、证据矛盾、到期 required/开放必改、超授权/预算时暂停受影响阶段，登记并回流调查或用户裁决；不自动扩容，不把 unresolved 改成 not-applicable。

只有缺口对应必要需求、调查边界和替代检查有记录、区分“尚未查明”与“已发现适用限制”、继承/有限改造不足、原创范围和停止条件明确、相关信息/审计/授权门禁满足时，才可进入原创探索。禁止把“没搜到”写成“理论不存在”。

沿用 R1 v0.6.4 的需求边界、创作者主责与 AI 可选协助、输入来源/版本/用途/权限核对、观察/推断/假设/建议/裁定分离、可手填结构与逐项映射退出契约、条件工具策略及停止/变更机制。R1 完成只证明协议冻结，不证明 H1/H2/H3 或任何理论适用。原 9 格/180 人分钟仅约束旧 H 可行性工作，不自动挪作 prior-art 调查额度；新增执行授权/预算由 I-007 核对，不自动扩容。

本次不选具体理论、不核实候选书目、不授权新试验/付费/API。拒绝先补完旧 H 预登记、未调查就原创、删史/伪造完成等替代；详细理由沿 Root D-021。
