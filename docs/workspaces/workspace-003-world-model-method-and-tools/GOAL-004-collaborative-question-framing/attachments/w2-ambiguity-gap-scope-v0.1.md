# W2 模糊真实问题的协作定界缺口与范围

用户将“世界有多大”明确为实际创作问题。方法须主动协助定界、查资料和参考、分析并拆解，回答子问题后综合回应原问题；拆解深度由具体创作需要约束，避免无限细化。

现有输入基线为 [W2 v0.4](../../GOAL-002-r2-method-working-version/attachments/world-model-method-working-version-v0.4.md)。第 2 章步①由真实客观需求进入步②能力发现；第 3 章已假设可描述的客观问题、状态、参数和精度；第 6 章提供现实参考适用边界；第 8 章五步用于现有能力、状态、组合、精度与新能力缺口。这些规则可继续支撑后续回答，但尚未提供从模糊问题共同定界、收敛到最小充分问题集、再综合回答原问题的操作过程。

W3 的“世界有多大”试填在 G01 停住，见 [E-004](../../GOAL-003-w3-minimal-structures/02-execution/E-004-w3-s2-sample-at-g01.md)。用户纠正说明，先要求创作者自行给齐对象与量纲暴露了方法缺口。两份结构的 S1 草案仍保留，S2 等待 W2 修订和影响检查；结构级预核不能代替创作者逐字段可填性核对。

本目标交付协作定界过程的真实探针证据、W2 有界修订及 W3 交接。验收意图是能够回答实际创作需要，并说明问题集为何足够及何时停止细化；具体判据待共同确定。父级原 W4 判据保持原状；不扩展为通用知识体系，不替创作者决定世界设定。

尚未确定：具体创作场景、答案服务的剧情/设计判断、资料来源、所需精度及充分性判断方式。登记 I-401；共同定界本身属于工作内容，不能把未知包装成已回答或输入失败。v0.4 / A-008 是历史基线，本次不否认当时闭审结果，不产生正式 required audit finding。
