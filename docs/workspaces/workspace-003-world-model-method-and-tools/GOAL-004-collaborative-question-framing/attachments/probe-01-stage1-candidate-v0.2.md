# 探针一 · 创作判断与客观问题结构候选 v0.2

**仅为本次测试输入产生的中间案例结果，不是通用方法结构；尚未由创作者确认；不含答案或世界模型，也尚未达到 W2 可交接状态。** 原始输入为“世界有多大”。创作者确认：问题真实、每个世界观都必须回答、剧情中必须得到解答。创作者纠正：可能需要支持的剧情判断可以并存；当前判断候选非穷尽，应先分析关系，不应强迫 OR。

## 参考如何帮助发现解释维度

- Oshan 等人的空间尺度综述区分地理范围、观测/测量分辨率与过程尺度，并指出不同领域和任务对尺度有多种用法。这支持先区分“客观空间外延”“观察/表达精度”和“某过程的有效范围”，但不表示三者都必须进入本案例问题集。[论文](https://link.springer.com/article/10.1007/s10109-022-00384-8)
- Piatti 等人讨论虚构世界的地理表达，说明故事空间可处于现实可识别空间到完全想象空间的不同位置，地图只是处理叙事空间的一种方式。这支持将客观空间与故事涉及/呈现的空间分开考虑，不要求本案例必须制图。[论文](https://doi.org/10.1179/174327711X13190991350051)
- Weber 等人的叙事地图综述指出，setting 涉及地点、社会语境及空间叙事尺度；跨空间和时间的故事有时需要多尺度表达。这支持保留多项可并存的创作判断，而不是把“大小”压为单一指标。[论文](https://doi.org/10.1080/00087041.2019.1633103)

这些资料帮助生成或挑战假设；它们不决定创作者意图，不是该虚构世界的事实，也不证明以下候选穷尽。

## 创作者层：可能的用途与目标判断

| 编号 | 暂定候选 | 与其他候选的关系 | 状态 |
|------|----------|--------------------|------|
| C-01 | 保持故事涉及的地点、区域或群体范围与设定一致 | 可与 C-02 并存；可能限定 C-02 所需检查的空间域 | 可能的创作判断，未确认 |
| C-02 | 判断具体情节行动、事件或影响是否能在相关空间范围内成立 | 可能依赖 C-01 的范围；也可能反向要求调整故事覆盖范围 | 可能的创作判断，未提供具体情节实例 |
| C-03 | 判断角色/读者对空间的所知、可达或呈现范围是否支撑情节 | 仅当情节依赖空间知识、地图、可达性或信息差时才需要；不等于客观世界外延 | 条件候选 |
| C-04 | 其他由实际情节用途引出的目标判断 | 可补充、合并、拆分或删除 | 开放，当前未枚举 |

C-01 与 C-02 不互斥。当前可提出“故事覆盖范围为情节可行性提供适用域/约束”，以及“情节所需的行动或影响范围可能反向要求更大的叙事覆盖”两条关系假设。C-03 与前两项也可能并存，但仅在创作者的剧情用途需要时才进入。本表中的创作判断不是 W2 的客观问题节点。

## 阶段一工作与可能的客观 W2 问题

以下先区分待完成的阶段一工作和可能交给 W2 的客观问题；它们不是一一对应，尚须根据具体剧情用途压缩：

| 编号 | 内容 | 归属 / 当前状态 |
|------|------|-----------------|
| A-01 | 在创作上下文中澄清“世界”所指的对象/空间，以及“多大”可能针对的外延、故事覆盖或过程范围 | 阶段一语义与用途澄清；不是 W2 求解节点 |
| A-02 | 确认哪些创作判断真实需要世界事实支持，并识别对它们有用的情节、约束或示例 | 阶段一协作工作；创作选择本身不交给 W2 |
| A-03 | 按需查找可以限制解释范围的资料或反例，区分外部参考与本世界既定事实 | 阶段一研究动作；不是 W2 求解节点 |
| Q-01 | 根据创作者明确的“世界”指涉与精度约束，回答该客观对象的空间外延/尺度 | 可能的客观 W2 问题；含义与尺度尚未明，不可直接求解 |
| Q-02 | 对创作者指定的情节相关过程，回答其客观作用范围、可达范围或跨空间关系 | 可能的客观 W2 问题；须先从实际剧情判断识别过程，不能预设成固定目录 |
| Q-03 | 若情节判断依赖角色掌握的空间信息或实际可达范围，回答相关客观信息状态 | 条件性 W2 问题；仅按用途加入 |

答案精度是 Q-01～Q-03 的约束，需按要支持的创作判断确定，不预设为独立世界事实问题。支持关系和 W2 节点间的求解依赖分开表示：一个事实答案可以支持多项创作判断，但不因此与其他问题构成先后依赖。

## 暂定关系结构

```text
创作者层（判断 / 用途）
  C-01 故事空间覆盖 ──限定适用域──┐
       ▲                           │
       └──可能受情节范围要求影响── C-02 情节可行性
  C-03 角色/读者空间知识（仅按用途启用）
  C-04 其他用途（开放）

阶段一需先完成的澄清与研究（A-01～A-03）不作为 W2 节点

W2 客观问题候选（待语义与剧情上下文明确）
  Q-01 世界对象的空间外延 ──约束──┐
       ▲                            │
       └────情节所需范围可能回推── Q-02 相关过程的空间作用范围
  Q-03 角色空间知识/可达状态（条件性）
  精度需求横向约束 Q-01～Q-03

支持关系：Q-01 / Q-02 / 条件性 Q-03 ──支持但不代替──> C-01 / C-02 / C-03
```

这里的箭头只表达待验证的约束、迭代或支持假设，不表示所有关系已证实。Q-01 与 Q-02 可并存并可能联合处理；是否包含、前置、派生或冲突，须看创作者定义的“世界”及具体情节用途。当前没有证据表明候选间有不可并存的冲突，因此不请求 OR 裁决。

## 当前边界与继续分析所需上下文

第一轮方法试跑错误地把 C-01/C-02 包装为二选一；用户指出它们可能同时成立。v0.1 的候选还把“澄清”“创作范围选择”“精度要求”和客观事实问题混成同质 Q 节点，因此不能作为 W2 输入。以上 v0.2 将两层分开，但仍只是中间结构。

现在还没有一个具体剧情判断/场景作为用途证据，也未确认“世界”的指涉及所需精度。助手可以基于现有上下文继续提供候选，创作者可指出一个实际剧情时刻或补充/改写/删除判断；无需自行拆题。等这些用途信息形成后，再用充分性反例和必要性删除检查 Q-01/Q-02 是否已足够，以及是否还需要其他客观问题。

截至 v0.2：没有回答任何 Q 节点，没有确定世界边界、度量、数值或机制，没有生成 W2 模型；没有宣称候选穷尽、经确认或最小充分。
