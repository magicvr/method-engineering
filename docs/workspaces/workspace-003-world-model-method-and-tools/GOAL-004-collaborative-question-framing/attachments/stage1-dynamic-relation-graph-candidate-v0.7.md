# 阶段一动态问题关系图方法候选 v0.7

**draft / candidate / unaccepted；尚无经检验通过的方法证据，未交接 W2。** 本版按创作者对 v0.6.0 第一例隔离试跑的判定修订（[D-009](../01-decision/D-009-analysis-first-and-non-checklist.md) / [E-016](../02-execution/E-016-v06-run-failed-analysis-first.md)）：该次运行（[运行 01](probe-01-stage1-test-v0.6-run-01.md)）**未通过**，失败机制为 **premature elicitation**——识别出语义开放性后未继续有界的候选解释、比较与结构发现，而是把定界任务交回创作者；另有八类操作被近似逐项打卡的观察。v0.6.1、v0.5 与既有探针记录保留为历史，不构成本版的验证证据；任何案例节点、关系或结论均不提升为通用结构。

## 方法对象与工作表示

阶段一从创作者的原问和现有上下文出发，逐步辨认需要回答什么、为什么需要回答、哪些内容相互依赖以及哪里仍不确定。动态问题关系图是协助思考的工作表示：随理解变化而增删、改写、合并或撤销，服务于形成**足以启动阶段二求解的候选结构，交创作者确认**。它不保证问题一定可解，也不表示答案或模型已经存在。

**原问通常是不完整的**：歧义、未定指称与未定参数是阶段一的常规输入，不是异常，也不自动构成回问信号。阶段一的工作正是对这种模糊输入做有界的解释、比较与结构发现。

节点可以暂时承载需要支持的判断、待答问题、约束、必要未知等；关系可以表达依赖、支持、派生、约束、共享前置或冲突等。这些只是开放例子，不预定世界问题分类，不封闭节点或边的类型。遇到现有称呼无法表达的内容，先保留原意和理由，允许换一种表述。图无需覆盖全部上下文，也无需连成一个整体；原问及其整体意图始终保留在图外作为参照。简单问题允许不建图、不拆分。

这里的图不规定数据库、schema、存储格式或 UI。文字也可以表达关系；是否显式画图取决于它能否帮助当前理解，而非方法的必经门槛。

## 歧义处理：先分析、后回问

对**合理可分析的歧义**（含义开放、指称未定、参数未给值、用途未说明等），默认动作如下，且**先做完再谈回问**：

1. **建立候选解释集**：主动提出若干有理由的解释候选，标明来源——创作者已述 / 上下文可推 / 分析者推断；不因没有唯一解释而不提。
2. **并列比较**：比较各解释对「所求是什么、答案形式与精度、下一步需要什么结构」的实际差别，形成差异清单；差异要落到具体关系或所求上，不停留在措辞。
3. **并存推进**：多个解释默认可暂时并存，不因尚未选定唯一含义而停止；在能并存的范围内继续结构发现，把差异记在对应内容或关系上。
4. **未定参数变量化**：某参数未定但不阻塞推理时，把它作为变量（符号、参数、条件项）保留在结构里继续推理，并记录关键取值下的结构差异；**不得转为等待创作者给定值后才继续**。
5. **先自查能否自行缩小**：能靠现有上下文、分析或资料查找缩小的差异，先做；只有确认为创作者取舍的差异才进入回问候选。发现需要研究只表示有收集或核验工作，不记作已获得证据。

**回问条件（三条同时成立才回问创作者）**：

- ① 剩余差异**不能由分析消除**（不是资料未查、不是尚未分析、不是尚未尝试并存或变量化）；
- ② 该差异**确实改变回答要求或所求结构**（只影响措辞或呈现顺序的不算）；
- ③ 差异属于**创作者取舍**（创作意图、叙事用途、可接受精度与边界），而非客观待答内容。

任一条件不成立 → 不回问：继续分析，或把差异变量化保留并标明其影响。客观事实争议不因无法分析就转为回问，应按研究缺口保留。

**明确禁止**：

- 不得把「请创作者定义某个词」当作推进方式；发现歧义只说明需要继续分析。
- 不得以「发现了一个可以问用户的问题」作为阶段一分析已够用的理由。
- 不得把定界工作整体退回创作者。
- 确实需要回问时：一并给出已完成的分析结论、最小可纠正的具体选项，并说明该差异会怎样改变结构；不用空白问卷，也不要求创作者先自行拆题。

## 可反复调用的认知操作

表中操作是当前开放、非穷尽的工作候选，没有必经顺序。助手根据当前困难选择、组合、重复或撤销操作；发现新关系可以回到原问，覆盖挑战可以引发合并或剪枝。

| 操作 | 助手如何作用于当前理解与关系结构 |
|------|----------------------------------|
| 发现 | 从原问、上下文及其出处中辨认尚未表达清楚的判断、问题、条件或未知，提出有理由且非穷尽的候选；标明哪些来自创作者，哪些只是分析者推断。既能新增，也能纠正已有内容。 |
| 并列解释与比较 | 对开放词项或未定参数生成多个有理由的解释候选，比较各自对所求、答案形式/精度与所需结构的影响；允许并存，或把参数变量化继续推理，不因未定即回问。 |
| 展开依赖 | 对一个仍相关的内容追问：理解或处理它需要先知道什么、接受什么条件，或与什么联合考虑？说明关系为何成立及适用条件；区分答案支持某判断与求解必须依赖某答案，不凭语义相近连边，不强拆循环为单向次序。 |
| 拆分与合并 | 只有当不同所求、前提、精度或关系被混在一起而妨碍理解/交接时才拆分；同一回答足以处理多个内容且不丢失重要差异时可合并。保留与原表述的联系，避免细分后失去整体意图。 |
| 找共享前置 | 比较多个问题或判断是否依赖同一个条件、未知或依据，显式标出共用处及各自适用范围；共同用词不自动证明共享，共享前置也不预定共享模型。 |
| 识别真实冲突 | 检查表面分歧是否在同一条件下确实不能并存，还是范围、时间、精度或假设不同。能并存则保留；真正改变问题结构的创作取舍交创作者裁定，客观事实争议保留为待研究问题，不以投票或创作偏好证明其真伪。 |
| 剪枝 | 暂去一个内容或关系，检查是否丢失回应原问、支持保留判断或启动后续求解所必需的依据。冗余、离题或仅对已撤回分支有用的内容可删除或暂缓，保留理由与恢复条件；未解决的关键未知不能因难处理而消失。 |
| 挑战覆盖 | 设想当前问题都得到回答，原问是否仍可能缺少重要支持；反查遗漏条件、反例与被忽略的解释。连通、节点多或图形完整都不能证明覆盖充分。挑战相对于已说明的意图与边界，不追求穷尽世界。 |
| 判断何时够用 | 回看原问，判断当前结构能否说明后续应求什么、为何相关、必要条件与主要未知在哪里，以及继续展开会带来什么具体收益。足够时呈示候选与理由；仍存在影响所求的歧义时先按「先分析、后回问」继续，不用无限展开也不用回问代替判断。 |

### 操作触发纪律（防止清单退化为隐式流程）

1. 操作**由当前认知困难触发**；只调用当前困难需要的操作，不按顺序遍历，也不以求全为目标。
2. **未触发或无实例的操作，在记录中如实写「未触发 / 无实例」**；不得为覆盖清单补造实例、条目或关系。
3. 本表不是步骤、问卷栏目或流程图，操作名称不是交付物字段，也不要求创作者先自行拆题。
4. 方法表现证据 = 「哪个困难触发了哪个操作、产生了什么结构变化、有什么局限」；**不是**「执行了几项操作」或「清单完成度」。
5. 清单本身接受检验：可以出现无用、需拆分/合并/改写或缺失的操作；发现新操作即补入，不维护形式完整。

## 区分内容及其依据

创作者意图、客观问题、推断与证据是帮助辨认来源和认知地位的区分维度，不是穷尽且互斥的节点种类。图中的内容可相互关联，但须能辨认其性质与来源，不能因画成节点就具有同等事实地位：

- **创作者意图与取舍**说明想回答什么、答案用于什么、愿意保留哪些创作条件；创作者可以纠正或确认这些内容。
- **客观问题**表达在已说明条件下需要求证的世界状态、关系或后果；仍未知就是未知，不能以创作者确认某种取舍证明世界事实为真。
- **分析者推断**是助手对用途、问题或关系的暂定解释，应给理由、标不确定性，并允许撤销。未经确认的推断不能成为既定创作事实；**候选解释与并存分支同样属于分析者推断**，不因并列就获得同等事实地位。
- **证据与研究动作**分别说明已有依据及其出处、接下来如何收集或验证；计划研究不等于证据，证据是否适用也需判断。它们不能冒充待求的世界结论。

这些区别用于防止混淆，不构成封闭节点分类。每项重要关系也应能说明是谁提出、根据什么、在什么条件下有效；条件变化时重审关系，而非维护图的形式稳定。

## 收束与创作者确认

助手准备呈示候选时，应能解释：原问如何被对应；**哪些歧义已被候选解释覆盖并比较、哪些未定参数已变量化保留**；当前保留哪些解释和边界、主要问题所求及必要的答案形式/精度、重要依赖与共享前置、仍未确定的事项；以及为什么进一步展开暂时没有重要收益。**「存在需要向创作者提问的事项」本身不构成够用的理由**——只有完成上述分析与变量化之后，剩余的确属不可由分析消除、且会改变所求的创作者取舍时，才进入回问或呈示。必要信息尚不足时应明确缺口，不能用「可解」标签掩盖不确定性。这是相对于当前意图的定性判断，不是固定字段门槛，也不是唯一或数学最小结构的证明。

呈示的终点是**足以启动阶段二求解的候选结构，交创作者确认**。助手说明真正改变结构的待裁定处和推断依据，提供易于纠正的表述；创作者可以补充、删除、改边界或否定关系。确认前仍是候选。创作者确认的是创作意图、取舍及可采用的问题结构，不是对客观命题真实性或最终可解性的担保。若无法支持启动求解，则保留未就绪结论与具体原因。

## 图表述风险与约束

| 风险 | 约束 |
|------|------|
| 节点化丢失整体意图 | 始终保留原问、上下文出处与回指；拆分后回看整体，必要时合并、改述或不拆分。 |
| 边实化：暂定联系被当成事实关系 | 重要关系有理由、有条件、标明推断或证据及不确定性；允许撤销，不因已有一条边而默认其真实或永久有效。 |
| 连通性幻觉 | 不以路径存在证明支持充分或依赖真实；用覆盖反例挑战，允许孤立内容、多个局部结构和未确定关系。 |
| 过度展开 | 每次扩展说明其对原问或交接的具体价值；无重要收益则停止，允许剪枝、不建图或保留整体问题。 |
| 过早回问（premature elicitation） | 发现歧义时先做有界的候选解释、并列比较与变量化；只有三条回问条件同时成立才回问；不得把定界任务退回创作者，也不得要求创作者先定义关键词。 |
| 操作打卡：为证明方法被执行而遍历清单 | 按当前认知困难选择操作；未触发如实标注；证据记结构变化与局限，不记完成度。 |
| 阶段一越界建模 | 只形成问题与关系候选，不提前构造世界机制或回答领域问题；发现须靠求解才能澄清的未知时明确交接条件，必要时由后续发现回流。 |

## 阶段二边界与本版状态

从创作者确认的问题结构逆向识别模型依赖，属于阶段二的后续研究，本版不设计其方法。问题关系不直接等同模型依赖，也不意味着一问题一模型。阶段二的新发现若改变所求、边界或关系，应带具体原因回流阶段一，修订受影响部分。

本版为 `v0.7.0`，尚无经检验通过的方法证据：第一例（同案例）v0.6.0 运行经创作者判定未通过并驱动本版修订，首个通过检验的运行尚未发生；尚无创作者对结构的纠正，未交接 W2，没有回答原问、构建世界模型或图工具。`I-401` / `I-402` 状态及既有验证门禁保持不变，第二个不同真实创作问题尚未选定。

## 后续探针如何检验图式操作

后续检验先固定候选版本，仅输入“世界有多大”原问及当时实际可提供的上下文，不预载案例图或期望答案。只运行阶段一，观察助手如何增删、改写关系，拆分与合并内容，发现共享前置，区分真实冲突，剪枝、挑战覆盖，以及说明停止/交接理由；同时观察创作者能否理解并纠正候选结构。观察重点也包括哪些操作无用、需调整或遗漏，而非逐项完成清单。

本版修订后，检验额外观察：

- 歧义是否**先被分析**（候选解释集、并列比较、差异清单），而不是直接回问；
- 需继续的推理是否以**变量化**方式推进，而不是停在等待创作者给定参数；
- 若发生回问，是否三条条件同时成立，且附带已完成的分析与最小可纠正选项；
- 未触发的操作是否如实标注，方法证据是否以**结构变化**而非清单完成度呈现；
- 是否存在为覆盖清单而补造的实例或条目。

分别记录方法操作证据与本次案例节点、关系结果；案例的边和节点不升级为方法本体，单次测试只提供局部证据。v0.7 仍未接受。
