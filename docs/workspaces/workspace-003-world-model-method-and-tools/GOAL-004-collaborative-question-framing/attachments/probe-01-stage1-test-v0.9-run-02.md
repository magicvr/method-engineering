## 4. 有界诊断性探索

**探索 A · 量级-精度探索（服务 U3）**

- 问题：要判定「多大」需要多高精度，需知道哪些量级会改变叙事上的可能性。
- 范围：仅「空间延展 ＋ 前现代移动速度 ＋ 单个人一生」的最小情形；不设定世界机制、不选择答案。
- 粗算：步行 ~30 km/日 × 40 年（≈1.5×10⁴ 日）≈ **4×10⁵ km ≈ 11 倍地球周长**（4×10⁴ km）；马/帆船 150–300 km/日 × 40 年 ≈ **2–4×10⁶ km**（面积上约 10⁴ 倍地球表面）。
- 观察结论：**≲10⁴ km** 可数年—数十年走遍 → 尺寸可被角色亲身经验并说出；**~10⁵ km** 为一生步行极限；**~10⁶ km** 为车船极限；**≳10⁷ km** 前现代个体一生不可及 → 知识必然局部，答案只能以「局部已知 ＋ 未知边界」交付。
- 改变了哪个判断：把 N2「精度未定」从潜在阻塞项改为**可路由项**——只有 10⁵、10⁷ km 两个量级边界在叙事上有效，小于一个数量级的差异通常不改变所求，故单位与精确值可继续以变量保留，不阻塞阶段二。
- 局限：预设了空间性、欧氏度量与球形；若世界非空间或非欧，本估算法本身失效——这反过来说明「世界是否空间化」是一个独立约束。

**探索 B · 可解性探针（服务 U7）**

- 问题：在「角色不可能知道世界大小」的情况下，「剧情中必须解答」是否仍可满足。
- 范围：只检验交付通道是否存在，不做任何世界设定。
- 局部推演：F1 需测量/启示事件；F2 需比较事件；F3 需边界经验；F4 需禁令/失传/不可及被明确确认；F5 需变化可观察。五类**均不需要在剧情中给出完整数值**。
- 观察结论：可解性不由问题本身限制；不需创作者先保证可解。
- 改变了哪个判断：由「可能与『剧情必答』冲突」改为「不构成冲突，F4 保留为合法答案形式」。

**探索 C · 检索（服务 U5）**：记录见 §2‑U5。

**不可升级声明**：A、B、C 均只用于判断解释是否成立、依赖是否真实、边界在哪里；**不进入 W2 交付物，不作为世界事实，不作为案例结论，不用于证明方法有效**；一旦需要构造机制模型或回答领域问题即刻停止——本轮未越界。
