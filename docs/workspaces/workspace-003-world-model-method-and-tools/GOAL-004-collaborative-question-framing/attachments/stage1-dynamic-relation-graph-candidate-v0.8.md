# 阶段一动态问题关系图方法候选 v0.8

**draft / candidate / unaccepted；尚无经检验通过的方法证据，未交接 W2。** 本版修正 v0.7 未触及的**结构性问题**：认知操作本身被退化为 elicitation——未定项在图里只有「创作者给定」一条出路，操作又以动作完成而非结构产出为准，于是每次识别歧义都变成一次索要定义。诊断与三条对治规则见 [D-010](../01-decision/D-010-operations-must-produce-structure.md) / [E-017](../02-execution/E-017-cognitive-ops-anti-elicitation-revision.md)。v0.7、v0.6.1、v0.5 与既有运行记录保留为历史，不构成本版的验证证据。

## 退化诊断（本版要修的东西）

| 环节 | 机制 | 结果 |
|------|------|------|
| 未定项的出路 | 图中的「未定」被当作待填字段，只有创作者能赋值 | 每次识别歧义都导向一次索要 |
| 操作定义 | 只写「做什么动作」，不写「动作完成后结构里必须多出什么」 | 无法产出结构时，「提出问题」成为动作完成的替代品 |
| 收束判据 | 把「已能提出待创作者裁定的问题」当作阶段一完成态 | 识别歧义越多越早收束；停止分析的激励与产生问题的激励同向 |

第一例 v0.6.0 运行即为此形态：八项操作执行完毕后，产出物是两个「请创作者补定义」的提示与一个用途选择提示，而没有留下候选解释及其后果对照（见 [运行 01](probe-01-stage1-test-v0.6-run-01.md)）。

## 方法对象与工作表示

阶段一从创作者的原问和现有上下文出发，逐步辨认需要回答什么、为什么需要回答、哪些内容相互依赖以及哪里仍不确定。动态问题关系图是协助思考的工作表示：随理解变化而增删、改写、合并或撤销，服务于形成**足以启动阶段二求解的候选结构，交创作者确认**。它不保证问题一定可解，也不表示答案或模型已经存在。

**原问通常是不完整的**：歧义、未定指称与未定参数是阶段一的常规输入，是**待加工的原料，不是待索取的输入**。阶段一的工作正是对这种模糊输入做有界的解释、比较与结构发现；把原料退回给出题人，等于没有加工。

节点可以暂时承载需要支持的判断、待答问题、约束、必要未知等；关系可以表达依赖、支持、派生、约束、共享前置或冲突等。这些只是开放例子，不预定世界问题分类，不封闭节点或边的类型。遇到现有称呼无法表达的内容，先保留原意和理由，允许换一种表述。图无需覆盖全部上下文，也无需连成一个整体；原问及其整体意图始终保留在图外作为参照。简单问题允许不建图、不拆分。

这里的图不规定数据库、schema、存储格式或 UI。文字也可以表达关系；是否显式画图取决于它能否帮助当前理解，而非方法的必经门槛。

## 三条对治规则

**规则 A · 产出物规则**：每项认知操作的产出必须是**作用于当前结构的分析产物**——候选解释及其后果差异、条件、依赖、变量依赖、反例、排除理由、剪枝结果等。**某项操作若只能产出对创作者的提问，则视为该操作未执行**，不得记入方法表现证据，也不得作为收束理由。

**规则 B · 未定项处理次序**：任何未定项（指称未定、含义开放、量纲/精度未定、用途未说明等）在被提交给创作者之前，必须先走完四步：

1. **解释候选化**：给出两个以上有理由的解释候选，标明来源（创作者已述 / 上下文可推 / 分析者推断）与各自适用条件；不得只登记「此处有歧义」。
2. **后果推导**：逐个候选推导它使**所求、答案形式与精度、必要依赖**如何变化；产出「候选 × 后果」对照，并落到具体关系上，不停留在措辞差异。
3. **可判别性检查**：用现有上下文与推导，并按需做资料/既有知识检索，判断能否排除或区分候选；能则判定并记录依据与不确定性。
4. **变量化继续**：仍不可判别但推理可以推进时，把未定参数作为变量写入结构，记录它影响哪些所求与关系、以及关键取值下的结构差异；**不得停在「等创作者给定值」**。

四步走完而残余差异仍满足规则 C 时，才允许回问；否则继续分析或维持变量化保留。

**规则 C · 回问条件（末位手段，三条同时成立）**：

- ① 分析（含资料检索）无法消除该差异；
- ② 该差异确实改变回答要求或所求结构；
- ③ 该差异属于创作者取舍（创作意图、叙事用途、可接受精度与边界），而非客观待答内容。

回问必须**携带分析结果**（候选、后果对照、已排除项、为何不能自行判定），并以最小可纠正选项呈现；不得要求创作者先定义关键词或先自行拆题。客观事实争议不因无法分析就转为回问，应按研究缺口保留。

## 认知操作（触发 + 必须产出）

每行两件事：什么困难才触发它；完成后结构中**必须出现**什么。规则 A 适用于每一行。

| 操作 | 触发困难 | 完成后结构中必须出现的产物 |
|------|----------|---------------------------|
| 解释候选化 | 出现指称未定、含义开放或精度未定的词项/表述 | 两个以上有理由的解释候选，标注来源与各自适用条件 |
| 后果推导 | 已存在多个候选解释或未定参数 | 「候选 × 后果」对照：每个候选使所求、答案形式/精度、必要依赖如何不同 |
| 可判别性与排除 | 候选尚不能区分 | 已排除或已区分的候选及其依据（含资料/既有知识检索结果）；剩余不可判别项及其原因分类（资料不足 / 属创作者取舍 / 属客观待答） |
| 变量化继续 | 不可判别但推理仍可推进 | 未定参数以变量形式进入结构，连同它影响的所求/关系与关键取值下的结构差异 |
| 发现 | 原问、上下文或出处中似有未表达的内容 | 有理由且非穷尽的候选内容；标明哪些来自创作者、哪些是分析者推断；既能新增也能纠正 |
| 展开依赖 | 某项内容的相关性或可处理性不明 | 依赖关系及其成立理由与适用条件；区分「答案支持某判断」与「求解必须依赖某答案」；不凭语义相近连边，不强拆循环 |
| 拆分与合并 | 不同所求、前提、精度或关系被混在一起而妨碍理解/交接 | 拆分或合并后的结构，及其与原表述、整体意图的联系 |
| 找共享前置 | 多个内容可能依赖同一条件、未知或依据 | 共用处及其各自适用范围；共同用词不构成共享证据 |
| 识别真实冲突 | 出现表面分歧 | 该分歧在同一条件下可否并存的判断；能并存则保留，创作取舍交创作者裁定，客观争议保留为待研究问题 |
| 剪枝 | 出现冗余、离题或仅服务已撤回分支的内容 | 删除或暂缓的项、理由与恢复条件；未解决的关键未知不得因难处理而消失 |
| 挑战覆盖 | 结构看似完整时 | 反例、遗漏条件与被忽略的解释；连通、节点多或图形完整都不证明覆盖充分 |
| 判断何时够用 | 感到可以收束时 | 「出口退回检查」的逐项结论（见下节） |

### 触发纪律（防止清单退化为流程）

1. 操作**由当前困难触发**；只调用当前困难需要的操作，不按顺序遍历，也不以求全为目标。
2. **未触发或无实例的操作，如实写「未触发 / 无实例」**；不得为覆盖清单补造实例或条目。
3. 本表不是步骤、问卷栏目或流程图；操作名称不是交付物字段。
4. 方法表现证据 = 哪个困难触发了哪个操作、结构中出现了什么产物、有什么局限；**既不以「执行了几项」计，也不以「提出了几个待确认问题」计**。
5. 清单本身接受检验：可以出现无用、需拆分/合并/改写或缺失的操作；发现新操作即补入。

## 出口退回检查（收束前必做）

收束前，逐项审查本次运行产出的**每一个**「待创作者裁定 / 待确认 / 请补充」事项：

1. 它是否已经过规则 B 的四步？若某项只是要求创作者定义词项或给出参数值 → **阶段一未完成**，退回分析，不得计入收束产物。
2. 它的残余差异是否满足规则 C 三条？不满足 → 退回为变量化保留或继续分析。
3. 若确需回问：是否携带候选、后果对照、已排除项与最小可纠正选项？

检查结论（通过 / 退回项与原因）与运行记录并列留痕。**「发现了要问的问题」不是够用的理由**；够用的标志是：剩余不确定要么已变量化并记录影响，要么满足规则 C 且已附分析。

## 区分内容及其依据

创作者意图、客观问题、推断与证据是帮助辨认来源和认知地位的区分维度，不是穷尽且互斥的节点种类。图中的内容可相互关联，但须能辨认其性质与来源，不能因画成节点就具有同等事实地位：

- **创作者意图与取舍**说明想回答什么、答案用于什么、愿意保留哪些创作条件；创作者可以纠正或确认这些内容。
- **客观问题**表达在已说明条件下需要求证的世界状态、关系或后果；仍未知就是未知，不能以创作者确认某种取舍证明世界事实为真。
- **分析者推断**是助手对用途、问题或关系的暂定解释，应给理由、标不确定性，并允许撤销。候选解释、并存分支与已被排除的候选同属此类，不因并列就获得同等事实地位；被排除项保留出处与理由，以便复核当时的排除是否成立。
- **证据与研究动作**分别说明已有依据及其出处、接下来如何收集或验证；计划研究不等于证据，证据是否适用也需判断。它们不能冒充待求的世界结论。

这些区别用于防止混淆，不构成封闭节点分类。每项重要关系也应能说明是谁提出、根据什么、在什么条件下有效；条件变化时重审关系，而非维护图的形式稳定。

## 收束与创作者确认

助手准备呈示候选时，应能解释：原问如何被对应；**哪些歧义已给出候选解释并完成后果对照、哪些未定参数已变量化保留**；当前保留哪些解释和边界、主要问题所求及必要的答案形式/精度、重要依赖与共享前置、仍未确定的事项；以及为什么进一步展开暂时没有重要收益。呈示中若含需要创作者裁定的项，必须逐项附上已完成的分析（规则 C 的形态要求）。

呈示的终点是**足以启动阶段二求解的候选结构，交创作者确认**。助手说明真正改变结构的待裁定处和推断依据，提供易于纠正的表述；创作者可以补充、删除、改边界或否定关系。确认前仍是候选。创作者确认的是创作意图、取舍及可采用的问题结构，不是对客观命题真实性或最终可解性的担保。若无法支持启动求解，则保留未就绪结论与具体原因。

## 图表述风险与约束

| 风险 | 约束 |
|------|------|
| 操作退化为 elicitation：把「未定」当待填字段，以提问完成动作 | 规则 A/B/C：操作必须产出结构；未定项先做候选化—后果推导—可判别性检查—变量化；只有分析见底且确属创作者取舍才回问，且回问携带分析。 |
| 节点化丢失整体意图 | 始终保留原问、上下文出处与回指；拆分后回看整体，必要时合并、改述或不拆分。 |
| 边实化：暂定联系被当成事实关系 | 重要关系有理由、有条件、标明推断或证据及不确定性；允许撤销，不因已有一条边而默认其真实或永久有效。 |
| 连通性幻觉 | 不以路径存在证明支持充分或依赖真实；用覆盖反例挑战，允许孤立内容、多个局部结构和未确定关系。 |
| 过度展开 | 每次扩展说明其对原问或交接的具体价值；无重要收益则停止，允许剪枝、不建图或保留整体问题。 |
| 过早回问（premature elicitation） | 发现歧义时先走规则 B；只有规则 C 三条同时成立才回问；不得把定界任务退回创作者，也不得要求创作者先定义关键词。 |
| 操作打卡：为证明方法被执行而遍历清单 | 按当前认知困难选择操作；未触发如实标注；证据记结构变化与局限，不记完成度。 |
| 阶段一越界建模 | 只形成问题与关系候选，不提前构造世界机制或回答领域问题；发现须靠求解才能澄清的未知时明确交接条件，必要时由后续发现回流。 |

## 阶段二边界与本版状态

从创作者确认的问题结构逆向识别模型依赖，属于阶段二的后续研究，本版不设计其方法。问题关系不直接等同模型依赖，也不意味着一问题一模型。阶段二的新发现若改变所求、边界或关系，应带具体原因回流阶段一，修订受影响部分。

本版为 `v0.8.0`，尚无经检验通过的方法证据：第一例（同案例）v0.6.0 运行经创作者判定**未通过**（premature elicitation 与操作打卡），v0.7 的门禁收紧未解决操作终点的结构问题，故有本版；首个通过检验的运行尚未发生。未交接 W2，没有回答原问、构建世界模型或图工具；`I-401` / `I-402` 状态及既有验证门禁不变，第二个不同真实创作问题尚未选定。

## 后续探针如何检验

后续检验先固定候选版本，仅输入“世界有多大”原问及当时实际可提供的上下文，不预载案例图或期望答案。只运行阶段一，观察助手如何增删、改写关系，拆分与合并内容，发现共享前置，区分真实冲突，剪枝、挑战覆盖，以及说明停止/交接理由；同时观察创作者能否理解并纠正候选结构。观察重点也包括哪些操作无用、需调整或遗漏，而非逐项完成清单。

本版修订后，检验额外观察：

- 是否出现**以提问替代操作**：某项操作的唯一产出是不是「请创作者定义/给出」；
- 未定项是否走完规则 B 四步（候选化 → 后果推导 → 可判别性检查 → 变量化），以及变量化后推理是否**继续**；
- 回问（若有）是否满足规则 C 三条，且携带候选、后果对照与已排除项；
- 运行记录是否含**出口退回检查**结论，是否出现过退回与整改；
- 未触发的操作是否如实标注，方法证据是否以结构产物而非完成度或问题数量呈现。

分别记录方法操作证据与本次案例节点、关系结果；案例的边和节点不升级为方法本体，单次测试只提供局部证据。v0.8 仍未接受。
