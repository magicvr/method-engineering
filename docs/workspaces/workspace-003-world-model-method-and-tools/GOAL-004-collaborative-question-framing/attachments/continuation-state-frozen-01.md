**S-1（继承）**：① 所求＝该世界在其世界内可指认的计量基准／参照系下存在哪些可判定的尺度维度（是否有定义、各维度大小关系、是否有边界、尺度结构类型），以可检验表述给出；② 答案形态＝可判定的尺度结构陈述；世界客观可实现的精度属 B3、不另立 B1；③ 分支影响仅记有依据者（有界/有限 → 可用尺度参数表达；无界/无限 → 数值型答案可能无定义、须改述为尺度结构），其余「分支待阶段二发现」；④ 来源＝原问直接追问＋N2 变量化。
