## 边界

上述“不能回答”仅指当前输入和 S1 职责不足以确定这些客观事实，不表示相应尺度、机制、自由度或限制不存在。若阶段二未找到某类事实或机制，须区分“当前资料／搜索未找到”与“有依据地判定不存在”，并按冻结合同登记范围、owner、当前不阻断理由及回流触发。

①-b 的 B3-b-01 已在 [b-refinement-03 §5](b-refinement-03.md) 有 F.2 四要素记录；本文件不重复改写。
