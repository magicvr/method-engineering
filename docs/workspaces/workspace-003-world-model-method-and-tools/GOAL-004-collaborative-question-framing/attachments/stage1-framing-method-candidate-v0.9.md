# 阶段一协作定界方法候选 v0.9

**draft / candidate / unaccepted。** 本版是 v0.8 的**试跑前修订**：v0.8 的方向经创作者通过——方法主体开始表现为「由认知困难触发、必须形成结构性分析产物、仅在不可约创作者取舍处回问」的操作系统，而不是澄清问卷。据此做三项小修：① 未定项改为**按性质路由**的主动分析（防止反 elicitation 规则自身退化为新的固定流水线或制造虚假候选）；② 显式允许**有界诊断性探索/局部试解**（用于判断解释、依赖与边界，不升级为正式模型或答案）；③ **弱化工作表示的命名**，方法身份是「操作与产物」而非某一种表示。裁定见 [D-011](../01-decision/D-011-routing-and-bounded-exploration.md)，事实见 [E-018](../02-execution/E-018-prerun-revision-v09.md)。

本版为第二次试跑的固定基线（跑前不再改动）。文件名不再沿用 `dynamic-relation-graph`，方法要求与 v0.8 保持连续，只是不再由图形命名。

## 为什么会有这一版（退化诊断，历史保留）

| 环节 | 机制 | 结果 |
|------|------|------|
| 未定项的出路 | 图中「未定」被当作待填字段，只有创作者能赋值 | 每次识别歧义都导向一次索要 |
| 操作定义 | 只写「做什么动作」，不写「动作完成后结构里必须多出什么」 | 无法产出结构时，「提出问题」成为动作完成的替代品 |
| 收束判据 | 把「已能提出待创作者裁定的问题」当作阶段一完成态 | 识别歧义越多越早收束，停止分析的激励与产生问题的激励同向 |

第一例 v0.6.0 运行即此形态：八项操作执行完毕后，产出物是两个「请创作者补定义」的提示与一个用途选择提示，没有候选解释及其后果对照（见 [运行 01](probe-01-stage1-test-v0.6-run-01.md)）。

## 方法对象与工作表示（工作表示可替换）

阶段一从创作者的原问和现有上下文出发，逐步辨认需要回答什么、为什么需要回答、哪些内容相互依赖以及哪里仍不确定，服务于形成**足以启动阶段二求解的候选结构，交创作者确认**。它不保证问题一定可解，也不表示答案或模型已经存在。

**方法身份是操作与产物，不是表示形式。** 工作表示可以是一张关系结构、一张对照表、一份提纲或几段文字；本方法不要求建图，不规定数据库、schema、存储格式或 UI，也不以「图」作为方法名称或验收对象。是否使用某种表示，取决于它能否帮助当前理解；换掉表示不改变方法要求。

**原问通常是不完整的**：歧义、未定指称与未定参数是阶段一的常规输入，是**待加工的原料，不是待索取的输入**。阶段一的工作正是对这种模糊输入做有界的解释、比较与结构发现；把原料退回给出题人，等于没有加工。

若采用关系式表示，节点可以暂时承载需要支持的判断、待答问题、约束、必要未知等；关系可以表达依赖、支持、派生、约束、共享前置或冲突等。这些只是开放例子，不预定世界问题分类，不封闭节点或边的类型。表示无需覆盖全部上下文，也无需连成一个整体；原问及其整体意图始终保留在结构之外作为参照。简单问题允许不做显式表示、不拆分。

## 规则 A · 产出物规则

每项认知操作的产出必须是**作用于当前结构的分析产物**——候选解释及其后果差异、条件、依赖、变量依赖、反例、排除理由、剪枝结果等。**某项操作若只能产出对创作者的提问，则视为该操作未执行**，不得记入方法表现证据，也不得作为收束理由。

## 规则 B · 按性质路由的主动分析

未定项**不按固定步骤处理**，而是按其性质路由到相应的主动分析方式。路由是一次判断，不是一遍流程：只做该性质需要的动作，做完即继续。

| 未定项性质 | 典型形态 | 路由到的主动分析 | 必须留下的产物 |
|------------|----------|------------------|----------------|
| N1 指称/含义歧义 | 某个词指什么、某表述含义开放 | 解释候选化 + 后果推导 | 两个以上有理由的候选及其后果差异；**只有一个合理解释时直接采纳并记录理由，不得为满足形式制造候选** |
| N2 参数/精度未定 | 知道要什么，但数值、精度或量纲未给 | 变量化继续 | 变量进入结构，连同它影响哪些所求/关系与关键取值下的差异 |
| N3 事实/知识缺口 | 答案取决于世界中的事实或既有知识 | 可判别性检查 + 按需资料/既有知识检索 | 能排除或区分的结论与依据；剩余项的不可判别原因（资料不足 / 属创作者取舍 / 属客观待答） |
| N4 用途/取舍未定 | 答案用来干什么、愿意接受什么条件 | 各用途对结构的差异推导 → 必要时规则 C | 各用途下的结构差异；仅在差异确实改变回答要求且不可由分析消除时才进入回问 |
| N5 可解性未知 | 不确定是否存在可回答的结构 | **有界诊断性探索/局部试解**（规则 D） | 探索记录，以及它对可解性判断的改变；不得要求创作者先保证可解 |

路由要求：一个未定项可同时具备多种性质，按**当前最影响所求**的一类路由，并留下路由理由。**本规则不产生「每个未定项都要把所有动作做一遍」的要求**；若某类只需一个动作（例如 N2 直接变量化），就只做那一个。若路由后已无残余差异，直接继续，不必回问。

## 规则 C · 回问条件（末位手段，三条同时成立）

- ① 分析（含有界诊断性探索与按需检索）无法消除该差异；
- ② 该差异确实改变回答要求或所求结构；
- ③ 该差异属于创作者取舍（创作意图、叙事用途、可接受精度与边界），而非客观待答内容。

回问必须**携带分析结果**（候选、后果对照、已排除项、为何不能自行判定），并以最小可纠正选项呈现；不得要求创作者先定义关键词或先自行拆题。客观事实争议不因无法分析就转为回问，应按研究缺口保留。

## 规则 D · 有界诊断性探索

阶段一**允许**为判断解释、依赖与边界做小规模诊断性探索或局部试解，例如构造一个小反例、代入一个样例、做一次局部推演、做一次检索、做一次粗略量级估算以判断所需精度。约束：

1. **有界**：只覆盖当前歧义或依赖判断所需的最小范围，不做完整求解或系统建模。
2. **目的限定**：产出只用于判断解释是否成立、依赖是否真实、边界在哪里；**不得**作为正式模型、世界答案或案例结论。
3. **记录**：写出探索的问题、范围、观察结论，以及它改变了哪一个判断。
4. **不升级**：探索结果不进入 W2 交付物，不作为世界事实，也不得用来证明方法有效；案例产物与方法证据继续分开。
5. **越界即停**：一旦必须构造机制模型或回答领域问题才能继续，停止，并把它转成交接条件或回流触发。

## 认知操作（触发 + 必须产出）

每行两件事：什么困难才触发它；完成后结构中**必须出现**什么。规则 A 适用于每一行。

| 操作 | 触发困难 | 完成后结构中必须出现的产物 |
|------|----------|---------------------------|
| 解释候选化 | 出现指称未定、含义开放或精度未定的词项/表述 | 两个以上有理由的解释候选，标注来源与各自适用条件；或在只有一个合理解释时给出采纳理由 |
| 后果推导 | 已存在多个候选解释或未定参数 | 「候选 × 后果」对照：每个候选使所求、答案形式/精度、必要依赖如何不同 |
| 可判别性与排除 | 候选尚不能区分 | 已排除或已区分的候选及其依据（含检索结果）；剩余不可判别项及其原因分类（资料不足 / 属创作者取舍 / 属客观待答） |
| 变量化继续 | 不可判别但推理仍可推进 | 未定参数以变量形式进入结构，连同它影响的所求/关系与关键取值下的结构差异 |
| 有界诊断性探索 | 解释是否成立、依赖是否真实、边界在哪，仅靠静态分析无法判断 | 探索的问题与范围、观察结论、它改变了哪个判断，以及未升级为模型或答案的声明 |
| 发现 | 原问、上下文或出处中似有未表达的内容 | 有理由且非穷尽的候选内容；标明哪些来自创作者、哪些是分析者推断；既能新增也能纠正 |
| 展开依赖 | 某项内容的相关性或可处理性不明 | 依赖关系及其成立理由与适用条件；区分「答案支持某判断」与「求解必须依赖某答案」；不凭语义相近连边，不强拆循环 |
| 拆分与合并 | 不同所求、前提、精度或关系被混在一起而妨碍理解/交接 | 拆分或合并后的结构，及其与原表述、整体意图的联系 |
| 找共享前置 | 多个内容可能依赖同一条件、未知或依据 | 共用处及其各自适用范围；共同用词不构成共享证据 |
| 识别真实冲突 | 出现表面分歧 | 该分歧在同一条件下可否并存的判断；能并存则保留，创作取舍交创作者裁定，客观争议保留为待研究问题 |
| 剪枝 | 出现冗余、离题或仅服务已撤回分支的内容 | 删除或暂缓的项、理由与恢复条件；未解决的关键未知不得因难处理而消失 |
| 挑战覆盖 | 结构看似完整时 | 反例、遗漏条件与被忽略的解释；连通、节点多或表示完整都不证明覆盖充分 |
| 判断何时够用 | 感到可以收束时 | 「出口退回检查」的逐项结论（见下节） |

### 触发纪律（防止清单退化为流程）

1. 操作**由当前困难触发**；只调用当前困难需要的操作，不按顺序遍历，也不以求全为目标。
2. **未触发或无实例的操作，如实写「未触发 / 无实例」**；不得为覆盖清单补造实例或条目。
3. 本表不是步骤、问卷栏目或流程图；操作名称不是交付物字段。
4. 方法表现证据 = 哪个困难触发了哪个操作、结构中出现了什么产物、有什么局限；**既不以「执行了几项」计，也不以「提出了几个待确认问题」计**。
5. 清单本身接受检验：可以出现无用、需拆分/合并/改写或缺失的操作；发现新操作即补入。

## 出口退回检查（收束前必做）

收束前，逐项审查本次运行产出的**每一个**「待创作者裁定 / 待确认 / 请补充」事项：

1. 它是否已经过规则 B 的路由与相应主动分析？若某项只是要求创作者定义词项或给出参数值 → **阶段一未完成**，退回分析，不得计入收束产物。
2. 它的残余差异是否满足规则 C 三条？不满足 → 退回为变量化保留或继续分析。
3. 若确需回问：是否携带候选、后果对照、已排除项与最小可纠正选项？

同时确认没有把方法本身做成固定流水线：若某个未定项被机械套用了全部动作，记为偏差并整改。

检查结论（通过 / 退回项与原因）与运行记录并列留痕。**「发现了要问的问题」不是够用的理由**；够用的标志是：剩余不确定要么已变量化并记录影响，要么满足规则 C 且已附分析。

## 区分内容及其依据

创作者意图、客观问题、推断与证据是帮助辨认来源和认知地位的区分维度，不是穷尽且互斥的节点种类。图中的内容可相互关联，但须能辨认其性质与来源，不能因画成节点就具有同等事实地位：

- **创作者意图与取舍**说明想回答什么、答案用于什么、愿意保留哪些创作条件；创作者可以纠正或确认这些内容。
- **客观问题**表达在已说明条件下需要求证的世界状态、关系或后果；仍未知就是未知，不能以创作者确认某种取舍证明世界事实为真。
- **分析者推断**是助手对用途、问题或关系的暂定解释，应给理由、标不确定性，并允许撤销。候选解释、并存分支、诊断性探索结论与已被排除的候选同属此类，不因并列就获得同等事实地位；被排除项保留出处与理由，以便复核当时的排除是否成立。
- **证据与研究动作**分别说明已有依据及其出处、接下来如何收集或验证；计划研究不等于证据，证据是否适用也需判断。它们不能冒充待求的世界结论。

这些区别用于防止混淆，不构成封闭节点分类。每项重要关系也应能说明是谁提出、根据什么、在什么条件下有效；条件变化时重审关系，而非维护表示的形式稳定。

## 收束与创作者确认

助手准备呈示候选时，应能解释：原问如何被对应；**哪些歧义已给出候选解释并完成后果对照、哪些未定参数已变量化保留**；当前保留哪些解释和边界、主要问题所求及必要的答案形式/精度、重要依赖与共享前置、仍未确定的事项；以及为什么进一步展开暂时没有重要收益。呈示中若含需要创作者裁定的项，必须逐项附上已完成的分析（规则 C 的形态要求）；诊断性探索的结论只能作为判断依据出现，不得当作答案。

呈示的终点是**足以启动阶段二求解的候选结构，交创作者确认**。助手说明真正改变结构的待裁定处和推断依据，提供易于纠正的表述；创作者可以补充、删除、改边界或否定关系。确认前仍是候选。创作者确认的是创作意图、取舍及可采用的问题结构，不是对客观命题真实性或最终可解性的担保。若无法支持启动求解，则保留未就绪结论与具体原因。

## 风险与约束

| 风险 | 约束 |
|------|------|
| 操作退化为 elicitation：把「未定」当待填字段，以提问完成动作 | 规则 A/B/C：操作必须产出结构；未定项按性质路由到主动分析；只有分析见底且确属创作者取舍才回问，且回问携带分析。 |
| 反 elicitation 规则退化为新的固定流水线 | 未定项按性质路由；只做该性质需要的动作；不对每个未定项机械套用全部动作；路由理由留痕。 |
| 制造虚假候选 | 候选必须有理由并能被后果区分；只有一个合理解释时直接采纳并记录理由。 |
| 诊断性探索升级为结论 | 探索有界、目的限定、留痕、不升级；越界即停并转为交接条件或回流触发。 |
| 表示形式变成方法身份 | 方法身份是操作与产物；表示可替换，不要求建图，也不以表示完整度作为验收对象。 |
| 节点化丢失整体意图 | 若采用关系式表示，始终保留原问、上下文出处与回指；拆分后回看整体，必要时合并、改述或不拆分。 |
| 边实化：暂定联系被当成事实关系 | 重要关系有理由、有条件、标明推断或证据及不确定性；允许撤销，不因已有一条边而默认其真实或永久有效。 |
| 连通性幻觉 | 不以路径存在证明支持充分或依赖真实；用覆盖反例挑战，允许孤立内容、多个局部结构和未确定关系。 |
| 过度展开 | 每次扩展说明其对原问或交接的具体价值；无重要收益则停止，允许剪枝、不做表示或保留整体问题。 |
| 过早回问（premature elicitation） | 发现歧义时先按规则 B 路由分析；只有规则 C 三条同时成立才回问；不得把定界任务退回创作者，也不得要求创作者先定义关键词。 |
| 操作打卡：为证明方法被执行而遍历清单 | 按当前认知困难选择操作；未触发如实标注；证据记结构变化与局限，不记完成度。 |
| 阶段一越界建模 | 只形成问题与关系候选，不提前构造世界机制或回答领域问题；发现须靠求解才能澄清的未知时明确交接条件，必要时由后续发现回流。 |

## 阶段二边界与本版状态

从创作者确认的问题结构逆向识别模型依赖，属于阶段二的后续研究，本版不设计其方法。问题关系不直接等同模型依赖，也不意味着一问题一模型。阶段二的新发现若改变所求、边界或关系，应带具体原因回流阶段一，修订受影响部分。

本版为 `v0.9.0`，是第二次试跑的**固定基线**（跑前不再改动）：方向经创作者通过，三项试跑前小修已落入规则 B/D 与命名。尚无经检验通过的方法证据——第一例 v0.6.0 运行经创作者判定未通过（premature elicitation 与操作打卡），v0.7 只收紧门禁未触及操作终点，v0.8 改造操作定义后方向获通过。未交接 W2，没有回答原问、构建世界模型或图工具；`I-401` / `I-402` 状态与既有验证门禁不变。

## 后续检验观察项

后续检验先固定候选版本，仅输入“世界有多大”原问及当时实际可提供的上下文，不预载案例图或期望答案。只运行阶段一，观察助手如何增删、改写与收束，以及说明停止/交接理由；同时观察创作者能否理解并纠正候选结构。观察重点也包括哪些操作无用、需调整或遗漏，而非逐项完成清单。

本版修订后，检验额外观察：

- 未定项是否**按性质路由**、是否只做必要动作，而不是把全部动作机械套一遍；
- 是否出现**虚假候选**（为满足形式硬凑解释）；
- **有界诊断性探索**是否出现、是否保持有界，且未升级为正式模型或答案；
- 是否出现**以提问替代操作**；回问（若有）是否满足规则 C 并携带候选、后果对照与已排除项；
- 运行记录是否含**出口退回检查**结论，是否出现过退回与整改；
- 未触发的操作是否如实标注，方法证据是否以结构产物而非完成度或问题数量呈现；
- 是否把**表示形式**当成方法身份（例如把「必须建图」当作交付要求）。
