# 阶段一认知操作与 W2 交接候选 v0.3

**draft / candidate / unaccepted。** 本附件按 [D-005](../01-decision/D-005-stage1-method-level-correction.md) 与 [D-007](../01-decision/D-007-coexisting-judgments-and-relations.md) 整理世界模型构建范围内的阶段一方法，不是案例问题结构或已验证规范。

## 阶段一要完成的转换

输入是不完整的真实原问与现有创作上下文。输出分成两个相连但不同的层次：创作者层的用途、目标判断、选择与约束；以及可交给 W2 的明确客观问题节点及其依赖。另须说明每个客观答案如何支持一项或多项创作判断。创作用途和创作判断不是 W2 的待求解节点；“答案支持某项判断”也不等于两个客观问题之间存在求解依赖。创作者仍裁定意图、取舍和创作选择，助手不自动代定 canon。

只有客观世界状态、规律、关系或后果才可能形成 W2 问题节点；创作者选择、语义澄清、研究动作和“接下来要分析什么”是阶段一上下文或工作动作，不冒充客观问题。“可解”不等于已答或已有模型：问题含义、所需答案、条件与精度、支持需求已足以交给阶段二处理。答案或模型暂缺可以成为阶段二能力发现及缺口判定的对象，不能反向要求创作者先提供它们才允许定界。

## 认知操作候选

以下操作允许往返迭代，不是依次填写字段的流程。适用的顺序取决于当前理解与证据。

- **重建目标判断候选。** 保留真实原问与上下文，从中推断答案可能支持哪些创作判断，区分明确意图和助手假设。候选默认可并存、可合并、可补充或可删除，不视为穷尽清单；不得把暂定解释直接包装成互斥选择。
- **分析判断间关系。** 检查候选判断是并列、包含、前置、派生、互相约束，还是确有冲突；能并存时保留其关系并继续推理。只有经证据或上下文确认无法同时成立、且这种冲突会改变后续问题结构时，才把真实冲突交给创作者裁定。
- **定位有影响的歧义与未知。** 分析哪些不同解释或缺失信息会改变目标判断、答案有效性或后续处理方式。混有非客观创作选择时先协助区分，再按创作者选择处理，不以无限枚举歧义代替分析。
- **辨别结论由什么支持、由谁决定。** 对每项待处理内容，判断它需要客观依据，还是需要创作者的意图或取舍；混合内容则分离创作选择与支持该选择的客观问题。可由研究消除的未知由助手主动处理；不会改变问题结构的未决选择可作为显式前提继续分析；仅当差异会实质改变问题结构时，才向创作者说明影响并请求裁定。
- **按需研究。** 为当前理解困难查资料、参考及反例，核对适用条件和证据边界；研究的作用是支持或挑战解释与推断，不直接把参考变成世界设定。
- **从判断逆推客观依据。** 思考作出各项目标判断需要哪些客观答案或证据，再推导客观问题单元；不把目标判断自身变成客观问题。每个客观节点说明问题含义、答案形式、条件与精度，以及支持哪些判断；不能仅凭领域名词列出目录。
- **发现依赖并区分支持关系。** 标明客观答案间的先后、约束、共享输入、联合处理或循环依赖；另行标明答案对创作判断的支持关系。可存在循环；循环标注为联合处理及其未决处，不强行拆为有向无环图，也不据此宣称已求解。
- **压缩并检视整体。** 用下述候选检查挑战问题结构的充分性与必要性，调整节点与依赖，形成有依据的结构候选，并标出需要创作者裁定的意图、前提与取舍。创作者对这些实质事项的裁定，是阶段二使用问题结构的接口条件，不是阶段一的方法主体或主要工作成果。

## 最小充分检查（均为 candidate/unaccepted）

| 候选检查 | 认知动作与局限 |
|----------|----------------|
| 并存与开放性检查 | 检查暂定目标判断能否同时成立、彼此是什么关系，以及是否有尚未覆盖的合理用途；不因出现多个解释就强制 OR，也不因当前列表暂时稳定就宣称穷尽 |
| 充分性反例 | 尝试构造“这些客观单元都有答案，但仍不足以支持指定创作判断”的情形，发现遗漏前提、依赖或范围问题；充分只表示信息足以支持判断，不表示创作者已经作出选择；没有找到反例不证明普遍充分 |
| 必要性删除 | 暂去一个单元，检查原问判断与有效性是否仍可支持；保留理由应联系用途及依赖，不能只因列表已有该项 |
| 细分边际价值 | 分析进一步细分是否会改变判断、有效性或可交接性；有价值则提出调整，无明确价值不自动无限展开，具体停止条件仍待共同确定 |
| 综合回应 | 检视未来子答案应如何共同回应原问，是否仍缺从依据到判断的联系；此时检视支持结构，不伪造尚不存在的答案 |

目标是相对于用途、边界和精度的局部充分与不可约候选，不承诺全局数学最小。具体检查方式、证据要求和停止规则尚未接受或验证；不能把四项变成强制问卷或机械门禁。

## 输出与 W2 接口

输出需能区分并关联：① 非穷尽的创作用途、目标判断、选择与约束；② 明确客观问题节点及节点间求解依赖；③ 客观答案支持一项或多项创作判断的关系。另保留答案形式与精度、前提/证据/未知、助手假设与创作者裁定。充分的信息可以使创作者能够作决定，但不等于决定已作出。表达形式可随问题而变，不要求固定表格。

阶段二只接收创作者确认的客观问题节点、客观节点之间的依赖、适用前提/边界及必要精度；创作用途、目标判断和答案支持关系作为解释相关性与够用程度的上下文，不作为模型缺口。阶段二沿用父级 [W2 v0.4](../../GOAL-002-r2-method-working-version/attachments/world-model-method-working-version-v0.4.md) 的能力发现、缺口判定（状态、组合、精度、机制）与最小充分机制模型构建。一个问题不对应一个必建模型；多个问题可能共用能力或模型，一个问题也可能依赖多种能力。阶段一不预先把问题节点等同模型清单。

阶段二的答案应回到原问进行综合。若阶段二的新证据或综合不足表明需要改变范围、前提、精度或重要依赖，按 [D-002](../01-decision/D-002-two-stage-conditional-return.md) 将受影响的问题结构返回阶段一修订；涉及创作意图、前提或取舍的实质变化仍由创作者裁定。回流用于修订问题结构，不是反复确认的流程。本附件仅说明接口，不执行阶段二，也不改写 W2 正文。

## 以后如何观察测试结果

方法候选形成后，探针可作为黑箱输入。测试时应分别保存：

- 方法能力证据：认知操作如何推进理解、是否保留并检查并存假设、能否判断目标判断之间的关系和真实冲突、能否区分创作判断与客观问题、是否区分问题依赖与答案支持关系、能否发现问题依赖、是否达到可交接状态，以及暴露的缺口与失败机制。
- 案例结果：该次领域子问题、具体关系、答案和模型。它们只属于该次案例，不能直接升为通用分类、流程或固定结构。

方法修订可依据有证据的操作缺口提出候选，不把案例内容照搬为方法。跨问题最低验证范围与证据强度仍待 I-402 共同确定；真实场景充分性仍待 I-401，不以本附件代替验证。
