## 1. 当前问题集（＝覆盖攻击的**约束集**）

攻击时须保证：两个世界在**下列全部问题的答案上逐项相同**。

- **Q1** 世界尺度是否有定义（是否存在可指认的计量基准／参照系）；
- **Q2** 世界是否有边界（有界／无界／无限）；
- **Q3** 世界的尺度结构类型（单一连续域／分层／多连通／其它）；
- **Q4** 世界内是否存在认知／可达限制，使世界尺度不能被主体整体把握；
- **条件槽（结构要求，非独立问题）**：**所求一律取「带条件槽」的形式**——即尺度**不是单值**，而可能依赖时间／进程／条件；两世界的比较必须在**条件化的答案形式**（「在条件 C 下为 X」）上也逐项一致。
