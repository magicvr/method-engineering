# Run 19 · S1 可用执行轨迹

## 输入与执行边界

- 原问（输入卡原文）：**世界有多大？** 输入卡没有对象定义、数值、作品用途、叙事要求或额外事实。
- 实际使用：`stage1-framing-method-v0.18.5-execution-projection-v0.1.0.md`（draft / unaccepted）、`shared-research-loop-core-v0.1.0.md`、`shared-research-record-schema-v0.1.0.md`、`s1-research-adapter-v0.1.1.md`、`s1-raw-question-input-v0.1.0.md`。后三份研究组件本轮未调用；组件仅作为按需调用约束阅读。
- 本记录只保存截至首次必要的 S1 创作者裁定点的轨迹。没有创作者回复；没有最终结构确认、S1→S2 交接或阶段二求解。

## 由原问生成的当前层分析

**Q 的最低限度释义。** “世界”暂记作对象 `W`，而不是预设为地球、某颗行星、宇宙或某部作品的可达区域。“有多大”至少要求对 `W` 的某种大小给出答案。当前输入未给 `W` 的实例，也未给大小判准。保留 `W` 不意味着要遍历所有可能的世界。

**N1／N2 路由。** `W` 的实例是 N2 未实例化对象；先变量化，继续找共同必要问题，不仅因值未给就回问。大小判准 `M` 是 N1 含义／N2 答案口径未定；不同判准可能要求不同答案形态与求解任务，须先比较后果。当前没有创作者用途，N4 未触发。目标世界的具体尺度未知属将来客观待答内容，不能由 S1 猜数值。尚无必须靠外部资料解决的当前判断：未知目标对象缺乏可迁移的资料对象，眼前的口径差异是对原问的分析和可能的创作者取舍。因此没有启动 shared research，也没有 research-return；Demand Preservation Check 不适用。

**共同必要结构（候选）。**

1. `P1`：待量的 `W` 所涵盖的空间对象或范围是什么？若实例未给，保留 `W` 为抽象对象，阶段二面对具体目标时须确定其对应范围。这个问题来自“世界”的指称要求；不确定范围就无法说明大小归属于什么。此处不指定“行星/宇宙/已知区域”等取值，也不假定边界已存在。
2. `P2`：大小按什么空间量 `M` 表达？“多大”直接支持大小问题；不同 `M` 决定互不替代的求解任务及答案类型。`M` 此时是未决口径，不是已经允许阶段二遍历所有量法的自由参数。
3. `P3(M)`：在 `W` 与 `M` 确定的口径下，大小是否有定义；若有，结果是什么（包括可能的有限、无界或依赖条件的答案）？`P1`、`P2` 决定 `P3` 的问题口径；`P3` 是客观求解位置，S1 不填答案。存在性/可定义性是大小答案的前提分支，不是对目标世界已作出的边界判断。

这些是回答原问的候选依赖，不是具体世界模型或答案。“范围”与“大小”不可仅因都含空间字眼而合并：固定大小口径后，不同对象范围可能给出不同结果；固定对象后，不同口径可能要不同求解任务。

## 候选解释、规则 E 与后果

为检验 `M`，在同一个抽象 `W` 上比较两个由“多大”的空间读法和下述反事实探针支持的候选：

| 候选 | 当前输入依据与认知地位 | 所求、答案形态、必要依赖的后果 | E 处置 |
|---|---|---|---|
| `M-span`：跨度，例如最长空间距离 | “多大”的空间大小读法；分析者对原问的暂定解释。反事实探针表明跨度与空间总量不能互推。 | 求 `W` 的跨度或说明其不适用；需要可比较的点间距离/延展边界。答案可为长度或无界等。 | **有条件的解释候选**，结构贡献明确；不可凭输入选作唯一承载口径。 |
| `M-total`：空间总量，例如二维面积或三维体积，具体维数随 `W` 而定 | 同一原问及反事实探针支持的另一暂定解释；不是已知目标事实。 | 求 `W` 覆盖空间的总量或说明其不适用；需要确定度量对象、维数与合计规则。答案类型与 `M-span` 不同。 | **有条件的解释候选**，结构贡献明确；不可凭输入选作唯一承载口径。 |

两候选的 `M` 值只是后果差异记录，**均未采纳为最终所求**；当前结构只保留 `M` 及其未决状态。不能把两个量都写作 AND 型阶段二义务：原问没有要求“所有尺度都算一遍”。

候选池／排除清算：

- `W=地球`、`W=宇宙`、`W=某颗行星`：词汇可能性，没有输入锚点支持其中任何一个成为承载对象；这些是 `W` 的未定取值，不分别进入问题结构。
- “可到达区域有多大”“已知区域有多大”：需要行动主体、可达性或知识边界等附加设定；原问未给，不能提升为当前世界范围。
- “世界有多少人口/文明/叙事篇幅”：可能使用“大”的其他口语义，但没有本次输入的相关性依据，也未通过必要结构改变检查；留在池中，不据此增列任务。
- “拿某参照物作相对比较”：参照物及比较用途未给；目前只是答案表达方式的可能性，不单独改变必要求解问题。

## 规则 G · 当前候选集的攻击记录

以下世界只作反事实诊断；没有把几何形状、边界或单位升级为目标世界事实，也未进行世界尺度求解。

**攻击 1：检验只有 `P1 + M-span + P3` 是否覆盖原问。** 约束：两世界的 `P1` 口径同为各自整个空间对象，`M-span` 答案逐项相同。方向：先沿跨度作差，因约束禁止而失败；继而改向空间总量。世界 A 是外径相同的实心圆形空间，世界 B 是同外径但仅有细环的空间；跨度相同，总面积不同。若创作者把“多大”用于空间总量，两世界对原问的整体回答不同。差异点是 `M-total` 的问题口径，改变必要问题及答案形态，构成交接相关增量。按 E，原问的空间大小读法加这次同答案反例提供相关性，确有结构改变，非 `M-span` 冗余；但这证明需要处理解释竞争，不证明目标世界实际是任何形状，也不证明必须同时问两种量。

**攻击 2：反向检验只有 `P1 + M-total + P3`。** 约束：两世界的对象范围定义方式与面积答案相同。方向：先改变总量因约束失败；继而改向跨度。世界 C 与 D 面积相同，一个近圆形，另一个细长；跨度不同。若“多大”意指延展跨度，原问整体回答不同。`M-span` 相对于 `M-total` 同样是有条件的、非冗余解释候选，形成口径层增量。此轮同样只处理读法竞争，不能把 C/D 的形状当成 `W` 的事实。

**已出现而未准入差异的逐项清算。** `W` 的各种具体取值只是同一抽象对象的实例差异；它们会改变客观答案，尚未证明创作者在问不同问题，不生成并列对象节点。可达/已知区域会改变所量范围，却没有当前输入中的行动主体/认识主体锚点；不准入，若以后创作者说明其意图则重过 E。人口/文明/篇幅依赖新增非空间读法，当前只有语言可能性；不准入，若新输入给出相应用途则重过 E。相对参照物只改变表达或比较需求且无参照输入；不准入，若出现具体比较要求再处理。

**攻击状态。** 两轮展示了：单独采纳任一度量口径不能在当前原问下证明足以承载另一口径。`M` 形成未裁决 OR，故当前问题集尚未冻结为唯一口径。依据 G.1.4，不在这个非唯一约束上宣称最终收束，也不声称“无更多增量”；当前层攻击的已发现增量已记入 `M` 的取舍问题。创作者裁定后须按确定口径重跑当前结构上的覆盖攻击、候选差异清算及残余遗漏登记。

## 规则 F、层级、粒度与停止判断

| 未决项 | 当前类与原因 | owner / 下一状态 |
|---|---|---|
| `W` 的具体实例与空间范围 | 当前按 N2 保留抽象对象；对象实例不同可能改变答案，但现有证据不证明不同创作者所求。具体范围是否纯目标事实或创作者世界设定，在当前实例到来时再依据其来源核定；**此项归属尚未完全收敛**。 | S1 继续维护变量及来源，不作为让创作者先填对象的回问；不得在此状态交接。 |
| `M` 的大小判准 | **B1 创作者取舍型**：`M-span` 与 `M-total` 指向不同所求、模型职责及答案类型；原问未指定要哪一个，也没有事实检索能替创作者选择。 | 创作者；待规则 C 最小澄清并记录裁定。未裁定，阻断最终交接。 |
| `W` 在选定 `M` 下的实际大小及是否有定义 | **B3 客观求解型**，当前可写成条件化求解位置，但最终 F.2 答案形态需跟随 `M` 的裁定。 | 阶段二潜在求解 owner；目前不得假称已完成最终 B3 转写。 |

上述三个位置均为 L1 “世界是什么样”。输入没有作品叙事消费需求，L2 无实例；没有跨层依赖或接口。`P3` 目前可能仍是较粗问题族：模型职责会随 `M` 改变，故四项 handoff-ready 要素中，所求、求解任务与答案类型尚不确定，owner 状态亦未完成。此处不能向创作者请求仅仅“保持／继续／不接受”的粒度三态来暗中裁定 `M`；先按规则 C 处理真实所求取舍。

**规则 C 三条件和可继续性。** 抽象 `W` 已使对象值未给的困难不阻断共享结构；但把 `M-span` 与 `M-total` 保留为未裁决 OR，仍不能决定 `P3` 应承担的具体求解任务与答案形态。攻击和候选对照无法从原问消除该差异（①）；它实质改变回答要求（②）；选择哪种大小才符合创作者所问，不是外部事实可裁定（③）。可继续的共同分析已经完成至此，受阻点是 `P2 → P3` 的口径依赖。因此向控制方请求转达下面的一项最小创作者澄清；不要求创作者先列子问题或给出 `W` 的数值。

> **给创作者的问题：** 这里“世界有多大”主要想问哪一种空间大小？
>
> A. **跨度**：世界从一端延展到另一端有多远；回答偏向长度/无界。
>
> B. **空间总量**：世界覆盖的面积或体积有多少；具体维数随世界对象确定。
>
> 若两者都不符，请用一句话说出你关心的“大小”判准；无需给出答案或具体数值。

## 出口退回检查（此停止点）

1. B 路由与继续分解：`W` 已变量化；`M` 已生成、比较并攻击候选。未仅因对象未实例化而回问。
2. C/F：对 `M` 的回问满足三条件。`W` 的最终 F 归属、`P3` 的最终 B3 转写仍待口径与对象来源进一步分析；不能交接。
3. 回问携带候选、后果对照、排除项及具体受阻位置；仅问一个所求判准。
4. E：结构未采纳只有词典义项的具体世界或附加用途；反例只支持问题口径相关性，未作目标事实。
5. L1/L2：本轮只有 L1；无伪跨层依赖。
6. D：诊断世界是假想反例，未导出数值或目标世界结论；无分析者假定污染目标定界。
7. F.3：B1 尚未裁定，其他项尚未全部达到最终状态，交接失败。
8. G：已在当前层执行受约束的整体差异攻击并换方向，已清算池项；`M` 的 OR 未裁决，尚无唯一冻结问题集，不执行最终停止测试，也不制作可交接残余遗漏登记。
9. 粒度：`P3` 尚未 handoff-ready；未请求粒度三态，也未擅自展开下一层。
10. 认知操作按困难触发；未触发外部研究、L2 分析或完整模型构建。
11. 没有 research-return；Demand Preservation Check = N/A。

**当前停止点：** 等待创作者对大小判准的澄清。此前结构、候选与攻击记录均为可纠正的 S1 工作产物。仍可能遗漏别的有效读法或覆盖维度；现阶段不宣称问题集充分或已穷尽。
