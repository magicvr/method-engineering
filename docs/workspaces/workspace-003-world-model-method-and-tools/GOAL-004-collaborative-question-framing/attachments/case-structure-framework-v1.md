# 案例结构组织框架 v1（定稿）· 世界有多大

**性质**：**组织框架已获创作者确认并定稿**（[D-032](../01-decision/D-032-framework-v1-and-b-refinement.md)）；**但框架的确认不等于**① 覆盖维度**已穷尽**，也**不等于**每个覆盖节点**已细化到阶段二可直接求解的粒度**。
**方法基线**：阶段一方法候选 **v0.16.1**（指纹 `sha256 E6C1EF61…4C34`）。
**本文件取代** [呈示 02](case-structure-presentation-02.md) 作为**当前组织框架**（呈示 02 保留为历史）。

## 1. ① 覆盖维度（原问需要回答的内容构成）

| 编号 | 覆盖维度 | 依据 | 粒度状态 |
|------|----------|------|----------|
| **①-a** | **空间延展** | 原问直接支持 | 待后续判断（本框架不预设其粒度已足够） |
| **①-b** | **体量／内容规模**（泛指「世界**包含／承载多少内容**」这一类规模问题；**不绑定任何固定指标**） | 原问直接支持；创作者确认其成立 | **粗粒度覆盖维度族——允许递归展开** |

**保留声明**：① **可能不是完整集合**（仍可能存在与之正交、又共同回答原问的 AND 型维度）→ **R-1**；且 **①-b 本身可能需要递归展开**（当前已由创作者指令启动一次**局部递归细化**，见 §6）。

## 2. ② 横切结构／度量条件

**判据**：横切条件＝**规定「任一覆盖维度上的答案怎么给出」**——在**每个**覆盖维度上都要重判一次，其答案本身**不是对「多大」的部分回答**。

| 编号（来源） | 条件内容 | 认知地位 |
|--------------|----------|----------|
| **K-1**（原 Q1） | 该维度尺度**是否有定义**（是否存在可指认的计量基准／参照系） | 答案形态＝**存在性读法**（唯一性不在本项） |
| **K-2**（原 Q2 形态侧；**已按 D-032 泛化**） | **有界性／范围限制的定义与判定**——该维度上的**范围限制**如何定义、相对哪一个可指认基准、以何方式判定（**空间边界只是其在空间维度上的表现**） | 分析者推断（泛化后）；**「边界性」不单独升为第三覆盖维度** |
| **K-3**（原 Q3；**限定为**） | **尺度答案的结构形态**（答案须取定的结构形态；取值空间含「有局部尺度而无全局尺度」一类；**不写成固定枚举**） | B2 已收敛（度量读法） |
| **K-4**（原 Q4 关系侧） | **可把握性条件**：该维度答案能否被整体把握（是否存在世界内认知／可达限制；若存在，来自世界结构还是主体有限性） | **世界规模与主体之间的关系侧**；纯客观命题＝**S-4** |
| **K-5**（原 Q5；**限定为**） | **该结构及其量级是否由世界内事实唯一确定**（是否存在不可消除的度量自由度） | 读法＝**实际确定性**（不含模态必然性） |
| **K-6**（原条件槽） | **条件化要求**：所求非单值，答案取「在条件 C 下为 X」的条件化形式 | 结构要求；**不声称世界实际随时间变化**（那是 S-2） |
| **K-7a** | 答案形态须容纳「该维度尺度**无唯一量级／只结构可答**」 | 结构要求；客观部分＝S-3 |
| **K-7b** | 答案形态还须容纳「**含不可确定大小的基准／不可消除的表述空洞**」 | 表述要求（分析者推断）；世界事实层面**未升级** |

**K-3／K-5 的分立口径（T-3 裁定）**：**K-3＝答案的结构形态**；**K-5＝该结构及其量级是否由世界内事实唯一确定**。**二者概念不合并**；**仅清理重叠的示例／取值**（同一取值若同时像「结构形态」与「确定性判定」，须择其归属并留痕）。

## 3. ③ B3 求解项（交阶段二）

| 编号 | ① 所求 | ② 答案形态／精度 | ③ 分支影响（仅记有依据者） | ④ 来源 |
|------|--------|------------------|---------------------------|--------|
| **S-1** | 该世界在其世界内可指认计量基准下**存在哪些可判定的尺度维度**（是否有定义／各维度大小关系／范围限制／结构形态） | 可判定的**尺度结构陈述**；**世界客观可实现的精度属 B3** | 「有界／有限」→ 可用尺度参数表达；「无界／无限」→ 数值型答案可能无定义、须改述为尺度结构；其余**分支待阶段二发现** | 原问直接追问＋N2 变量化（变量＝计量基准类型） |
| **S-2** | 尺度**是否**随进程／时间／条件变化；依赖什么条件、以什么关系变化 | 常量／变量判定＋（若变量）条件形式陈述 | 常量 → 单一值可用；变量 → 所求带条件槽 | run-08 第 3 轮（＝K-6 客观侧） |
| **S-3** | 尺度**是否由世界内事实唯一确定到量级** | 确定性判定＋（若存在自由度）**须改述为结构／比值型陈述、不得给单一量级** | 唯一确定 → 可按量级型；存在自由度 → **量级型答案无定义** | run-09 第 5 轮（＝K-5／K-7a 客观侧） |
| **S-4** | 世界内**是否存在客观认知／可达限制**使尺度不能被主体整体把握；及其**来源** | 存在性判定＋来源分类 | 来自世界结构 → 「尺度可被整体把握」不成立（L2 可知性以其为前提，**只经需求接口**）；仅来自主体有限性 → 尺度本身可被整体把握 | run-08 第 1 轮＋原 Q4；＝**K-4 的客观实现** |

**精度口径**：世界客观可实现的精度属 B3；**当前输入无创作者侧精度／容差／答案边界要求 → 不立任何 B1 项**。
