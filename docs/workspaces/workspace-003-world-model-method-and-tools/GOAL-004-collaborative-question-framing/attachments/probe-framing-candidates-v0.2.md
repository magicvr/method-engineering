# “世界有多大”协作定界候选 v0.2

**candidate / unaccepted：仅供创作者裁定。** 本附件是第一阶段候选准备，不代表已确认或已证明最小的问题集，不构成 canon。第二阶段尚未实施，I-401/I-402 均未闭合。方法范围遵循 [D-004](../01-decision/D-004-reusable-world-model-framing-scope.md)，保留 [D-002](../01-decision/D-002-two-stage-conditional-return.md) 两阶段与有条件回流，以及 [D-003](../01-decision/D-003-generic-method-probe-scope.md) 当时的单探针第一阶段试行限额。[v0.1](probe-framing-candidates-v0.1.md) 保留为历史候选。

## 从现有表达出发

用户已明确：“世界有多大”是真实创作问题，每个世界观都需回答，剧情中必须解答。由此可以推断：答案需要对世界构建和剧情判断有用，单纯要求创作者先把问题精确化不足以完成协助；目前存在多个可分析的回答方向。

仍须由创作者裁定：当前主要回答任务、对象与边界取舍、期望的创作效果，以及哪些假设可用于当前试行。现有表达不能推出具体作品、宇宙形态、尺度数值、行动能力或人物知识范围，也不能推出三个回答方向都必须逐一展开。

## 当前主要回答任务：三选一的候选

A/B/C 在本轮作为互斥的主要回答任务，便于确认当前问题集基线；这不声称它们在世界中彼此独立。依赖可在求解时显露并按 D-002 回流，不能把三个候选自动累加成必填问卷。

| 主要任务 | 最小候选问题（尚未证明最小） | 可能支持的剧情判断 |
|----------|----------------------------|--------------------|
| A · 整体空间范围 | ① 当前称为“世界”的空间对象是什么、按什么划定整体边界？② 在该口径下，哪些尺度或范围表达足以描述其大小，哪些部分仍未知？ | 故事舞台是否容纳拟议地区、远行是否跨越世界边缘、地图之外是否仍有空间；几何范围本身不直接证明能否到达 |
| B · 行动或影响范围 | ① 谁或什么在何种条件与时间内行动、传递资源/信息或施加影响？② 可达或可影响的范围及主要限制是什么？ | 远行与隔绝是否成立、通信是否及时、组织能否维持控制；物理距离未必等同实际可达范围 |
| C · 认知范围 | ① 哪个主体在何时、凭何种信息认识世界？② 其已知范围、可信程度与未知边界是什么？ | 探索是否仍有未知、人物能否知道远方事件、地图与实际世界的差异是否足以支持情节 |

上述问题是比较候选的起点，不是完整问题树。范围确认后仍可能合并、删除、改写或补充问题，不能据表中条数认定充分性。

## 没有具体事件时，助手先做什么

助手仍可主动查资料、寻找参考和反例，列出上述多种定界框架，并用明确假设做用途对照。例如，仅假设当前关心“地图是否容纳几个区域”时，A 可能更直接；仅假设关心“边陲能否长期隔绝”时，B 可能更直接；仅假设关心“发现未知地域是否可信”时，C 可能更直接。这些是用于比较的假设，不表示用户已经选择了真实场景。

候选的作用是让创作者有可比较的具体对象可裁定。后续实际应用仍须共同明确 I-401；跨问题最低验证范围和证据强度仍由 I-402 承载。

## “最小充分”的四种待试检查

以下仅为候选检查，不是已获裁决的硬规则或自动停止算法：

| 待试检查 | 可共同检视的问题 |
|----------|------------------|
| 用途 | 每个保留问题的答案可能支持当前哪项创作判断？这种联系是否只是助手假设？ |
| 删除 | 暂时去掉该问题，是否仍能支持当前判断并回答原问题？是否遗漏了重要依赖？ |
| 继续细分的价值 | 再细分会改变当前判断或解决有影响的不确定性吗？若暂不能判断，是否需要先做有限分析？ |
| 综合性 | 把候选子答案放回原问题，能否形成连贯且有适用边界的回答，还是仍只是孤立信息？ |

这些检查如何操作、允许什么证据、何时足以停止细化，均待试行与创作者共同确定。不能用“删不动”或问题少就宣称最小充分，也不能因尚有未知而无限扩展。

## 有界的第二阶段候选流程（尚未执行）

以下是供裁定的试行安排，D-002 已确认的是两阶段主流程；本节细节尚未获确认。

1. 取得当前主要任务与问题集基线的确认，明确本次试行假设及不确定之处。
2. 对保留问题逐项组织证据、分析和暂定答案。可比较复用既有答案或联合求解的方式，但具体组织方式仍待共同确定。
3. 在确认的范围内综合回应“世界有多大”，说明答案适用的对象、条件、精度和未解部分，再共同检视能否支持所选判断。
4. 按 D-002，若求解需要改变范围、关键假设、精度或重要依赖，或综合答案不足，则回第一阶段重确认受影响部分。确认不是永久冻结；本节不自动授权新增问题或扩大本轮范围。

未获问题集确认前，本附件不进入分项求解，也不把假设演示记为真实剧情结论。

## NASA 候选参考：现实结构，不是设定依据

- [太阳系边缘在哪里](https://science.nasa.gov/resource/where-is-the-edge-of-the-solar-system/)区分行星终点、太阳磁场与引力影响等边界口径。它支持比较“边界依据不同，大小答案也可能不同”，不证明创作世界应使用太阳系边界。
- [地球事实](https://science.nasa.gov/earth/facts/)给出赤道直径 12,756 km、与太阳距离约 1 AU 等不同量度。直径和对象间距离回答不同关系；这可帮助比较尺度表达，不能代替创作者选择对象或单位。
- [奥尔特云事实](https://science.nasa.gov/solar-system/oort-cloud/facts/)以估算区间描述极远边界，并用光行时间和航行时间表达尺度。它可供比较空间范围、时间尺度和不确定性的表达；时间口径涉及不同传播或运动条件，不可直接作为虚构角色的可达能力。

这些官方资料已在前期资料查找中取得，仅作现实参考结构和定界启发；尚未经创作者采纳为世界事实，不关闭 I-401/I-402，不构成当前探针或方法可复用性的验证结论。
