## 方法对象与工作表示

阶段一从创作者的原问和现有上下文出发，逐步辨认需要回答什么、为什么需要回答、哪些内容相互依赖以及哪里仍不确定。动态问题关系图是协助思考的工作表示：随理解变化而增删、改写、合并或撤销，服务于形成**足以启动阶段二求解的候选结构，交创作者确认**。它不保证问题一定可解，也不表示答案或模型已经存在。

节点可以暂时承载需要支持的判断、待答问题、约束、必要未知等；关系可以表达依赖、支持、派生、约束、共享前置或冲突等。这些只是开放例子，不预定世界问题分类，不封闭节点或边的类型。遇到现有称呼无法表达的内容，先保留原意和理由，允许换一种表述。图无需覆盖全部上下文，也无需连成一个整体；原问及其整体意图始终保留在图外作为参照。简单问题允许不建图、不拆分。

这里的图不规定数据库、schema、存储格式或 UI。文字也可以表达关系；是否显式画图取决于它能否帮助当前理解，而非方法的必经门槛。

## 可反复调用的认知操作

表中操作是当前开放、非穷尽的工作候选，没有必经顺序。后续探针可能表明某项操作无用、需要拆分/合并/改写，或发现新操作；清单本身也须接受检验，不能变成固定步骤。助手根据当前困难选择、组合、重复或撤销操作；发现新关系可以回到原问，覆盖挑战可以引发合并或剪枝。操作名称不是问卷栏目，不要求创作者先自行拆题。

| 操作 | 助手如何作用于当前理解与关系结构 |
|------|----------------------------------|
| 发现 | 从原问、上下文及其出处中辨认尚未表达清楚的判断、问题、条件或未知，提出有理由且非穷尽的候选；标明哪些来自创作者，哪些只是分析者推断。既能新增，也能纠正已有内容。 |
| 展开依赖 | 对一个仍相关的内容追问：理解或处理它需要先知道什么、接受什么条件，或与什么联合考虑？说明关系为何成立及适用条件；区分答案支持某判断与求解必须依赖某答案，不凭语义相近连边，不强拆循环为单向次序。 |
| 拆分与合并 | 只有当不同所求、前提、精度或关系被混在一起而妨碍理解/交接时才拆分；同一回答足以处理多个内容且不丢失重要差异时可合并。保留与原表述的联系，避免细分后失去整体意图。 |
| 找共享前置 | 比较多个问题或判断是否依赖同一个条件、未知或依据，显式标出共用处及各自适用范围；共同用词不自动证明共享，共享前置也不预定共享模型。 |
| 识别真实冲突 | 检查表面分歧是否在同一条件下确实不能并存，还是范围、时间、精度或假设不同。能并存则保留；真正改变问题结构的创作取舍交创作者裁定，客观事实争议保留为待研究问题，不以投票或创作偏好证明其真伪。 |
| 剪枝 | 暂去一个内容或关系，检查是否丢失回应原问、支持保留判断或启动后续求解所必需的依据。冗余、离题或仅对已撤回分支有用的内容可删除或暂缓，保留理由与恢复条件；未解决的关键未知不能因难处理而消失。 |
| 挑战覆盖 | 设想当前问题都得到回答，原问是否仍可能缺少重要支持；反查遗漏条件、反例与被忽略的解释。连通、节点多或图形完整都不能证明覆盖充分。挑战相对于已说明的意图与边界，不追求穷尽世界。 |
| 判断何时够用 | 回看原问，判断当前结构能否说明后续应求什么、为何相关、必要条件与主要未知在哪里，以及继续展开会带来什么具体收益。足够时呈示候选与理由；仍存在影响所求的歧义时，定向协作或继续分析，不用无限展开代替判断。 |

资料、类比与反例可按需要帮助这些操作，但须说明来源、适用性及不确定性。发现需要研究只表示有收集或核验工作，不能记作已经获得证据。本版已完成一次隔离阶段一测试，未执行资料研究；记录见 [v0.6 运行 01](probe-01-stage1-test-v0.6-run-01.md)。

## 区分内容及其依据

创作者意图、客观问题、推断与证据是帮助辨认来源和认知地位的区分维度，不是穷尽且互斥的节点种类。图中的内容可相互关联，但须能辨认其性质与来源，不能因画成节点就具有同等事实地位：

- **创作者意图与取舍**说明想回答什么、答案用于什么、愿意保留哪些创作条件；创作者可以纠正或确认这些内容。
- **客观问题**表达在已说明条件下需要求证的世界状态、关系或后果；仍未知就是未知，不能以创作者确认某种取舍证明世界事实为真。
- **分析者推断**是助手对用途、问题或关系的暂定解释，应给理由、标不确定性，并允许撤销。未经确认的推断不能成为既定创作事实。
- **证据与研究动作**分别说明已有依据及其出处、接下来如何收集或验证；计划研究不等于证据，证据是否适用也需判断。它们不能冒充待求的世界结论。

这些区别用于防止混淆，不构成封闭节点分类。每项重要关系也应能说明是谁提出、根据什么、在什么条件下有效；条件变化时重审关系，而非维护图的形式稳定。

## 收束与创作者确认

助手准备呈示候选时，应能解释它如何对应原问，当前保留哪些解释和边界、主要问题所求及必要的答案形式/精度、重要依赖与共享前置、仍未确定的事项，以及为什么进一步展开暂时没有重要收益。必要信息尚不足时应明确缺口，不能用“可解”标签掩盖不确定性。这是相对于当前意图的定性判断，不是固定字段门槛，也不是唯一或数学最小结构的证明。

呈示的终点是**足以启动阶段二求解的候选结构，交创作者确认**。助手说明真正改变结构的待裁定处和推断依据，提供易于纠正的表述；创作者可以补充、删除、改边界或否定关系。确认前仍是候选。创作者确认的是创作意图、取舍及可采用的问题结构，不是对客观命题真实性或最终可解性的担保。若无法支持启动求解，则保留未就绪结论与具体原因。

## 图表述风险与约束

| 风险 | 约束 |
|------|------|
| 节点化丢失整体意图 | 始终保留原问、上下文出处与回指；拆分后回看整体，必要时合并、改述或不拆分。 |
| 边实化：暂定联系被当成事实关系 | 重要关系有理由、有条件、标明推断或证据及不确定性；允许撤销，不因已有一条边而默认其真实或永久有效。 |
| 连通性幻觉 | 不以路径存在证明支持充分或依赖真实；用覆盖反例挑战，允许孤立内容、多个局部结构和未确定关系。 |
| 过度展开 | 每次扩展说明其对原问或交接的具体价值；无重要收益则停止，允许剪枝、不建图或保留整体问题。 |
| 阶段一越界建模 | 只形成问题与关系候选，不提前构造世界机制或回答领域问题；发现须靠求解才能澄清的未知时明确交接条件，必要时由后续发现回流。 |

## 阶段二边界与本版状态

从创作者确认的问题结构逆向识别模型依赖，属于阶段二的后续研究，本版不设计其方法。问题关系不直接等同模型依赖，也不意味着一问题一模型。阶段二的新发现若改变所求、边界或关系，应带具体原因回流阶段一，修订受影响部分。

本版已用与 v0.5 相同的“世界有多大”输入完成一次隔离阶段一操作复测，尚未接受；既有 v0.5 结果保留历史。此次只足以提交创作者定向纠正，不够启动明确阶段二求解；尚无创作者纠正、未交接 W2，没有回答原问、构建世界模型或图工具。I-401/I-402 状态及既有验证门禁保持不变，第二个不同真实创作问题尚未选定。此次文档版本升为 0.6.1 仅同步测试事实，实际运行基线为 v0.6.0，方法操作内容未改。

## 后续探针如何检验图式操作

后续检验先固定候选版本，仅输入“世界有多大”原问及当时实际可提供的上下文，不预载案例图或期望答案。只运行阶段一，观察助手如何增删、改写关系，拆分与合并内容，发现共享前置，区分真实冲突，剪枝、挑战覆盖，以及说明停止/交接理由；同时观察创作者能否理解并纠正候选结构。观察重点也包括哪些操作无用、需调整或遗漏，而非逐项完成清单。

分别记录方法操作证据与本次案例节点、关系结果；案例的边和节点不升级为方法本体，单次测试只提供局部证据。上述安排已有一次孤立阶段一操作运行的局部证据，见 [E-015](../02-execution/E-015-probe01-stage1-v06-test-result.md)；它是同案例版本复测，不是第二例。共享前置、真实冲突、合并、创作者可纠正性、创作者实际回答效果和阶段二可求解性仍未测；v0.6 仍未接受。
