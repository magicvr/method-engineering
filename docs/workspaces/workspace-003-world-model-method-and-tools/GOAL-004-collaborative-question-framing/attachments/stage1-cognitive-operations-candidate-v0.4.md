# 阶段一认知操作与 W2 交接候选 v0.4

**draft / candidate / unaccepted。** 本版根据 [D-005](../01-decision/D-005-stage1-method-level-correction.md)、[D-007](../01-decision/D-007-coexisting-judgments-and-relations.md) 及 v0.3 的独立复核意见修订。它规定世界模型构建范围内的阶段一认知操作候选；不把任何测试案例的具体拆解、领域结论或模型提升为通用结构。

## 阶段一的任务与边界

输入是创作者提出的、在实际创作中有必要回答但含义或范围尚未充分确定的客观世界问题，以及现有创作上下文。阶段一由助手主动把原问与上下文转换为一个**相对于明确用途、边界、精度和保留分支的可解问题结构候选**；创作者可据此修订并确认交给阶段二的问题结构。

阶段一同时保留创作目的、创作者判断/选择与客观问题之间的联系，但三者不混为同一种节点：

- 创作目的、判断和取舍用于确定问题为何重要、哪些答案才有用，以及问题结构适用的范围；
- 客观世界的状态、规律、关系和后果才可能成为交给 W2 的求解节点；
- 一个客观答案支持某项创作判断的关系，与客观问题节点之间的求解依赖分开表示。

语义澄清、外部资料检索、创作者选择、助手分析动作均是阶段一的分析对象或工作，不冒充客观问题节点。“可解”指已说明客观问题所求、答案形式、必要条件/边界与精度、以及与创作用途的关系，足以让阶段二发现能力和缺口；不表示答案已知或模型已建。

## 可往返的认知操作

下列四组操作是助手推进理解的认知动作，不是固定顺序、填表步骤或穷尽分类。助手根据当前不确定性在它们之间往返。

### 1. 解释原问与用途

- 保留原问，并结合对话和已有创作材料推断它要支持哪些具体创作判断、限制或后续行动，以及为什么必须回答。
- 将明确表达的创作者意图与助手推断的用途分开标注；提出的用途候选默认非穷尽、允许并存、合并、修订或删除。
- 对关键用词提出有依据的不同解释，指出它们是否会改变所需结论；不把不完整输入直接打回给创作者要求自行拆题。

### 2. 逆推所需客观依据并处理未知

- 对每项仍相关的创作判断反向追问：哪些客观状态、规律、关系或后果会改变该判断，缺少什么依据会使判断无法检验？由此推导待答内容，而不是按学科名词列目录。
- 区分创作者意图/取舍、客观世界问题、可通过研究处理的外部知识或语义未知，以及助手下一步分析动作。混合内容先分离；不将创作者选择伪装成世界模型缺口，也不要求创作者代做问题分解。
- 按需查找资料、参考、类比和反例，帮助生成、限制或挑战解释；说明来源的适用条件及其不能证明什么。研究不能替创作者决定本世界设定。

### 3. 组织可回答单元与关系

- 将必要客观依据写成候选问题单元。每个单元至少能看出对象/所求、什么样的回答算相关，以及适用前提、边界或精度要求；尚未知道答案不妨碍形成问题。
- 分别绘出：① 客观问题间的先后、前置、共享输入、范围约束、联合处理或反馈/循环依赖；② 客观答案对一项或多项创作判断的支持关系。支持关系不自动构成求解依赖。
- 分析用途或解释候选之间是并列、包含、前置、派生、互相约束还是冲突。可并存时保留关系；只有确有不能并存的创作取舍且差异实质改变问题结构时，才请创作者裁定。未决但可继续分析时保留明示的条件分支，不把助手偏好的分支当作 canon。

### 4. 挑战、压缩并确定交接状态

- **充分性反例**：尝试构造所有当前候选问题都已回答、但仍缺少支撑某项保留创作判断的重要依据的情形；据此补前提、节点、关系或边界。充分性针对保留用途与分支，不表示客观答案会替创作者作出选择。
- **必要性删除**：暂去一个问题，检查是否会使创作者失去评估任一仍保留选择的可行性、后果、约束或重要差异所需的依据。若只对某分支必要，记为条件必要；对所有保留分支都无必要支持时，才考虑删除或暂缓。
- **合并/细分**：若同一回答能满足两个节点且不丢失重要条件、精度或依赖，可考虑合并；仅当合并隐藏了会改变判断或阶段二可交接性的不同所求时才细分。
- **边际价值与停止**：只有在能指出继续细分会改变所需判断依据、解决实质歧义/遗漏、或改善阶段二的能力/缺口识别时才继续。若更细粒度没有这类具体收益，不因形式完整而继续展开。

得到的是相对于当前创作用途、明确边界/精度和保留分支的**最小充分候选结构**，不是全局、数学或唯一的最小值。创作者尚未裁定多个分支时，不声称存在对所有可能意图都最终最小的单一结构。

## 定界、求解与交接的判别

| 当前未知 | 判别问题 | 处理位置 |
|----------|----------|----------|
| 影响定界的含混或创作者选择 | 不同解释/选择会否改变所求结论、范围、必要节点、依赖或答案形式/精度？ | 阶段一研究、比较并分析影响；属于创作取舍的交创作者决定。可保留显式条件分支；不得静默选定。 |
| 可交给阶段二的未知 | 已清楚要回答什么、答案如何支持用途且所需条件/精度/依赖已说明；未知的是世界状态、关系、能力或机制是否成立/如何成立？ | 随经创作者确认的问题结构交给 W2 发现能力、判定缺口和构建模型；阶段一不提前求答案。 |
| 阶段二揭示的问题结构遗漏 | 新证据表明所求边界、前提、精度或依赖不足，或答案仍不能支持原问？ | 带具体发现回流阶段一修订受影响结构；不推翻无关节点，不把回流变成重复确认流程。 |

**关键界线**：不知道答案，可以是阶段二的工作；还不知道究竟要求什么答案，通常仍是阶段一的工作。若结构未决处可被清楚表示为创作者认可范围内的条件分支，可先形成条件化候选；未获创作者确认的分支不作为既定 canon。

## 可交接候选的定性检查

准备向创作者呈示并请求确认前，助手应能说明：

1. 每个候选客观节点都能指出对象、所求和足够的答案形式/条件/精度，不再是“接下来研究什么”或“由创作者决定什么”；
2. 重要的节点间依赖、共享前提、边界和条件分支已可辨认；尚未解决的创作意图与助手假设均已标明；
3. 能追溯每个节点如何支持一项或多项仍保留的创作判断；充分性反例检查未留下已识别而未处理的关键缺口；
4. 必要性删除、合并和细分检查相对于保留用途/分支有理由；继续细化已没有具体、重要的定界或可交接收益；
5. 剩余主要未知属于答案、世界模型能力或机制，而不是仍不清楚“要回答什么”。

这是一组可解释的定性判断，不是机械门槛或创作者填表。助手应先呈示候选及依据，明确标出真正改变结构的创作者裁定点，并给出简洁的修改入口（增补、合并、拆分、删除、改边界或纠正关系）；不得把拆题工作退还给创作者。只有创作者确认后的客观问题节点、客观依赖、适用前提/边界和必要精度进入阶段二。创作用途与答案支持关系用于判断相关性和够用程度，不成为模型缺口。

## 与阶段二的接口

阶段二继续使用父级 W2 的能力发现、缺口判定（状态、组合、精度、机制）与最低充分机制模型构建。一客观问题不对应一模型；多个问题可共用能力或模型，一个问题也可能需要多个能力。阶段一不把问题清单预先等同于模型清单，也不承担世界答案求解。

阶段二若发现被确认的问题结构无法支持裁决，应给出具体证据并只把受影响的问题、前提、范围、精度或关系回流阶段一。创作者的意图、取舍和最终设定仍由创作者决定。

## 验证时观察什么

候选形成后，可用真实创作问题检验这些操作。测试需先固定候选版本，输入原问与当时实际可得上下文，不预载案例拆解或预期答案；只运行阶段一，到可交接候选为止。分别记录方法证据与案例结果：

- **方法证据**：助手是否主动重建实际用途且标明推断；能否借资料与反例分析而不把任务退给创作者；是否保留可并存用途并分析关系；是否区分创作者选择、客观问题和助手研究动作；能否逆推所需依据、组织答案形式与依赖；能否按保留用途检查充分性、必要性和细分价值；能否说明剩余未知属于哪个阶段、何时停止，以及交接候选是否可被创作者修订。
- **案例结果**：本次产生的用途候选、客观问题结构、依赖、答案和模型。它们是案例测试结果，不直接成为通用分类或结构。

若助手强迫 OR、要求创作者先自行拆题、把创作者选择当模型缺口、混淆支持与求解依赖、遗漏重要结构关系，或不能说明停止/交接理由，则记录为方法缺口及失败机制。一次测试只提供局部证据；跨案例迁移和真实创作充分性仍须按目标信息门禁核验。
