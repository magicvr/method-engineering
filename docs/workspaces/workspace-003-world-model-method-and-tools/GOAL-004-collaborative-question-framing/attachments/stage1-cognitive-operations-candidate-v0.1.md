# 阶段一认知操作与 W2 交接候选 v0.1

**draft / candidate / unaccepted。** 本附件按 [D-005](../01-decision/D-005-stage1-method-level-correction.md) 整理世界模型构建范围内的阶段一方法，不是案例问题结构或已验证规范。

## 阶段一要完成的转换

输入是不完整的真实原问与现有创作上下文。输出是可交接 W2 阶段二的明确可解单元及其依赖结构，并能说明各单元如何支持原问对应的创作判断。模糊是助手需要处理的工作内容；创作者仍裁定意图、取舍和创作选择，助手不自动代定 canon。

“可解”不等于已答或已有模型：问题含义、所需答案、条件与精度、支持需求已足以交给阶段二处理。答案或模型暂缺可以成为阶段二能力发现及缺口判定的对象，不能反向要求创作者先提供它们才允许定界。

## 认知操作候选

以下操作允许往返迭代，不是依次填写字段的流程。适用的顺序取决于当前理解与证据。

- **重建目标判断。** 保留真实原问与上下文，从中推断答案将支持何种创作判断，区分明确意图和助手假设；存在实质取舍时给出可比较解释，由创作者裁定。
- **定位有影响的歧义与未知。** 分析哪些不同解释或缺失信息会改变目标判断、答案有效性或后续处理方式。混有非客观创作选择时先协助区分，再按创作者选择处理，不以无限枚举歧义代替分析。
- **按需研究。** 为当前理解困难查资料、参考及反例，核对适用条件和证据边界；研究的作用是支持或挑战解释与推断，不直接把参考变成世界设定。
- **从判断逆推依据。** 思考作出目标判断需要怎样的答案或证据，再推导需要处理的单元。每个单元说明问题含义、答案形式、条件与精度、所支持的判断；不能仅凭领域名词列出目录。
- **发现依赖。** 明确哪些答案有先后要求、哪些约束另一些答案、哪些共用输入、哪些需要联合处理。可存在循环；循环标注为联合处理及其未决处，不强行拆为有向无环图，也不据此宣称已求解。
- **压缩并检视整体。** 用下述候选检查挑战问题结构的充分性与必要性，调整节点与依赖，形成有依据的结构候选，并标出需要创作者裁定的意图、前提与取舍。创作者对这些实质事项的裁定，是阶段二使用问题结构的接口条件，不是阶段一的方法主体或主要工作成果。

## 最小充分检查（均为 candidate/unaccepted）

| 候选检查 | 认知动作与局限 |
|----------|----------------|
| 充分性反例 | 尝试构造“这些单元都有答案，但目标判断仍不能作出或仍可能失效”的情形，发现遗漏前提、依赖或范围问题；没有找到反例不证明普遍充分 |
| 必要性删除 | 暂去一个单元，检查原问判断与有效性是否仍可支持；保留理由应联系用途及依赖，不能只因列表已有该项 |
| 细分边际价值 | 分析进一步细分是否会改变判断、有效性或可交接性；有价值则提出调整，无明确价值不自动无限展开，具体停止条件仍待共同确定 |
| 综合回应 | 检视未来子答案应如何共同回应原问，是否仍缺从依据到判断的联系；此时检视支持结构，不伪造尚不存在的答案 |

目标是相对于用途、边界和精度的局部充分与不可约候选，不承诺全局数学最小。具体检查方式、证据要求和停止规则尚未接受或验证；不能把四项变成强制问卷或机械门禁。

## 输出与 W2 接口

输出需能表达原问与目标判断、问题节点、答案形式与精度、依赖关系、前提/证据/未知，以及子答案如何支持各判断和原问。助手假设、可核对事实和创作者决策须能区分。表达形式可随问题而变，上述是需要保留的关系，不要求固定表格。

阶段二接收该结构，沿用父级 [W2 v0.4](../../GOAL-002-r2-method-working-version/attachments/world-model-method-working-version-v0.4.md) 的能力发现、缺口判定（状态、组合、精度、机制）与最小充分机制模型构建。一个问题不对应一个必建模型；多个问题可能共用能力或模型，一个问题也可能依赖多种能力。阶段一不预先把问题节点等同模型清单。

阶段二的答案应回到原问进行综合。若阶段二的新证据或综合不足表明需要改变范围、前提、精度或重要依赖，按 [D-002](../01-decision/D-002-two-stage-conditional-return.md) 将受影响的问题结构返回阶段一修订；涉及创作意图、前提或取舍的实质变化仍由创作者裁定。回流用于修订问题结构，不是反复确认的流程。本附件仅说明接口，不执行阶段二，也不改写 W2 正文。

## 以后如何观察测试结果

方法候选形成后，探针可作为黑箱输入。测试时应分别保存：

- 方法能力证据：认知操作如何推进理解、能否发现依赖、是否达到可交接状态，以及暴露的缺口与失败机制。
- 案例结果：该次领域子问题、具体关系、答案和模型。它们只属于该次案例，不能直接升为通用分类、流程或固定结构。

方法修订可依据有证据的操作缺口提出候选，不把案例内容照搬为方法。跨问题最低验证范围与证据强度仍待 I-402 共同确定；真实场景充分性仍待 I-401，不以本附件代替验证。
