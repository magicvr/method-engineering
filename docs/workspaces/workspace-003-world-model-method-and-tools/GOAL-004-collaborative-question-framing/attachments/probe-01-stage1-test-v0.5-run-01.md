## 案例结果：非穷尽、未确认的用途候选

| 编号 | 候选用途 / 判断 | 来源状态 | 暂定关系 |
|------|----------------|----------|----------|
| P0 | 本次问题实际存在且须在故事中得到回答 | 创作者明确输入 | 其他用途候选可能为 P0 提供回答材料；P0 本身不等同于具体客观问题 |
| P1 | 让故事能给“世界”整体范围/尺度以可理解定位 | 助手推断，来自“世界有多大”字面 | 可能并行于 P2；也可能约束 P2 的适用空间域 |
| P2 | 让故事中的地点关系、远近、行动或跨越有可判断的空间依据 | 助手推断，来自“剧情中必须解答”；尚无具体场景证据 | 可并行于 P1；某些行动问题可受 P1 范围约束，也可能反向要求扩展叙事覆盖 |
| P3 | 若故事内回答依赖角色/叙述者掌握的信息，检查其回答依据及范围 | 条件假设；“剧情需回答”本身不能证明必须存在某一在世界内的信息来源 | 只在该叙事处理方式成为创作要求时，与 P1/P2 相关；是否是客观世界问题仍待分析 |

P1～P3 是开放候选，不表示完整、必须保留或互斥。当前没有证据证明真实冲突。P3 可能是回答呈现方式的创作约束，而不应自动成为 W2 的客观求解节点。

## 案例结果：客观问题候选与关系

| 节点 | 暂定所求与答案形式 | 条件/精度候选 | 支持关系 |
|------|------------------|--------------|----------|
| N1 范围与尺度 | 被称为“世界”的指定空间，其范围及大小指标；可用边界描述、尺度区间或相对比较回答 | 对象边界、相关故事时段和足够区分创作者关心差异的精度未定 | 支持 P1；仅条件性地支持 P2 |
| N2 空间联系 | 故事相关地点/区域之间的位置、连接与阻隔；关系说明或连接示意 | 只覆盖对保留用途有影响的地点，不预设完整制图 | 支持 P2，也可能辅助 P1 |
| N3 行动可及与跨越条件 | 指定行动者、方式、资源和时限下的可及范围、所需时间或代价 | 仅在行动/跨越判断确属用途时保留；精度按是否能区分相关剧情判断确定 | 条件性支持 P2 |
| N4 回答来源的知识依据 | 若采用依赖角色/叙述者知识的讲述方式，检查其能依据什么回答及信息覆盖/局限 | 仅在叙事确实需要该类信息一致性判断时考虑；当前还未证明它是世界模型问题 | 条件性支持 P3 |

暂定求解关系：创作者确认的对象范围将约束 N1/N2；N2 仅在相关行动依赖空间联系时前置于 N3；N1 只有在采用全域尺度推导可及范围时才条件性前置于 N3。N1～N3 到 N4 是核对回答者认知与世界结论的一种条件比对输入，不是所有节点都必须先求出的依赖。

支持图与求解图分开：N1→P1、N2/N3→P2、条件性 N4→P3/P0 表示答案支持；以上不直接确定节点间先后。用途修订造成的重定界属于阶段一返回，不是求解依赖。

## 相对充分性、必要性与停止

- **充分性反例**：若只得到 N1，整体范围仍未必说明具体旅程体验；若保留 P3，N1～N3 已答也不能说明故事内回答者依据。后两种缺口均依赖创作者是否保留相关用途。
- **必要性删除**：N1 只对 P1 用途候选必要；N2/N3 对行动用途条件必要；N4 仅对特定叙事信息来源用途条件必要。若创作者不保留相关用途，对应节点可能可删。
- **合并/细分**：整体尺度与局部连通若同一答案精度足够可合并；若影响判断的对象/精度不同可分开。N2/N3 暂分因空间联系与行动条件不能互相推出。N4 暂独立，但其是否属于客观问题仍未确定。
- **停止判断**：不再展开地形、交通方式或信息传播等更多子项，因为目前没有具体用途依据证明这些细分有价值；同时暂不交接，因为“世界”边界及实际剧情用法仍会改变节点与精度。

本次输出只能称为**条件化结构候选**，不能称为本创作的最小充分问题集或 W2 可交接结构。它的可用性取决于创作者对真实故事用途的修订。

## 方法表现评估与待观察风险

### 已观察到的能力

- 在一个输入中保留多个用途候选，没有把“世界范围”与“剧情行动”强制二选一。
- 将创作者已确认的必要性要求与助手推断的具体创作用途分开标注。
- 将可交接的客观问题候选、求解依赖和答案支持关系分层。
- 通过条件必要性与未交接判定防止把所有合理想象都当成已确认需求。

### 局限或潜在方法缺口

- **用途扩张风险**：P2 和尤其 P3 主要从“剧情要回答”推断；执行者标注了推断/条件，但尚未说明为何这些候选足以进入主动问题集，而非仅作备忘。N4 可能把叙事呈现方式过早转换成世界模型问题。
- **协作出口未充分实测**：执行者说明了需要创作者上下文和它会改变哪些节点，但没有形成一个低负担、针对结构差异的具体协作提问；因此尚不能证明方法会主动完成下一步共同定界，而非停在分析报告。
- 没有创作者校正，无法判断 P1～P3 的相关性，也无法确定上述支持、依赖与删减检查是否契合真实剧情。

这些是本次方法表现的观察与待确认风险，不是已裁定的通用方法缺陷。需由创作者给出的实际用途/剧情情境和后续操作证据进一步判断；不得将 P/N 节点复制为通用方法结构。
