# 探针一 · 阶段一判断与问题关系候选 v0.1

**仅为本次测试输入产生的案例结果，不是通用方法结构；尚未由创作者确认；不含答案或世界模型。**原始输入为“世界有多大”。创作者补充：该问题真实，每个世界观都必须回答，剧情中必须得到解答。创作者进一步纠正：剧情可行性和叙事范围一致性可同时成立；当前任何判断候选都不得被当作穷尽集合。

## 资料如何帮助定界

- Oshan 等人的空间尺度综述区分了地理范围、观测/测量分辨率与过程尺度，并指出“scale”在不同领域和任务中存在多种用法。这支持将“世界的总外延”“故事所覆盖的空间”和“某种空间过程有效的范围”分别作为可能候选，而不把它们压成一个含义；它不表示本案例必须回答全部维度。[论文](https://link.springer.com/article/10.1007/s10109-022-00384-8)
- Piatti 等人讨论虚构世界的地理表达，指出虚构情节的地点可从现实可识别空间延伸到完全想象空间，地图只是处理叙事空间的一种方式。这支持区分客观世界外延与叙事中涉及、呈现的空间，不要求本案例必须制图。[论文](https://doi.org/10.1179/174327711X13190991350051)
- Weber 等人的叙事地图综述指出，setting 不只涉及地点，也涉及社会语境及空间叙事尺度；跨空间和时间的故事有时需要多尺度表达。这支持保留多个可并存的尺度判断，具体是否相关仍待创作者裁定。[论文](https://doi.org/10.1080/00087041.2019.1633103)

资料用于生成和挑战假设，不代表创作者意图，不是世界观事实或 finding 关闭证据。

## 暂定目标判断

以下是从现有输入与参考中提出的开放候选，允许并存、合并、补充或删除；关系判断也暂定：

| 编号 | 可能需要支持的判断 | 状态 / 适用条件 |
|------|--------------------|-----------------|
| J-01 | **客观世界的空间外延**：故事所说的“世界”指什么空间对象、其总体范围到哪里；“大小”需要何种尺度表达 | 候选。具体 referent 和尺度含义待澄清；不预设要给出单个数字 |
| J-02 | **叙事涉及的空间范围**：哪些地方/区域需要纳入故事的设定和情节关系 | 候选。可小于客观世界外延，也可能与其重合 |
| J-03 | **情节相关过程的空间作用范围**：情节实际依赖的行动、接触或影响能跨越何种空间范围 | 候选。具体过程尚未从剧情上下文识别，故不是已确认的子问题目录 |
| J-04 | **足够的尺度与精度**：以上判断需要细到什么程度才会改变创作判断 | 横向约束候选；不能先规定统一量纲或精度阶梯 |
| J-05 | **被角色/读者认识或呈现的空间** | 条件候选。只有当剧情依赖角色所知、可达、可绘制或读者认识范围时才加入；与客观外延分开 |

J-02 与 J-03 可以同时成立。J-01 可能包含 J-02，也可能因“世界”指涉被创作者界定为故事空间而与其重合；现有证据不能确定。J-01 对 J-03 的客观可行范围构成约束，而 J-03 也可能反向说明剧情实际要求覆盖多大范围，故暂记为相互约束/迭代关系，不强行排成单向层级。J-04 横向限制 J-01～J-03 的答案精度。J-05 目前只作为条件候选，不默认加入核心集。

## 暂定问题结构

```text
原问：世界有多大？
  ├─ Q-01 澄清“世界”在本创作中的指涉，以及所问的空间尺度
  │    ├─ Q-02 确定客观空间外延 / 故事涉及的空间覆盖之间的关系
  │    └─ Q-03 找出情节真正依赖的空间作用范围（具体过程待剧情上下文）
  ├─ Q-04 确定何种精度足以支撑相关创作判断（横向约束 Q-02、Q-03）
  └─ Q-05 仅在角色/读者空间认知影响剧情时，再处理其已知或呈现范围
```

依赖不等同于固定树：Q-01 是解释其他节点的前置问题；Q-02 与 Q-03 之间暂为相互约束，可并存，必要时联合处理；Q-04 是跨节点精度约束；Q-05 是按情节用途启用的条件分支。该结构尚不是最小充分结论。

## 当前仍需的创作上下文

助手先前把 J-02 与 J-03 误作二选一；创作者已指出两者可同时成立。当前主要未知是：故事中的什么判断、场景或情节后果依赖这类尺度信息。助手可在现有“剧情必须解答”的说明下继续提出结构候选；随后由创作者补充、改写、合并或删除相关判断，不要求创作者自行拆题。若补充的情节信息使资料检索能消除或限定某些候选，再按需查询参考。
