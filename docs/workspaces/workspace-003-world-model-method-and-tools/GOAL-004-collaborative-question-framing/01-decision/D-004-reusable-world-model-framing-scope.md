用户明确选择：现有 GOAL-004 承载世界模型构建范围内的可复用协作定界方法，无须新增治理子目标，不扩为跨领域通用问答。

模糊的真实创作问题可以作为入口。助手主动协助理解用途，查找资料、参考与反例，分析并提出可比较的定界候选；创作者裁定创作意图与取舍。对属于客观世界模型状态、规律、关系或后果的部分，形成相对于当前创作判断的最小充分问题集，逐项求解并综合回答原问题。
