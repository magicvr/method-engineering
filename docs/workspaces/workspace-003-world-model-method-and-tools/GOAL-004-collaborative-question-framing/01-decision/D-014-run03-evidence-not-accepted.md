# D-014 · 裁定 run-03 证据不采信并在 v0.10.1 上重跑

## 裁定来源

2026-09-27 创作者就 [D-013](D-013-v0101-rule-c-restored.md) 第 3 项「run-03 证据地位留待裁定」作出选择：**不采信** run-03 为方法行为证据，并在补正后的 [v0.10.1](../attachments/stage1-framing-method-candidate-v0.10.1.md) 上**重跑**。

## 决定

1. **run-03 的方法行为证据不被采信**：其基线 v0.10 缺规则 C 定义节，不是完整意图版本。该记录保留为**历史样本**，不作为方法表现证据、不作为 v0.10 / v0.10.1 的通过依据，也不作为任何 finding 的闭合依据。
2. **在 v0.10.1 上重跑（run-04）**：仍由隔离执行者执行，只读 v0.10.1 与给定输入；**基线指纹须与 v0.10.1 文件一致并写入记录**。
3. **run-04 必须逐项核对规则 C**：阅读后先确认该文件是否**完整载明其引用的全部规则**（特别是规则 C）并复述其条件；「出口退回检查」中每个候选回问项须逐项说明规则 C 的适用——满足或未满足哪一条。
4. **不追加方法修改**：run-03 暴露的基线缺陷已由 D-013 修复（补回规则 C）。未处理项不变——触发可判别性缺陷（全局「真触发 vs 清单遍历」无外部判据）；L1/L2 分层对父级 W2/W3 的潜在影响仍待父级按 P-006 处理。
5. **run-03 的案例产物**维持「未获判定、不引用」状态，不因本次裁定转为可用。

## 未选方案

- **采信 run-03 为局部正证据**（D-013 第 3 项的建议 A 案）：创作者未采纳；治理口径取「基线不完整即不作证据」。
- **只补测规则 C 相关行为而不重跑**：无法覆盖门槛／假定／层级三项在同一完整基线下的联合表现；未选。

## 处置与边界

- 本轮不新建子目标、不改目标 `status` / `progress`；不进入 W2；`I-401` 仍 `open`、`I-402` 仍 `collecting`。
- run-04 的事实见 [E-022](../02-execution/E-022-probe01-v0101-run04.md) 与其运行记录。
