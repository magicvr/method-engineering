# D-025 · 裁定 run-08：唯一阻断性执行错误为 U-6，按 B2＋B3 整改并以修正结构续跑 run-09

## 裁定来源

2026-09-27 创作者对 run-08（[运行 08](../attachments/probe-01-stage1-test-v0.15.1-run-08.md)，基线 v0.15.1）的判定：**不判运行行为完全通过，但保留绝大多数局部正证据**；**唯一明确的阻断性执行错误是 U-6**。

## 判定与理由

1. 第 3 轮覆盖攻击**已经成功构造**出「**尺度恒定 vs 随进程变化**」的反例，并证明该差异在**当前问题集答案相同**的情况下**仍然改变原问所求**（**单值 → 轨迹**）。依**规则 G→E 的证据接口**（G.4.2：差异点本身即构成当前案例内的新分析依据），**不能**随后又以「输入未直接提供时间性」为由判 **规则 E 条件①不成立**。
2. 因此 **U-6 必须重新经过规则 E**；按本轮记录，**它应通过准入**，并**进入规则 F 归属**。
3. 其余行为**作为正证据保留**：多次换向、候选差异逐项清算、**未制造 B1**、**无假定污染**、以及 **G.3 阻止非法交接**（攻击仍然高产时，**不得**把「单次运行到时间了」伪装成方法允许的停止条件）。
4. **暂不修改 v0.15.1 方法正文**——**先按正确规则整改本运行记录**；若后续隔离执行**再次出现同一错误**，再判断是否属于**文本歧义**而需要修方法。

## U-6 的整改处置（B2／B3 拆分，创作者指定）

- **B2 部分（阶段一收敛）**：阶段一的问题结构**必须允许**「**尺度不是单值，而可能依赖时间／进程／条件**」——即把**所求**从**单一尺度值**扩展为**带条件槽的尺度关系**。**该部分应在阶段一收敛。**
- **B3 部分（转写为求解项）**：目标世界**实际上是否存在**这种变化、**依赖什么条件**、**具体关系是什么**，属**世界客观事实** → **转写为阶段二求解项**（新设 **S-2**，按 F.2 四要素）。
- 因此 U-6 **不再**作为「未过门槛的候选池项」，**也不由创作者裁定**。

## run-09 的处置

- **选 A，但先整改**：先完成 run-08 记录的 U-6 整改，**再启动 run-09**。
- **run-09 不是从空白开始的独立运行**，而是**同一案例在修正后的当前结构上继续执行规则 G**：**继承**已成立的问题结构、覆盖攻击记录、候选池与清算结果，再执行「保持当前问题集全部答案不变，最大化两个世界在原问整体判断上的差异」。
- **G.3 阻断交接是正确行为**；**不得**把「单次运行到时间了」当作合法停止。
- **新增观察项：「coverage 长期不收敛」**（当前仅一轮出现该状态）——**不立即**新增固定轮数、预算或人为停止规则；若后续**多个 continuation cycle 仍持续产生独立且有价值的新维度**，**再单独审查**方法是否缺少**有界收束机制**。
