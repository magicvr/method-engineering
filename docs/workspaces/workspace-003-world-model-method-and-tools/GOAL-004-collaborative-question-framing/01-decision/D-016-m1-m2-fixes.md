# D-016 · 修 M1／M2 并形成 v0.11.1（run-05 固定基线）

## 来源

2026-09-27 创作者在 run-04 判定中给出的选择：**先修 M1／M2（→ v0.11.1）再跑**。两项缺口由 run-04 的隔离执行者报告、经编排器核对属方法文本缺口（非执行者理解偏差）：

- **M1**：层级规则第 3 条内部张力——需求接口既被写成「不改变 L1 的客观结构」，又被要求「说明它改变了 L1 的哪一项」。
- **M2**：**变量取值域内的具体项是否需先过规则 E 门槛**，方法文本未载明。

## 决定

1. **M1 修法**：需求接口的判定标准由「必须说明它改变了 L1 的哪一项」改为「**必须指名 L1 需产出的具体信息/精度项**」。语义澄清——接口**不改变 L1 的客观问题内容**，它改变的是 **L1 的产出需求登记**；因此判据是可指名的具体信息/精度项，**指不出来就不写**。同步更新层级规则第 3 条、出口退回检查第 5 项、风险表「层级混合」行，消除同一条规则内的张力。
2. **M2 修法**：明确**变量取值域不是结构项**——进入结构的是**变量本身**；**取值域是「后果差异记录」**，每项须标**依据类型**，并说明该取值对 (a) 原问所求、(b) 阶段二所需模型类型、(c) 必要问题结构的影响（这三项同时是**规则 F 的分级判据来源**）。取值域中的某一取值**若要成为承载项**，它就不再是取值域记录，必须作为候选按规则 E 过门槛，未过者留候选池；取值域**不得被表述为「已采纳」**，也不得单独构成交接结构。
3. **后续检验观察项**补两条：跨层接口是否指名了 L1 需产出的具体信息/精度项；取值域是否只作后果差异记录、标了依据类型、未被表述为「已采纳」或单独构成交接结构。
4. **未修项**：「12/14 触发无外部判据」**不因本版修复**，继续观察。

## 未选方案

- **保留 M1 旧措辞、只在规则 F 里补充**：同一条规则内的张力仍在，下一轮运行会再次报告同一缺口；未选。
- **M2 采用「取值域每一项都须过门槛」**：会把合法的后果差异记录一并卡住，且与「变量本身进结构」重复设门；未选。
- **把 M2 留到下一版**：创作者要求先修再跑；未选。
