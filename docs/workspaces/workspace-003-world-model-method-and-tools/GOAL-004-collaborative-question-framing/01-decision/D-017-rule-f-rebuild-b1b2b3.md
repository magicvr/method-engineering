# D-017 · 裁定 run-05 并据 B1／B2／B3 分流重构规则 F

## 裁定来源

2026-09-27 创作者对 run-05（[运行 05](../attachments/probe-01-stage1-test-v0.11.1-run-05.md)，基线 v0.11.1）的判定：**交接不通过，但执行行为正确——暴露的是方法规则的内部死循环**；保留 M1／M2 修复正证据，**据此修规则 F，不回退整体方向**。

确认的死循环：**规则 C 已规定客观待答内容应作为研究缺口保留，而规则 F 又把「会改变模型类型／必要问题结构」的未知一律定义为必须在阶段一清零的 V-阻断** —— 于是阶段二本来就要回答的客观命题变成「既不能收窄、又不能回问、又不能交接」。

## 决定（按创作者给定的定义）

1. **规则 F 重构为「未决项分类与归属」**，且**不再以「是否改变阶段二所需模型类型／必要问题结构」作为分类判据**——该判据只说明该未决项重要，不说明它应由谁、在哪个阶段解决；分类看**未决的原因与归属**：
   - **B1 创作者取舍型**：不同取值意味着**创作者要求回答不同的问题**，或采用**不同的创作边界** → 分析无法收窄后按规则 C 回问；交接前**必须已裁定**。
   - **B2 定界结构型**：未决的是**阶段一对问题本身的理解或结构**，而非世界事实；**不解决就无法明确阶段二到底要回答什么** → **必须在阶段一继续分析**；分析后若属创作者取舍 → **转 B1**，若属客观世界命题 → **转 B3**；**不得把「会改变模型结构」本身作为 B2 判据**。
   - **B3 客观求解型**：问题已经明确，该未决项本身就是**阶段二应回答的世界客观命题** → **不构成交接阻断**，须**转写为阶段二求解项**：① 所求 ② 答案形式/精度（精度不明确则**另立 B1 项**）③ **分支路由**（不同答案如何路由后续模型分支）④ 来源与现状。
2. **交接门禁重述**：不再要求「V-阻断清零」，而要求**每个未决项都有明确的 resolution owner 与下一阶段状态**——**B1 已裁定、B2 已收敛、B3 已转写为求解项**；**不得存在职责未归属的悬空未决项**，存在即不得交接。交接结构附**未决项台账**（逐项：未决项／类别／归属与状态／依据），替代原「变量三清单」。
3. **出口退回检查同步改写**：第 2 条改为「不得用『可变量化』充当归属」（B1 收窄不掉按规则 C 回问；B2 继续分析；B3 转写求解项）；第 7 条改为「未决项归属检查」（B1 已裁定／B2 已收敛／B3 已转写且含分支路由；悬空项即不得交接）。
4. **同步更新**：风险表「变量化被当作已消除差异」行；认知操作表「变量化继续」的必须产物（类别与归属状态）；交接段（未决项台账）；后续检验观察项（是否把 B1／B2 标成 B3 换取交接、B3 是否都有分支路由）。**规则 C** 补交叉引用：**B3 不适用回问**，按「客观事实争议不按无法分析转为回问、应按研究缺口保留」落实为求解项。
5. **未修项**：「12/14 触发无外部判据」继续观察（不因本版修复）。

## 未选方案

- **保留「V-阻断清零」口径、只给 B3 开例外**：两类阻断仍混在同一张清单里，容易再次死锁；未选。
- **把客观待答项交回创作者裁定**：会把世界事实与创作取舍混同（创作者亦未选此案）；未选。
- **只改文字不改门禁**：不解决死循环；未选。
