# D-020 · 裁定 run-06 不通过（单轴坍缩）并新增规则 G 问题集充分性

## 裁定来源

2026-09-27 创作者对 run-06（[运行 06](../attachments/probe-01-stage1-test-v0.12.1-run-06.md)，基线 v0.12.1）的**最终判定：不通过**。因此 **run-06 的后继问题封存，不需要继续求解**；[D-019](D-019-run06-verdict.md) 的「交接门禁通过／进入呈示待确认」结论**作废**（保留为历史，其「不另立 B1（精度）」的子判断仍有效）。

## 保留的局部正证据

本轮**没有**出现：premature elicitation、候选过生成、任意假定探索、L1／L2 混合、变量逃逸、resolution-owner 死锁——这些机制视为**有效**。

## 新暴露的失败机制：coverage failure / single-axis collapse

方法把「世界有多大」解释为**空间延展**后，就围绕**空间尺度**形成**单一求解链**，并判定足以交接。但至少「**人口规模**」就是一个明显**独立且可并存**的必要维度：**即使两个世界空间尺度完全相同，人口相差若干数量级，它们在合理的「世界规模」意义上仍显著不同。**

**因此**：阶段一**不能只寻找一个合理的承载解释或一个必要问题**，而必须协助创作者形成**足以回应原问的问题集／问题关系结构**。

## 决定（创作者要求）

1. **区分两类开放性**：
   - **解释竞争**：不同解释**互相竞争**（通常 **OR**：哪个才是原问的意思）→ 需要收窄；
   - **覆盖维度**：多个问题**共同组成**充分回答（通常 **AND**）→ **不因已有一个合理解释就停止**。
2. **新增针对问题集的覆盖挑战**：假设当前**所有问题都已得到相同答案**，尝试构造**两个世界**，使它们**仍在原问关心的意义上存在显著差异**；若能构造 → 存在**遗漏维度** → 分析该差异并决定是否加入问题结构；**重复**该攻击，直到**继续攻击不再产生有实质贡献的新问题**，或新增内容**只属派生／冗余**。
3. **不得预先把人口、交通、定居等写成固定分类**——这些应由覆盖攻击**从具体探针中发现**。
4. **run-06 因未通过该充分性要求，不交接 W2。**
