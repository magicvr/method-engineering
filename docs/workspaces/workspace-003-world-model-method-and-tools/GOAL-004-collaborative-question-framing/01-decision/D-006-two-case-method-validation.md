# D-006 · 裁定阶段一方法的两案例递进验证范围

## 裁决

用户选择“两案例递进”：先用“世界有多大”作为阶段一方法的黑箱试跑，再用一个不同的真实创作世界问题检查方法迁移。有限案例只能提供有限迁移证据，不支持普遍有效的结论。

## 执行边界

1. 第一例仅测试阶段一认知操作。输入保留用户已经给出的上下文：这个问题真实、每个世界观都必须回答、剧情中必须得到解答。不得把旧 A/B/C 候选、探针拆解或领域结论预载为方法步骤或正确答案。
2. 第一例须先记录原问、目标判断重建、假设与创作者纠正、按需查找的参考及其作用、可解单元与依赖、压缩检查和交接就绪度。创作者尚未说明的剧情判断属于待协作澄清内容，不能据此宣布输入无效，也不能由助手静默代定。
3. 两例的案例问题结构与可能答案均单独作为测试结果留存。只把认知操作的表现、创作者纠正、依赖发现、可交接性和失败机制作为方法证据；案例结构不得直接升为通用分类或固定模板。
4. 两例均不在本轮执行 W2 的答案求解或世界模型构建。第二例须使用与第一例不同的真实创作世界问题，待第一例记录完成后再由创作者提供或裁定。

## 待验证与限制

候选方法的实际效果、停止条件、所需证据以及是否需要修订，须由两例的操作证据再判断。该范围不证明数学意义的最小性，也不证明超出世界模型构建范围的通用性。阶段一方法候选仍为 draft/unaccepted；I-402 在两例证据收集与有限结论形成前保持 collecting。
