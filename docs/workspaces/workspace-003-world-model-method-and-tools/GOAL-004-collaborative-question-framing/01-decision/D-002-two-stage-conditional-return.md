# D-002 · 确认两阶段与有条件回流主流程

2026-09-27，用户确认 S2 采用以下主流程：

1. **第一阶段：协作定界。** 助手与创作者共同定界，形成并确认当前问题集基线。
2. **第二阶段：求解与综合。** 将保留问题逐项作为真实问题处理，再综合回答原问题。
3. **有条件回流。** 若求解中发现需要改变范围、关键假设、精度或重要依赖，或综合答案不足，则返回第一阶段，重确认受影响范围。问题集的确认不是永久冻结。

本次裁决仅确认上述主流程。问题集充分性准则、停止细化的具体操作判据、既有答案如何复用以及何时联合求解，仍属 S2 待试、待共同确认内容，不能扩写为用户已裁决的规范。

当前尚在第一阶段准备，I-401 open，未形成创作者确认的问题集。真实探针仍为“世界有多大”，不改变父级 W4 正式判据、W2 v0.4/A-008 历史或 GOAL-003 S2 暂停状态。
