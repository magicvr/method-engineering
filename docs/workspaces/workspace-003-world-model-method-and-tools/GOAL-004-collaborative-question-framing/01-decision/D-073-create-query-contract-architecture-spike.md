# D-073 · 建立 GOAL-006 QueryContract 架构验证子目标

- **日期 / 状态**：2026-09-30；accepted（creator 明确选定在 GOAL-004 下建子目标）。
- **决定**：以 `GOAL-006-query-contract-architecture-spike` 承载独立、短周期的 QueryContract 与 capability 分类架构验证；GOAL-004 保持 `active`，现有 v0.18.5 S1 路线继续暂停。

- **后续**：先按 GOAL-006 I-001～I-003 收集并核实真实需求、capability 基线和试验判据；这些门禁关闭前不进行试验。阶段证据完成后再提交 creator 裁定。
