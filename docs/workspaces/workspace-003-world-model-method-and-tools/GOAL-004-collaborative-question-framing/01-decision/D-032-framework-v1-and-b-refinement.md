# D-032 · 定稿组织框架并派发 ①-b 的局部递归细化（不重启全局覆盖搜索）

## 1. 重组框架获确认（**定稿**）

创作者：**A，重组方式贴合**——「**① 覆盖维度 / ② 横切结构与度量条件**」的分层**符合其对阶段一产物的理解**，**可以据此定稿组织框架**。

> **但该确认不等于**：① 中的覆盖维度**已经穷尽**；② 每个覆盖节点**都已细化到阶段二可直接求解的粒度**。
> 特别是 **①-b「体量／内容规模」**：**本身成立**，但**更像一个覆盖维度族／粗粒度节点**，**后续需要允许递归展开**。

## 2. T 项处理（创作者逐项裁定）

| 项 | 裁定 |
|----|------|
| **T-1** | **接受**：K-3（尺度结构类型）**作横切条件**，不再作独立覆盖问题项。 |
| **T-2** | **采用修改后的口径甲**：**顶层覆盖维度暂保持两项**（空间延展／体量与内容规模）；**「边界性」不单独升为第三覆盖维度**，而**作为各规模维度的横切属性**处理。**并把 K-2 从偏空间化的「边界性」泛化为「有界性／范围限制的定义与判定」**——**空间边界只是它在空间维度上的表现**。 |
| **T-3** | **不合并 K-3 与 K-5**。**K-3 限定为「尺度答案的结构形态」**；**K-5 限定为「该结构及其量级是否由世界内事实唯一确定」**；**清理二者重叠的示例／取值**，**而不是合并概念**。 |

## 3. 充分性判断与下一步（创作者）

**B：目前仍不构成充分回答。** 创作者能明确指出的缺口**不是**「已知存在第三条顶层覆盖维度」，而是：

> **①-b「体量／内容规模」仍是一个粗粒度覆盖维度族，尚未达到阶段二可直接求解的粒度。**

他**接受 ①-b 本身成立**：它泛指「**世界包含／承载多少内容**」这一类规模问题；**人口规模是帮助理解的明显实例，但不是预设的唯一指标**。

**下一步（明确指令）**：**不要**继续对整个「世界有多大」做**开放式 coverage search**；而是**对 ①-b 做一次局部递归细化**：

1. **把 ①-b 作为新的局部原问**；
2. **由助手使用同一阶段一方法**发现其**可并存的 AND 型子维度、必要 OR 分歧和依赖**；
3. **不预写人口等固定 taxonomy**；
4. **创作者负责判断**「是否值得继续展开／当前粒度是否已足够」，**而不是负责自己列子问题**；
5. **细化目标不是不可再分的原子节点**，而是达到**阶段二可以明确开始求解的 handoff-ready 粒度**；
6. **其它顶层正交覆盖维度是否存在**继续**保留为 R-1**，**不因这次局部展开自动重启全局搜索**。

## 4. 处置

- 形成 **[案例结构组织框架 v1](../attachments/case-structure-framework-v1.md)**（**定稿**：① 两项覆盖维度，其中 **①-b 标注为「可递归展开的粗粒度覆盖维度族」**；② 横切条件 **K-1～K-7b**，其中 **K-2 已泛化为「有界性／范围限制的定义与判定」**；**K-3／K-5 保持分立并清理重叠取值**；③ 求解项 S-1～S-4；④ 分析层可逆判断；⑤ 残余登记 R-1～R-4；⑥ 台账与声明）。
- **派发 ①-b 的局部递归细化**（隔离子会话）：方法＝**v0.16.1**；输入＝方法文件＋**框架 v1**＋本裁定；**以 ①-b 为局部原问**应用同一阶段一方法（规则 E 门槛／规则 F 归属／规则 G 覆盖攻击与收束判据），**不重启全局搜索**、**不预写任何固定分类**；产物＝①-b 的**子维度结构（AND 子维度／必要 OR 分歧／依赖）**＋**handoff-ready 粒度判断**＋残余与回流触发。
- **不修改方法候选正文**（v0.16.1 仍为当前基线）；**不改目标 `status` / `progress`**；**未进入 W2／阶段二**。事实见 [E-046](../02-execution/E-046-framework-v1-and-b-refinement.md)。
