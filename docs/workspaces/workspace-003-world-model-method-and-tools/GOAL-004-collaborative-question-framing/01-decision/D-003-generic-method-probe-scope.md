# D-003 · 选择通用方法探针范围

用户选择“通用方法探针”：当前不绑定具体作品，只验证两阶段流程能否从“世界有多大”提出候选问题集；演示答案不视为真实剧情结论。

当前范围只到第一阶段的候选生成与确认准备。不得声称问题集已最小或已获确认，也未完成分项求解和综合答案。本决定不新增方法规则，不改变 D-002 的主流程。

I-401 保持 open，仍阻断最终真实案例充分性验证及目标关门；具体创作场景在后续实际应用中与创作者共同明确。此范围选择不作为 I-401 已验证或残余风险接受。进度仍 33%；正式 W4 判据、W2 v0.4/A-008 历史及 GOAL-003 暂停状态不变。
