# D-012 · 以 run-02 为失败样本修正候选门槛、探索假定边界与层级区分

## 裁定来源

2026-09-27 创作者对 v0.9 第二次试跑（[运行 02](../attachments/probe-01-stage1-test-v0.9-run-02.md)）的判定：**未通过**，但保留局部正证据。

**保留的局部正证据**：premature elicitation 已实质改善——未定项能够主动分析、变量化继续；出口退回检查实际拦截 T2 并整改。这些机制不作为失败项。

**判定未通过的理由（三条结构性问题）**：

1. **候选过生成**：从合理的主动释义滑向穷举语义可能性；一些候选仅有词典、词源或抽象可能性依据，却被提升进当前问题结构。方法仍缺少「候选值得进入结构」的相关性门槛。
2. **诊断性探索越界**：探索自行引入输入未提供的条件（「前现代移动＋个人一生」），并据此产生 10⁵/10⁷ km 等精度判断——已不是判断解释/依赖，而是用任意场景假设制造定界结论。
3. **层级重新混合**：世界客观尺度、角色知识与剧情交付虽被区分成节点，又通过「求解必须依赖承载装置」等关系重新绑在一起；应进一步区分世界模型问题与其叙事消费要求。

**附带观察**：13/13 操作全部触发仍可疑；「单个未定项没有跑遍所有动作」不足以排除全局清单遍历，且本轮已出现「共享前置」与「展开依赖」产物重叠。

## 决定

1. **新增规则 E · 入结构门槛（候选相关性）**：候选进入结构须同时满足「当前输入依据 ＋ 结构改变」；能由输入排除者直接排除；词典义项、词源、逻辑/抽象可能性、其他作品惯例**只证明可能存在、最多进入候选池**；禁止以「非穷尽列举」为由把可能性集合搬入结构，也禁止为显示广度扩张候选。L1 的产出不得以「请创作者挑选读法」为主要形态。
2. **规则 D 增补假定边界**：探索只能用输入已给出的条件；禁止引入输入未提供的场景条件并据此产出定界结论（数值、边界、量级、regime 阈值、精度判定）；需要外部条件时登记为新的未定项或以变量/条件项保留，不得用具体假定量替代；每次探索须列假定清单及来源，分析者引入的假定下结论只能记为「该假定下的结构差异」且不得进入交接结构。
3. **新增层级规则 L1 / L2**：L1＝世界模型问题（命题是「世界是什么样」，不依赖某作品如何讲述），L2＝叙事消费需求（命题只在「某作品如何讲述」框架下才有意义）；两层分别记录，**禁止跨层「求解必须依赖」**，跨层只允许**需求接口（L2→L1）**与**素材接口（L1→L2）**且须说明改变了 L1 的哪一项；角色可知性须明确归属并给判据，不得两边各挂一半；交付要求属 L2，不构成 L1 的求解依赖；交接给阶段二的是 L1 问题结构，L2 需求作为消费约束单列。
4. **出口退回检查增加三项**：门槛检查（结构里是否只有词典/词源/抽象依据的候选）、层级检查（是否存在 L2→L1 伪求解依赖）、假定检查（假定是否标源、是否污染定界结论）。
5. **判例封存**：run-02 的案例产物（读法、度量轴、答案形式、叙事功能、关系、T1～T6 待确认项、r1/r2 读法）按创作者裁定**全部封存**——不作为事实、不作为后续决策依据、不在别处引用；也不再把问题简化为「等创作者在 T1/T3/T4 中选择」。

## 未选方案

- **全面回退到 v0.8 或更早**：创作者明确 v0.9 总体方向可保留、无需全面回退；未选。
- **只加「少生成候选」的一句话约束**：不足以形成可核对门槛，未选。
- **禁止一切诊断性探索**：会把「解释是否成立」重新推回回问，与规则 A/C 冲突；未选。
- **把 L2 需求移出阶段一**：交付要求是真实输入，移出会丢失必要约束；改为分层＋显式接口，未选移出。

## 未处理项（登记，不声称已修）

- **触发可判别性缺陷**：全部操作被触发时，如何从外部区分「真触发」与「清单遍历」，本版未给判据；执行者提出的两项观察（记录被主动跳过的操作、以结构产物为证据单位）按裁定**封存待决**，不作为本版修复项。
- **下游影响**：L1/L2 分层可能影响父级 W2（方法主文档）与 W3（两个最小结构）的结构；本目标不自行改动父级，待阶段一方法稳定并获接受后由父级按 P-006 处理。登记为跨目标影响提示。
