# D-015 · 裁定 run-04 不通过交接门禁并引入变量分级

## 裁定来源

2026-09-27 创作者对 v0.10.1 的 run-04（[运行 04](../attachments/probe-01-stage1-test-v0.10.1-run-04.md)）判定：**记录接受；运行结果不通过交接门禁；保留大量局部正证据，不回退方法方向。**

**保留的正证据**：三项修复（候选过生成／任意假定探索／L1-L2 层级混合）效果明显；本轮没有出现 premature elicitation；也没有用外部场景假定制造定界结论。

## 新暴露的阻断性问题（裁定要点）

**变量化被错误地视为消除了残余差异，从而绕过规则 C。** 变量化只允许分析继续，**不等于该变量无需在交接前解析**。应区分：

- 可暂时变量化；
- 可带入阶段二的**非阻断变量**；
- 在交接前**必须由分析或创作者确认解决的阻断变量**。

**判据**：若不同取值会改变**原问所求**、**阶段二所需模型类型**或**必要问题结构**，则该变量**不能仅因「可变量化」而通过出口门禁**。按此标准，run-04 中**变量 A（度量轴）与条件项 E（「必须回答」的强弱读法）至少需要重新检查**，不能据当前「0 项回问」直接交接 W2。

## 决定

1. **新增规则 F · 变量分级**：V-暂时 / V-非阻断 / V-阻断 三级；判据＝是否改变 (a) 原问所求、(b) 阶段二所需模型类型、(c) 必要问题结构。**V-阻断在交接前必须解决**：先由分析收窄，收窄不掉则按规则 C 回问（此时条件①因分析已尽而成立）。
2. **改写出口退回检查第 2 条**：「退回为变量化保留」**只对 V-暂时与 V-非阻断成立**；分级为 V-阻断时，条件①**不因可变量化而成立**。
3. **新增出口检查第 7 项·变量分级检查**：每个变量是否写明分级结论与判据；**交接前 V-阻断清单是否为空**；存在未解析的阻断变量 → **不得交接**。
4. **交接门禁**：交接结构须附**变量三清单**（V-阻断应为空／V-非阻断含判据／V-暂时含判据）；呈示终点补此要求。
5. **风险表**新增「变量化被当作『已消除差异』，绕过规则 C」一行；认知操作表「变量化继续」的必须产物补**分级结论与判据**；后续检验观察项补变量分级观察。
6. **M1 / M2 保留为待修文本项**（M2 与本规则相关，但不因本规则自动关闭）；「12/14 触发无外部判据」**继续观察**。
7. **不重跑 run-04 的案例**：其案例产物未获判定，本目标不据其内容推进；本次只把标准写入方法。下一步（在 v0.11 上重跑 / 先修 M1-M2 / 其他）由创作者决定。

## 未选方案

- **回退方法方向**（如取消变量化）：创作者明确不回退；未选。
- **只把「阻断变量」写进口头提示、不立规则**：判据不可复核，未选。
- **现在就替创作者判定 run-04 的变量 A／条件项 E 是否阻断**：属未判定案例产物，本目标不代裁；未选。
