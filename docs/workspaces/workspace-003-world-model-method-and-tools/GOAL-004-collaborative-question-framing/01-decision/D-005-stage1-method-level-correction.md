# D-005 · 纠正方法层级并聚焦阶段一认知操作

用户明确纠正：本目标应形成世界模型构建范围内的通用阶段一方法，不能把探针的领域问题结构、答案或模型当作通用方法。现有目标继续承载，无须另开目标。

阶段一从不完整原问与创作上下文出发，助手重建目标判断，识别影响判断的歧义与未知，按需研究资料、参考和反例，从目标判断逆向推导所需答案依据，形成明确可解单元及依赖结构，再以充分性反例、必要性删除、细分边际价值和综合回应进行候选压缩检查。操作可迭代，不是填表流程；依赖可含先后、约束、共享输入、联合或循环，循环标为联合处理，不强拆为 DAG。

可解指问题含义、所需答案、条件与精度、支持需求已足以交接父级 W2 阶段二，不表示已有答案或模型。阶段二沿用 W2 v0.4 的能力发现、状态/组合/精度/机制缺口判定及最小充分机制模型构建，一问题不等于一模型。D-002 两阶段及有条件回流仍有效。

探针只能在方法候选形成后作为黑箱测试输入；当前不运行、拆解或求解“世界有多大”。未来测试须区分方法能力证据（操作表现、依赖发现、可交接性、缺口及失败机制）和案例结果（领域子问题、具体关系、答案及模型），后者不能直接回流成通用结构。

撤回三份旧候选的当前依据资格并保留原文，改以新的阶段一认知操作候选供审视。每种最小充分检查仍为 candidate/unaccepted，未宣告验证。此前选择器空答案不构成用户裁决或否决；本决定只记录本轮明确纠正。目标 active、33%，I-401/I-402 保持 open。
