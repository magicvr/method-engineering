# D-074 · 确认真实下游用途并修正 GOAL-006 案例门槛

- **日期 / 状态**：2026-09-30；accepted。
- **决定**：确认 VP-003 对应下游仓的真实用途是“构建星际时代的修真世界观”，它是 GOAL-006 的实际使用情境。采用 GOAL-006 D-002 的最小门槛修订：四项 creator 提供/确认的真实问题可来自该同一用途；不要求额外项目、用户或 persona；不要求试验前先证明已有 capability 不足，后者由 S1 对照能力基线后观察。若未观察到，则限定相应结论。I-001 已 verified；I-002、I-003 保持 required/open。
- **理由**：真实下游用途已经给出方法和工具的实际交付目的；将另一个独立“案例”当作进入试验的必要条件会错把用途情境与查询样本分开，也可能把能力评估结果倒置为样本准入条件。
- **未选方案**：保留试验前必须具备已证明 capability 不足的案例要求，或另找独立使用项目；二者会造成不必要阻塞，且可能诱发合成案例。
- **影响**：仅修订 GOAL-006 的案例与试验准入/结论范围；GOAL-004 仍 `active`、progress 33%，I-401/I-402 不变；v0.18.5、run-19、方法正文、handoff、GOAL-003 及历史审计不变。没有开始 S1/S2。
- **后续**：在 GOAL-006 下完成 I-002 能力基线与 I-003 试验判读标准，再准备 S1。
