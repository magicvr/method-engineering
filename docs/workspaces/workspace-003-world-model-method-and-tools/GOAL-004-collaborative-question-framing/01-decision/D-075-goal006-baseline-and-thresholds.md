# D-075 · 确认 GOAL-006 能力基线状态与试验判读阈值

- **日期 / 状态**：2026-09-30；accepted。
- **决定**：Creator 确认 GOAL-006 当前尚无可评估的既有 capability baseline，并接受本次 spike 的局部判读阈值（详见子目标 D-003）。I-002 以“无可评估 baseline”这一已知状态 verified；I-003 以 creator 接受的预设判据 verified。无 baseline 不自动证明 capability insufficiency。
- **理由**：实验需要保留真实信息状态与证据边界；不应把尚未建立的 capability inventory 当作能力不足结论，也不应将本次 threshold 升格为通用规则。
- **未选方案**：把 baseline 缺失推断为所有能力都不足，或改用未经确认的通用架构门槛；均会超过现有证据。
- **影响**：GOAL-006 的 required 信息项 I-001～I-003 已核实；S1 试验包及执行授权仍须另行准备。GOAL-004 status/progress、I-401/I-402、v0.18.5 与历史 S1 路线不变。
- **后续**：准备明确无 baseline 限制的 S1 试验包，供后续核查与执行授权；不自动启动 S1/S2。
