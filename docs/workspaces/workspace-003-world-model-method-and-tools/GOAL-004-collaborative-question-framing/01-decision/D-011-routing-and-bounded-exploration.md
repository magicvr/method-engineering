# D-011 · 按未定项性质路由主动分析并允许有界诊断性探索

## 裁定来源

2026-09-27 创作者通过 v0.8 方向（「由认知困难触发、必须形成结构性分析产物、仅在不可约创作者取舍处回问」的操作系统，而非澄清问卷），**允许进入第二次探针试跑**，并在试跑前提出三项实质性小修。

## 决定

1. **规则 B 由「所有未定项固定走四步」改为「按未定项性质路由主动分析」**：
   - 性质分类与路由：N1 指称/含义歧义 → 解释候选化 + 后果推导；N2 参数/精度未定 → 变量化继续；N3 事实/知识缺口 → 可判别性检查 + 按需检索；N4 用途/取舍未定 → 各用途结构差异推导，必要时才进入回问；N5 可解性未知 → 有界诊断性探索。
   - 只做该性质需要的动作，做完即继续；不产生「每个未定项把所有动作做一遍」的要求。
   - **禁止制造虚假候选**：只在确实存在多个有理由的解释时做候选化；只有一个合理解释直接采纳并记录理由。
   - 理由：原「固定四步」会让反 elicitation 规则自身退化为新的固定流水线，并诱发为满足形式而硬凑候选。
2. **新增规则 D · 有界诊断性探索**：允许为判断解释、依赖与边界做小规模探索或局部试解（反例、样例代入、局部推演、检索、粗量级估算），约束为有界、目的限定、留痕、**不升级**为正式模型或答案、越界即停并转交接条件或回流触发。
3. **弱化工作表示的命名**：方法身份是**操作与产物**，不是某一种表示；本方法不要求建图，不以表示完整度作为验收对象。新候选文件不再以 `dynamic-relation-graph` 命名。

## 未选方案

- **保留固定四步、只调顺序**：仍是流水线，未解决创作者指出的退化风险；未选。
- **取消候选化、只做变量化**：会丢失 N1 类歧义的解释比较能力；未选。
- **禁止一切诊断性探索**：会使「解释是否成立、依赖是否真实」永远无法在阶段一判断，反而抬高回问率；未选。

## 处置与边界

- 形成 [v0.9 候选](../attachments/stage1-framing-method-candidate-v0.9.md)（第二次试跑的**固定基线**，跑前不再改动）；v0.8 保留历史并加后续注记。
- 三项小修**不改变**阶段二边界、两阶段与有条件回流（D-002 / D-008 继续有效），也不改变阶段一「不回答原问、不建模」的边界；诊断性探索的产物不得进入 W2 交付物。
- 本轮不新增审计条目、不改目标 `status` / `progress`；`I-401` 仍 `open`、`I-402` 仍 `collecting`。事实见 [E-018](../02-execution/E-018-prerun-revision-v09.md)。
