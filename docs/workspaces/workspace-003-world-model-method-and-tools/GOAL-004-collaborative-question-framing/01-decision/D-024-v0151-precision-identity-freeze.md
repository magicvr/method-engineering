# D-024 · 两处最小一致性修正形成 v0.15.1 并冻结为 run-08 基线

## 来源

2026-09-27 创作者：**v0.15 的方法主体方向接受，但不直接冻结**——先做一次**最小文本一致性修正**形成 **v0.15.1**，然后**立即冻结并作为下一次隔离试跑基线**。明确要求：**不新增规则、不重新设计规则 G。**

## 决定（只两处）

1. **修正规则 F.2 关于「创作者要求精度 → B1」的旧口径**。旧写法（「**创作者要求的精度**属 **B1**（另立 B1 项）」）会让执行者**仅因求解项涉及「精度」就主动创建一个 B1**——run-07 的 U-8 已因此被裁定**否决**。F.2 第 2 项改为：
   > **答案形式与精度**：记录该求解项需要什么**答案形态**。**世界客观可实现的精度属于 B3**，由阶段二求解。**只有当前输入中实际存在创作者侧的精度、容差、答案边界或类似要求时，才另立 B1；不得仅因理论上可能存在这种创作者取舍而制造 B1。**
   
   并**同步检查所有引用处**：v0.12.1 历史修订说明中的旧口径加注「**已按 v0.15.1 修正**」（历史保留）；出口退回检查第 7 项的「精度分流」改为「答案形态与世界客观可实现精度的归属」。**正文不再残留「只要涉及精度就必须建立 B1」的语义。**
2. **修正文末版本身份残留**：原状态段同段同时出现 `v0.13.0` 与 `v0.15.0`。已改写为**版本沿革＋当前版本身份**（「**本版为 v0.15.1（冻结为 run-08 基线）**…」），避免隔离执行者误认为版本身份冲突。

## 明确不做（创作者明令）

- 不新增**覆盖维度分类**；不**预写任何具体维度示例**；不规定**固定攻击轮数**；不新增**停止阈值**；不因「最大化」不够形式化而**继续扩展规则**。
- **规则 G 保持不动**：核心动作仍是「**在保持当前问题集全部答案不变的约束下，尝试最大化两个世界在原问整体判断上的差异**」，并保留「同方向失败必须改变搜索方向」「候选差异清算」「换过方向后仍无法得到实质差异或新增只属派生／冗余才可停止」——**该机制交由试跑验证，不再理论扩写**。
