# GOAL-004 · 阶段一协作定界认知方法与 W2 交接

## 概述

按用户 [D-005](01-decision/D-005-stage1-method-level-correction.md) 纠正，承载世界模型构建方法的阶段一：从不完整原问与创作上下文出发，经助手主动认知操作，形成足以启动阶段二求解的问题结构候选，交创作者确认后再交接父级 W2。当前 v0.12 将阶段一表达为一组**按认知困难触发、必须产出结构分析产物**的操作（工作表示可替换，方法身份不是图形）：每项操作若只能产出提问即视为未执行；未定项按其性质（指称歧义 / 参数未定 / 知识缺口 / 用途取舍 / 可解性未知）路由到相应的主动分析，而不是固定步骤；允许**有界诊断性探索**用于判断解释、依赖与边界，且不升级为模型或答案；回问仅作末位手段且须携带分析。v0.10 另加三项结构约束：候选进入结构须过**相关性门槛**（词典/词源/抽象可能性只入候选池）、诊断性探索**只能用输入已给出的条件**（不得由自设假定产出定界结论）、**L1 世界模型问题与 L2 叙事消费需求分层记录**且禁止跨层求解依赖。阶段二从确认结构逆向识别模型依赖属于后续研究，本轮不设计。v0.11 另加**规则 F 变量分级**（V-暂时／V-非阻断／V-阻断）：变量化只允许分析继续，**不等于差异已消除**；不同取值若改变原问所求、阶段二所需模型类型或必要问题结构，即为 **V-阻断**，交接前必须由分析收窄或按规则 C 回问，**不得仅因「可变量化」通过出口门禁**；交接须附变量三清单（阻断应为空）。v0.11.1 为文本补正版：**M1** 需求接口改为「须指名 L1 需产出的具体信息/精度项」（接口不改变 L1 的客观问题内容，改变的是其产出需求登记，指不出来就不写）；**M2** 明确**变量取值域不是结构项**（只作后果差异记录、须标依据类型与对所求/模型类型/必要结构的影响；某一取值要成为承载项须按规则 E 过门槛）。v0.12 按 run-05 判定**重构规则 F**：未决项不再按「是否改变模型结构」分级，而按**未决的原因与归属**分为 **B1 创作者取舍型／B2 定界结构型／B3 客观求解型**；交接门禁不再要求「阻断清零」，而要求**每个未决项都有明确的 resolution owner 与下一阶段状态**（B1 已裁定／B2 已收敛／B3 已转写为求解项，含所求、答案形式/精度与分支路由），**不得存在职责未归属的悬空未决项**。

阶段一围绕可修订的问题关系结构执行按需、可往返的认知操作：从原问和上下文发现需要澄清或回答的内容，按需展开、拆分/合并、辨认关系、剪枝并挑战覆盖。节点与关系称谓保持开放，不规定固定顺序或问题分类；同时辨认创作者意图、客观待答内容、助手推断与证据来源，不混淆答案支持判断的关系和求解依赖。收束为足以启动 W2 求解、待创作者确认的候选结构。
