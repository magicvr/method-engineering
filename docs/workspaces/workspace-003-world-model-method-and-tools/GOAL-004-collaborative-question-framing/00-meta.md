# GOAL-004 · 协作定界与最小充分问题集

## 概述

承载父目标 [GOAL-002](../GOAL-002-r2-method-working-version/00-meta.md) 的 W2 有界回流，形成**世界模型构建范围内可复用的协作定界方法**，见用户范围裁决 [D-004](01-decision/D-004-reusable-world-model-framing-scope.md)。模糊真实创作问题可以作为入口；助手主动协助理解用途，查找资料、参考与反例，分析并提出可比较的定界候选；创作者裁定创作意图与取舍。

对属于客观世界模型状态、规律、关系或后果的部分，形成相对于当前创作判断的最小充分问题集，逐项求解并综合回答原问题。“世界有多大”是当前探针，不是方法唯一适用问题或普适性证明。方法不扩为跨领域通用问答，也不能将定界责任全部交回创作者或无限细化问题。

## 成功标准与验收意图

- [x] 真实需求、W2 现有支撑与缺口、修订范围和 W3 依赖有可核对记录，见 [缺口说明](attachments/w2-ambiguity-gap-scope-v0.1.md)。
- [ ] 与创作者明确具体创作场景及答案所支持的剧情或设计判断，以资料和分析形成当前场景下最小充分的问题集，回答子问题并综合回应原问题。
- [ ] 在世界模型构建范围内形成可复用的协作定界方法；按共同确定的跨问题最低验证范围与证据强度检验其可复用性（I-402），不以单探针代替该验证。
- [ ] 形成 W2 新版、影响检查与 W3 复开交接证据。

上述为目标意图。S2 的具体充分性、停止细化条件及答案精度仍需与创作者共同确定，不是已冻结验收规则。“问题足以支持当前创作判断、继续细化无助于该判断”仅为待确认候选；不得用问题数量或填表完成替代效果证据。

## S2 已确认主流程与待试细节

用户已确认 [D-002](01-decision/D-002-two-stage-conditional-return.md) 的两阶段与有条件回流：第一阶段与创作者协作定界，形成并确认当前问题集基线；第二阶段将保留问题逐项作为真实问题处理，并综合回答原问题。求解中若需改变范围、关键假设、精度或重要依赖，或综合答案不足，则回第一阶段重确认受影响范围。确认不意味着永久冻结。

第二阶段的具体操作、问题集充分性准则、停止细化的具体操作判据、既有答案如何复用、何时联合求解及跨问题验证强度，仍为 S2 待试、待共同确认内容。当前准备见 [候选附件](attachments/probe-framing-candidates-v0.1.md)；NASA 资料只作候选参考，未成为创作者认定的事实。I-401 仍 open，尚未确认最小问题集或形成答案。

## 方法范围与当前试行限额

[D-003](01-decision/D-003-generic-method-probe-scope.md) 保留当时不绑定具体作品、仅从“世界有多大”生成候选问题集与准备确认的单探针第一阶段试行限额；它不是方法的全部范围。方法范围以 [D-004](01-decision/D-004-reusable-world-model-framing-scope.md) 为准，覆盖世界模型构建中的可复用协作定界。当前已开展的证据仍只到第一阶段候选准备。问题集未被证明最小、未获确认，分项求解和综合答案未完成；演示答案不视为真实剧情结论。

I-401 仍 open，继续阻断最终真实案例充分性验证及目标关门；具体创作场景在后续实际应用中共同明确。本轮范围选择不关闭信息项、不接受其残余风险，进度仍 33%。
