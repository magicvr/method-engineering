# GOAL-004 · 阶段一协作定界认知方法与 W2 交接

## 概述

按用户 [D-005](01-decision/D-005-stage1-method-level-correction.md) 纠正，承载世界模型构建方法的阶段一：从不完整原问与创作上下文出发，经助手主动认知操作，形成足以启动阶段二求解的问题结构候选，交创作者确认后再交接父级 W2。

**当前方案为 v0.15.1**（v0.15 的两处最小一致性修正版，**冻结为 run-08 基线**；指纹 `sha256 E4C74617…E26C`）。阶段一的现行形态：

- **操作**：按认知困难触发、必须产出结构分析产物；**每项操作若只能产出提问即视为未执行**。
- **未定项路由（规则 B）**：按性质（指称歧义／参数未定／知识缺口／用途取舍／可解性未知）路由到相应的主动分析，不做固定步骤。
- **入结构门槛（规则 E）**：候选须有当前输入依据且采纳后改变结构；词典/词源/抽象可能性只入候选池；**变量取值域不是结构项**，只作后果差异记录（须标依据类型与对所求/模型类型/必要结构的影响）。
- **有界诊断性探索（规则 D）**：只能用输入已给出的条件；不得由自设假定产出定界结论；越界即停。
- **层级（L1／L2）**：世界模型问题与叙事消费需求分层记录，禁止跨层求解依赖；需求接口须**指名 L1 需产出的具体信息/精度项**。
- **回问（规则 C）**：末位手段，三条件同时成立且须携带分析。
- **未决项分类与归属（规则 F）**：按**未决的原因与归属**分为 **B1 创作者取舍型／B2 定界结构型／B3 客观求解型**（**不以「会改变模型结构」作分类判据**）；交接门禁要求**每个未决项都有 resolution owner 与下一阶段状态**——B1 已裁定、B2 已收敛、B3 已转写为求解项（所求／答案形态与世界客观可实现精度的归属／有依据的分支影响，未知时标「分支待阶段二发现」／来源与现状）；**B1 只在当前输入中实际存在创作者侧取舍（含精度、容差、答案边界）时才可立**——不得仅因理论上可能存在而制造 B1；**不得存在职责未归属的悬空未决项**。

- **问题集充分性（规则 G，覆盖攻击）**：区分 **OR 轴解释竞争**（需收窄）与 **AND 轴覆盖维度**（不得因已有一个合理解释而停止）。核心动作是**通用攻击指令**：**「在保持当前问题集全部答案不变的约束下，尝试最大化两个世界在原问整体判断上的差异。」**——约束＝当前全部答案逐项不变；目标＝**原问整体判断**上的差异；动作＝**最大化尝试**（鼓励换方向含正交，但不得用预设维度清单），且**每轮重新执行**。**同方向失败必须换方向**继续最大化；停止须满足：换过方向后仍无法构造**实质差异**（或新增只属派生／冗余），且对**已出现而未准入**且可能影响原问的候选差异**逐项**给出攻击／排除理由；**不得**以「同一方向失败」或「已找到若干维度」为由停止。**不得预写任何具体维度为固定分类**；**无覆盖攻击记录或不合上述要求 → 不得交接**。**与规则 D／E 的边界（G.4）**：反例世界属**反事实诊断样本**，其属性、数值、机制不得升级为目标世界事实或定界结论；新维度须作为候选**重新过规则 E 的门槛**（**不自动准入**、**不要求创作者事先提及**）；攻击阶段判断充分性、准入阶段判断结构归属，两个判断分开记录、互不否决。

阶段二从确认结构逆向识别模型依赖属于后续研究，本轮不设计。

阶段一围绕可修订的问题关系结构执行按需、可往返的认知操作：从原问和上下文发现需要澄清或回答的内容，按需展开、拆分/合并、辨认关系、剪枝并挑战覆盖。节点与关系称谓保持开放，不规定固定顺序或问题分类；同时辨认创作者意图、客观待答内容、助手推断与证据来源，不混淆答案支持判断的关系和求解依赖。收束为足以启动 W2 求解、待创作者确认的候选结构。
