# GOAL-004 · 阶段一协作定界认知方法与 W2 交接

## 概述

按用户 [D-005](01-decision/D-005-stage1-method-level-correction.md) 纠正，承载世界模型构建方法的阶段一：从不完整原问与创作上下文出发，经助手主动认知操作，形成明确可解单元及依赖结构，交接父级 W2 阶段二。阶段二沿用 W2 能力发现、状态/组合/精度/机制缺口判定及最小充分机制模型构建；一问题不等于一模型。

阶段一重建并保留非穷尽的创作判断候选、先分析并存关系；区分创作选择与客观问题节点，只把客观问题交接 W2，并把答案依赖与支持判断的关系分开。按需研究、从判断逆推依据，再检查充分性、必要性与细分价值。

## 成功标准与验收意图

- [x] 初始需求、W2 缺口与修订范围已有记录，S1 历史完成事实保留；当前目标层级以 D-005 修正为准。
- [ ] 形成可复用阶段一认知方法：输出原问/目标判断、问题节点、答案形式/精度、依赖、前提/证据/未知、建议与裁定区分及子答案支持原问的关系。
- [ ] 说明可解与已答/已有模型的区别，形成可交接父级 W2 阶段二的接口，不把问题集等同模型清单。
- [ ] 方法候选形成后，按共同确定的验证安排取得操作表现、依赖发现、可交接性及缺口/失败机制证据（I-401/I-402）；案例结果与方法能力证据分开。
- [ ] 完成 W2 有界修订、影响检查及 W3 复开交接证据。

最小充分的各项检查均为 candidate/unaccepted，具体操作与停止规则仍待共同确定，不宣称全局数学最小。当前不运行、拆解或求解“世界有多大”。

## S2 当前依据与两阶段关系

当前供审视的是 [阶段一认知操作候选 v0.5.0](attachments/stage1-cognitive-operations-candidate-v0.5.md)。v0.1.2 首轮试跑暴露 OR 式单选缺陷；案例 v0.1 又混合了创作者判断与客观问题，尚不适合作为 W2 输入。修订事实分别见 D-007/E-011 与 E-012。原三份方法/探针候选已撤回当前依据资格，案例结构不等于通用方法。v0.3/v0.4 保留为方法候选历史；早先探针输出不作为本次测试基线。本次隔离运行只使用 v0.5.0 和原问/已确认上下文。D-002 两阶段及有条件回流继续有效；D-003 仅代表当时试行限额，不是通用方法范围。此前空答复不构成任何方向的选择或否决。

阶段一的“可解”指含义、所需答案、条件/精度与支持需求足以交接；答案和模型可留阶段二发现或构建。依赖允许先后、约束、共享输入、联合与循环；循环标联合处理，不强拆 DAG。阶段二仍在父级 W2 接口内。

探针只作为阶段一方法测试输入。第一例按 v0.5.0 草案基线完成一次隔离阶段一运行，结果见 [运行 01](attachments/probe-01-stage1-test-v0.5-run-01.md)：产出非穷尽、未确认的案例用途/节点候选，未交接 W2，未产生领域答案或模型。此前 v0.2 仅保留为早期探索记录，不充当本次基线。案例结果与方法表现分开记录；本次观察到用途扩张和缺少定向协作提问风险，方法仍未接受，需结合创作者校正继续判断。
