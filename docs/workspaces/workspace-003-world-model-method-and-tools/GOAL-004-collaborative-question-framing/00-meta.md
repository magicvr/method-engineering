# GOAL-004 · 阶段一协作定界认知方法与 W2 交接

## 概述

按用户 [D-005](01-decision/D-005-stage1-method-level-correction.md) 纠正，承载世界模型构建方法的阶段一：从不完整原问与创作上下文出发，经助手主动认知操作，形成足以启动阶段二求解的问题结构候选，交创作者确认后再交接父级 W2。当前 v0.6 将阶段一表达为动态问题关系图上的认知操作；阶段二从确认结构逆向识别模型依赖属于后续研究，本轮不设计。

阶段一围绕可修订的问题关系结构执行按需、可往返的认知操作：从原问和上下文发现需要澄清或回答的内容，按需展开、拆分/合并、辨认关系、剪枝并挑战覆盖。节点与关系称谓保持开放，不规定固定顺序或问题分类；同时辨认创作者意图、客观待答内容、助手推断与证据来源，不混淆答案支持判断的关系和求解依赖。收束为足以启动 W2 求解、待创作者确认的候选结构。

## 成功标准与验收意图

- [x] 初始需求、W2 缺口与修订范围已有记录，S1 历史完成事实保留；当前目标层级以 D-005 修正为准。
- [ ] 形成可复用阶段一认知方法：输出原问/目标判断、问题节点、答案形式/精度、依赖、前提/证据/未知、建议与裁定区分及子答案支持原问的关系。
- [ ] 说明可解与已答/已有模型的区别，形成可交接父级 W2 阶段二的接口，不把问题集等同模型清单。
- [ ] 方法候选形成后，按共同确定的验证安排取得操作表现、依赖发现、可交接性及缺口/失败机制证据（I-401/I-402）；案例结果与方法能力证据分开。
- [ ] 完成 W2 有界修订、影响检查及 W3 复开交接证据。

最小充分的各项检查均为 candidate/unaccepted，具体操作与停止规则仍待共同确定，不宣称全局数学最小。当前已将“世界有多大”作为阶段一测试输入进行同案例版本复测；未回答原问或进入阶段二求解。
