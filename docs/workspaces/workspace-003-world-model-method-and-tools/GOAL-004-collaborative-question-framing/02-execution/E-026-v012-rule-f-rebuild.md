# E-026 · 按 run-05 判定重构规则 F 并形成 v0.12

### 2026-09-27 · 拆掉规则 F／C 死循环

- 创作者对 [run-05](../attachments/probe-01-stage1-test-v0.11.1-run-05.md)（基线 v0.11.1）的判定：**交接不通过，但执行行为正确——暴露的是方法规则的内部死循环**；保留 M1／M2 修复正证据，**据此修规则 F，不回退整体方向**。
- **死循环确认**：规则 C 已写明「客观事实争议不因无法分析就转为回问，应按研究缺口保留」，而规则 F 又把「会改变模型类型／必要问题结构」的未知一律定义为必须在阶段一清零的 **V-阻断** → 阶段二本来就要回答的客观命题落入「既不能收窄、又不能回问、又不能交接」。
- 按 [D-017](../01-decision/D-017-rule-f-rebuild-b1b2b3.md) 重构并形成 [v0.12 候选](../attachments/stage1-framing-method-candidate-v0.12.md)：
  - **规则 F** 改为「未决项分类与归属」，分 **B1 创作者取舍型 / B2 定界结构型 / B3 客观求解型**；**明文禁止以「会改变模型结构」作为分类判据**；B2 的定义限定为「阶段一对问题本身的理解或结构未决」；B2 分析后可转 B1 或 B3，转类须留痕；无法归类者＝**悬空未决项 → 不得交接**。
  - **F.2** 规定 B3 转写求解项的四要素：所求／答案形式与精度（精度不明确则另立 B1 项）／**分支路由**／来源与现状。
  - **F.3 交接门禁**重述为「每个未决项都有 resolution owner 与下一阶段状态」——B1 已裁定、B2 已收敛、B3 已转写为求解项；交接结构附**未决项台账**（替代原「变量三清单」）。
  - **出口退回检查**第 2、7 条同步改写（不得用「可变量化」充当归属；悬空未决项不得交接）。
  - **规则 C** 补交叉引用：**B3 不适用回问**，按「研究缺口保留」落实为可交付求解项。
  - 风险表、认知操作表（变量化继续的必须产物改为类别与归属状态）、交接段、后续检验观察项同步更新。
