# E-046 · 定稿组织框架 v1 并派发 ①-b 的局部递归细化

### 2026-09-27 · 框架定稿与局部递归

- 创作者判定 **A（重组贴合）**：「**① 覆盖维度 / ② 横切结构与度量条件**」的分层**符合其对阶段一产物的理解**，**可据此定稿组织框架**；同时明确**该确认不等于**①覆盖维度已穷尽、也**不等于**每个覆盖节点已细化到阶段二可求解的粒度——特别是 **①-b「体量／内容规模」** 本身成立，但**更像一个覆盖维度族／粗粒度节点**，**允许递归展开**（[D-032](../01-decision/D-032-framework-v1-and-b-refinement.md)）。
- **T 项裁定**：**T-1 接受**（K-3 作横切条件）；**T-2 采用修改后的口径甲**——**顶层覆盖维度保持两项**（空间延展／体量与内容规模），**「边界性」不升为第三覆盖维度**，而作为各规模维度的**横切属性**，并把 **K-2 泛化**为「**有界性／范围限制的定义与判定**」（空间边界只是其在空间维度上的表现）；**T-3 不合并 K-3 与 K-5**——**K-3 限定为「尺度答案的结构形态」**、**K-5 限定为「该结构及其量级是否由世界内事实唯一确定」**，**仅清理重叠的示例／取值**。
- **充分性判断＝B（仍不构成充分回答）**：创作者能明确指出的缺口**不是**「已知存在第三条顶层覆盖维度」，而是 **①-b 仍是粗粒度覆盖维度族、未达阶段二可直接求解的粒度**；他接受 ①-b 成立（泛指「世界包含／承载多少内容」，**人口规模只是帮助理解的明显实例、不是预设唯一指标**）。
- **产物**：[案例结构组织框架 v1](../attachments/case-structure-framework-v1.md)（**定稿**；含 K-2 泛化、K-3／K-5 分立口径、①-b 标注为可递归展开的粗粒度族、R-4 记为 ①-b 粒度残余）。
- **派发**：隔离子会话做 **①-b 的局部递归细化**——只读两件（方法 **v0.16.1**、**框架 v1**）；**以 ①-b 为局部原问**（方法中「原问」在本任务内一律指 ①-b）执行同一阶段一方法（规则 E／B／G／F 与层级）；产出 **①-b 的子维度结构（AND 并存／OR 分歧／依赖）＋覆盖攻击逐轮记录＋收束判据核对＋残余登记＋台账＋handoff-ready 粒度判断**；**不得预写任何固定分类**（含常识／别处／上级举过的实例）；**不重启全局搜索**（顶层第三条正交维度属 **R-1**，保持不动）；**粒度是否足够由创作者判断**。
- **未做**：未修改方法候选正文（v0.16.1 仍为基线）；未改目标 `status` / `progress`；未进入 W2／阶段二。`I-401` open、`I-402` collecting 不变。
