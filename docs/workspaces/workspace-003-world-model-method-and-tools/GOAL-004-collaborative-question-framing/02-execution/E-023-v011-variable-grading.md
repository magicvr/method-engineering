# E-023 · 按 run-04 判定引入变量分级并形成 v0.11

### 2026-09-27 · 阻断性缺陷：变量化绕过规则 C

- 创作者对 [v0.10.1 运行 04](../attachments/probe-01-stage1-test-v0.10.1-run-04.md) 的判定：**记录接受；不通过交接门禁；保留大量局部正证据；不回退方法方向**。保留的正证据＝三项修复（候选过生成／任意假定探索／L1-L2 层级混合）效果明显、未再出现 premature elicitation、未用外部场景假定制造定界结论。
- **新暴露的阻断性问题**：**变量化被错误地视为消除了残余差异，从而绕过规则 C**。变量化只允许分析继续，不等于该变量无需在交接前解析；须区分「可暂时变量化」「可带入阶段二的非阻断变量」「交接前必须由分析或创作者确认解决的阻断变量」。判据＝不同取值是否改变**原问所求**、**阶段二所需模型类型**或**必要问题结构**。按此标准，run-04 的**变量 A（度量轴）与条件项 E（「必须回答」的强弱读法）至少需要重新检查**，「0 项回问」不足以支撑交接。
- 据此产出 [D-015](../01-decision/D-015-run04-gate-fail-variable-grading.md) 与 [v0.11 候选](../attachments/stage1-framing-method-candidate-v0.11.md)：
  - 新增**规则 F · 变量分级**（V-暂时／V-非阻断／V-阻断＋三条判据＋四级配套要求）；
  - **出口退回检查第 2 条**改为：「退回为变量化保留」只对 V-暂时与 V-非阻断成立，V-阻断时条件①不因可变量化而成立；
  - **新增出口检查第 7 项·变量分级检查**（判据是否写明、交接前 V-阻断清单是否为空），原第 7 项顺延为第 8 项；
  - **交接门禁与呈示终点**补「变量三清单」（阻断应为空／非阻断含判据／暂时含判据）；
  - 风险表新增「变量化被当作已消除差异，绕过规则 C」；认知操作表「变量化继续」的必须产物补分级结论与判据；后续检验观察项补变量分级观察（含「是否把 V-阻断标成 V-非阻断以换取交接」）。
- **未处理项（保留）**：M1（需求接口内部张力）、M2（变量取值域内的具体项是否需过规则 E 门槛）按裁定**保留为待修文本项**；「12/14 触发无外部判据」**继续观察**。
- **未重跑案例**：run-04 的案例产物未获判定，本目标不据其内容推进，也不代裁其变量 A／条件项 E 的阻断级别。
- 本轮未新增审计条目、未改目标 `status` / `progress`；`I-401` open、`I-402` collecting 不变。
