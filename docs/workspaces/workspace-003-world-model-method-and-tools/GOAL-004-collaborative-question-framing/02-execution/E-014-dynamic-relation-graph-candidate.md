# E-014 · 形成动态问题关系图方法候选 v0.6

### 2026-09-27 · 图式重构草案

- 用户本轮要求将阶段一重新理解为动态问题关系图上的操作方法，节点与关系保持开放，不预定世界问题分类或封闭边类型，不排列成固定步骤或问卷。
- 形成 [v0.6 草案](../attachments/stage1-dynamic-relation-graph-candidate-v0.6.md)：围绕发现、展开依赖、拆分/合并、找共享前置、识别真实冲突、剪枝、挑战覆盖与判断够用展开；记录图表述的五类风险及约束。
- 收束表述为足以启动阶段二求解的候选结构，交创作者确认；区分创作者意图、客观问题、分析者推断、证据与研究动作，不将创作确认视为事实证明。阶段二仅说明后续逆向识别模型依赖的边界。
- v0.6 为 draft/unaccepted，尚未测试或接受；v0.5 与既有探针测试保留历史，不提升案例节点、边或结论为通用结构。本轮未运行任何探针、未回答“世界有多大”、未构建模型或图数据库/schema/可视化。
- 同步当前候选引用与执行索引；I-401/I-402、Goal 状态和进度保持不变。未新增 Decision 或正式审计意见，未推进阶段二及 W3。
- 补充后续探针测试方案：固定版本与实际输入，观察图式操作及创作者可纠正性，分别记录方法证据和案例结果；明确操作清单开放、非穷尽，来源/认知地位维度不是互斥节点种类。仅补充方案，未实际测试。
