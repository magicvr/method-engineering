# E-020 · 按 run-02 失败判定修订三条结构性问题并形成 v0.10

### 2026-09-27 · 失败样本驱动的三修

- 创作者对 v0.9 第二次试跑（[运行 02](../attachments/probe-01-stage1-test-v0.9-run-02.md)）判定**未通过**，同时保留局部正证据（premature elicitation 实质改善、变量化继续、出口退回检查拦截 T2 并整改）；判例的延伸问题与执行者提出的两项方法层观察按裁定**封存**，不再追问。
- 失败机制三条：① **候选过生成**（词典/词源/抽象可能性依据的候选被提升进结构，缺相关性门槛）；② **诊断性探索越界**（自行引入「前现代移动＋个人一生」等输入未提供的条件，并产出 10⁵/10⁷ km 量级/精度判断）；③ **层级重新混合**（世界客观尺度、角色知识、剧情交付经「求解必须依赖承载装置」重新绑定）。附带观察：13/13 操作全部触发仍可疑，局部动作数核对不足以排除全局清单遍历。
- 据此产出 [D-012](../01-decision/D-012-run02-failure-three-fixes.md) 与 [v0.10 候选](../attachments/stage1-framing-method-candidate-v0.10.md)：
  - 新增**规则 E 入结构门槛**（当前输入依据＋结构改变＋可排除性；词典/词源/抽象可能性只入候选池；禁止为广度扩张候选；L1 不得以「请创作者挑读法」为主要形态）；
  - **规则 D 增补假定边界**（只用输入给定条件；禁止由外部假定产出定界结论；需外部条件时登记未定项或变量；假定清单与来源强制留痕）；
  - 新增**层级规则 L1/L2** 与两种显式跨层接口（需求接口／素材接口），禁止跨层求解依赖，角色可知性须明确归属，交付要求属 L2 且不构成 L1 求解依赖，交接内容为 L1 结构＋单列 L2 消费约束；
  - 出口退回检查增加**门槛检查／层级检查／假定检查**三项；操作表增加「层级归属判定」行；风险约束表增加「候选过生成」「探索引入任意假定制造定界结论」「层级混合」三行，并在触发纪律中**明文登记全局可判别性为未解决缺陷**。
- **判例封存事实**：run-02 的案例产物（读法、度量轴、答案形式、叙事功能、关系、T1～T6、r1/r2）按裁定封存，不作为事实或后续决策依据；本目标后续记录不再引用其内容作为依据。
- 登记两项未处理项（不声称已修）：触发可判别性缺陷；L1/L2 分层对父级 W2/W3 的潜在影响（跨目标提示，待父级按 P-006 处理）。
- 本轮未运行新探针、未新增审计条目、未改目标 `status` / `progress`；`I-401` open、`I-402` collecting 不变。下一步仍是以 v0.10 对同一输入再跑一次，并核对门槛／假定／层级三项是否真正生效。
