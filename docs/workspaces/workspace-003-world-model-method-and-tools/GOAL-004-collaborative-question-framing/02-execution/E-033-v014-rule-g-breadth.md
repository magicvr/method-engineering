- 创作者对 [run-07](../attachments/probe-01-stage1-test-v0.13.1-run-07.md) 的判定：**未通过**，但**保留覆盖攻击机制的局部正证据**——规则 G 确实执行了多轮反例攻击并从既有轴长出新问题（条件依赖／连通性／边界性）；**规则 E 准入、规则 D／G 边界、规则 F 归属均表现正常**。
- **证伪的关键反例**：第 4 轮「没有新维度，所以停止」不成立——当前结构下仍能构造出「**所有当前问题答案一致、却在原问意义上显著不同**」的两个世界（空间结构相同而总体规模相差巨大）。**缺陷名**：**coverage search myopia**——攻击只围绕已采纳的那条轴做局部变化，未充分搜索**与当前轴正交**的 AND 型维度；且**候选池中已出现的非空间尺度候选在停止前未被做充分性攻击检验**。
- 按 [D-022](../01-decision/D-022-run07-fail-search-myopia.md) 形成 [v0.14 候选](../attachments/stage1-framing-method-candidate-v0.14.md)（指纹 `sha256 94C3BEC3…D339`，46,517 B，206 行）：
  - **G.1 改为六步**：沿轴构造 → **正交搜索（必做）** → **候选差异清算（必做）** → 判定与准入 → 重复 → 留痕；并新增**停止条件收紧**（须同时满足：① 已执行跨轴含正交的攻击；② 已对已出现而未准入且可能影响原问的候选差异**逐项**给出攻击或排除理由；③ 继续攻击不再产生有实质贡献的新维度）；明写「**不得因同一轴上连续攻击失败而停止**」；

  - **G.3 门禁**：未执行正交搜索、或未逐项清算候选差异、或只有一轮、或未给停止理由 → **不得交接**；交接结构须含覆盖攻击记录（含正交搜索与候选差异清算）与「仍可能遗漏」声明；
  - **出口退回检查第 8 项**、**认知操作表（挑战覆盖）**、**风险表**（新增「**覆盖搜索近视**」）、**后续检验观察项**（新增正交搜索与停止证据的观察）同步；
  - **未把任何具体维度写入固定分类**（生成时已核对：具体维度名残留 0）。
