- 按 [D-027](../01-decision/D-027-a001-closure-v016.md) 形成 [v0.16 候选](../attachments/stage1-framing-method-candidate-v0.16.md)（指纹 `sha256 CB9D4C22…FC4C`，56,909 B，242 行）：
  - **新增 G.1.3「交接相关增量」**——新差异只有改变 **① 原问的所求／② 必要问题结构／③ 未决项的归属与下一阶段状态（直接引用规则 F 现有机制）** 至少一项才算增量；只「还能想到」而不改变这三项者 → **残余／回流风险登记，不单独阻断交接**；**明文禁止**把「构造不出」当**充分性证明**（只作观察）；增量仍须过规则 E。

  - **新增 G.1.5「残余遗漏登记」**（范围／为何暂不阻断交接／**回流触发**）。
  - **旧「停止条件」→「收束判据」**（四项同时满足：宽度要求、逐项清算、**不再产生交接相关增量**、残余遗漏登记）；**不得**以「同一方向失败／已找到若干维度／本次运行结束」为收束理由，**不得**把「再也构造不出」当充分性证明。
  - **同步**：G.2 第 3、5 条；**G.3**（四项缺失即不得交接＋写明**可交接第三态**）；认知操作表（挑战覆盖行）；**出口退回检查第 8 项**（改为「覆盖攻击与收束检查」）；**收束与创作者确认段**（写明第三态）；**风险表**（改写「单轴坍缩」、收紧「覆盖搜索近视」、**新增「把『再也构造不出差异』当作充分性证明」**）；**后续检验观察项**（新增残余登记／增量判据／读法不清零／唯一性四条）。
