# E-018 · 试跑前形成 v0.9 基线（路由、诊断探索、命名）

### 2026-09-27 · 方向通过后的三项小修

- 创作者通过 v0.8 方向并**允许进入第二次探针试跑**，同时给出三项试跑前小修：① 规则 B 改为按未定项性质路由主动分析（防止反 elicitation 规则退化为新的固定流水线或制造虚假候选）；② 显式允许有界诊断性探索/局部试解（用于判断解释、依赖与边界，不升级为正式模型或答案）；③ 弱化标题中的「动态关系图」，避免工作表示重新成为方法身份。
- 据此产出 [D-011](../01-decision/D-011-routing-and-bounded-exploration.md) 与 [v0.9 候选](../attachments/stage1-framing-method-candidate-v0.9.md)：
  - 规则 B 改写为 N1～N5 性质路由表（含「只做该性质需要的动作」「不得制造虚假候选」两条硬约束），并明文否定「每个未定项走完全部动作」；
  - 新增规则 D 与操作行「有界诊断性探索」，含五条约束（有界 / 目的限定 / 留痕 / 不升级 / 越界即停）；
  - 「方法对象与工作表示」改为表示可替换，明确方法身份是操作与产物、不要求建图、不以表示完整度验收；候选文件名改用 `stage1-framing-method-candidate-v0.9.md`；
  - 风险约束表新增「反 elicitation 规则退化为固定流水线」「制造虚假候选」「诊断性探索升级为结论」「表示形式变成方法身份」四行；出口退回检查增加「是否被机械套用全部动作」一项；后续检验观察项同步更新。
- v0.8 加后续注记保留原文；v0.7/v0.6.1 与两次运行记录仍为历史证据。
