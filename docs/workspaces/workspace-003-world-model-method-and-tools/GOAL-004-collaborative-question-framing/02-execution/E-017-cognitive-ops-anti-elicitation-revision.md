# E-017 · 按 elicitation 诊断改造操作定义并形成 v0.8

### 2026-09-27 · 结构性缺陷诊断与操作定义改造

- 创作者指出：本阶段首先要解决的是**认知操作被退化成 elicitation（向用户索取定义）**；v0.7 的门禁收紧不构成对此问题的修复。
- 诊断结论（三条机制）：① 未定项在图里只有「创作者给定」一条出路；② 操作定义只写动作、不写必须产出物，提问成为动作完成的替代品；③ 收束判据把「已能提出待创作者裁定的问题」当完成态，识别歧义越多越早收束。
- 据此产出 [D-010](../01-decision/D-010-operations-must-produce-structure.md) 与 [v0.8 候选](../attachments/stage1-dynamic-relation-graph-candidate-v0.8.md)：
  - 新增「退化诊断」节（对照 v0.6.0 实际运行产物）；
  - 三条对治规则：产出物规则（只能产出提问 = 操作未执行）、未定项处理次序（候选化 → 后果推导 → 可判别性检查 → 变量化继续）、回问条件与携带分析的形态要求；
  - 操作表由「动作描述」改为「触发困难 + 完成后必须出现的产物」，并把解释候选化、后果推导、可判别性与排除、变量化继续列为独立操作；
  - 新增「出口退回检查」节：收束前逐项审查待裁定项是否本可由分析推进，只索要定义者退回分析；
  - 风险约束表补「操作退化为 elicitation」一行；后续检验观察项改为以「是否以提问替代操作、是否走完四步、是否变量化后继续、是否留退回检查结论」为准。
- v0.7 加后续注记标记为被取代，原文保留；v0.6.1 与两次运行记录仍为历史证据。
- 本轮**未运行探针、未新增审计条目、未改目标 `status` / `progress`**；`I-401` open、`I-402` collecting 不变。下一步仍为：以 v0.8 对同一输入做隔离复测，并留存出口退回检查结论。
