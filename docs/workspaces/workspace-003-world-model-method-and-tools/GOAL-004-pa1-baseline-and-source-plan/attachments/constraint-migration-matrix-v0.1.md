# PA1 约束迁移矩阵 v0.1

## 迁移判定

本矩阵逐类核对 R1 v0.6.4 与 prior-art 调查的关系。判定分四类：

- **沿用**：对 prior-art 调查继续有效，必须保留。
- **内容基线**：作为最终方法的需求/非目标/退出契约输入，后续映射必须覆盖，但不是当前调查证据。
- **终止/不迁移**：只约束旧 H 可行性工作，不自动约束 prior-art；复用旧材料前必须重检。
- **用户裁决后冻结**：新增访问、费用、资源或来源范围选择；用户 2026-10-04 已按 D-003 作出选择并冻结，超出边界须重新裁决。

## 结论

- R1 的通用输入授权、角色分离、证据可追溯和停止责任继续适用。
- §10/§13、最终工作版契约和排除项是后续映射的需求基线，不是 theoretical evidence。
- 旧 H 的 9 格、180 分钟、预登记与 D-011 标签不迁移；旧 H3-SEM-001 不闭合。
- I-007 能否关闭仍取决于 S3/S4 的来源/访问方案、资源和停止规则，以及相应用户裁决；本矩阵本身不等于 I-007 verified。
