# D-003 · 用户裁决来源策略、访问残余与调查资源

## 用户决定

用户 2026-10-04 对 [S3/S4 裁决请求](../attachments/s3-s4-user-decision-request-v0.1.md) 的 J-01～J-03 全部接受推荐项：

- **J-01 A · 现代方法核心**：System Dynamics 以 PA-S04-C Sterman（2018）领域回顾和 PA-S04-D Naugle 等（2024）近期定义为核验来源；PA-S04-B Sterman（2000）作教科书细节入口；PA-S04-A Forrester（1961）仅作历史起源引用。
- **J-02 A · 公开托管作者/大学副本 + 明确残余接受**：授权为本次内部研究读取 PA-S01～PA-S03 的公开托管 PDF；以出版方版本引用，不提交/复制全文、不再分发、不推定再利用授权。用户明确接受以下残余，来源权限状态为 `accepted-residual`，**不是 `verified`**：
  - 未知：出版方对公开托管副本在拟议研究用途下的授权未核实。
  - 范围/影响：仅限本目标 PA2/PA3 内部阅读与引用，不影响对外发布、再分发或再利用许可。
  - 理由/缓解：核心原始来源且公开托管路径可访问；使用官方书目定位、只保留必要摘录；发现出版方异议或更可靠许可路径时停止该路径。
  - 期限/复审触发：外部交付前、出版方异议、获得正式许可或改用开放替代来源时复核。
  - 责任人：方法工程响应负责人。
- **J-03 A · 有界首轮**：每类 1 个核心来源，最多 2 个支撑来源；新增费用上限 0；人类复核与决策上限 6 人时；AI 执行时间另记，不折算为人时。覆盖五类后先作要素抽取，只有冲突、缺口或映射失败才新增来源；禁止声称穷尽或“理论不存在”。

## 理由

该组合在来源代表性与可执行性之间保持有界：System Dynamics 使用现代方法定义和领域回顾，避免以 1961 历史文本直接代表当代实践；PA-S01～PA-S03 保留核心原始来源，同时把未核实的公开托管权限显式作为用户接受的残余而非已核实许可；J-03-A 限定来源数量、费用和人类投入，防止调查无限扩张。

## 被拒替代

- J-01 B/C：历史与现代全量并列或历史起源主导，扩大抽取量且与“吸收成熟方法而非复制历史”目标不够直接。
- J-02 B/C：购买/机构访问增加费用和前置依赖；仅开放/摘要会让三个核心来源在无开放全文时无法进入抽取。
- J-03 B/C：深入检索超出首轮有界目标；最小检查缺少跨来源冲突检查，风险过高。

## 后果与门禁

- S3 来源/访问方案据此冻结；S4 进入 I-007 证据更新与 PA1 退出审计。
- Root I-007 可按“权限未知部分由用户明确接受有界残余”处理，但必须记录为 `accepted-residual`，不得写成 `verified`。
- 用户本次选择不自行关闭 I-007、不退出 PA1、不开始 PA2；仍需更新 Root 证据并完成独立阶段审计。
- 超出 6 人时、产生新增费用、增加核心/支撑来源数量、改变来源策略或扩大范围时，暂停并重新请求用户裁决。
