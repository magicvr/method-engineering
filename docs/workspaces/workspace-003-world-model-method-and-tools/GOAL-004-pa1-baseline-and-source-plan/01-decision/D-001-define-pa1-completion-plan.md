# D-001 · PA1 范围与完成计划

## 决定

建立 GOAL-004 作为 GOAL-003/PA1 的阶段子目标，只承载基线与来源方案。PA1 依次完成需求固定、约束迁移、来源/访问方案和资源/授权/停止规则；Root I-007 满足并经过阶段审计后再返回 GOAL-003 决定是否进入 PA2。

## 理由

GOAL-003 有 PA1～PA5 纲领路线图，PA1 本身含多项独立证据和可能触发用户裁决的访问/资源选择。用阶段子目标隔离治理上下文，可以避免把来源核实误写成理论吸收，并将用户授权点与后续 PA2 证据分开。

## 完成边界

- S1 只固定需求/H 基线，不评价 H 假设有效性。
- S2 只迁移约束和授权，不扩大调查范围。
- S3 只提出来源与访问路径；闭源获取、付费或范围扩张若需选择，必须由用户书面裁决。
- S4 只完成 I-007 证据与 PA1 退出审计；来源权限未知时仅可由用户明确接受有界残余，且不把残余写成 verified。S4 不关闭 I-008～I-010，不完成 GOAL-003。

## 被拒替代

- 直接在 GOAL-003 内混合执行 PA1～PA5：会使来源识别、理论抽取和路线判断的证据边界混淆。
- 为 PA2～PA5 预建全部子目标：违背渐进拆分，且后续边界依赖 PA1 结果。
- 以公开摘要或候选书目替代原文方案：不能支撑后续理论要素抽取。
