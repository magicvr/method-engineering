# PA5 五类未决有界信息收敛计划 v0.1

## 核心判断

五类未决应拆成事实问题、用户规范问题和实践效果问题。推荐：既有证据限定结论 → 用户裁决必要边界 → 授权有限离线纸面反例检查 → 对尚未验证的实践效果明确接受残余或保持阻塞。不把新增来源、真实案例、完整 H 实验、工具或原创作为 PA5 默认前置。

## 五类路径

| 未决 | 现有证据可收敛的局部结论 | 需用户裁决 | 仍需新增证据 | 可保留的有界阻塞 |
|---|---|---|---|---|
| G-01 客观问题边界 | 角色信念可以成为建模对象；查询清晰不等于模型有权裁决 | 世界事实、认知事实、作者取舍及混合问题的操作边界 | 边界例检查；实际可用性需后续真实使用证据 | 未定设定、认知依据不足、不能保真拆分的子问 |
| G-02 诊断充分性 | 当前来源不证明五项互斥、穷尽或触发充分；定性输出有精度限制 | 严格顺序、多标签、回访及新建模触发条件 | 交叠/漏判反例检查 | 必要检查信息不足、规则冲突未裁决 |
| G-03 能力发现与最低充分性 | 查不到不等于不存在；目的相关不等于数学最小或跨实例有效 | 是否采用局部充分性解释、是否允许非机制表示 | 发现失败模式、粒度/删减及条件内外对照 | 目录不完整、适用性不明、跨实例有效性未验证 |
| G-04 版本影响与创作回接 | 修订循环不能推出完整版本管理或回接协议 | 人工保守复核是否足够；自动重裁/事实晋升等是否排除 | 变更影响/回接纸面检查 | 依赖不明的旧裁决待复核；自动传播/跨模型权威 |
| G-05 H2/H3 可靠性 | 查询驱动不证明转译/综合可靠；主体视角不证明采样代表性 | H2 是否仅为可选提示；H3 是否为首版必要前置 | H2 有限对照；若保留 H3，先定义采样/充分性再另行授权验证 | H2 可靠性/增益；H3 代表性/覆盖/冷启动充分性 |

“有界阻塞”是合法收敛结果，但不是放行方式；若阻塞项是 R2-W 必要依赖，必须阻止对应路线冻结。

## 方案对比

| 方案 | 范围 | 新增投入估算 | 风险/条件 |
|---|---|---|---|
| A 最小 | 证据限定 + 用户裁决/残余，不做检查 | 1.5–3 人时，直接费用 0 | 操作风险基本未检查；只有用户接受覆盖路线冻结的残余且必要功能未阻塞时才可能进入 S3 |
| B 推荐 | A + 最多 20 个局部离线纸面检查单元；一次汇总复核；不默认新增来源/真实案例/完整 H 实验/工具/原创 | 6–8 人时，直接费用 0 | 能暴露操作边界错误；仍不能证明真实可用性，须保留实践效果残余 |
| C 深入 | B + 最多两个明确问题的新来源切片，优先 G-03/G-04；经授权的真实使用或 H2/H3 验证 | 10–16 人时起，费用另设上限 | 证据较强，但存在扩界、访问权限及前置依赖风险 |

推荐 B。顺序：用户先裁决需求边界与必要性；再授权有限纸面检查；达到上限或遇明确反例即汇总，不自动增加检查；按结果选择限定验证、书面残余或阻塞。

## 需另行书面授权的动作

- 新增来源：具体问题、范围/数量、访问方式、用途、预算、停点。
- 付费：类别与绝对上限。
- 真实案例：案例、用途、材料范围、去标识、结果权威、责任；先核对 I-002。
- 实验/检查：合成材料、局部候选、对照、数量、判据、记录、停止/失败处理；纸面对照也需要授权。
- 外部执行/审计：provider、材料、权限、费用、输出用途。
- 原创：必要需求、实际替代检查、继承/有限改造不足、范围/输出/反例/资源/责任/审计门禁。

I-007 现有权限残余只覆盖 PA2/PA3 内部阅读/引用；不能推定覆盖 PA5 新原文调查或外部发送。

## I-010 进入 PA5 路线冻结的必要条件

任一路径前不得进入 GOAL-008 S3：

1. 证据闭环：拟冻结路线依赖的局部问题均有必要需求、调查边界、实际替代检查、继承/有限改造不足、限定结论、不能证明什么、R2-W 范围/退出/停止/责任/复审触发。
2. 用户明确扩展残余：逐项说明接受什么未知、为何可进入指定 R2-W 范围、只解除哪一门禁、排除哪些承诺、缓解/监控、责任、期限与复审触发。

两条路径共同要求：五类均有可追溯处置；必要依赖的 blocked 项阻断对应冻结；需求变化/冲突/新增权限已合法裁决；I-002/I-004/I-006、I-007/I-008 和旧 H 门禁未被顺带关闭；无对应冻结门禁的开放 required finding；PA5 退出另需覆盖范围的独立审计。

## 当前结论

批准 B 仅表示批准 S1 候选计划和后续授权申请，不自动执行 S2，不冻结路线，不改变 I-010。只有实际证据或明确扩展的残余决定，才能成为 S3 门禁依据。
