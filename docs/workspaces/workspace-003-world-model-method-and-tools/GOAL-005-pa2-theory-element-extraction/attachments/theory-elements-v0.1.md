# PA2 理论要素抽取 v0.1

## 使用边界

本文件只记录来源中的理论要素或局部主张及原文定位，不映射需求 §10/§13，不给整理论贴 inherit/adapt/not-applicable 总标签，也不证明适用性。证据等级为“原论文/原PDF局部内容”；来源内限制与未决项单列。PDF PAGE 指 PA2 本地访问台账中对应副本的页标记。

## PA-S01 · Compositional Modeling

| ID | 要素/局部主张 | 前提 | 输入/输出 | 范围、限制、反例线索 | 定位 |
|---|---|---|---|---|---|
| S01-01 | 以查询需要为导向构造场景模型，模型应足以回答查询并尽量排除无关细节。 | 有领域理论、系统描述和查询。 | 输入：领域理论、系统结构、查询；输出：针对查询的场景模型。 | 建模全部方面或总选最精确模型代价过高；依赖领域表示和模型片段组织。 | PDF PAGE 1–2，摘要/§1 |
| S01-02 | 领域理论由可按需组合、显式条件化的模型片段构成。 | 片段适用条件可描述，片段关系可判断。 | 输入：条件及涉及个体；输出：约束/关系集合，可组合进场景模型。 | 片段可覆盖部分设备/过程；假设不总独立，也可能冲突。 | PDF PAGE 8–9，§2.1–2.2 |
| S01-03 | 建模假设显式标注本体、粒度、抽象/近似、视角及操作承诺与适用性。 | 有足够领域知识写明假设条件。 | 输入：系统/现象及假设；输出：模型候选及约束。 | 假设适用性依赖领域；并非所有简化都有通用判断技术。 | PDF PAGE 13–19，§2.3 |
| S01-04 | 粒度假设决定哪些对象进入分析，并可将部件集合聚合为实体。 | 系统组成、部件关系和分析范围可知。 | 输入：系统结构、关注范围；输出：纳入分析的对象及模型。 | 视角外对象可忽略；聚合可能隐藏个体差异。 | PDF PAGE 15，Grain assumptions |
| S01-05 | 模型组合受查询驱动并需保持一致，排除假设与场景冲突的候选。 | 查询可指示所需行为；结构/假设可用于一致性检查。 | 输入：查询、场景、领域模型；输出：可回答查询的组合模型。 | 对象选择、粒度、相关现象、视角、近似等仍是待解决问题；组合算法不保证自动判定所有选择。 | PDF PAGE 20–24，§3–3.1 |
| S01-06 | 模型验证与修订构成循环：分析结果可揭示假设与推导行为不一致，据此修订模型。 | 可分析已组合模型并比较假设/结果。 | 输入：组合模型、分析结果；输出：不一致及修订。 | 不保证自动发现正确模型；模型制定仍是困难问题。 | PDF PAGE 5–6，图 2/§1.1 |

## PA-S02 · Qualitative Process Theory

| ID | 要素/局部主张 | 前提 | 输入/输出 | 范围、限制、反例线索 | 定位 |
|---|---|---|---|---|---|
| S02-01 | 以对象、量、过程表示物理变化；过程描述导致量随时间变化的机制，而不只是微分方程。 | 有对象、量及过程词汇的领域描述。 | 输入：对象/量/过程；输出：可能过程及其对量的影响。 | 聚焦常识性物理推理；过程概念比纯数值动力学更结构化。 | PDF PAGE 1–6，§1–3.1 |
| S02-02 | 量空间以有序标志值和区间位置作定性表示。 | 已知相关量的有意义标志值及序关系。 | 输入：量及标志/不等式；输出：定性值及跨阈值关系。 | 只保留序关系会丢失具体数值；适合过程条件依赖序关系变化的情形。 | PDF PAGE 11–15，§2.2–2.3 |
| S02-03 | 个体视图组织个体的量；功能关系表达量之间的关系或依赖。 | 领域存在可识别个体和可陈述关系。 | 输入：个体、量、函数/关系；输出：状态组合约束。 | 功能关系不必是完整数值函数；信息不足时可能保留多个可行状态。 | PDF PAGE 15–19，§2.5–2.6 |
| S02-04 | 多过程对同一量的影响可合成，推断其增加、减少或保持不变。 | 已识别活动过程及其影响方向。 | 输入：过程结构、量的影响；输出：定性变化方向。 | 相反影响可能无法唯一确定；属于定性推理而非精确数值预测。 | PDF PAGE 22–25、79，§3.6.3 |
| S02-05 | 极限分析推断过程何时启动或停止，并产生后继结构变化。 | 过程条件与量空间中的极限点已表示。 | 输入：视图/过程结构及量关系；输出：极限事件及后继行为结构。 | 可能产生多种后继；须区分真实振荡与状态重复造成的 stutter。 | PDF PAGE 26–31，§3.3/3.6.4 |
| S02-06 | 视图、过程、影响和极限推理可组合成可能行为历史（envisionment）。 | 有初始情境、过程知识和量关系。 | 输入：情境、过程模型；输出：可能行为序列/历史。 | 信息不完备时可能有多个分支，不保证唯一轨迹。 | PDF PAGE 19–36，§2.7/3.7–3.8 |
| S02-07 | 因果定向假说将感知为因果的变化与依赖关系联系起来。 | 依赖结构可表述并追踪变化传播。 | 输入：依赖关系与量变化；输出：因果方向相关推理结构。 | 文中以 hypothesis 提出，并讨论推理僵局和安全假设；不应外推为普遍因果理论。 | PDF PAGE 69–74，§5.2 |
| S02-08 | 微分定性分析比较速率、持续时间等变化对结果差异的定性影响。 | 有可比较的参数历史。 | 输入：基准/变化情境；输出：定性差异判断。 | 结论依赖历史与区间假设，不是一般精确敏感性分析。 | PDF PAGE 75–78，§5.4 |

## PA-S03 · Thinking about Mechanisms

| ID | 要素/局部主张 | 前提 | 输入/输出 | 范围、限制、反例线索 | 定位 |
|---|---|---|---|---|---|
| S03-01 | 机制由实体与活动组织构成，产生从设置条件到终止条件的规律变化。 | 活动产生变化，实体凭借性质参与活动。 | 输入：设置条件、实体/性质/活动；输出：终止条件/现象。 | 作者不主张所有解释都是机制描述。 | PDF PAGE 3–4，§1–2 |
| S03-02 | 机制说明须交代实体、性质与活动如何组织并逐步产生结果。 | 同类机制在相同条件下通常以相同方式运作。 | 输入：已组织实体/活动；输出：中间阶段及结果。 | 组织可含位置、结构、方向、时序、速率、持续时间；依具体机制而定。 | PDF PAGE 4–5，§2 |
| S03-03 | 活动是特定类型的原因；泛称 cause 需由更具体的生产性活动说明。 | 实体作为原因是因为其进行某种活动。 | 输入：实体参与的活动；输出：被产生的变化。 | 生产性活动不能仅由标记传递或守恒量交换穷尽。 | PDF PAGE 7–8，§3.1 |
| S03-04 | 机制描述包含设置条件、中间活动与终止条件；充分描述不应留下难以理解的缺口。 | 解释目标与所界定的过程匹配。 | 输入：设置条件；输出：中间阶段/终止条件。 | 阶段可线性、分叉、汇合或成环；连续过程可离散表示。 | PDF PAGE 11–13，§4.1–4.3 |
| S03-05 | 机制处于嵌套的部分—整体层级；低层组件参与产生高层现象。 | 低层组件与高层现象存在生产关系。 | 输入：低层组件机制；输出：高层机制/现象。 | “到底”层级相对研究者/团队/领域；不要求统一追到量子层。 | PDF PAGE 14–15，§5–5.1 |
| S03-06 | 机制图式是可填入已知组件的抽象机制类型；实例化后可解释、预测或设计实验。 | 图式保留足以刻画机制的结构并可对应实例。 | 输入：图式+具体组件/设置；输出：解释、预测或实验方案。 | 抽象程度不等于适用范围；同样抽象的图式可有不同范围。 | PDF PAGE 16–18，§5.3 |

## PA-S04-D · Quantitative System Dynamics

| ID | 要素/局部主张 | 前提 | 输入/输出 | 范围、限制、反例线索 | 定位 |
|---|---|---|---|---|---|
| S04D-01 | 模型以因果反馈结构为基础，只纳入焦点问题定义下的相关因果关系。 | 问题边界、粒度和变量已界定。 | 输入：因果关系；输出：反馈结构及随时间展开的行为。 | 不是无边界地囊括全部关系。 | PDF PAGE 4，Characteristic 1 |
| S04D-02 | 反馈环分为强化环和平衡环，对行为作用不同。 | 因果链闭合并回到焦点变量。 | 输入：反馈结构；输出：加速或回归均衡的倾向。 | 是倾向性描述，不表示所有系统必达均衡或必然指数增长。 | PDF PAGE 4，Characteristic 1 |
| S04D-03 | 累积、存量和流量是基础；存量带来惯性/路径依赖。 | 存量承载累积，流量改变存量。 | 输入：流入/流出；输出：存量变化及系统动态。 | 与轻视存量的“微分世界观”对照。 | PDF PAGE 5，Characteristic 2 |
| S04D-04 | 延迟由不同步的流入、流出等累积过程导致。 | 累积过程的流入/流出时序不一致。 | 输入：累积与不同步流动；输出：延迟及后续动态影响。 | 未给出普适定量规则。 | PDF PAGE 5，Characteristic 2 |
| S04D-05 | 模型以方程定义变量，通过逐步计算变量值模拟假设的逻辑后果。 | 假设已具体化为方程。 | 输入：初始值、方程；输出：后续时步变量值。 | 测试/政策等支持元素不必描述现实机制；随机/统计/离散事件元素通常少量且特定用途。 | PDF PAGE 5–6，Characteristic 3 |
| S04D-06 | 概念上使用连续时间，实际仿真用差分方程近似。 | 连续时间结构可按离散时步仿真。 | 输入：连续时间模型；输出：离散时步仿真结果。 | 概念连续不等于计算连续；通常聚焦有界时间尺度。 | PDF PAGE 6，Characteristic 4 |
| S04D-07 | 分析重点是因果反馈结构如何驱动行为，可用仿真或非仿真方法。 | 反馈、累积、延迟已由方程表达。 | 输入：结构与行为分析；输出：可能的杠杆点。 | 仿真不是唯一方法。 | PDF PAGE 6，Characteristic 5 |
| S04D-08 | 五项特征用于界定定量系统动力学建模；具备这些特征的模型视为系统动力学模型。 | 使用该文界定的定量建模范围。 | 输入：五项特征；输出：模型归属判定。 | systems thinking、group model building 等过程内容不在该文界定对象内。 | PDF PAGE 2–3，定义/范围声明 |

## PA-S05 · Agent-Based Modeling

| ID | 要素/局部主张 | 前提 | 输入/输出 | 范围、限制、反例线索 | 定位 |
|---|---|---|---|---|---|
| S05-01 | ABM 将系统表示为自主决策实体及其关系和交互。 | 研究对象可表达为实体、决策、行为和交互。 | 输入：agents、规则、关系、情境；输出：个体行为与系统动态。 | 需按目的确定描述层级；不是所有问题都适合一般化 ABM。 | 引言，ABM 定义段 |
| S05-02 | 个体交互可产生不可还原为部件性质之和的涌现现象。 | 整体行为受组成实体交互影响。 | 输入：个体行为/交互规则；输出：整体涌现行为。 | 涌现可能反直觉、难预测；呈现行为不等于可靠预测。 | Benefits of ABM，emergent phenomena |
| S05-03 | 当自然描述单位是行为主体时，从主体视角建模较自然。 | 领域 actors 与待描述行为单位对应。 | 输入：主体及行为；输出：主体交互与系统表现表示。 | 不证明个体行为已被正确识别或参数化。 | Benefits of ABM，natural description |
| S05-04 | 微观表示可加入异质性、个体状态和适应行为。 | 个体差异或适应对问题有意义。 | 输入：个体属性、规则、学习机制；输出：异质主体动态。 | 细节增加行为设定和计算负担；应服务模型目的。 | Benefits of ABM，flexibility |
| S05-05 | 聚合描述难以表达个体行为与系统结果之间复杂映射时，ABM 可模拟该映射。 | 结果依赖多个主体行为且聚合方法不足。 | 输入：偏好、行为、环境；输出：等待时间等系统表现。 | 案例论证不能外推为任何复杂映射都必须用 ABM。 | 主题公园案例 |
| S05-06 | ABM 可描述组织中的个体活动、风险事件及其对组织表现的影响。 | 风险可刻画为作用于成员活动的事件。 | 输入：成员行为、风险事件；输出：风险传播/组织结果。 | 该处含较强作者判断，不能视为该段独立验证的普遍结论。 | organizational simulation |
| S05-07 | 模型必须服务特定目的并选择足够细节；不存在适合所有目的的通用模型。 | 建模前明确目的。 | 输入：目的、描述层级、细节；输出：目的特定模型。 | 细节选择仍带艺术性；不应仅因技术可实现而扩大范围。 | Issues with ABM |
| S05-08 | 人类 agent 的非理性、主观选择和复杂心理因素可能难以量化、校准或论证。 | 模型涉及人类行为或软因素。 | 输入：数据、专家知识、行为假设；输出：受输入完整性影响的模拟结果。 | 可能只支持定性洞见；不应自动用于定量决策。 | Issues with ABM |
| S05-09 | 对大量组成单位逐一描述和模拟可能带来显著计算成本和运行时间。 | 模型覆盖大量个体并模拟行为。 | 输入：个体数量、规则；输出：结果及资源耗用。 | 聚合方程可能更省状态变量，但是否足够取决于问题。 | Issues with ABM |
