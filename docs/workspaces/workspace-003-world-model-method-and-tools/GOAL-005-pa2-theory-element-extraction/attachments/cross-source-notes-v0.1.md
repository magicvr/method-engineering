# PA2 跨来源差异与冲突线索 v0.1

本文件只记录来源间概念差异、不同范围或潜在张力，不作需求映射，不判定哪一理论更适合本需求。

## 已抽取来源的范围差异

| 比较项 | 已记录差异 | 证据 |
|---|---|---|
| 建模对象 | S01 以查询驱动的模型片段组合为中心；S02 以对象、量和定性过程为中心；S03 以实体—活动机制为中心；S04-D 以反馈、存量、流量和方程为中心；S05 以异质 agent 及其交互为中心。 | S01-01/02、S02-01、S03-01、S04D-01/03、S05-01 |
| 粒度与聚合 | S01 有显式粒度假设和聚合选择；S03 使用部分—整体层级；S05 强调微观 agent 异质性及计算负担。 | S01-04、S03-05、S05-04/09 |
| 形式化程度 | S02 支持定性值、极限和多分支行为；S04-D 使用方程和离散时步近似；S05 可用规则/模拟表达 agent 行为。 | S02-02/05/06、S04D-05/06、S05-01/04 |
| 确定性 | S02 在信息不足时保留多个可能行为；S04-D 从方程推导假设的逻辑后果；S05 明确模型呈现不等于可靠预测。 | S02-06、S04D-05、S05-02/08 |
| 目的与停止 | S01 以查询充分性控制模型细节；S03 的“到底”层级相对研究目的；S05 明确模型必须服务特定目的。 | S01-01/03、S03-05、S05-07 |

## 张力与待观察项

- **定性 vs 定量**：S02 的定性过程/极限推理与 S04-D 的方程/离散仿真在表示和确定性上不同；尚未判断二者是替代、互补还是适用条件不同。
- **机制层级 vs 系统反馈**：S03 的组织层级以实体—活动机制为核心，S04-D 以反馈/存量/流量结构为核心；尚无同一案例上的比较证据。
- **个体异质性 vs 聚合**：S05 强调 agent 异质性和涌现，S01 允许通过粒度假设聚合部件；两者对“何时需要微观表示”没有共同验证案例。
- **模型目的控制**：S01、S03、S05 都显式限制模型/解释的范围；S04-D 也限定为定量系统动力学建模，但没有跨来源统一的停止规则。

## 未发现与未核实

- 在已抽取的 S01/S02/S03/S04-D/S05 中，未发现直接的、同一条件下的相互否证。
- S04-C 全文未取得，无法参与跨来源比较；任何声称“五类来源已完成交叉核对”的结论都不成立。
- 以上张力只作 PA3 比较入口，不构成理论适用性、缺口或选路结论。
