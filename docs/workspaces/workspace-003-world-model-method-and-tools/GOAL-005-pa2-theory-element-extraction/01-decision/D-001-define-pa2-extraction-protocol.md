# D-001 · PA2 抽取协议与边界

## 决定

按 PA1 冻结来源执行 PA2。抽取对象是理论要素或局部主张，不是整理论；每项登记来源 ID/版次、原文定位、主张、前提、输入/输出、适用范围、限制、反例/冲突线索和证据等级。无法核实的项保持 unresolved。

## 来源与顺序

- PA-S01～PA-S03 使用 PA1 接受的公开托管作者/大学副本，以出版方版本引用；权限未知部分按 accepted-residual 执行。
- PA-S04 使用 J-01 A：PA-S04-C Sterman 2018 和 PA-S04-D Naugle 等 2024 为核心；PA-S04-B/A 仅作细节/历史入口。
- PA-S05 使用 PMC 公开全文。
- 每类 1 个核心来源、最多 2 个支撑来源；新增费用 0；人类复核/决策上限 6 人时；超出须重新请求用户裁决。

## 证据与停止

- 只引用必要短摘录并给定位；不提交受限全文。
- 原文不足、访问状态冲突、来源版本不一致或需要新增来源/费用/范围时，停止受影响项并登记 unresolved。
- 本阶段不把来源内容直接映射到需求或旧 H；PA3 才作适用性比较。
