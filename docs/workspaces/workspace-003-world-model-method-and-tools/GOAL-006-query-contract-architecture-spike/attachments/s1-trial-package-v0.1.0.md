## 3. 控制侧判读标准（不交执行者）

采用 creator 已批准的 [D-003](../01-decision/D-003-baseline-and-trial-thresholds.md) I-003 局部阈值：

1. **实质歧义**：至少两种合理解释会改变答案形态、适用范围或能力 / gap 分类；仅用词不同不计。
2. **不必要征询**：让 creator 代做本可由助手给出有界选项的建模。创作者拥有的意图、边界、取舍仍可询问；记录被询问的原话及为何属于哪一种。
3. **S1 支持**：四题契约能启动既有能力基线评估、保存各自原始所求、关键假设与范围可追溯。缺少基线或 creator-owned 决定时，仅把依赖它的具体主张判为 `inconclusive`，不伪造观察结果。
4. **gap 观察**：逐题核对 semantic ambiguity、world-state gap、mechanism gap、mapping/composition gap 能否依证据区分。无可比较能力证据时，受影响类别为 `not observed` / `inconclusive`；能力不足若未实际观察，记 `not observed`，不宣称该情形已被验证。
5. **S2 入口**：仅在 S1 得到支持、且有一条可执行的**既有**能力路径时，才可另行考虑一次执行反馈；本包不授权该步骤。
6. **强制 grounding 重审触发**：至少两题真实模糊问题在缺少相关真实情境时反复停留于字面解释枚举或要求 creator 代建模，并且两题补入真正有来源的情境后都达到能力评估就绪，才提交 creator 重审；不自动生成规则。逐题留存重复卡住的输出、情境来源和补入前后变化，缺任一证据则不触发。

## 4. 可观察执行程序与停止条件（待授权）

1. 固定本文件版本与四题来源；保存执行者实际收到的每一段输入。四题分别在隔离上下文中完成 A，封存全部 A 输出后逐题进入 B；封存全部 B 输出后逐题进入 C。B / C 只沿用本题上下文和已封存契约，不引入其他题目的内容；不回写首轮记录。每题至少产生一个带版本号的契约；修订时保存差异。
2. 控制侧逐题核对原始所求是否保留、答案形态/范围/假设是否可追溯、实质歧义与征询是否出现。记录可开始何种基线评估、实际对照材料的来源及缺口；不要把试验解释写进执行者提示。
3. 若执行者把未确认内容当世界事实、改变原始所求、无法给出可追溯契约，或需要 creator-owned 决定而尚未获得，立即停止受影响题目的依赖判断，保留原始输出及原因。若某题无真实情境增量，记零变化；不制造额外情境。
4. 若无可评估能力证据，停止该题的能力充分性与具体 gap 判定；若四题仍不能满足 S1 支持标准，停止后续阶段并报告 `refute` 或 `inconclusive` 及具体证据。即使 S1 支持，只要没有可执行的既有能力路径，也停止于 S1。

**应捕获的证据**：输入及顺序、执行者原样输出、每题契约版本与版本差异、假设及其来源、未决的 creator-owned 决定、征询原话、情境补入前后的变化、实际能力材料的来源与可比较内容、四类 gap 的观察依据或未观察原因、所有停止点。创作者尚未作出的决定及未观察类别保持空缺，不用推测填补。
