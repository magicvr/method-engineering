# D-022 · 接受 S1 research-loop 试跑设计并授权形成窄 host 集成候选

创作者接受 GOAL-005 的 S1 独立调用试跑设计 v0.1 为设计基线，条件是仅按创作者指定修改 §3：不得预设任何具体系统配置、故障缓解机制或固定子问题清单。45 分钟为计划工作量边界；不能可靠按墙钟计时时，以查询数、来源数、检查点和停止理由作为可复核预算。细节见 [GOAL-005 D-008](../../GOAL-005-shared-research-loop/01-decision/D-008-s1-trial-design-accepted.md)。

下一步已明确授权为：从冻结的 S1 v0.16.1 派生并审阅一个窄 host 集成候选。此授权只覆盖候选文档和审阅；不授权把它合入 v0.16.1、修改已接受的 core/schema/adapters、启动研究调用或执行试跑。正式 host 集成和试跑执行仍须依已接受 integration plan 后续分别放行。GOAL-004 Probe 1、run-10 与案例结论保持不变。
