## D-011 · 接受 A-006 的闭合确认：重新记 W2 完成

### 触发

独立 closure check [`A-006`](../03-audit/A-006-a005-closure-check.md)（`source: independent`，auditor = Grok 4.7，保证等级 L0，verdict **`pass`**）：`A-005-F-001` / `F-002` / `F-003` 逐条核对后均判 **`fixed`**；`F-004` **与创作者裁定一致**（不另立更严 finding）；**本 scope 内没有新的 open required**；并**同意重新记 W2 完成**（子目标进度按 4 个工作包中的 2 个完成项回到 50%）**并进入 W3**。

### 决定

1. **接受该闭合确认**：`A-005` 的三条 required → **`fixed`**（**由独立闭审确认，非编排器自证**）；`A-005` 原文 `verdict: conditional` 保留为历史，其**有效状态为 `pass`**（以 `A-006` 与本目标索引投影表达）。
2. **重新记 W2 完成**：本目标 `progress` **25% → 50%**（2/4）；W2 的产出为草稿 [`world-model-method-working-version-v0.3.md`](../attachments/world-model-method-working-version-v0.3.md)（`v0.1` / `v0.2` 保留为历史）。Root `progress` **不变**（25%，1/4）——R2 未完成。
3. **开放 required → 0**；**审计门禁解除**（R4 交付前的独立审仍由 Root `I-004` 约束，不在本轮到达）。
4. **按 `A-006` 的台账观察更新投影**：`goal-tree.md` 的 Root 行由「草稿 `v0.2` / 开放 required finding 3」改为「**草稿 `v0.3` / 开放 required 0**」；子目标行 W2 由「整改中」改为「**完成（`v0.3`）**」、`progress` 50%。
5. **空转形态 ②「过程代替内容」的完整判定仍留在 W4**（`A-006` 亦未勾选）——无真实内容时不做诚实判定。
6. **下一阶段：W3**（「能力缺口判定清单」与「模型条目最小结构」）；W3 退出条件不变，`I-202` / `I-203` / `I-204` 均**未到期、不阻断**。

### 为什么

- 三条 required 的闭合**由独立闭审确认**，编排器**不再自证**——这是上一轮（`A-001-F-001` 被独立审部分否定、`A-005` 抓到自审盲区）之后确立的口径：独立意见的闭合主张要由独立确认收口。
- **收回与重新记的对称处理**使 `progress` 与退出条件的实际状态一致：`A-005` 判不满足时收回，`A-006` 确认闭合后重新记，而不是让数字自行漂移或长期低估。
- `A-006` 明确同意重新记完成，并已列出需更新的两处投影，故本轮落账有直接依据。

### 未选方案

- **继续维持 25%、不重新记 W2 完成**：未选。闭审已确认三条 `fixed`，且明确"同意重新记 W2 完成"；继续低估同样是台账与事实不一致。
- **把 `A-005` 原文 `verdict` 改写为 `pass`**：未选。审计原文不改写；有效状态另以 `A-006` 与索引投影表达。
- **在本轮顺带勾选空转形态 ②**：未选（须留 W4 用真实内容检验）。
- **把 `A-006` 的台账观察当作可选项**：未选。`A-006` 点名了两处需要 `/govern` 更新的投影，不更新会让 `goal-tree` 继续显示闭审前的旧值。
