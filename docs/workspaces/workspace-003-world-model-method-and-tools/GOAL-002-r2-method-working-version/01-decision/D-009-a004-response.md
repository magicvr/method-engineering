## D-009 · 响应 A-004：整改为草稿 v0.2 并完成 W2

### 触发

`self` 审视 [`A-004`](../03-audit/A-004-w2-draft-self-review.md)（verdict `conditional`，4 条 required + 2 条 advisory）落盘后，用户 2026-09-26 确认：**按该审视一并整改，出草稿 `v0.2`，并由编排器自行复核**；同时裁决**删除**工作区中一份由并行会话产出、引用不存在条目的 `independent-review-request-A-005.md`。

### 决定

1. **出草稿 `v0.2`**：[`world-model-method-working-version-v0.2.md`](../attachments/world-model-method-working-version-v0.2.md)。逐条整改见 [`A-004`](../03-audit/A-004-w2-draft-self-review.md) 的响应节与本版「修订说明」；**`v0.1` 保留为历史**（不覆盖、不删除，便于比对）。
2. **W2 记完成**：对照 W2 退出条件逐项核对通过（核对表见 `A-004` 响应节的「整改复核」）——10 章齐备、含 §13 映射表、**逐章**适用条件/已知边界/未决事项、**逐章**人机协作位、建议与裁定分开的留痕要求、草稿落 `attachments/`。
3. **进度**：本目标 `progress` **25% → 50%**（2/4）。Root `progress` **不变**（25%，1/4）——R2 未完成。
4. **闭合口径**：`A-004` 的 4 条 required 与 2 条 advisory 均以 `fixed` 闭合，开放 required **0**。**本轮为自审的自闭合，不冒充独立审计**；R4 交付前的独立审计仍由 Root `I-004` 约束。
5. **空转对照检查**：四形态中 **① 代劳 / ③ 框架先行 / ④ 不可复现**已在草稿层判定为"设计上不成立"；**② 过程代替内容**的完整判定**移到 W4**（须用真实问题与真实内容检验）。因此该**成功标准项本轮不勾选**。
6. **并行会话残留文件已删除**：`attachments/independent-review-request-A-005.md`（由并行会话产出；引用一份本仓**并不存在**的 `A-004-w2-self-review.md`；其独立审计路线与本轮"自审计即可"的选择不一致）经用户裁决**删除**。该文件**从未提交**，删除只影响工作区，故在此与 [`E-009`](../02-execution/E-009-w2-draft-v0-2.md) 留痕。其**两处有效发现**已由本目标的 `A-004-F-006`（§6 统一处理缺失）与 `F-001` 的补充关闭要求（总流程未标出「非客观问题 → 回绝」出口）**吸收**。

### 为什么

- `A-004-F-001` / `F-006` 不是措辞问题：前者决定 **W4 判据能否与原文 §13 闭环对齐**，后者决定读者会不会把"能算数值的模型"当成**另一类模型**而重复建模。
- "检查"必须在总流程里分成两处，否则建模期检查与裁决后检查会互相顶替——前者查模型是否成立，后者查这次裁决是否越出已声明边界。
- 空转形态 ② **不能在 W2 诚实判定**：本阶段只有方法文本，没有真实内容；把它也勾掉就是自我美化。故明确移到 W4。
- 删除并行会话文件而不试图合并：它引用的条目不存在、其路线与本轮选择冲突，**保留会造成两个 `A-004` 的假象**；其有效发现已按上面第 6 项吸收，信息没有丢失。

### 未选方案

- **覆盖 `v0.1` 为 `v0.2`**：未选。整改链需要可比对的历史（与 `D-004 → D-005 → D-006` 的处理一致）。
- **把空转形态 ② 也在 W2 判定成立**：未选（无真实内容，无法诚实判定）。
- **就并行会话的请求包发起独立审计**：未选。用户已选择自审计路径，且该包引用不存在的条目；若日后要独立审，应另起一份引用**真实**条目的请求包。
- **把 `A-004` 的自闭合写成"独立确认"**：未选。`source: self` 就是 `self`，台账已标明。
