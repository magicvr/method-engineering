# D-025 · 记录授权执行一次 S1 research-loop 独立调用试跑

创作者在同步裁决中选择“授权执行（推荐）”，授权按 GOAL-005 [D-011](../../GOAL-005-shared-research-loop/01-decision/D-011-s1-trial-execution-authorized.md) 执行一次受限 S1 独立调用。授权范围仅为已接受试跑设计和绑定包内的单一合成案例与单一研究问题；不授权 S2、Probe 1、额外调用、全局 coverage search 或任何方法/组件改写。

本决定记录授权与对应范围，不预判研究结论或接受候选结构；执行事实与待裁结果见 GOAL-005 [E-014](../../GOAL-005-shared-research-loop/02-execution/E-014-s1-independent-call-trial-run-01.md)。GOAL-002 保持 `active / 25%`，W2 四个工作包顺序与分母不变。
