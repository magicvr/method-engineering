# D-018 · 裁决共享研究组件集中落点与宿主最小接入范围

创作者选择将 shared core、共享记录 schema、S1 adapter 与 S2 adapter 集中放在 GOAL-005 的 `attachments/`，首个候选修订标识各为 `v0.1.0`；S1/S2 宿主各只增加一个窄的调用/回流接口。细项与建议文件名见 [GOAL-005 D-003](../../GOAL-005-shared-research-loop/01-decision/D-003-central-shared-boundary.md) 及 [接入方案 v0.2](../../GOAL-005-shared-research-loop/attachments/shared-research-loop-integration-plan-v0.2.md)。

该边界决定不接受研究 core 的语义，也不授权修改 S1/S2 正文或运行试跑。宿主正式版本号待可用基线确定：S1 v0.17.0 仍未接受；S2 W2 v0.4 为历史版，当前有界回流尚未产出新的可用基线。具体插入点依对应基线确定，并保留 S1 Rule E/F/G、S2 模型构建/验证的原裁决权。

GOAL-002 仍按 W1→W2→W3→W4 顺序推进，W2 的当前顺序切片仍由 GOAL-005 承载；本决定不改变任何目标 `status` / `progress`、W2 退出条件或 W3 门禁。
