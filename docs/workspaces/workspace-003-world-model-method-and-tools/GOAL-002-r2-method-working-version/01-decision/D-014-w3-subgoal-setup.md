## D-014 · 为 W3 建立统一承载子目标

### 依据与决定

用户 2026-09-26 明确授权：先判断 W3 是否应有子目标承载治理上下文，是则开设。W2 已按 D-013 / A-008 冻结为 v0.4，W3 已具备独立输入、交付范围与可核对的证据链，因此建立 [GOAL-003-w3-minimal-structures](../../GOAL-003-w3-minimal-structures/00-meta.md)，parent 为本目标。

现有父级台账技术上足以继续承载 W3；拆分是按独立范围、输入与交付证据隔离上下文，不是补齐原台账能力。两份结构共享条款映射、创作者可填性与一致性验收，统一放在一个子目标；不拆成两个目标，避免重复输入与相互一致性责任分散。继续仅留父级虽可行，但会把结构字段与核对过程叠加到方法主文档治理记录中，未采用。

### 范围与回流

子目标只承载两份可填写结构、字段映射、可填性/建议与裁定可区分核对、双结构与 W2 v0.4 一致性、自审视及冻结交接。W3 原退出条件不变，证据改落子目标 attachments/ 与 D/E/A 台账，父级引用并核对。W4 真实问题走查留本目标；I-202 / I-203 / I-204 仍 open，均不阻断 W3，不因立项被关闭。

风险是字段设计可能隐含新方法裁定或使父子状态重复。发现输入冲突、关键未知或需改 W2 时，记录证据、暂停受影响范围并回流本目标；涉及 P-004 的裁决由用户作出。子目标按三检查点计算进度，父级 W3 只在原退出条件及 required 门禁满足后记完成，两者不得机械换算。

### 当前状态

本轮完成子目标立项；W3 结构实施尚未开始。父级 progress 保持 50%（W1/W2，2/4），Root 保持 25%。W3 审计沿用 self；此决策不改变 W2 冻结内容，也不代替 W4 或 R4 门禁。
