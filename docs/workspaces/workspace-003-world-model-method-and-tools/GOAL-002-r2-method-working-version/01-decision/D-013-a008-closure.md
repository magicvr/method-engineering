## D-013 · 接受 A-008 闭审：冻结 W2（`v0.4`）并进入 W3

### 触发

独立闭审 [`A-008`](../03-audit/A-008-a007-closure-check.md)（`source: independent`，GPT Web 会话、由用户转述并代贴，verdict **`pass`**）：`A-007-F-001`～`F-005` **全部 `fixed`**（并逐条说明"修到了语义、不只是换措辞"）；**无新增 required finding**；**1 条 non-blocking wording advisory**；结论 **「W2 可以冻结」「可以进入 W3」**；并建议**停止继续打磨 W2**——继续纯文本审计的边际价值已很低，最可能发现真正问题的地方是**把它变成 W3 的可执行结构、再跑一次 W4**。

用户 2026-09-26 指示：**按格式代贴该意见**，**顺手修掉那条非阻断问题**，然后**准备进入 W3**。

### 决定

1. **接受闭审结论**：`A-007` 的五条 finding 全部 **`fixed`**；**无新增 required**；本目标开放 required 投影 **4 → 0**（`A-005` 三条已于 `A-006` 闭合、`A-007` 三条由本条闭合）。`A-007` 原文 `verdict: conditional` **保留为历史**，其**有效状态为 `pass`**（以 `A-008` 与本目标索引投影表达）。
2. **冻结 W2：完成版本 = [草稿 `v0.4`](../attachments/world-model-method-working-version-v0.4.md)**，作为 **W3 的输入**。`v0.1` / `v0.2` / `v0.3` 保留为历史。本目标 `progress` 保持 **50%**（2/4）；Root `progress` 不变（25%，1/4）。
3. **应用唯一的非阻断 advisory**（文本一致性清理，**不改方法语义**）：
   - 位置：`v0.4` 第 6 章「已知边界」。
   - **改动前**：「不提供"哪个参考属哪一类"的总表；**分类依赖举例与创作者判断**。」
   - **改动后**：「不提供现实参考的统一分类表；是否需要显式声明文化、制度、组织等条件，由**具体问题及其适用条件**决定。」（即审计者建议文本）
   - 该清理是**本条闭审意见自带的建议**，审计者已明确其"不阻断 pass、不需要再开审计轮次"；为保持可核对，**改动前后原文记于本条**，并在 `v0.4` 的「修订说明」加注第 ⑥ 条。
4. **W3 解锁**：进入「**能力缺口判定清单**」（对应第 8 章五步 + §12 回绝项）与「**模型条目最小结构**」（对应第 7 章十一项），按 `v0.4` **最终口径**编写，要求**创作者可填**、**建议与裁定可区分**，并落实第 7 章的**条件关键项**（机制未知 → 不得声称可独立裁决、须写明允许的返回类别）与**依赖式**拒绝规则。
5. **接受审计者的程序建议**：**停止继续纯文本打磨 W2**；后续问题交由 W3 的可执行结构与 W4 的真实问题有界检验暴露。

### 为什么

- 五条 finding 经独立闭审逐条确认**实质闭合**（不是换措辞），且**无新增 required**——这是继 `A-006` 之后第二次"由独立通道收口"，编排器未自证。
- **冻结而非继续修改**：`A-007` / `A-008` 两轮都指向同一结论——骨架已稳，剩余风险在**文本之外的可用性**。继续加审会让"审计通过"变成目的本身（P-002 的"实施事实 ≠ 实施流水账"同理）。
- **非阻断清理就地应用**而非另开版本：它是**同一条闭审意见**给出的替换文本，改动仅涉及一句话的表述一致性；为不牺牲可核对性，**改动前后原文与理由一并落 `D-013`、并写进 `v0.4` 的修订说明**，使 `A-008` 所引原句仍可追溯。
- **不收回/不重记 W2 完成标记**：`A-008` 已确认其为 W2 的完成版本；标记与事实一致。

### 未选方案

- **为这一句话另出 `v0.5`**：未选。改动是同一闭审意见自带的文本清理、无语义变化；另立版本会把"版本号"变成流水账，而原文已在 `D-013` 留档。若日后有实质修订，再出正式新版本。
- **把该 advisory 记为 residual 留待以后**：未选。用户指示"顺手修"，且留着一句自相矛盾的边界说明没有必要。
- **先修再交第二次闭审**：未选。审计者明确"不阻断 pass、不需要再开审计轮次"，且建议停止继续打磨。
- **改写 `A-007` / `A-008` 的 verdict**：未选。审计原文不改写；有效状态以索引投影表达。
