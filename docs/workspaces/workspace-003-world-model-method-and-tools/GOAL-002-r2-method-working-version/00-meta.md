# GOAL-002 · 形成《世界模型构建方法（工作版）》与两个最小结构

## 概述

承载 Root [`GOAL-001-world-model-method-and-tools`](../GOAL-001-world-model-method-and-tools/00-meta.md) 纲领 **R2** 的全部工作（并落实 R3 的工具边界）：按 Root [`D-002-r1-freeze.md`](../GOAL-001-world-model-method-and-tools/01-decision/D-002-r1-freeze.md) 冻结的范围与形态，形成《世界模型构建方法（工作版）》主文档，以及「能力缺口判定清单」「模型条目最小结构」两个最小结构；并以用户 2026-09-26 提供的**真实世界问题**为适用性判据，核对方法能否支撑产出可回答该问题的世界模型。

本目标是本区第二个目标（编号 = 当前最大 `001` + 1 = `002`），父目标为本区 Root，`parent: GOAL-001-world-model-method-and-tools`。工作体量较大，本目标内先记工作包阶段计划；若其中某个工作包出现各自具有独立范围、依赖或交付证据的工作，再按 P-001 建立作为本目标子节点的平铺目标。

## 真实问题（R2 的适用性判据）

> 由用户 2026-09-26 提供，同时作为 `WRK-002` 的有界检验用例（Root `I-002`）与 R2 的适用性判据。原文落盘于下游仓 `WorldModel.ModernCultivation` @ `b10cadc`（分支 `dev/vp-002`）的 `exchange/WRK-002-world-model-method-and-tools/真实问题-2026-09-26.md`（其 `D-004` / `E-005`）。

```text
假定我们要构建一个星际时代的修真世界观，那么首先要回答的问题就是：修真者能实现哪些现实世界中所不存在的个体伟力，为什么可以实现，这种个人伟力的存在会对社会层面造成什么样的客观影响。
```

**判据含义**：按本方法走一遍该问题（至少到「缺口判定 → 定义裁决能力 → 模型条目定义」），方法必须足以支撑构建出能回答它的世界模型；核对结论与暴露的缺口记入 W4。

**边界（不得由本问题推定）**：

- 「星际时代」是**该用例的假定切片**，**不等于**下游 `H-003`（「现代化」锚定年代）的裁决；「为什么可以实现」触及下游 `H-004`（修真机制范式），同样只作该用例的切片处理。下游 `H-003` / `H-004` 整体**仍为 `open`**。
- 本问题与 W4 核对**不写**下游 `world/` 设定正文，**不替**下游作 canon 裁决，也不关闭下游承载未知 `U-1`～`U-8`。
- W4 的核对记录是**方法适用性的内部证据**；它是否并入交付包见 `I-202`，不得在未裁决前当作交付物。
