## 执行主体与协作约束（2026-09-26，**已修正**）

> 来源：用户在 R2 启动后提出的需求澄清，及随后对其解读的修正。材料见下游仓 `WorldModel.ModernCultivation` @ `e9054c9`（分支 `dev/vp-002`）的 `exchange/WRK-002-world-model-method-and-tools/需求澄清-2026-09-26-构建主体.md`（含第 2 版修正节）。本目标登记于 [`D-002`](01-decision/D-002-executor-boundary.md) / [`E-002`](02-execution/E-002-executor-boundary-recorded.md)，并由 [`D-003`](01-decision/D-003-executor-boundary-revision.md) / [`E-003`](02-execution/E-003-executor-boundary-revision-recorded.md) **修正**。**以修正后口径为准。**

1. **决策权属于创作者——这就是「不代劳」的含义**：世界模型的**主题、取舍与最终裁决**属于创作者。助手**不得代劳**：不得在创作者未实际参与判断的情况下确定结论并直接采用。
2. **助手应尽可能协助**：助手**可以且应当充分**提供提示、引导、候选方案、示例、追问、反例、检查与整理。对「这是不是客观问题 / 现有模型够不够 / 缺的是状态、组合、精度还是机制 / 新模型是否只是当前案例的补丁」等判断点，助手**可以给出建议与理由**；但**结论必须由创作者作出**。
3. **界线判据**：助手给建议 + 创作者裁定 = **协助**（允许且鼓励）；助手**直接确定结论并被采用**，或创作者退化为**被动确认** = **代劳**（禁止）。
4. **方法须标明人机协作位**：每章写明——① 必须由创作者作出的决定；② 助手可用的协助形式；③ 不得越过的界线；④ **建议与裁定分开记录的留痕要求**，使「结论是谁作的」可核对。
5. **不以 AI 为前提，也不禁止**：方法不把 AI 助手设为成功条件，也不假定必须无助手；验收口径是「**创作者能据方法作出决定并完成闭环，且协作位与留痕清楚**」。
6. **两个最小结构**：由创作者填写即可（无论是否借助助手协助）；若借助助手，结构与留痕应能区分「建议」与「创作者裁定」。
7. **禁止四种空转形态**：① **代劳**（结论由助手直接确定并被采用，或创作者只做被动确认）；② 过程代替内容（只在登记表里流转，不产出可裁决的机制模型正文）；③ 框架先行；④ 不可复现（无法核对「结论是谁作的」）。
