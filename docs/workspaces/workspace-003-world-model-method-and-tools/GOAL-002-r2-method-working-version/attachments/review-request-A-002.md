## 复审者可自行检查的边界

1. **是否仍有"把实现方式当原文"的残留**：抽查 `D-005` 第 ② 层各行是否确实只含原文自身规定，第 ③ 层是否确实未被当成已定。
2. **是否有语义降级**：§9 的「**11 项均须被处理**」是否在 `D-005` 表述中保持完整，未被"最小必填集"一类写法削减。
3. **是否把不变量降级为选择**：§11 的「追溯不变量」与「实现方式」是否已清楚分开。
4. **分级是否自洽**：被列为「助手默认设计」的项（`C1` / `C4` / `C5` / `C7` / `C8`）是否确实不涉及语义、责任边界、成本等级或不可逆承诺。
5. 若认为某条**未闭合**，请直接给出未闭合理由与最小修正要求；若认为修订**引入了新问题**，请另立 finding。
