# D-007 · 确定 H3 核心能力范围与局部标签边界

## 用户裁决与已选范围

2026-10-01，用户选择将评估端候选能力清单中的 **C-02～C-04** 作为 H3 核心机制能力：

- **C-02**：区分需求与实际供水，实际供水同时受需求、每步上限与步初存量约束。
- **C-03**：识别供水后的情景损失；损失只在对应情景中于供水后计入，且不超过供水后剩余存量。
- **C-04**：按正确次序转移状态并组合两步，前一步末状态成为后一步输入。

**C-01 状态/步界**属于输入与范围前提，不作为单独的机制能力项；冻结条目仍须正确遵守两步、步初/步末状态及无补水等已登记边界。用户接受的初步 H3 标签边界为：

- `supported`：参考揭示前形成并冻结的模型条目在测试范围内覆盖 C-02～C-04、证据可追溯且无矛盾，并正确符合 C-01。
- `partial`：已形成条目，但至少一个核心能力未覆盖或明确存在缺口；没有核心机制矛盾，且未错述 C-01。
- `refuted`：模型与任一核心能力 C-02～C-04 直接矛盾，或错误表述 C-01 输入/范围前提。
- `insufficient`：参考揭示前没有可审查的实际模型条目，或证据污染/不足、必要链输入缺失，无法可靠应用判据。

## 尚待完成的逐链与执行规则

本项没有裁定逐链证据如何聚合为整个模型集合标签，也没有裁定某一链 `not-elicited` 而另一链已覆盖该能力时如何汇总；逐链到实际模型/明确缺口的精确引用和证据格式、严重度、准确样本/快照、参考封存与揭示责任、预算/停止/偏离、人员及运行前冻结仍待写入预登记。
