# D-010 · 将全链未触及且不可评的核心能力判为不足

## 用户裁决与已选范围

2026-10-01，用户选择：若所有**适用**采样链都未触及某项核心能力，且最终冻结模型集合也没有足以评价该能力的证据，则不据此推断模型能力缺失或成功。若因此无法可靠判断整体 H3 主张，该项/整体结论标为 `insufficient`，并保留未触及事实与限制。

这与单条链的 `not-elicited` 区分：单条链未触及不自动导致整体失败；另一适用链或最终模型集合中的可追溯证据可以解决该项（D-008）。某链上 `explicit-gap` 若由最终冻结集合补足也不自动限制整体标签（D-009）。

## 未决范围与门禁

每项哪些链属于“适用”、混合的可判与不可判能力如何汇总、证据相互冲突时的处理、链级标签/严重度和准确输入/证据定位尚未完成。预登记须保证 `insufficient` 不被当作 refutation，也不作为放行 R2c 的充分证据。

H3-SEM-001 仍为 `required / OPEN`；其余映射与执行字段补齐前不得冻结 H3 预登记或运行。此决定不改变目标状态/进度、额度或 Root I-002/I-005。

汇总单位见 [D-008](D-008-aggregate-h3-at-model-set-level.md)，中间明确缺口见 [D-009](D-009-aggregate-explicit-gaps-at-final-set.md)。
