# D-016 · 设定 H3 两条初评链的 C-03 适用性

## 用户裁决

2026-10-01，用户选择将核心能力 C-03（供水后的情景损失）列为 `H3-01` 与 `H3-02` 两条初评链均 `applicable`。该选择针对当前角色可见日志候选：`H3-01` 的无额外损失轨迹作为负对照，`H3-02` 的供水后余额差作为损失正例。矩阵属于评估端材料，不进入生成上下文。

| 初评链 | C-03 适用性 | 当前候选可见轨迹与理由 |
|---|---|---|
| `H3-01` 值班操作员 × `CTX-017` | `applicable` | 候选日志为 `8 → 4 → 2`，需求 `5 / 2`、实际供水 `4 / 2`。无供水外减量，是用于核对模型是否对该链错误增设供水后损失的负对照。 |
| `H3-02` 检修员 × `CTX-042` | `applicable` | 候选日志为 `8 → 5 → 2`，两步需求和实际供水均为 `2`；水位相对供水后仍各减少 `1`，可检验模型是否记录未由供水解释的额外减量。 |

## 输入条件、理由与边界

这两条轨迹目前是 AI 合成的可见输入候选，不是采样链输出、观察结果或已冻结快照。`H3-02` 的逐步余额及完整角色可见字段仍须由创作者审定。两格均保留中性 `CTX-*` 键；生成端不得看到能力矩阵、`C-03` 标签、隐藏映射或评估参考。这里的 `applicable` 仅表示有机会核对“供水之外是否存在减量”这一部分，不表示完整 C-03 已可评：当前步界日志不能辨别步内损失相对供水的先后，也没有触发损失受剩余存量限制的边界条件。若正式冻结前的输入改变，以致水位/供水证据无法提供上述正、负对照，须在生成前重新审定适用性；不得根据运行输出或事后揭示的参考改写。

本决定只确定 C-03 的两个候选矩阵单元；C-02、C-04 单元与理由、其余准确可见输入/来源快照、封存揭示与执行字段仍待完成。它不关闭 H3-SEM-001，不授权正式预登记冻结或运行，也不改变抽样格数、目标状态/进度或 Root I-002/I-005。

## 2026-10-01 后续输入准备（D-017）

用户随后按 [D-017](D-017-prepare-h3-observable-boundary-input.md) 选择保留完整 C-03 并准备非零存量边界的更丰富可观测输入：H3-02 候选需求 `4 / 2.5`、步界 `8 → 3 → 0`，加上与 H3-01 同字段的供水完成/窗中/窗末读数。上文 `8 → 5 → 2` 保留为本次适用性裁决的历史依据。新精确读数、半单位精度、连续量与时间分布假设尚待创作者审定，当前矩阵理由须与新草稿复核，不能据本条或 D-017 宣称完整 C-03 已可评、输入已冻结或运行已获准。

2026-10-01，用户又按 [D-018](D-018-accept-h3-observable-input-candidate-baseline.md) 接受全套读数/观测语义和时间扩展为后续预登记候选基线；时间参考另定为 `H3-BALANCE@0.2` 候选，保留旧离散 `@0.1`。上述“尚待审定”是 D-017 准备时的历史状态。当前仍须按 D-012 在正式冻结前重新审定新准确输入与 C-03 适用性矩阵理由的一致性；本条旧轨迹不作为新快照的冻结依据，H3-SEM-001 保持 OPEN，未获运行授权。

2026-10-01，用户依 [D-019](D-019-bound-h3-c03-assessability-scope.md) 将本轮 C-03 可评范围限定为两条已选合成链上可观察的供水外减量、窗内变化与零存量边界，不外推一般因果损失公式。D-016 两个候选 applicable 单元保留为历史选择；正式冻结前须按最终输入和 D-019 范围复核完整矩阵及逐格理由。该范围决定不授权冻结或运行。
