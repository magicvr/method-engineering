# D-025 · 接受 H2 局部增益候选判据

## 用户裁决

2026-10-01，用户接受推荐候选规则：H2 只有在身份/情景路径保持原问约束、补出直接路径未补出的决策相关信息，且创作者明确判断所得增益值得所记录的额外问答步骤时，才可判为 `supported`；缺少路径比较或成本证据时判为 `insufficient`。规则不设 AI 代填的效用分数或复杂度阈值。

## 候选操作含义

1. **约束保持**：身份/情景路径须仍回答同一原问，并满足已登记需求、时点和完成条件；新增信息不能靠改变问题范围或引入快照外事实取得。
2. **增益差异**：须有可核对的路径对照，显示身份/情景路径取得至少一项直接路径未取得、且足以影响原问答案的决策相关信息。仅使用身份/情景措辞，或与直接路径取得相同信息，不计为身份/情景路径的增益。
3. **步骤价值**：创作者须明确判断观察到的增益值得该对照实际记录的额外问答步骤；逐项记录问题、回应和步骤，不将 AI 时间折算成人时。
4. **不足处理**：缺少上述路径比较证据，或没有创作者对增益/额外步骤价值的明确判断，候选标签为 `insufficient`，不得默认支持。

D-024 的 R-A/R-B 答案差异仅是合成输入的候选歧义演示。它表明请求对象可能改变供水答案，不证明任一路径运行时取得了增益，也不单独确认该问满足正式运行前的“确需澄清”筛选。实际路径效果与步骤价值须在允许运行后依据记录判断。

## 范围与未决项

本决定接受的是 H2 局部支持条件及缺少比较/价值证据时的 `insufficient` 候选处理；不是完整冻结的四标签规则，也不认定身份/情景路径优于直接路径。`partial` / `refuted` 的完整边界、严重度、正式“确需澄清”筛选与证据、复合/未覆盖问法、澄清轮数/停止、执行责任/证据路径和最终逐次预登记仍待补齐。本决定不授权冻结、运行、复验或改变 H2 两格上限、目标状态/进度及父级门禁。
