# D-015 · 设定 H3 最低模型启动能力与遗漏规则

## 用户裁决

2026-10-01，用户选择「最低机制关系」门槛。对本轮封闭的 H3 抽样框，首版模型集合只有同时满足以下条件才算已形成：

1. 参考揭示前形成并冻结至少一个实际、非占位的纯文本模型条目；纳入该模型集合的每个实际模型条目都须能定位 R1 v0.6.4 §2 的 12 类最低信息，不适用项写明理由。
2. 至少一条可追溯的具体机制关系，明确连接状态/输入、所用规则或约束、机制输出/状态变化及适用范围/次序；关系须能指回本轮采样链证据，不能仅以问题清单、能力列表或事后参考比较代替。

此“最低启动”不要求三个核心能力均已覆盖；C-02～C-04 仍按 D-007～D-011 的既有判据分别评估。因此，模型形成与 H3 `supported` 是不同判断；达到最低启动条件不自动意味着支持。

## 理由与未选方案

该门槛要求至少一条有实际内容且可核对的机制关系，避免把问题清单、能力列表或仅填字段的空泛条目误算为首版机制模型；同时把“模型已形成”与“核心覆盖充分”分开，保留既定 `partial` / `insufficient` 判定空间。

- 未选“C-02～C-04 全部可评才算已启动”：这会把产物形成条件与证据可评性绑定，使“模型已形成但核心证据不可评”的情况不能单独记录；可评但未覆盖仍按既定规则标 `partial`。
- 未选“12 类字段齐备就算已启动”：字段可以形式齐备但没有任何机制关系，无法证明首版模型已从采样链产出。

## 链→能力/模型映射与关键遗漏

- 对每条实际尝试链及每个适用核心项，分别记录链中的来源回合/证据位置、相关冻结模型条目及段落；若没有对应条目或链证据，明确记录，不留空白推断。逐链适用性与运行后证据状态继续按 D-012 分轴记录。
- 关键遗漏以最终冻结模型集合为单位判断：C-02～C-04 中任一项在最终集合仍缺少可核对的模型表达，且该核心可评时，按 D-007、D-011 记为核心缺项（总体可评时为 `partial`）；单链未触及不自动算缺项，且中间明确缺口若在参考揭示前由最终集合补足，不单独降级（D-008～D-010）。
- 若核心能力证据不可评且影响整体判断，按 D-010～D-011 判 `insufficient`；可核对的核心矛盾或错误表述 C-01 仍按既定规则判 `refuted`。

## 边界

本决定关闭 H3-SEM-001 中最低启动能力、映射规则与关键遗漏判定方法这部分；准确可见输入/来源快照、逐链适用性矩阵及理由、冲突/严重度、责任/预算/停点和完整冻结安排仍待补齐。未冻结正式预登记、未授权运行，不改变样本格数、目标状态/进度或 Root I-002/I-005。
