# D-009 · 确定明确能力缺口以最终冻结集合判定

## 用户裁决与已选范围

2026-10-01，用户选择以最终冻结模型集合的内容判断 H3 总体标签：某条链上出现的 `explicit-gap` 仍须作为逐链过程证据留存；若该能力由其他所选链形成的模型条目在冻结前补足，且最终集合满足 [D-007](D-007-set-h3-core-capability-boundaries.md)，该中间缺口不自动将集合结果降为 `partial`。

相应地，`partial` 适用于冻结集合本身仍缺 C-02～C-04 中的核心能力，或明确缺口未被集合其他条目补足的情况。此规则不删除中间链的缺口记录，也不允许参考揭示后修改冻结集合来追溯性补足；参考揭示后修订另记。

## 仍待裁定与门禁

- 所有适用链均未触及某一核心能力时，该集合应判 `insufficient`、`partial` 还是按其他证据判断。
- 逐链证据如何证明能力已被另一个模型条目补足；如何处理相互冲突的模型主张、链级标签、严重度及具体证据定位。
- 准确输入、样本与快照、责任、预算/停止、隔离、偏离、冻结及适用运行授权。

H3-SEM-001 仍为 `required / OPEN`；其余预登记字段补齐前不得最终冻结 H3 或运行。该决定不改变目标状态/进度、样本额度、人时额度或 Root I-002/I-005，也不授权试验。

汇总单位见 [D-008](D-008-aggregate-h3-at-model-set-level.md)，能力与标签边界见 [D-007](D-007-set-h3-core-capability-boundaries.md)。
