# D-019 · 限定 H3 C-03 有界可评范围

## 用户裁决

2026-10-01，用户选择将 C-03 本轮可评范围限定于两条已选封闭合成链及 D-018 接受的精确观测候选。范围是：在本供水站两步输入内，区分正常链供水完成后的无额外下降，与损失链供水完成后的候选下降；核对窗内下降顺序、均匀分布候选及存量归零下限是否被模型表达。具体证据只来自运行前冻结的可见链输入、运行前冻结的模型和独立评估参考。

本范围不主张有限轨迹可以识别唯一的一般因果损失公式，也不外推到其他设备、角色、参数、时间分布或情景。H3-BALANCE@0.2 仍是评估端候选参考版本；D-018 观测输入仍未冻结。现有 C-03 两个 D-016 候选单元保留为 applicable 的历史选择；正式冻结前，仍须按本范围、准确输入与完整矩阵理由逐格复核。

## 选择理由与未选方案

该边界使本轮判断能覆盖已设计的供水外变化、窗内顺序和零存量截断，同时避免把两条有限合成轨迹解释成对一般因果机制的识别。

未选“保留一般性主张并补充证据”：在当前两条链与既定额度内，有限轨迹仍不能唯一识别一般公式；若保留此范围，须另行设计证据并重新处理链数/额度，不能默认追加。未选“退回离散端点”：该方案会舍弃 D-018 已接受的窗内及非零截断候选输入，需另作设计修订。

## 影响与未决门禁

本决定仅确定 C-03 的评估边界，不判断模型实际表现，不将任何 H3 标签预先定为 supported、partial、refuted 或 insufficient。它不构成正式预登记冻结、运行授权或 H3-SEM-001 的整体关闭。

冻结前仍需：按 D-012 结合最终输入复核完整逐链适用性矩阵及理由；完成 C-02/C-04 单元、输入/参考快照、W 的确切时长/单位、来源与封存揭示、创作者局部判据和严重度、链间非直接矛盾冲突规则、角色/责任、证据路径、预算/停止/偏离规则及完整性核对。该决定作成时，C-02 步初存量绑定供水案例尚未补足；后续 D-020 为 H3-01 增加了候选第三步，尚无冻结输入或实际证据。H3-SEM-001 继续 required / OPEN，阻断正式冻结与运行；目标状态/进度、goal-tree、Root I-002/I-005 和结果格数不变。

2026-10-01，用户按 [D-020](D-020-add-h3-inventory-binding-step.md) 在 H3-01 增加 C-02 库存绑定候选步。该步属正常无额外损失链，保持 D-019 的 C-03 评估范围，不增加 C-03 行为主张；H3-01 三步与 H3-02 两步的长度差异须在最终矩阵与链间证据解释中明示。
