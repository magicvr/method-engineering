# D-001 · 建立 R2 子目标并界定职责与门禁

## 决定

按用户选择建立平铺子目标 `GOAL-002-r2-method-validation`，承载 Root `GOAL-001-world-model-method-and-tools` 的 R2a–R2d 执行、证据与审计上下文。Root 继续维护项目级目的、纲领路线图、全局信息门禁和最终交付目标；本目标不改变 R3/R4 顺序或 Root 状态。

## 理由与边界

R2 有一条独立且有序的交付链：操作化 H1/H2/H3、有界试验、证据选路、形成方法工作版。单独维护 R2 的执行事实与证据有助于追踪此阶段，同时保留 Root 为唯一整体路线与信息门禁来源。

本目标阶段退出条件沿用 Root 已记录的 R2 范围。Root I-002 控制真实案例的运行授权，I-005 控制 R2c 证据选路及 R2d，I-006 属于 R3；本目标不复制、降级或关闭这些信息项。

## 未选方案

将整个 R2 留在 Root 的现有账本中。用户在本轮选择以子目标承载 R2 治理上下文。

## 后续

先完成 R2a 的逐项操作化与预登记；现有 [准备方案](../attachments/R2a-operationization-plan-v0.1.md) 仅为待填写的工作稿。任何运行仍须对应登记完整、适用授权成立，并遵守 v0.6.4 的格数与人时上限。
