# D-023 · 接受 H1 局部主张与裁决规则候选

## 用户裁决

2026-10-01，用户接受推荐版，将 H1 局部主张与结果标签规则作为预登记候选。范围仅为 D-022 接受的两种模型、基线/变化两种初始存量条件组成的四格；不外推为一般方法有效性结论。

**局部主张候选**：在四格候选范围内，分别按已声明规则给出可追溯到模型、输入与步骤的第二步结束存量答案。

| 标签 | 候选规则 |
|------|----------|
| `supported` | 四格均可追溯到已声明模型、输入与逐步演算，且答案符合冻结的逐格预测。 |
| `partial` | 有可评证据表明部分格满足上述条件、其余格未满足，但没有触发预登记否决观察；须列出具体格及边界。若关键证据缺失导致整体无法可靠判断，则按 `insufficient`。 |
| `refuted` | 出现预登记否决观察：模型自相矛盾、条件变化与事先声明的机制预测冲突，或必须事后添加规则才能得到预期结果。若同时有满足格，仍记录各格证据，并以否决观察标记本局部主张。 |
| `insufficient` | 必要模型、输入、预测或关键证据未冻结/缺失，导致不能可靠判断；不得把缺证当成否决或支持。 |

严重度按受影响的结果格及偏离性质逐项定性记录，不另设跨 H 分数。以上是预登记规则候选；运行前仍须核对其与最终输入、证据字段及停止/偏离处理一致并冻结。

## 后续门禁

创作者/记录者、评估责任人、逐格证据落点以及遇到输入不足时的具体停止与返回裁决步骤仍待登记。D-022 的候选输入/预测与本决定的局部规则均未构成正式冻结或运行授权；R2a 未完成，不放行 R2b，不改变目标状态/进度、goal-tree、父级门禁或结果格数。
