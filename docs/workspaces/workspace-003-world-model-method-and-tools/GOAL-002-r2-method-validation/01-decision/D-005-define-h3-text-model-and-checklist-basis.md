# D-005 · 确定 H3 文本模型产物与能力清单判定基础

## 用户裁决与已选范围

2026-10-01，用户明确 H3 从零形成的首版模型集合，其最低产物类型是**可审查的纯文本机制模型条目**；不要求该条目可执行、数值化或形式化。模型构建和评估不局限于自然语言推理：证据需要时可进行数学推导、数值计算、统计分析、程序化核验或模拟；若纯文本推理足以支撑该项证据，则不强制使用工具。分析手段由问题与证据需要决定，不为了形式化或量化本身而加入。

用户选择以**能力清单逐项核对**作为 H3 链→模型/缺口、遗漏与局部判定规则的起草基础。后续候选应逐链记录模型条目实际表达的能力、明确缺口、未触及项或矛盾，并在揭示参考后逐项核对。此选择确定判定方法的组织形式，不等于接受任何具体能力清单、最低覆盖数、关键遗漏定义、支持/partial/否决/insufficient 标签边界或严重度。

## 尚未裁定与门禁

- 纯文本模型条目的具体最低字段/内容及何种表述算足以承载一个机制模型。
- H3-BALANCE 参考应拆分为哪些可核验能力项、逐链结果如何映射到模型或缺口，以及哪些未覆盖/矛盾属于关键遗漏。
- 能力逐项结果如何汇总为 H3 局部 `supported` / `partial` / `refuted` / `insufficient`，以及各结果的严重度与边界。
- 准确链输入、参考版本与封存、执行上下文隔离、职责、证据路径、人时/本轮预算、停止/偏离和运行前授权。
