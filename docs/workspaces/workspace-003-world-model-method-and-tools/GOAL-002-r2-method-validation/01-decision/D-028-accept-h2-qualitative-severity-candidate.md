# D-028 · 接受 H2 逐格定性严重度记录候选

## 用户裁决

2026-10-01，用户选择推荐方案：H2 按受影响对照格与偏离性质逐项作定性严重度记录，不另设等级或跨 H 分数。

## 决定与理由

将 D-023 已接受的 H1 记录方式作为 H2 的候选形式：对每项可判偏离，写明受影响的路径/比较格、对原问约束或答案的影响、具体偏离及定性判断理由。不得用一个 H2 汇总分数替代逐格证据。选择此方式是为了沿用既有局部记录口径，避免在没有锚点依据时新造 H2 专用等级阈值。

未选方案：另建 H2 专用等级和触发锚点。它可能便于横向比较，但会增加未获依据的阈值与解释成本；用户本轮选择了与 H1 一致的逐格定性方式。

## 范围与后续

本决定只接受候选记录形式，不预判任何结果格的实际严重度，不改变 D-027 四标签判据、格数或停点，也不构成正式预登记冻结或运行授权。创作者仍须在逐次预登记中结合最终输入写明具体偏离的严重度判断与证据；其余责任、证据路径、轮数/停止、预算及偏离处理仍待完成。
