# D-006 · 接受 H3 首版模型采用 R1 完整条目字段

## 用户裁决与已选范围

2026-10-01，用户选择将冻结的 R1 v0.6.4 §2「模型条目最小结构」完整应用于 H3 从零形成的首版纯文本模型条目。以下 12 类信息都必须在条目中可定位：

1. 问题类别；
2. 现有模型不足；
3. 前提 / 参考；
4. 状态输入；
5. 机制输出；
6. 适用范围；
7. 精度；
8. 组合；
9. 拒绝条件；
10. 反例 / 条件变化；
11. 版本；
12. 创作者裁定。

各项可用简洁的纯文本组织，不要求固定字段标题、可执行代码、数值化或形式化。确实不适用的项目须标为 `N/A` 并说明理由；不得因表述未使用固定标题而漏检字段内容。工具仍按证据需要使用；纯文本足以支撑时无需额外工具。

## 未决范围与门禁

此决定只确定“已形成的首版文本模型条目”的最低信息结构，不决定模型是否覆盖 H3-BALANCE 中的特定能力，也不接受附件中的能力清单项目、关键性、最低覆盖、逐链映射或 `supported` / `partial` / `refuted` / `insufficient` 汇总规则及严重度。上述局部检验规则仍由创作者后续裁定。

H3-SEM-001 保持 `required / OPEN`，阻断 H3 正式预登记最终冻结与 H3 运行。该决定不冻结候选包、不授权试验，不改变目标 status/progress、格数、人时限额或 Root I-002/I-005。

此前已选择的产物类型与能力清单判定基础见 [D-005](D-005-define-h3-text-model-and-checklist-basis.md)；R1 字段权威见 [冻结协议 v0.6.4 §2](../../GOAL-001-world-model-method-and-tools/attachments/R1-freeze-proposal-v0.6.4.md)。
