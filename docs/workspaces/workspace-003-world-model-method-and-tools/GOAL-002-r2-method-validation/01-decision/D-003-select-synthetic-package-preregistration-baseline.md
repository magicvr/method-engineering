# D-003 · 选择供水站合成候选包作为正式预登记基线

## 用户选择与范围

2026-10-01，用户选择当时的 H1/H2/H3 供水站合成候选包 v0.1.3（草稿 checkpoint `fa0fc37`；[当前工作稿](../attachments/R2a-H123-synthetic-candidate-pack-v0.1.md)继续同步）作为补齐正式预登记的基线。该选择接受的是基线结构：共享 AI 构造的有界供水站背景，H1/H2/H3 单元分立；从该包继续补齐各 H 预登记，不另换背景或将真实黑箱探针用于前置方法设计。

基线包含 H1 的明确问题、两模型与基线/唯一条件变化结构，H2 的含混请求、同信息同回应规则的两路径对照结构，以及 H3 的封闭身份—情景抽样、生成端与评估参考隔离、先生成并冻结链记录再揭示参考的结构。候选初评 H1 4 + H2 2 + H3 2 = 8 格是继续登记的安排基线，仍须逐次明确输入、程序与授权；R1 各 H 上限 4/2/3、全局 9 格及累计 180 人分钟继续适用，没有扩容。
