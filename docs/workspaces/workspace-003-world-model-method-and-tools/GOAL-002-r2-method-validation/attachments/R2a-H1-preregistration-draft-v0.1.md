# R2a · H1 多机制模型求解预登记草稿 v0.1.0

> **边界**：整理 D-022/D-023 接受的合成候选输入和局部判据，供创作者补齐准确版本、证据、责任、偏离/停止、人时和价值判断后核验。此稿不是冻结预登记，不包含运行观察，不授权运行。

## 1. 目标与范围

在四个合成候选格内，分别使用两个事先声明的机制模型回答同一个明确问题。每格以该格初始存量独立起算；唯一条件差异是初始存量 8 或 4。不比较 H1 与 H2/H3，不将局部结果外推为一般方法有效性。

候选局部主张依 [D-023](../01-decision/D-023-accept-h1-local-claim-and-judgment-rules.md)：四格内分别按已声明规则，给出可追溯到模型、输入和逐步演算的第二步结束存量答案。最终问题为：“无补水运行两步后水箱还剩多少水？”

## 2. 候选输入

以下均为 AI 构造候选；依 [D-022](../01-decision/D-022-accept-h1-candidate-inputs-and-predictions.md) 接受但尚未冻结。准确版本及字段须在正式登记时逐项核对。

| 字段 | 候选值 |
|---|---|
| 容量 | 10 |
| 运行步数 | 2 步 |
| 补水/其他损失 | 无补水、无其他损失 |
| H1-M1@0.1 | 每步固定请求排水 2 |
| H1-M2@0.1 | 步开始存量 ≥ 5 时请求排水 3，否则请求排水 1；阈值判断使用该步开始存量 |
| 两模型的共同执行规则 | 实际排水 = min(请求排水, 步初存量)；步末存量 = 步初存量 − 实际排水 |
| 基线 B | 初始存量 8 |
| 唯一变化 V | 初始存量 4；其余模型、容量、步数和补水条件均与 B 相同 |

## 3. 四格候选与事前预测

四格相互独立起算。下表是候选算术预测，不是试验结果。冻结时应锁定数值、模型版本与计算规则；运行后不得为符合结果回改预测或模型规则。

| 格 ID | 模型 / 条件 | 第一步候选演算 | 第二步候选演算 | 第二步结束预测 |
|---|---|---|---|---:|
| H1-01 | M1 / B | 8 − min(2, 8) = 6 | 6 − min(2, 6) = 4 | 4 |
| H1-02 | M1 / V | 4 − min(2, 4) = 2 | 2 − min(2, 2) = 0 | 0 |
| H1-03 | M2 / B | 8 ≥ 5，排 3；8 − 3 = 5 | 5 ≥ 5，排 3；5 − 3 = 2 | 2 |
| H1-04 | M2 / V | 4 < 5，排 1；4 − 1 = 3 | 3 < 5，排 1；3 − 1 = 2 | 2 |

四格均属 H1 初评候选；H1 上限为 4 格，因此如四格全部尝试，H1 不剩可用的复验格数。试格之前复核当时全局累计格数和实际人时，遵守 R1 的全局 9 格/180 人分钟限制。

## 4. 候选局部判据

依 [D-023](../01-decision/D-023-accept-h1-local-claim-and-judgment-rules.md)，下列为候选边界，仍须结合最终准确输入、证据和停止/偏离流程正式冻结。

| 标签 | 候选判定 |
|---|---|
| supported | 四格均有可追溯的模型、输入与逐步演算，且答案符合冻结的逐格预测。 |
| partial | 部分格满足主张、其余格未满足，且没有预登记否决观察；列出具体格和边界。关键证据缺失导致不能可靠判断时用 insufficient。 |
| refuted | 任一预登记否决观察成立：模型自相矛盾、条件变化与事先声明的机制预测冲突，或必须事后添加规则才能得到预期结果。逐格保留证据。 |
| insufficient | 必要模型、输入、预测或关键证据未冻结/缺失，以致不能可靠判断；不得从缺证推导支持或否决。 |

严重度依 D-023 按受影响格和偏离性质逐项定性记录，不另设跨 H 分数。创作者须在正式预登记中确认可预见的偏离类型及各自对主张的影响；不得以空白默认严重度。

## 5. 每格记录与候选证据

每格至少留存：预登记与模型规则版本、初始状态、每步步初状态、请求排水量、实际排水量、步末状态、第二步结束答案、逐步计算、原始输入/输出、适用范围、创作者判断及理由。逐格证据路径和记录责任人待指定。预测表与运行观察分开保存；不添加方法并未要求的程序或工具。

输入不符、关键字段不可得、模型/版本与冻结稿不一致或证据无法复核时，先停受影响格、原样记录偏离并返回创作者裁定；不得临场修改规则继续得到预期答案。最终停止流程须结合 R1 通用停点和实际运行安排在冻结前细化。
