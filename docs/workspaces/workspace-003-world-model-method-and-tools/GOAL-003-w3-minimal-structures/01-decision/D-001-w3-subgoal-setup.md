## D-001 · 建立 W3 子目标并固定输入与边界

用户 2026-09-26 授权「首先判断一下目标2的w3阶段是否应该再开设一个子目标承载治理上下文，是的话开设子目标」。按父级 [D-014](../../GOAL-002-r2-method-working-version/01-decision/D-014-w3-subgoal-setup.md)，建立本子目标；两个结构共享输入、映射与一致性验收，放在同一目标中。

输入是父级已冻结的 [W2 v0.4](../../GOAL-002-r2-method-working-version/attachments/world-model-method-working-version-v0.4.md)，以父级 D-013 / A-008 为冻结和门禁依据；条款追溯使用父级 D-004 及其 D-005 / D-006 修订、D-007 冻结链，设计裁定沿用 D-008 及 D-012 修订。

范围是两份可填写结构、字段映射、创作者可填性与建议/裁定可区分核对、双结构/W2 一致性、自审视和冻结交接。成功标准与三阶段路线图在 meta 中维护。审计模式 self，正式意见在本目标 A 台账。

W4 真实问题走查留父级，I-202 / I-203 / I-204 不在此处解决。发现输入矛盾、字段要求改变方法语义或关键未知，先记录并暂停受影响范围，回流父级处理；不得以结构字段默认值代替创作者裁定。子目标完成后由父级核对 W3 退出条件再更新父级检查点，不能凭子目标 progress 自动放行。
