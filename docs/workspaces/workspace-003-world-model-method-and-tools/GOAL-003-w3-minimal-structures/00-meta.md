# GOAL-003 · W3 · 两个最小结构形成

## 概述

承载父目标 [GOAL-002](../GOAL-002-r2-method-working-version/00-meta.md) 的 W3：以 W2 冻结版本 [v0.4](../GOAL-002-r2-method-working-version/attachments/world-model-method-working-version-v0.4.md) 为输入，形成「能力缺口判定清单」与「模型条目最小结构」两份创作者可填写的结构，并统一保存字段映射、可填性与一致性核对、自审视和冻结交接证据。当前只完成立项，两份结构尚未产出。

## 成功标准

- [ ] 「能力缺口判定清单」（对应需求 §10）与「模型条目最小结构」（对应需求 §9）均形成，可直接填写。
- [ ] 两份结构的每个字段均能指回对应条款及 W2 章节，字段映射可核对。
- [ ] 逐项通过创作者可填性核对，字段不依赖任何程序输出；借助助手时能区分建议与创作者裁定。
- [ ] 两份结构相互一致，且与 W2 冻结正文 v0.4 无矛盾。
- [ ] W3 自审视完成、required finding 均合法闭合，冻结两份结构及映射/核对证据并向父目标交接。

前四项逐条对应父目标 W3 原退出条件；第五项为阶段治理收尾，不代表 W4 适用性核对完成。
