## 填写与停步纪律

按 G01 → G02 → G03 → G04 → G05 依次检查。每步有真实记录才能认定检查发生；若前一步已找到合法处理路径，后续逐项写“未进入：停于 Gxx，原因……”，不能伪造检查。未知时写待确认及下一收集动作，不自动等同“已排除”。

只有五步均已检查且仍无法解决，才可认定新的世界模型能力缺口。找到已有路径只是确定输入和路径，实际裁决仍须经过 W2 第 2 章步⑦，再检查并返回创作。本清单不判断“值不值得建”。可以自然语言填写，无程序输出要求；空白不代表任何创作者裁定。

## G01 · 这是否真的是客观世界问题？

来源：§10①；§12；§3、§13 第1项；W2 第 8 章步①、回绝与回流、不覆盖事项；第 2 章步①。

写问题原文、真实需求与要求精度；判定是否为机制/状态产生的可观察、可裁决客观影响。非客观问题须明确回绝、说明理由、回流创作，不得改写成建模任务；停在此步，后续写未进入/原因。

### 就近对照：§12 十一项不覆盖事项

1. 剧情大纲方法。
2. 主题选择。
3. 宏观历史演化方法。
4. 叙事窗口选择。
5. 角色选取。
6. BDI 或其他角色决策方法。
7. 角色风险控制。
8. 观众信息呈现。
9. 自动编剧。
10. 完整世界模拟器。
11. 固定的软件架构。

这些事项不作世界模型裁决对象；提出时明确回绝并回流创作，不转建模。它们可消费世界模型能力，但不能决定其应返回什么事实。机制或状态对制度、经济、群体行为造成的可观察客观影响仍在范围内；叙事演化安排不在范围内。具体界线由创作者裁定。
