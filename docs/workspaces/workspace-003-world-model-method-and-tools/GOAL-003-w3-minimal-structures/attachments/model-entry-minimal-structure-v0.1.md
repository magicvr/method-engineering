## 填写约定

十一项均须处理；每项可写实际内容，或显式写“未知 / 尚待验证 / 不适用”并说明理由，不适用不能空过。可直接用自然语言段落填写，无需数学化或任何程序输出。空白模板尚不是模型或裁决证据。

未完成不阻止暂定注册，但能力声明不得超过未完成项允许范围，暂定注册后须同步原有能力目录条目。注册前仍须执行 M06/M10 的最低边界与 challenge test 动作，未做不能声称做过。

每个判断分别填写助手建议及理由、创作者实质裁定及依据、后续责任；不能只写“确认”，不能把建议当裁定。无助手时写“无”。以下统一留痕布局依据 W2 前言与父级 D-003，不冒充 §9 原文独立条款。
