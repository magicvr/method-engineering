# PA3 关键未决与决策点 v0.1

## 关键 unresolved

1. **客观问题边界**：§10-1、§13-1，以及角色信念/世界状态的关系；需边界例。
2. **诊断充分性**：§10 五项检查与 §13-3 四类诊断的交叠、穷尽性和新建模触发依据。
3. **能力发现与最低充分性**：查不到不等于不存在；目的相关不等于已证明最小。
4. **版本影响与创作回接**：§13-9/10 只有间接候选，不能由建模理论硬推管理协议。
5. **H2 转译/综合可靠性、H3 冷启动充分性**：仍是未验证局部主张；H3-SEM-001 不闭合。

以上均为未决项，不是 PA4 缺口结论或原创许可。

## 可能需要用户裁决的点

- 若客观问题边界存在竞争解释，需展示边界例并由用户选择。
- 若要改变 §10 严格检查顺序、改为多标签诊断或放宽新建模启动条件，需用户确认。
- 若把“最低充分机制模型”改为“最低充分裁决模型、机制表示按问题选择”，需说明与原需求的差异并裁决。
- 对关键未决接受残余、开展有界实验、增加来源/费用/范围，按 P-004/P-005 留痕；S04-C 残余不自动覆盖。
- 真正证据冲突出现时，暂停受影响选路，不自动选胜者。

## PA3 边界

这些未决项可以登记并在 PA4 作为缺口/吸收输入，但不能在 PA3 被自动关闭、写成缺口或用于冻结 R2-W 路线。
