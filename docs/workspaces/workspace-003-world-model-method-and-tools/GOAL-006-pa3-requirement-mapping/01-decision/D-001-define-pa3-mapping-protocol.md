# D-001 · PA3 映射协议与四类处置边界

## 决定

以 PA2 的 37 项要素为输入，逐项映射需求 §10/§13 与旧 H1/H2/H3 局部主张。每个映射登记：需求/主张 ID、候选要素 ID、对应条件/差异、处置、适用依据/限制、验证或后续动作。

## 四类处置

- `inherit`：来源和适用依据均已核对，要素语义可直接保留；PA2 内容抽取本身不构成适用性依据。
- `adapt`：保留可追溯来源，但需记录有限改造、差异风险与验证安排。
- `not-applicable`：有已核实的范围/前提与需求不匹配依据；不是“没找到”。
- `unresolved`：来源、解释、适用性或比较证据不足；不得当作已吸收或已证缺口。

## 证据与停止

- 不把来源要素自动外推为需求适用性；没有适用性证据时保持 unresolved 或记录 adapt 的验证安排。
- H1/H2/H3 仅作旧局部主张，不作为已验证理论；H3-SEM-001 和旧 H 门禁不闭合。
- 来源间冲突、关键 unresolved、需要新增来源/费用/范围时暂停受影响映射并回流。
- S04-C 全文未决按 D-002 残余处理；不以摘要替代全文结论。
