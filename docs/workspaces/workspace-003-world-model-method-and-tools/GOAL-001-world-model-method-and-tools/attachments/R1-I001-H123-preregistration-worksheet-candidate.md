# I-001 · H1/H2/H3 预登记工作表候选（待确认）

> 此工作表仅把已选择的证据清单、创作者局部裁决和小型可行性工作量上限变成可填写字段。所有内容均为待填模板，不含具体问题、模型、样本或结果；不授权试验、复验、替代方向验证，也不关闭 `I-001` / `I-002`。

| 执行授权依据 | 〔待填；没有明确授权与适用的 `I-002` 关闭记录时，不开始涉及真实案例的运行〕 |

**共同判定规则**

- `supported`：该局部主张所需的预注册条件均有可核对证据。
- `partial`：支持、未支持和未覆盖部分能按执行前规则分开，并明确边界。
- `refuted`：观察到执行前登记且适用于该范围的否决条件；不得把缺证据或输入不足当作否决。
- `insufficient`：任何必要输入、对照、样本、证据或预注册裁决规则缺失，致使无法按原范围判断；不得事后扩展范围以补成通过。

**已选择的计划上限（D-010）**：共同维护组全项目合计最多 3 人时；全项目最多 1 次在原因可定位后的定向复验；最多 1 个替代方向并只验证 1 次；不含额外付费服务、API 或专用工具授权。这些是计划上限，不等于已授权开始、复验或替代验证。
