# ARCHITECT 目标漂移审查 v0.1

来源：独立 ARCHITECT 只读审查，基线 HEAD 205841a。非正式审计，不替代维护者外部 independent/cross 审计。

## 结论

存在实质性目标漂移，主要发生在实现路线、方法入口和验收尺度上；尚不能说 Charter 或 VP 已正式变成“签字打卡流程”。

上层仍承诺“帮助创作者获得可用的世界模型裁决能力”；下层越来越擅长说明“材料是否齐全、哪些尚未验证、应在哪里停止、下一步由谁负责”。RUN-001 证明方法把本应协助完成的问题形成工作退回创作者。

## 主要漂移证据

1. 帮助形成问题变成先提供已形成的问题：方法工作版 §1 把对象/范围/结果/输出契约可说明列为适用条件；步骤0要求完整上下文和十一项排除确认，否则暂停；RUN-001 只返回三问，没有候选理解、分解提案或候选机制范围。
2. 旧路线识别过的能力没有替代实现：旧 H2 曾包含“将模糊问题转译为机制模型可求解的问题集合”；reframe 后主要冻结查询驱动、人工条件化、可停止/拒答，未保留替代 intake/decomposition 操作。
3. 完成标准奖励描述齐全而非能力出现：R2-PA/R2-W/R3 的退出对象是来源、映射、文本、结构和分支决定；直到 R4 才第一次检验入口是否可用。
4. 黑箱纪律被扩展成方法内部不得拆解：保留原始输入不等于运行中不能生成明确标注的候选分解；禁止擅自确定设定与禁止提出暂定分解被混同。
5. 流程替代能力的问题成立，但历史重复签字已整改：不能重新宣称当前仍要求重复签字；真正问题是重复签字取消后，专业问题形成负担仍被退回用户。

## 严重度

高。应阻断受影响的成功交付与关门，但无需推翻整个 Charter。RUN-001 的直接症状是步骤0缺少有效 intake/decomposition；系统性根因是方法输入契约把核心转化工作前置给用户。

P-006 判断：需要方向偏差回流与结构选型复核；主推荐仍在同 Root、同 VP 内修复；尚未自动触发 Charter strategic 修订。若用户决定扩大项目级目的/边界，再进入 strategic 修订。

## 根因

- 把转化结果写成输入条件；
- 将作者决策权误扩展成作者必须承担方法工程；
- 将“不冒充证据”过度落实成“未知就先停止”；
- 缺少 capability-first MVP；
- R4 的运行有效性与能力效用尺度混在一起。

## 建议

主推荐：停止沿当前 R4 路线继续向交付推进，保留 RUN-001 失败事实，退回 R2-W 能力开发；先明确最小能力，再修订方法与运行限制，以能力结果而非材料齐全度验收。建议做一次聚焦的决策层确认，但不默认改 Charter、不启动大型 re-align。

应保留：Charter 真实问题优先、VP-003 能力闭环、prior-art 抽取与映射、状态/组合/精度/机制检查次序、事实/假设/建议/作者决定区分、no-tool 分支、RUN-001 负面证据。

应停止或改写：要求用户先提供完整问题契约；要求用户逐项证明排除项不适用；将不能确认保真拆分落实成不能提出暂定分解；把禁止外部预处理扩展成禁止方法内部拆解；用流程覆盖/字段齐全/无开放 finding 代替能力通过；能力未出现前继续扩建运行基础设施。

## 下一轮最小能力定义

在创作世界模型语境下，面对尚未结构化的真实需要，方法能够承担候选理解、问题分解和机制范围形成的工作；用户只需作实质性的意图与设定选择，不必预先完成问题工程。随后，方法能围绕一个选定子问题形成可检查的局部条件模型，产出对创作有用的有限答案。

必须出现的可见结果：

1. 候选理解与初步分解；
2. 至少一个可裁决问题；
3. 有限的候选机制范围；
4. 一个实际工作的局部模型；
5. 具体回到创作的用途。

成功标准：方法主动承担问题形成；分解与原问关系清楚；追问具体低负担；局部模型有明确规则/输入/输出；条件变化能产生有理由响应；用户能据此推进创作决定。

失败标准：再次要求用户先完成对象/契约/机制范围；仅返回未知清单/追问清单/停止记录；生成宽泛说明却无可裁决问题与局部模型；编造用户决定；只填字段没有推演；只能针对 RUN-001 措辞工作。

## 用户决策点

1. 是否将宽泛需要 intake/decomposition 明确纳入能力边界，而不把完整问题契约作为调用前提。
2. 是否暂停当前 R4 交付推进，回到能力开发，并如何调整 R2-W 检查点含义/状态。
3. 是否授权有限方法修订与重跑，及交互限额、候选/假设使用边界。
4. 任何规则实质变更、residual/overrule、愿景边界变化和最终能力验收，必须由用户裁决。
5. 原定外部正式审计仍由维护者执行，本审查不能替代。
