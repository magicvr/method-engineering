## R1 · I-003（required）条件式工具策略

R1 只冻结 D-009 已选独立 Codex 项目 Skill 首发方向、最小职责/权限与产物类型、价值评估依据/触发时点/责任及两分支。创作者显式调用，工作流与单次可导出记录；不自动写 canon、不自行运行假设试验，不并入治理包。

工具价值评估使用既有实践或 R2 人工方法过程，责任人为同一维护人，AI 可在授权范围整理证据。I-003 的 R1 结论不要求已有重复使用证据、Skill 名称/源路径/精确字段/持久化/安装/实现验收；关闭 I-003 不表示工具价值成立或已工具化。

## R3 · I-006（required）价值评估与落实分支

I-006 不阻断 R1/R2。R3 最迟退出时完成已有证据评估与分支决定：

- 证据支持本轮工具化：说明重复任务、实践依据、收益/维护负担；方法接口稳定后形成最小工具。名称/路径、字段、持久化、安装/更新与可观察验收项在实现前明确。
- 证据不足或价值未成立：明确本轮不引入，记录证据范围与理由、下次评估触发条件及责任人。结论不要求正价值，不无限追加运行，不以 Skill 先实现/启用或 R4 反馈为前提。

此 no-tool 分支是 VP-003 判据 3 已允许的标准路径，不要求先书面拒绝 Skill 或新设愿景门禁。证据不足不冒充已验证工具价值；R3 退出核对分支是否落实。
