# 继任 R1 能力边界承诺 v0.1（草案，待用户确认）

本轮承诺：提供一套方法（必要时包含工具），帮助创作者将模糊世界观设定转化为可持续使用、回答问题并按需扩展的世界模型机制。承诺对象是能力，不是文档、流程或签核的完整性。

## 1. 服务对象与真实需要

服务于只有部分、模糊或不一致世界观设定的创作者。帮助其逐步回答可抽象为“这个世界是怎样一个世界”的一系列问题，使设定能够长期组织、调用和演化，而不要求一次性构造庞大的完整世界模型。

## 2. 最低输入

接受尚未结构化的设定、片段、想法和用户已有资料；未知可以保留。不要求创作者预先提交完整机制模型、问题契约或专业分类。连用途也不明确时，由方法协助澄清，而非要求用户先完成问题工程。

## 3. 方法承担的工作

吸收、整理已有设定，区分已确定内容、矛盾、未知与候选；提出可修改的理解和暂定问题分解；形成初始问题族及支持它们的局部机制，明确哪些内容现在需要、哪些可以以后再建；提供回答、复用和增量扩展的方法，而非仅提供记录槽位。

## 4. 用户承担的工作

提供真实意图、已有资料和确定设定；决定关键设定、创作取舍及是否采用候选。用户不替方法完成核心问题分解和模型设计。方法不得虚构用户的选择，也不得将建议自动确认为世界事实。

## 5. 最低输出

在获准真实需要上产出：

- 可持续使用的局部世界模型机制：必要结构、规则、状态，以及适用范围、扩展接口和拒答边界；
- 至少一个实际可回答的问题族，而非只有问题目录；
- 新问题到来时如何复用、补充或修订机制，以及如何检查对既有回答的影响；
- 结果如何支持具体创作的说明。

这些是功能要求，不预设固定目录、软件架构或工具形态。

## 6. 正向验收底线

至少一个获准真实需要跑通：

模糊设定 → 候选理解与分解 → 局部世界模型机制 → 有依据的有限回答 → 新问题驱动的按需扩展。

须展示既有机制能够再次使用，并通过一个新增问题检验增量扩展及对既有回答的影响。字段、清单或停止记录不能代替通过。“长期可用”先以可复用、可维护、可演化的实际表现检验，不以一次运行证明永久有效。

## 7. 明确失败

以下情形不得按原承诺验收：核心工作退回创作者；只有记录没有机制；只写流程却不能回答问题；要求先完成整个世界，或无必要地为未提出的需求建造超大模型；偷换真实需要；虚构设定或作者决定；扩展后无法说明既有机制和回答的适用变化。

## 8. 停止与证据边界

权限不足或必须由作者决定的设定，可停止相关范围；未知但可探索时，允许明确标注的候选、假设与条件分析。保留实际输入、关键选择、机制、回答、扩展结果及限制。正确停止不等于能力通过；条件推演不等于设定已确定或领域有效性已证明。

## 9. 对原 R1 的处理

保留对象与非目标、作者决定权、证据诚实、实质授权和条件工具策略；补正最低入口、方法责任、正向能力及失败底线；废弃其作为验收依据的用途：重复确认、材料齐全即能力就绪、未知一律整体停止。历史冻结事实保留。

建议同步澄清 VP-003 的能力范围：从模糊设定形成可演进世界模型，而不只是处理预定义裁决问题；不能仅替换 R1 标题。是否构成实质范围修订由用户确认，不默认改 Charter。

## 10. 用户必须裁决

确认上述入口与能力范围；确认候选设定的允许边界、首轮投入上限及“复用＋增量扩展”的验收底线；确认 VP-003 的相应澄清或修订。初始问题族由方法提出、用户选择，不要求用户先自行设计。工具仅在确有助益时引入，不作为能力成功条件。
