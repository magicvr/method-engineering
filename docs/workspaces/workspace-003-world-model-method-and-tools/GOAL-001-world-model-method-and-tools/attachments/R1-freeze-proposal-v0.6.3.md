### 逐假设预注册结果判据

正式标签沿用 Root 的 `supported` / `partial` / `refuted` / `insufficient`；不设跨 H 总分或通用比例门槛。`supported` 仅表示预先声明的局部主张满足其必要证据，不支持向整体 H 或完整方法外推。各 H 的细化条件仍须在运行前写入预登记记录；空白、缺证据或输入不足不得由执行者自行补成通过。

| 标签 | 当前局部解释 | 运行前要求 |
|------|--------------|------------|
| `supported` | 已声明的局部主张，其全部预注册必要条件有可核对证据 | 写明主张、适用范围、证据清单与记录位置 |
| `partial` | 支持、未支持和未覆盖部分可以区分，且能说明边界 | 预先写明部分结果的拆分规则，不以样本数替代理由 |
| `refuted` | 观察到预登记且适用于该局部主张的否决条件 | 各 H 写明可观察的否决项、适用严重度和责任；信息不足不得记为否决 |
| `insufficient` | 必要输入、对照、样本、证据或预登记规则不足以按原范围判断 | 写明缺项及其对判断的影响；保持 `I-005` open/collecting，不放行 R2d |

预登记须注明创作者/判据作者、运行者、评估者、记录者（可由同一人承担）、证据路径、规则冻结版本、偏离记录方式及变更复核责任。H2 的“是否值得额外步骤”与 H3 的“足以启动”具体规则由创作者在运行前写明并给出理由。模板见[预登记工作表](R1-I001-H123-preregistration-worksheet-candidate.md)。不得事后调整规则、增加模型/问题/身份/情景以获得通过结论。
