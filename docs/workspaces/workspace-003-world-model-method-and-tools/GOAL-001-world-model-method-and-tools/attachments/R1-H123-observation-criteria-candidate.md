## 1. 共用记录与判定结构

每个拟检验单元应在执行前写明：问题边界与纳入/排除条件、输入的状态和参数、所用模型及版本、预期输出与目标精度、观察项目、证据来源、适用范围，以及哪些观察会支持、局部支持或否决假设。字段未冻结前，不得据此执行试验或事后补写通过条件。

每个假设分别使用 `supported`、`partial`、`refuted`、`insufficient`。标签仅说明被明确限定的检验范围：

- `supported`：预先约定的支持条件在记录证据中满足；不得泛化到未检验范围。
- `partial`：可支持的条件/切片与失败或未覆盖部分能清楚分界；只保留有证据的部分。
- `refuted`：发生预先登记的否决观察；不得把可补充输入造成的暂不能裁决直接算作否决。
- `insufficient`：问题、输入、样本或证据不足以判断；保持未决，不视为支持或否决。

具体阈值、证据充分性、否决条件和资源限额仍须另行书面裁决。`insufficient` 按 D-002 保持 `I-005` open/collecting，并阻断 R2d。

## 2. H1 · 机制模型求解

**拟观察对象**：对明确的客观问题，给定其声明的机制模型、模型版本、世界状态/时空切片、条件与参数，能否产生符合模型适用范围和目标精度、且可追溯的裁决结果。

**拟记录证据**：

1. 问题所需的对象、条件、结果与状态输入能被明确列出；缺失输入须能标记为待补、降低精度或当前无法裁决。
2. 每个答案、区间、精度限制或拒绝裁决，都能指回所用模型版本、必要状态/参数和相关规则或机制依据。
3. 对预先选定的适用条件变化或反例，记录模型输出如何随条件变化；同时记录模型组合冲突、依赖和无法推出的部分，不用新增未声明前提补成期望结果。

**结果判据候选**：在约定范围内，输出可由声明的模型与输入推出、精度和边界明确、且通过预登记条件变化/反例检查，可作为支持证据；仅部分范围满足时可形成局部支持；若预登记范围内答案不可由所声明机制推出、条件变化与模型规则冲突，或必须依赖未声明的结果补丁，则可作为否决证据。需要哪些条件变化、允许怎样的近似及证据充分性待确认。

## 3. H2 · 身份/情景转译

**拟观察对象**：对一项需要澄清的模糊问题，身份/情景入口形成的问题集合能否保留原问意图、揭示影响裁决的条件，并相较直接「对象—条件—所求结果」整理方式带来达到预定标准的增益。

**拟比较方式**：对同一原问分别记录身份/情景转译路径与 D-002 指定的轻量直接路径；两路使用相同可用信息和任务边界。已足够明确、无需澄清的问题不用于证明 H2。

**拟记录证据**：

1. 转译出的每个子问题与原问目标的对应关系，以及新增的身份、情景、条件和未知输入。
2. 子问题结果如何回到原问；综合时是否遗漏原问的必要约束、引入无依据假设或超出客观裁决职责。
3. 与直接路径相比，额外澄清是否改变了可求解性、所需输入、结果边界或裁决质量；同时记录额外步骤/维护成本。

**结果判据候选**：身份/情景路径保持原问意图且在预先约定的效用标准上优于或补足直接路径，可作为支持证据；增益只在可界定的模糊类型或条件下出现时可形成局部支持；若转译丢失原问的关键约束、综合无法回到原问，或按预先约定的标准未体现足以抵偿额外步骤的增益，可作为否决证据。效用标准、成本权衡和严重性边界待确认。

## 4. H3 · 冷启动覆盖

**拟观察对象**：在明确限定的典型身份、情景和问题采样范围内，按采样得到的问题集合能否帮助启动一组最低必要的机制模型，并暴露其覆盖边界与待补缺口。

**拟记录证据**：

1. 每个样本从身份到情景、问题及所需裁决能力的来源链；采样范围、排除项和选择理由。
2. 样本问题对应的机制/状态/参数需求、重复项、未能处理项和边界外未知；哪些问题足以启动建模，哪些仍不能裁决。
3. 按预先约定的“足以启动”标准核对初始模型集合，并记录预先纳入范围的补充样本或反例是否暴露范围内的关键遗漏；不得因遗漏而自动扩展样本范围。

**结果判据候选**：在约定采样边界内，问题集合达到预先约定的启动标准，且覆盖与遗漏可追溯，可作为该边界内的支持证据；仅部分身份/情景切片可启动时形成局部支持；若按预登记标准仍不能启动所约定的模型集合，或出现预先定义的范围内关键遗漏，可作为否决证据。采样框、代表性限制、“足以启动”标准及关键遗漏判定待确认；任何结果都不表示覆盖完整世界。

## 5. 假设间边界

- H1 检查明确问题下机制模型能否按已声明输入求解；H2 只检查需要澄清的问题是否从身份/情景入口获得增益；不得因 H2 转译步骤没有必要而否决 H1。
- H3 检查有界采样能否形成可启动的问题集合；其样本数量或分布不能代替 H1 求解证据，也不能代替 H2 对照证据。
- 同一材料如被多个假设引用，须分别记录它实际回答的观察项；不得把单个结果重复计作相互独立的支持证据。
- `partial` 必须给出适用切片与未支持切片；任何判定只覆盖实际检查的范围。
