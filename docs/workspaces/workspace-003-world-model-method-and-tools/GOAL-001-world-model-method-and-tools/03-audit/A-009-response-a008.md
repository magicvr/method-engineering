# A-009 · 响应 A-008

## 响应结论

A-008 的 F-001、F-002、F-003、F-005、F-006、F-007 已形成 fixed 修正；F-004 的投入上限经用户 user-overruled，候选设定边界保留。当前无开放 required；D-028 待 A-010 independent 闭合核验后冻结。

## Findings 响应

| ID | 响应 | 证据 |
|---|---|---|
| F-001 | fixed | 草案新增“回答成立的判定”：回答须映射获准需要、由登记机制/状态推出、满足输出契约、经受条件变化检查、可追溯；登记或类型相符不构成通过。 |
| F-002 | fixed | 草案新增“长期可用的验收与观察标准”：初始验收只证明一次复用、一次扩展和一个条件变化；长期可用另列后续观察标准，不以一次运行宣称满足。 |
| F-003 | fixed | 用户确认 VP-003 澄清；VP-003 v0.1.2 已写明从模糊设定构建可长期使用、可按需扩展、具备可登记/可验证裁决能力的世界模型；问题拆解为辅助；R1 客观裁决对象、十一项排除、缺口次序、停止建模和条件敏感性继续有效。 |
| F-004 | user-overruled | 用户明确否认投入上限要求，认定其为与能力建设无关的形式要求；投入上限退出冻结门禁。候选设定边界（授权资料、候选/假设标注、不新增来源/费用/canon、用户决定关键设定）保留。 |
| F-005 | fixed | 运行时交互已改为无效否决规则；产品失败清单只保留交付状态。 |
| F-006 | fixed | 草案新增适用层级：历史 R1/GOAL-009/GOAL-010 关门事实保持原判；不改判 RUN-001；不自动放行 R4；列出继续有效的停止条件。 |
| F-007 | fixed | 附件 status 改为 draft，与 D-028 proposed 对齐。 |
