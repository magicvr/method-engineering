# A-009 · 响应 A-008

## 响应结论

A-008 的 F-001、F-002、F-005、F-006、F-007 已在 D-028 草案中形成 fixed 修正；F-003 已将绑定服务对象收回 R1/VP 客观裁决范围，并把更宽 VP 范围单独列为用户裁决；F-004 已提出首轮边界与投入上限提案，但仍待用户确认。F-004 未确认前，D-028 不能冻结。

## Findings 响应

| ID | 响应 | 证据 |
|---|---|---|
| F-001 | fixed | 草案新增“回答成立的判定”：回答须映射获准需要、由登记机制/状态推出、满足输出契约、经受条件变化检查、可追溯；登记或类型相符不构成通过。 |
| F-002 | fixed | 草案新增“长期可用的验收与观察标准”：初始验收只证明一次复用、一次扩展和一个条件变化；长期可用另列后续观察标准，不以一次运行宣称满足。 |
| F-003 | fixed（绑定范围）；VP 更宽范围待用户单独裁决 | 草案 §1 绑定到 R1/VP 客观裁决对象；更宽的“模糊设定→可演进世界模型”列为 VP 澄清候选，VP 确认前不作验收依据；十一项排除、缺口次序、停止建模、条件敏感性继续有效。 |
| F-004 | open（待用户确认） | 草案新增首轮边界提案：只使用授权资料；候选设定标为假设；不新增来源/费用/canon；一个真实需要、最多三轮短交互、一个局部机制、一个问题族、一次扩展验证；超限停止。 |
| F-005 | fixed | 运行时交互已改为无效否决规则；产品失败清单只保留交付状态。 |
| F-006 | fixed | 草案新增适用层级：历史 R1/GOAL-009/GOAL-010 关门事实保持原判；不改判 RUN-001；不自动放行 R4；列出继续有效的停止条件。 |
| F-007 | fixed | 附件 status 改为 draft，与 D-028 proposed 对齐。 |

## 未闭合

F-004 的投入上限与候选设定边界仍待用户确认；F-003 的 VP 更宽范围是否正式纳入仍待用户裁决。F-004 未合法闭合前，D-028 不冻结。
