# GOAL-001 · 为消费方构建并交付世界模型的方法与工具

## 概述

承接真实消费需求 `WRK-002-world-model-method-and-tools`：为下游 `WorldModel.ModernCultivation` 构建并交付「世界模型构建方法工作版 + 配套工具」，在至少一个真实世界问题上有界检验，并按 [`protocols/consumer-response-protocol.md`](../../../../protocols/consumer-response-protocol.md) v1.0.0 完成交付、实际收件、验收或异议迭代与结束回路。本目标是 VP-003 的实现承载：VP 给方向级意图与退出判据，本目标给可执行纲领阶段、信息门禁与证据。

### R2 子阶段与证据选路

用户于 2026-09-30 选择「先验证、失败转向」（[D-002](01-decision/D-002-prioritize-hypothesis-validation.md)）。这是路线选择，以下假设仍待验证：

- **H1 · 机制模型求解**：多个自洽的机制模型能用定义、关系/抽象公式与规则，在显式条件下回答明确问题；必要时输入世界状态/时空切片。先将状态作为显式输入，不预设独立状态层；共享状态、跨模型一致性或重复使用的证据支持后再判断是否分层。角色认知/可知信息与客观状态分别表达，并核对必要模型接口与组合冲突。
- **H2 · 身份/情景转译**：从世界内部的「谁在什么情景下提问」出发，能将模糊问题转译为机制模型可求解的问题集合，再综合为原问的答案。身份/情景是问题发现与澄清入口；已明确的问题可直接进入求解。用直接「对象—条件—所求结果」的轻量对照检查该步骤的增益，不展开第二套完整方法。
- **H3 · 冷启动覆盖**：有界采样典型身份，再采样情景与问题，可得到足以启动首版机制模型集合的问题集，后续按需补充并检查其他视角。身份/情景的有限、可穷尽组合及样本代表性均未经验证；资料只能提供采样参考，不能据此声称覆盖完整世界。

| 子阶段 | 计划与退出要求 |
|--------|----------------|
| **R2a · 操作化假设** | 在 R1 冻结范围内将 H1/H2/H3 分成可核对的问题、输入/输出、正例、反例与预注册判据；明确采样边界、对照方式、必要接口/组合检查及证据落点。不得先设一套不可证伪的完整方法。 |
| **R2b · 有界试验** | 按冻结判据逐项试验，记录反例、失败与缺失证据；使用真实案例前，必须先由共同维护组书面选定案例、用途范围及授权并关闭该范围的 `I-002`。若失败可定位且 R1 已授权，则按冻结的有限次数/资源上限修订复验；本路线不预先授权复验或固定次数。不得无限追加模型、身份或场景直到通过。 |
| **R2c · 证据选路与必要转向** | 对 H1/H2/H3 分别记录 `supported` / `partial` / `refuted` / `insufficient` 及证据。只有前三类可核对证据足以形成路线选择时，才可作为 `I-005` 的选路结论；`insufficient` 保持 open/collecting 并阻断 R2d。支持时采用有证据的部分；局部失败时保留已支持部分，对失败部分进入有界替代思路构想/验证；整体失败时停止原假设验证并进入有界替代方向。局部失败不等于整套世界模型方法被否决。替代方向的数量、试验回合与资源上限须由 R1 预先冻结，不为得到通过结论自动扩容。 |
| **R2d · 暂定方法工作版** | 按选路证据形成并核对工作版，覆盖识别需求、能力发现、state/composition/precision/mechanism 缺口、定义新能力、最低充分机制模型、反补丁检查、适用条件/敏感性、组合/冲突、版本/受影响旧裁决、回流创作。未试到的指导内容标注限制/未决与后续责任，不宣称已验证；证据只支持有界范围。 |

**停止规则**：出现预注册否决条件时停止对应假设试验；仅在失败可定位且 R1 已授权时，按冻结的有限次数/资源上限修订复验，不能定位可修订原因时直接停止。`insufficient` 不能冒充通过，`I-005` 保持 open/collecting 并阻断 R2d。到达冻结限额、替代方向用尽仍无足以选路的证据、或需要改变范围/授权/预算时，暂停受影响阶段并请求用户裁决、留痕，未获裁决前不扩大试验或进入 R2d。现有路线选择不代替 R1 冻结、案例选择或残余风险接受。
