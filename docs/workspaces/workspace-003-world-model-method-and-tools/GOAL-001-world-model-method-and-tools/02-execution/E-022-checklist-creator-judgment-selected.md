# E-022 · 用户选择证据清单与创作者局部裁决判据形式

用户于 2026-09-30 选择 Root `D-011` / `E-021` 候选 A。后续 H1/H2/H3 计划采用各自证据清单，不设跨 H 总分；H2 增益是否值得、H3 最低启动条件应由创作者在执行前书面说明并留痕。

选择规则形式没有冻结个案的局部阈值、输入字段、证据责任与完整停止规则，也没有授权使用案例或启动试验。`I-001` 仍 open。
