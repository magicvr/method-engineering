# E-032 · 冻结上游 R1 协议 v0.6.4

依据 [D-017](../01-decision/D-017-freeze-r1-protocol-v0-6-4.md)，上游将 [v0.6.4](../attachments/R1-freeze-proposal-v0.6.4.md) 标记为已接受并冻结的当前 R1 协议。独立复核见 [A-004](../03-audit/A-004-independent-review-r1-protocol-v0-6-4.md)：审阅通过，初审三项非阻断建议和范围对齐提醒已写入正文，后续复核无阻断项。

本条记录的是上游协议冻结事实。记录时下游当前引用仍为 v0.6.3；下游尚未同步 v0.6.4。故 Root 的 R1 检查点仍进行中，`I-001` / `I-003` 保持 open，阶段进度和 Root 状态不变。下游提交、双向精确引用、R1 关门及运行主记录转换待后续实际发生后分别记录。

冻结的协议限定 H1/H2/H3 与最多一个有原因的定向复验、最多一个替代方向共用九个结果格；总计 3 人时含预登记、准备、执行、评估和记录。没有运行试验、选定 R2b/R4 真实案例、形成 R2d 方法工作版、实施 Skill、交付、收件或验收。
