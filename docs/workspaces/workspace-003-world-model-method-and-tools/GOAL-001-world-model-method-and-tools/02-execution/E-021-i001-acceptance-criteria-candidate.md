# E-021 · 准备 I-001 各 H 局部支持判据候选

在用户选定 A 档工作量上限后，形成按声明范围区分 H1/H2/H3 局部结果的判据候选，见[附件](../attachments/R1-I001-H123-acceptance-criteria-candidate.md)。候选将证据必要项、`supported` / `partial` / `refuted` / `insufficient` 的边界与待裁决的 H2/H3 阈值放在一处比较，提供定性清单、固定数值和延后裁定三条路径。

候选不使用黑箱探针输入或结果，不包含具体案例或实际结果，也未合并到两仓当前绑定；没有执行 H 假设测试。`I-001` 保持 open，待用户裁决及后续填写具体范围/判据。
