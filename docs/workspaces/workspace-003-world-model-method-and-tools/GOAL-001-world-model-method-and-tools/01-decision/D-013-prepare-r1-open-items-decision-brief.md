# D-013 · 整理 R1 I-001 / I-003 未决项裁决清单

## 决策

用户选择先整理 I-001 / I-003 未决字段的裁决清单，作为继续澄清的准备材料。清单按 I-001 → I-003 的依赖次序列出问题、已选方向、需要的书面依据和门禁边界，见 [R1-open-items-decision-brief-v0.6.2.md](../attachments/R1-open-items-decision-brief-v0.6.2.md)。

此决策只授权整理未决项，不授权助手代填方法值、案例、判据、资源分配、执行责任或工具验收条件；不发送给共同维护组，不更改当前 v0.6.2 候选，不关闭信息项或放行阶段。

## 为什么

用户已接受将 v0.6.2 作为两仓当前澄清对象，但草案中的 I-001 具体边界、预登记与停止规则仍未完成，I-003 的工具接口又依赖 I-001。先把已选内容与待确认内容分开，有助于后续由正确责任方提供书面输入，不把计划上限误写成执行授权。

## 未选路径

- 现在在对话中逐项裁决所有具体字段：本次未选。
- 暂停准备，等待共同维护组先提供书面输入：本次未选。
