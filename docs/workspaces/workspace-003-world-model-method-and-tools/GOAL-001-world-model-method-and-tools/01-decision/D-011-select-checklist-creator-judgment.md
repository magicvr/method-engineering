# D-011 · 选择证据清单与创作者局部裁决判据形式

## 决策

用户于 2026-09-30 选择 Root `E-021` / 候选 A「可观察清单 + 创作者局部裁决」。不设跨 H 总分或通用比率；H1/H2/H3 分别按预注册证据清单，仅对声明范围给出 `supported` / `partial` / `refuted` / `insufficient`。

- **H1**：两模型、基线与一个条件变化的每个结果格都须与事先声明的模型、输入和条件预测可追溯；遗漏单元或输入不足时不作整体支持。
- **H2**：身份/情景路径须保持原问约束，并在执行前登记什么算决策相关增益及额外步骤如何由创作者评估；若增益是否值得或比较标准未事前写明，结果为 `insufficient`。
- **H3**：执行前由创作者书面确定此抽样框的最低启动能力、链条到能力/模型的映射规则和关键遗漏判定；按不超过 3 条样本所覆盖的范围评估，不外推至完整覆盖。最低启动条件未写明时结果为 `insufficient`。

实际使用什么问题、对其“值得”或“足以启动”的个案判断、条件预测、严重度和责任仍须在执行前进入预注册记录；本决定不选择案例、不构成真实案例使用或实验授权。

## 决策边界

此项只选择规则形式，并不关闭 `I-001`：预注册记录所需字段、各 H 精确范围、H2/H3 局部裁决规则、停止条件、预算计量与执行/评估责任仍须写入 R1 合并冻结稿。黑箱探针仍排除在方法规划之外；未完成 I-001 / I-003 与双仓同版记录前，不放行 R1/R2。
