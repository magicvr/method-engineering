## D-007 · 选择共享背景、分立 H 检验单元

### 触发与用户裁决

上游准备了 H1/H2/H3 检验单元结构候选（[E-014](../02-execution/E-014-h123-test-unit-structure-candidate.md)）。用户于 2026-09-30 选择「共享背景、分立单元（推荐）」。

### 决定

1. 后续 R1 检验计划按“共享有界消费问题背景、每个 H 建立独立检验单元”澄清。
2. 共享背景只有在能提供符合相应 H 输入条件的有效单元时才可复用：H1 用清晰客观问题；H2 用确需澄清且可与直接路径对照的问题；H3 独立登记有限采样框。不得要求同一问句覆盖所有 H。
3. 共享源材料不共享判据、检验结果或证据充分性；三项假设分别记录，不将某一 H 的结果转借给另一 H。
4. 这只是计划结构，不选真实案例/样本，不授权任何测试、试验、复验或替代验证，不关闭 `I-001` / `I-002` / `I-003` / `I-005`，不更新下游 v0.6.1 当前绑定，也不放行 R1/R2/R3/R4。

### 为什么

在同一消费者问题背景中派生多个合格的假设单元可减少不必要的范围扩展；保持 H 单元、判据与证据分立，则避免把不同假设混成一个结论。某项假设若不适配该背景，仍可另选问题，不以共享为由强行套用。

### 未选方案

- 各 H 分别使用独立问题/样本组：未选；归因清楚，但会增加案例与资源需求。若后续发现共享背景对某项 H 不适配，仍可就该 H 提出具体例外方案。
- 等案例确定后再决定共享或分立：未选；会使检验范围与资源计划继续无法完成。所选结构不决定实际案例。

### 影响与后续

- 更新上游检验单元候选；仍无下游指针更新或跨仓候选接受。
- `I-001`～`I-005` 继续 open；实际案例、用途范围、阈值、数量、资源、停复验限额与工具边界仍待裁决。无试验或阶段放行。
