## 处置与原创许可

分类对象为理论要素或局部主张，不给整理论贴总标签。inherit：有来源和适用依据、无需实质改变而继承；adapt：保留来源并显式记录有限改造、理由与需验证的差异；not-applicable：记录已核实的适用限制/需求不匹配，不宣称理论错误；unresolved：来源、解释或适用依据不足，继续调查，不等于已发现缺口。

只有缺口对应必要需求、调查边界和替代检查有记录、区分“尚未查明”与“已发现适用限制”、继承/有限改造不足、原创范围和停止条件明确、相关信息/审计/授权门禁满足时，才可进入原创探索。禁止把“没搜到”写成“理论不存在”。
