## D-006 · 选择按声明范围判定证据充分性

### 触发与用户裁决

上游准备了 H1/H2/H3 证据充分性候选（[E-012](../02-execution/E-012-h123-evidence-sufficiency-candidate.md)）。用户于 2026-09-30 选择「按声明范围判充分（推荐）」。

### 决定

1. 证据只支持预先限定且实际检验的声明范围；检验单元结果与 H1/H2/H3 假设范围汇总分别记录。
2. 对部分预定义范围有充分证据时，只允许对应局部主张为 `supported`；未覆盖的更广 H 范围记为 `partial` 或 `insufficient`。仅当预先定义的整个 H 范围均有充分证据、且无未闭合否决条件时，才可考虑将整体 H 标为 `supported`。
3. 该规则不改变各 H 的最低证据包，不决定案例、样本数量、阈值、资源、结果精度或统计置信要求；这些仍需逐项形成候选并裁决。
4. 不选案例，不授权测试/真实案例/试验/复验/替代验证；不关闭 `I-001` / `I-002` / `I-003` / `I-005`，不改变下游 v0.6.1 当前绑定，不放行 R1 或启动 R2/R3/R4。

### 为什么

该规则让结论范围与证据覆盖范围一致，避免单个示范被扩张为普遍有效结论；也允许后续保留有证据的局部部分，并将未覆盖项明确标为部分支持或证据不足。

### 未选方案

- 要求任何 H 的 `supported` 都先有跨情景证据：未选；能降低单例偶然性，但增加案例、样本与资源需求，具体范围目前没有依据。
- 等待 I-002 案例与资源信息再决定：未选；这样会继续阻断 R1 判据冻结。所选规则仍要求后续确认实际范围、案例与有限资源。

### 影响与后续

- 更新证据充分性候选，以区分局部结果与整体 H 汇总；上游候选仍为 draft，未并入下游当前绑定。
- `I-001`～`I-005` 均保持 `open`。真实案例、数量、阈值、资源、停止/复验与替代规则仍须裁决；无试验或阶段放行。
