## D-003 · 因回滚授权替换下游 R1 当前绑定

### 触发

下游仓库 `WorldModel.ModernCultivation` 保留了 2026-09-26 对上游提交 `c69f0adb09adaf7988883f6225f24ffa03eca296` 的 R1 冻结绑定。核对本仓当前分支时，该提交不是当前上游 `dev/vp-003` 的祖先；当前分支在此后经历回滚。用户于 2026-09-30 明确说明可在下游仓覆盖上一次的「R1 绑定」。

### 决定

1. 将当前 R1 澄清对象改为本仓 [R1 冻结提案草案](../attachments/R1-freeze-proposal.md) v0.5.0，并授权下游以本仓提交 + 路径的限定引用替换其**当前绑定指针**。
2. 旧提交 `c69f0adb09adaf7988883f6225f24ffa03eca296` 及下游既有 `D-003` / `E-004` 保留为当时接受与收件的历史事实；它们不再作为当前 R1 执行依据，也不删除或改写旧材料。
3. 新绑定只指向待确认草案，不代表共同维护组接受草案内容，不构成冻结，不关闭 `I-001` / `I-003`，不授权实验、复验、真实案例使用或 R1 退出。

### 为什么

- 本仓当前 Git 历史已不包含旧冻结提交，继续把它作为当前绑定会让下游依据与本仓现行 R1 状态不一致。
- 用户明确授权替换当前绑定。仅更换当前指针并保留旧记录，可同时反映回滚事实和此前真实发生的接受行为。
- 当前提案含未确认字段，故新绑定必须保持 draft，待共同维护组书面确认后才可能形成正式冻结。

### 未选方案

- 删除或改写旧冻结材料及其 D/E 记录：未选，避免抹去当时的真实记录。
- 将新草案标记为 accepted/frozen 或据此放行 R1：未选，尚未取得完整书面确认，required 信息门禁仍开放。

### 影响与后续

- `I-001` / `I-003` 继续 `open`；R1 仍为草案准备，Root 保持 `active` 与 `0/4`。
- 下游仅将 README 与当前绑定材料改指向本草案，另记 D/E 事实；其 M1 与 `I-005` 不因绑定替换而关闭。
- 执行事实由 [E-007](../02-execution/E-007-r1-binding-replacement.md) 记录。跨仓引用需使用仓库、提交和路径。
