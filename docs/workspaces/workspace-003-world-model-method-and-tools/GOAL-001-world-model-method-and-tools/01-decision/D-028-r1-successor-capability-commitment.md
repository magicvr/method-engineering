# D-028 · 继任 R1 能力边界承诺

## 目的

在保留 v0.6.4 历史冻结事实的前提下，补清 R1 原应先承诺的最低能力边界：方法/工具能够从创作者的模糊、不完整设定出发，构建可长期使用、可按需扩展的世界模型机制；该世界模型必须具备预期的裁决问题能力，否则方法/工具交付失败。

## 推荐承诺（待用户确认）

提供一套方法（必要时包含工具），支持：

模糊设定 → 世界模型机制构建 → 预期的裁决问题能力验证 → 有依据的有限回答 → 新问题驱动的按需扩展。

主承诺是构建世界模型；裁决问题能力是该模型的验收条件；问题拆解是辅助能力，不是主产品或创作者前置作业。运行时交互允许且是方法能力的一部分；预期裁决能力必须在世界模型机制内可登记、可验证，验证依据是实际回答行为而非字段/签字。不要求创作者预先完成问题工程、机制模型或专业分类；用户保留设定与采用决定权。字段、清单、停止记录不能代替能力通过，只有问题拆解而没有可回答模型也不能通过。

完整草案见 [r1-successor-capability-commitment-v0.1](../attachments/r1-successor-capability-commitment-v0.1.md)。

## 边界

不扩建治理包，不先做全面 prior-art 调查，不把工具作为能力成功条件。A-008 的 F-001/F-002/F-005/F-006/F-007 已形成修正；F-003 的 VP 更宽范围已由用户确认并通过 VP-003 v0.1.2 澄清；F-004 的投入上限已由用户 user-overruled，退出冻结门禁，候选设定边界保留。D-028 待 independent 闭合核验后冻结。
