# D-016 · 裁决 R1 协议候选 v0.6.4 的边界与总量计法

## 本次用户裁决

用户选择 AI 推荐解释：**H1/H2/H3 的所有初次评价、至多一次原因可定位的定向复验、至多一个替代方向的一次验证，共用绝对累计最多 9 个结果格**。H1/H2/H3 各自最多 4/2/3 格仍生效。每个分别尝试的预登记模型—条件格、H2 比较路径或 H3 链计一格，输入不足或中途停止的已尝试单元也计入。可复验、可验证替代方向只是在剩余额度内的有界选项；本裁决不授权立即运行或额外格数。

用户同时明确：3 人时上限累计 H1/H2/H3 的 R2a 预登记、准备、执行、评估、记录及被允许的复验/替代；多人工作按各人投入相加，不计无人值守等待。此额度只控制 H 可行性工作，不计 R1 治理文稿、R3 工具实现或 R4 交付。不增加付费 API、服务或工具。

## 协议解释与依据

本次将 [v0.6.4](../attachments/R1-freeze-proposal-v0.6.4.md) 作为新的 R1 协议候选，保留 v0.6.3 原文。适用对象、客观问题范围、按需扩展及 §12 十一项排除直接来自下游 `WRK-002` 需求原文 §§1–3、12；「能力缺口判定清单」与「模型条目最小结构」的职责来自原文 §§10、9，逐项覆盖矩阵来自 §10/§13。创作者运行并保留主题、取舍和最终裁决，AI 可充分提示、建议、解释、反例与检查但不能代劳，依据执行主体澄清的**第 2 版修正**；第 1 版的「AI 仅做非判断工作」限制已撤回，不再采用。已选 D-002、D-005～D-011、D-014～D-015 的路线、局部证据标签、角色边界和阶段分配继续有效；本次新增的是上述总量计法及完整协议表述，不将来源条文冒称本次新决策。已回滚的下游历史「澄清与冻结-2026-09-26.md」不作现行依据。
