# D-017 · 冻结 R1 方法协议与条件工具策略 v0.6.4

## 决定

将 [R1 协议 v0.6.4](../attachments/R1-freeze-proposal-v0.6.4.md) 冻结为上游当前协议。它汇总既有 R1 用户决定，并纳入 [D-016](D-016-r1-protocol-v0-6-4.md) 的九格共享上限与 3 人时累计口径；不生成方法有效性结论、R2d 工作版、具体运行预登记或工具实现授权。v0.6.3 与更早版本保留为历史。

独立审阅记录在 [A-004](../03-audit/A-004-independent-review-r1-protocol-v0-6-4.md)：初审为通过并附非阻断建议；建议落实后复核通过，无开放 required finding。既有用户裁决一次留痕，本次不增加同一维护人的重复确认门槛。

## 阶段边界

- v0.6.4 已在上游冻结；R1 目标检查点仍须等下游 `exchange/WRK-002-world-model-method-and-tools/` 当前引用与上游运行主记录更新后完成。同步前，`I-001` / `I-003` 保持 open，Root 维持 active 与原进度，不将“已写冻结协议”误作跨仓同步事实。
- 下游同步只更新当前引用和当前信息快照，不要求重复签字，也不表示下游已接受完整方法、收到工具或作出工具启用裁决。下游 `I-005` 仍由真实交付与其原定 M1 验收时点控制。
- R2a 逐次预登记、R2b 真实案例授权与试验、R2c `I-005` 证据选路、R2d 实际方法工作版、R3 `I-006` 分支评估与落实、R4 检验/交付/收件/验收，各由其既有阶段门禁控制；均不反向作为 R1 前置条件。

## 依据

I-001 的协议级边界、方法工作版退出契约、输入授权与证据规则、有限工作量、停止/变更责任已在 v0.6.4 固定；I-003 只冻结独立 Codex 项目 Skill 候选的职责、权限、产物类型与条件价值评估策略。v0.6.4 §2 显式规定能力登记、回交及后续创作裁决；§4 固定共享九格和人时口径及各 H 子上限；§5 将 I-006 留在 R3、限定 Skill 范围并保留 VP-003/Charter 边界。

## 结果与后续动作

本决定冻结上游协议，不替代实际下游同步。下一动作是按既有同一维护人授权，在下游将当前来源更新到本决定所在上游提交中的 v0.6.4；下游提交后，追加执行事实与自审记录，关闭 R1 检查点、验证 I-001/I-003，并更新 `WRK-002` 唯一运行主记录为「响应中」。
