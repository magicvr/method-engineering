# D-009 · 选择独立 Codex 首发 Skill 路径

## 决策

用户于 2026-09-30 选择「独立 Codex 首发（推荐）」。按 Root `E-005` 已提出的 Skills 交付方向，本波次采用**与 Goal Governance Skills 包分开的世界模型方法 Skill**作为首发候选：先支持 Codex 项目 Skill 表面，提供可调用工作流与可导出的单次运行记录；Skill 不自动写入 `world/` 或其他 canon。

## 选择理由与范围

- 现有 `skills/` 是独立 Goal Governance 产品，另有安装器、宿主适配和发布证据边界。方法 Skill 单独维护可避免把领域方法交付与治理产品的发布、版本和责任耦合。
- Codex 首发可复用下游已有 `.agents/skills/` 承载惯例，并将初版验证范围控制在当前宿主；Claude、Grok、Copilot 的移植未包含在本次选择中。
- R1 方法运行仍须依据冻结后的 `I-001` 流程；创作者保留主题、取舍和最终裁决。该 Skill 不运行 H1/H2/H3 试验，不代写或修改世界设定，也不在缺少单独门禁时调用外部模型或自动验证。

## 尚未关闭的边界

本决定只选择承载路径和首发宿主，不构成工具实现、安装、下游写入或发布授权。源文件目录/名称、输入输出字段、运行记录的具体格式、用户确认与持久化方式、可观察验收项及与下游同版引用仍待 R1 完整收敛；这些依赖 `I-001` 的冻结方法接口与共同维护组确认。因此 `I-003` 继续 `open`，R3 不启动。
