## D-005 · 选择 H1/H2/H3 判据形成路径

### 触发与用户裁决

上游准备了《H1/H2/H3 可观察判据候选》，供明确下一步如何形成三项假设的可观察证据。用户于 2026-09-30 选择「采用组合观察项（推荐）」。

候选记录见 [E-010](../02-execution/E-010-h123-observation-criteria-candidate.md) 及 [`R1-H123-observation-criteria-candidate.md`](../attachments/R1-H123-observation-criteria-candidate.md)；用户本次选择记录见 [E-011](../02-execution/E-011-h123-criteria-path-selected.md)。

### 决定

1. 后续判据澄清沿用组合观察结构：H1 观察机制求解的可追溯性与条件敏感性；H2 观察同一模糊问题相对于直接整理路径的增益；H3 观察有界身份/情景/问题采样对启动初始模型集合的作用。
2. 该决定只选择下一步 R1 草案形成路径，不接受完整判据或候选方法，不关闭 `I-001` / `I-003`，也不改变当前两仓绑定（仍引用 v0.6.1）。
3. H1/H2/H3 的具体范围、输入/输出精度、支持/局部支持/否决阈值、证据充分性、采样框、H2 效用/成本标准、停止条件、数值与资源限额、责任与复验/替代验证授权均继续待确认。
4. 不选择案例，不授权任何测试、试验、复验或替代验证；不关闭 `I-002` / `I-004` / `I-005`，不放行 R1 或启动 R2/R3/R4。

### 为什么

该路径分别保留 D-002 已选定的 H1 机制求解、H2 身份/情景转译及其直接路径轻量对照、H3 有界冷启动覆盖，同时把过程可追溯性与结果证据并列记录。先选择观察结构，可以按假设继续补齐边界，而不提前猜测具体案例、通过阈值或试验预算。
