## 责任、排除与字段名收窄的同步

- AI 边界：见 [方法工作版 §2](method-working-version-v0.1.md#2-角色)、[方法结构](method-structure-v0.1.md)及两项结构的“是否使用 AI / 协助形式”“AI 建议与理由”“创作者裁定记录”“AI 不得越界确认”分栏。创作者运行方法并作最终裁决；AI 可提示、追问、建议候选、解释、提供反例与检查、整理材料，不代作结论、不授权、不扩容；没有 AI 也可运行。
- 需求 §12：见 [方法工作版 §1](method-working-version-v0.1.md#1-目的适用与排除)的十一项排除，以及 [缺口清单](capability-gap-checklist-v0.1.md)与 [模型条目](model-entry-structure-v0.1.md)的逐项排除确认表；适用表示触及排除项而非许可，未知不得默认为通过。世界客观状态、角色所知、观众所知分开。
- §13-10：步骤 8B 与两项结构的创作者裁定记录相接；记录字段不等于已发生创作裁决、实际消费或创作效果，unresolved 不变。

R2-W 模型条目以 [GOAL-008 路线冻结落点](../../GOAL-008-pa5-information-closure-and-route-freeze/attachments/route-freeze-v0.1.md)为准；[R1 v0.6.4 §2](../../GOAL-001-world-model-method-and-tools/attachments/R1-freeze-proposal-v0.6.4.md) 的十二类字段名不另行逐项强制。两套字段清单并非已经完全同一，不能把字段名收窄写成逐项等同或已验证覆盖；机制表示保持条件性，不采用时注明不适用及理由，不据此要求新增机制。此为本轮按用户要求吸收 A-004-F-002 的收窄记录，不改变既有处置或门禁。

步骤 8A/8B 现为工作版步骤 8 的明确定义子步骤，主步骤保持 0～8。两项手填结构的对应字段逐项记录输入/缺失、比较对象/变化条件、拟做/已做动作、输出/证据/限制、停止范围/原因、下一责任/复审触发与未执行/未知状态；空白不等于通过。
