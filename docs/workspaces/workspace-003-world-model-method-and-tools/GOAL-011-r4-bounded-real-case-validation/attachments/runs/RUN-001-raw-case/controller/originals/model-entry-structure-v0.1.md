# 模型条目最小结构 v0.1

“最小结构”是最小记录要求，不是数学最小性或全局最低充分性证明。未知不得省略成默认成立。

| 字段 | 填写说明 |
|---|---|
| 是否使用 AI / 协助形式 | 填是/否/未知；无 AI 也可运行。AI 仅可提示、追问、建议候选、解释、提供反例与检查、整理材料 |
| AI 建议与理由 | 单独记录建议、理由和协助材料；与下一行创作者裁定分栏，不作为已确认事实或结论；未使用 AI 注明不适用 |
| 创作者裁定记录 | 由运行方法并作最终裁决的创作者填写：纳入 / 弃用 / 修改 / 未决定；记录裁定对象、理由、条件/版本、修改内容（如有）及回接去向；方法与 AI 不代作选择，不能仅被动确认；未决定不晋升作品事实 |
| AI 不得越界确认 | 逐项记录 AI 不代作结论、不授权、不扩容是否满足及依据；未使用 AI 注明不适用及理由，未知/空白不得默认为通过；无法确认时暂停受影响结论并返回创作者/用户 |
| §12 排除确认 | 逐项填写下表；适用表示触及排除项、不得在本方法内处理，不适用须说明依据，未知不得默认为通过并暂停受影响范围 |
| 世界状态 / 角色所知 / 观众所知 | 三者分开记录，不把角色或观众认知当成世界客观状态，不以世界状态推定其已知 |
| 条目身份/版本 | 人工区分条目与修订，保留旧版引用 |
| 用途/查询/别名 | 能处理什么；别名用于发现，不代表语义等价已证 |
| 输入要求 | 数据/设定、单位、来源、精度、权限 |
| 状态与时空参照 | 快照、初始情境、历史依赖、空间范围 |
| 输出契约 | 含义、单位、精度、分支、条件答案形式 |
| 适用条件 | 明确到可人工核对；不能只写“一般适用” |
| 假设与作者待决 | 给定规则、工作假设、未定设定分开 |
| 表示与细节边界 | 采用表示、保留/省略内容及理由 |
| 必要规则/关系 | 支持输出的规则/关系与来源 |
| 机制组织（条件性） | 机制表示时写实体、性质、活动、组织、设置/终止条件；否则说明理由 |
| 来源要素与定位 | 沿用 S 编号和 PA2 定位；不给整理论贴通用标签 |
| 有限改造差异 | 来源已有内容、项目增加内容、未获支持部分 |
| 检查证据 | 对象、输入、判据、动作、结果、证据类型、限制；未做写未执行 |
| 未验证范围 | 实际有效性、跨实例稳健、人工成本等逐项列出 |
| 不确定/失败/拒答 | 区分不能判断、违反判据、正确停止 |
| 组合依赖 | 条目版本、输入输出对应、共享量、条件、分支；未知单列 |
| 变更与旧裁决 | 变更内容、已知影响、影响未知、待复核旧记录 |
| 回接与责任 | 返回作者的信息、作者待决、创作者裁定记录（纳入 / 弃用 / 修改 / 未决定及理由、条件/版本、修改内容、回接去向）、维护/复审责任；方法不代作选择 |
| 步骤 8A：反补丁检查 | 条件内其他实例（如可用）、条件外反例/对照、偶然依赖分别记录；每项填所需输入/缺失、比较对象/变化条件、拟做/已做动作、输出/证据类型/限制、不能判断时的停止原因/范围、下一责任/复审触发、执行状态。无实例/反例不得宣称非补丁；B13 uncertain |
| 步骤 8A：范围/敏感性检查 | 假设一致性、边界条件、参数/条件变化、表示或计算分辨率分别记录（表示与计算分辨率再分开）；每项填上述输入、比较、动作、输出、停止、责任/复审与状态。逻辑后果不等于领域有效性 |
| 步骤 8B：版本/旧裁决回接 | 原问/契约及方法/条目/规则/条件/状态版本、组合依赖、旧版/旧裁决对照、变更与已知影响/影响未知、待复核旧记录、所需输入、拟做/已做复核动作、输出/未执行、条件结果/未决/拒答回接包及作者待决、创作者裁定记录（纳入 / 弃用 / 修改 / 未决定；建议与裁定分栏，方法不代作选择）、停止原因/范围、下一责任/复审触发、执行状态；依赖不明阻断受影响复用，B17 uncertain |

步骤 8A/8B 的详细动作见 [方法工作版](method-working-version-v0.1.md) 对应子步骤。执行状态逐项填未执行/未知/已执行/不适用及理由；空白不表示通过，未执行不填通过结论。本轮仅补字段与指导，实际检查、旧裁决复核及回接均未执行；拟做动作不是已做证据。
