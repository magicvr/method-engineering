# R2-W 方法结构与字段规格 v0.1

## 目的与适用边界

形成人工、条件化、可拒答的世界模型裁决方法工作版。适用于创作者负责设定与最终取舍的有边界问题；输入、条件、输出契约可核对；不足时停止、返回作者或拒答。不承诺诊断穷尽、发现完备、全局最小、自动版本管理、H2 可靠性或 H3 冷启动充分性。

沿用需求 §12 的十一项排除，逐项内容见 [方法工作版 §1](method-working-version-v0.1.md#1-目的适用与排除)及两项手填结构的“§12 十一项排除确认”表；每项均不处理，适用即停止受影响范围，不适用须说明依据，未知不得默认为通过。世界客观状态、角色所知、观众所知分开。

## 角色与责任

- 创作者：运行方法，提供/确认设定、状态、原问；决定创作取舍与是否使用结果，作最终裁决，不能仅被动确认。
- AI（可选协助）：可提示、追问、建议候选、解释、提供反例与检查、整理材料；AI 建议/理由与创作者裁定分栏留痕，不代作结论、不授权、不扩容；没有 AI 也可运行。
- 方法执行者：按流程检查、登记证据/版本/限制，不替作者补定或作创作裁决。
- 用户/维护人：裁决需求变化、冲突、残余和新增授权。
- 独立审计者：按指定范围核对追溯与门禁，不替执行者完成方法。

## 流程骨架

0. 建立问题记录：原问、来源、对象、条件、时空参照、输出契约；区分事实/假设/推断/作者待决。
1. §10-1 核对裁决边界：可裁决、条件化、返回作者；未定设定不补定。
2. §10-2 查找已有能力：目录/别名/人工复核；命中、适用、可解、达标分开。
3. §10-3 检查状态：所需输入/状态快照；补状态后回访。
4. §10-4 检查组合：接口、条件、共享量、分支；冲突无依据时停止。
5. §10-5 检查精度：输出要求、输入精度、表示分辨率、近似；不伪造精度。
6. 汇总去向：已解决、待信息/待裁决、有界能力缺口候选；未完成检查不等于失败。
7. 能力描述与局部模型候选：固定查询、条件、输出、表示、拒答边界；不声称全局最小。
8. 人工登记与回接：版本/依赖/检查证据；条件结果或拒答；不自动成为作品事实。

### 步骤 8A · 反补丁与范围/敏感性检查

步骤 8 的子步骤，详见工作版步骤 8A。非补丁分为条件内其他实例（如可用）、条件外反例/对照、偶然依赖；无实例/反例不得宣称非补丁，B13 保持 uncertain。范围/敏感性分为假设一致性、边界条件、参数/条件变化、表示或计算分辨率；表示与计算分辨率分别登记，逻辑后果不得冒充领域有效性。

各分项记录执行状态、所需输入/缺失、比较对象/变化条件、拟做/已做检查动作、输出/证据类型/限制、不能判断时的停止范围/原因、下一责任和复审触发。执行者登记；作者补条件/依据；维护人复核；超既有范围交用户。本轮只补指导，实际检查未执行。

### 步骤 8B · 版本/旧裁决与回接

步骤 8 的子步骤，详见工作版步骤 8B。对照方法/条目/规则/条件/状态版本、组合依赖与旧裁决，记录变更、已知影响/影响未知、待复核旧记录及复核输入/动作/输出；依赖不明阻断受影响复用，B17 uncertain。条件结果/未决/拒答分列回接作者，保留作者待决、创作者裁定记录（纳入 / 弃用 / 修改 / 未决定及理由、条件/版本、修改内容、回接去向）、停止理由、下一责任、复审触发与执行状态；AI 建议/理由另栏，方法与 AI 不代作选择；不自动晋升作品事实，不证明作者理解。本轮复核/回接未执行。

## 能力缺口判定清单字段

- 原问/对象/条件/输出要求/版本
- §10 五项顺序、检查依据、检查信息是否具备
- 结果、未解决原因、信息不足与能力不足区别
- 查找范围、替代检查、交叠/回访条件
- 最终去向、作者/用户待决事项、回接与创作者裁定记录（纳入 / 弃用 / 修改 / 未决定；方法不代作选择）
- 是否使用 AI、协助形式、AI 建议/理由与创作者裁定分栏、AI 不得越界确认
- §12 十一项排除确认（逐项适用 / 不适用 / 未知及依据/停止/责任；未知不得默认为通过）；世界状态/角色所知/观众所知分开
- 步骤 8A 反补丁检查、范围/敏感性检查；步骤 8B 版本/旧裁决回接
- 每项输入/缺失、比较对象/变化条件、拟做/已做动作、输出/证据/限制、停止原因/范围、下一责任/复审触发、执行状态；空白不表示通过

## 模型条目最小结构字段

- 条目身份/版本、用途、查询/别名
- 输入、状态、时空参照
- 输出含义、适用条件、假设、表示
- 必要规则/关系；机制表示时的实体、活动、组织
- 来源要素、有限改造差异、检查证据、未验证范围
- 不确定、失败、拒答条件
- 组合依赖、变更影响、旧裁决待复核、回接与责任、创作者裁定记录（纳入 / 弃用 / 修改 / 未决定；方法不代作选择）
- 是否使用 AI、协助形式、AI 建议/理由与创作者裁定分栏、AI 不得越界确认
- §12 十一项排除确认（逐项适用 / 不适用 / 未知及依据/停止/责任；未知不得默认为通过）；世界状态/角色所知/观众所知分开
- 步骤 8A 反补丁检查、范围/敏感性检查；步骤 8B 版本/旧裁决回接，沿用上述逐项记录要求；未执行/未知须明记

R2-W 模型条目以 [GOAL-008 路线冻结落点](../../GOAL-008-pa5-information-closure-and-route-freeze/attachments/route-freeze-v0.1.md)为准；[R1 v0.6.4 §2](../../GOAL-001-world-model-method-and-tools/attachments/R1-freeze-proposal-v0.6.4.md) 的十二类字段名不另行逐项强制。两套字段清单并非已经完全同一，不能把字段名收窄写成逐项等同或已验证覆盖；机制表示保持条件性，不采用时注明不适用及理由，不据此要求新增机制。此为本轮按用户要求吸收 A-004-F-002 的收窄记录，不改变既有处置或门禁。

## 停止/拒答规则

未定设定、不能确认保真拆分、未裁决冲突、依赖不明、必要输入/权限不足、需新增来源/实验/原创/工具/费用/真实案例时停止受影响范围并返回作者/用户。拒答不必然是失败，但不能据此宣称真实闭环成功。

## 六项残余

B03、B05、B08、B13、B17、B20 必须逐项保留在流程、结构、限制和复审触发中；不得把纸面检查写成实际验证。
