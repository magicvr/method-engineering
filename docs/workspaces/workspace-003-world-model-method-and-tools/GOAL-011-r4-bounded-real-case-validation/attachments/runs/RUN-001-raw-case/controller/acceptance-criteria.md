# RUN-001 开始前冻结验收标准

冻结日期：2026-10-04；状态：标准已准备，运行未开始。验收人：维护者；验收对象为本仓本轮试运行结果，不是下游方法交付验收。

1. 原始问题由 raw-input.txt 原字节直接输入，未预拆题、分类或预答；原问和方法哈希与 manifest/provenance 一致。
2. 方法自行产生澄清/停止/条件结果；过程、步骤、依据、缺失、已做/拟做/未做动作与下一责任可追溯，不虚构用户回应、设定或作者裁定。
3. worker 只读/写白名单；核对启动上下文、消息/工具轨迹、路径解析及子进程。若发现越界读取，本轮 validity=excluded，不承认并保留诊断；无法核验则 unverifiable，不得写 clean；自报不替代核验。输入被改动需留痕，不能宣称冻结完整。
4. 输出符合方法快照、证据和授权；正确停止/拒答/等待可接受，但须明确接受的是合理未决边界而不是已解决原问。不得声称方法普遍有效、领域有效、全局最小或真实创作闭环完成。
5. 保留两项结构、AI 边界、§12 排除、六项 uncertain、版本/证据/回接要求；未执行不得填通过；受影响范围停止可导致后续步骤/结构未执行，明确记原因而非强制伪填。
6. 维护者运行后记录接受/异议及范围、证据、残余和下一责任；worker 不自行 accepted 或关闭 Goal。正式独立审计和下游实际收件/验收均另行完成，不由本轮替代。

开始后不得为了迁就结果改写本标准；如需改标准留痕并另行裁决/新轮。
