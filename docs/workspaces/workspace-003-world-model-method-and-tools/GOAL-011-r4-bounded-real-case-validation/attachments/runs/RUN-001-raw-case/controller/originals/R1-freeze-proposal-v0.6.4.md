# R1 澄清与冻结提案 v0.6.4（协议候选）

本版继承 [v0.6.3](R1-freeze-proposal-v0.6.3.md) 的已选方向，并按 [D-016](../01-decision/D-016-r1-protocol-v0-6-4.md) 落实本次协议裁决。经 [D-017](../01-decision/D-017-freeze-r1-protocol-v0-6-4.md) 决定并由独立审阅 [A-004](../03-audit/A-004-independent-review-r1-protocol-v0-6-4.md) 通过，本版冻结为当前 R1 协议。Root 的阶段完成状态与信息门禁仍以 [00-meta.md](../00-meta.md) 为权威；下游精确引用同步完成前，R1 检查点保持进行中。这里冻结的是后续工作的协议与交付契约，不要求 R2 的试验、完成的方法工作版、已填写结构、R3 工具或 R4 交付。

依据：下游 `WRK-002` 需求原文 `exchange/WRK-002-world-model-method-and-tools/需求-2026-09-26.md` §§1–3、9–10、12–13，以及同目录 `需求澄清-2026-09-26-构建主体.md` 的**第 2 版修正**。精确来源提交见 v0.6.3 §1。本版不以已回滚的下游历史「澄清与冻结-2026-09-26.md」为权威。D-002、D-005～D-011、D-014～D-015 是已接受的路线或候选边界；下述新计量解释来自本次用户裁决。

## 1. 适用对象、职责与排除

本方法用于创作中出现的**有边界的客观世界问题**：给定条件下的机制、世界状态或交互结果能否被现有能力裁决，以及确有新机制缺口时如何以最低必要成本补足。创作者运行方法，决定主题、取舍及最终裁决。AI 可提示、追问、建议候选、解释、提供反例与检查、整理材料；AI 的建议和理由与创作者的裁定分别留痕。AI 不代作结论，创作者不能仅被动确认。方法无需 AI 才能运行；澄清第 1 版中「AI 只能做非判断工作」的限制已由第 2 版撤回。

从实际问题先核查已有裁决能力及所需状态/参数；若不能直接回答，依次区别：①缺当前状态或事实，②已有模型缺组合/求解方式，③要求精度超出现有能力，④确有新机制能力缺口。只有④启动新增或扩展模型；证据不足以分类时记录未决，不假定④。现有能力足够时停止建模；清楚的问题可直接进入能力查询或求解，身份/情景澄清仅在原问含混、需要补足客观约束时使用。结果可以是确定值、范围、有机制依据的不确定结果、较低精度结果或明确无法裁决，不伪造精度。新模型需说明适用范围、依赖、组合、一致性与基本反例，并把能力返回创作使用。

排除需求 §12 的十一项：剧情大纲方法、主题选择、宏观历史演化方法、叙事窗口选择、角色选取、BDI 或其他角色决策方法、角色风险控制、观众信息呈现、自动编剧、完整世界模拟器、固定软件架构。世界客观状态与角色所知、观众所知分开；本方法不写 canon 或替作品处理旧剧情。

## 2. 后续方法工作版的退出契约（R2d）

R2d 的版本化工作版至少包含：目的与适用/排除条件；创作者可照着执行的步骤；每步所需输入、输出与停止点；创作者决策点、AI 可协助形式及不得越界的界线；证据/版本追溯；适用限制、未决项与下一责任人。两个**可手填的纯文本结构**分别命名为「能力缺口判定清单」（来自需求 §10）和「模型条目最小结构」（来自需求 §9），不依赖程序或 AI 输出。清单承接客观问题、已有能力、状态/事实、组合、精度到新机制的逐项判断及创作者裁定；模型条目承接问题类、现有模型不足、前提/现实参考、状态输入、机制输出、范围、精度、组合、拒绝条件、反例/条件变化、版本及创作者裁定。建议和裁定保持可区分。

工作版还须附一张逐项映射矩阵，使用固定三类状态：`流程已描述`、`证据支持范围`、`未验证`。同一条可同时记流程与有限证据范围；写了流程不表示已验证。矩阵至少逐项覆盖：

| 来源项 | 工作版或结构须回答的内容 |
|---|---|
| §10-1 | 客观世界问题筛选；能力缺口判定清单 |
| §10-2 | 现有裁决能力查询；能力缺口判定清单 |
| §10-3 | 当前状态/事实缺口；能力缺口判定清单 |
| §10-4 | 已有模型组合/求解；能力缺口判定清单 |
| §10-5 | 现有模型的精度边界；能力缺口判定清单 |
| §13-1 | 识别新客观裁决需求；方法步骤/清单 |
| §13-2 | 经能力发现判断现有模型；方法步骤/清单 |
| §13-3 | 区分状态、组合、精度、机制；方法步骤/清单 |
| §13-4 | 定义新增裁决能力；方法步骤/模型条目 |
| §13-5 | 构造最低充分机制模型；方法步骤/模型条目 |

R2d 填实际状态、证据支持范围与未验证项，声明限制、未决事项及下一责任。R1 只设此契约，不以实际案例跑通、填表或形成工作版作为本阶段门槛。R2a 逐次预登记的细字段仍按 D-015 后移，R2c 以 I-005 的证据选路。

## 3. 输入、授权与证据协议

每份输入记录来源与版本、预期用途及范围、权限依据和约束；授权不明或范围不符时不用该输入。把客观世界状态、角色可知信息、假设、AI 建议与创作者裁定分别标示。方法结构可引用事实，但不能把假设或建议写成已确认的状态。此为通用核对协议；具体真实案例选择、授权和适配仍由 I-002 控制，不能从同一维护人身份推定。

每次证据至少保留：来源/引用、输入及版本、事先声明的程序/模型、观察或输出、主张的适用范围、创作者判断、限制与偏离。观察、推断、假设、AI 建议、创作者决定分别记录。H1/H2/H3 各自按预登记的局部主张使用 D-011 四标签 `supported` / `partial` / `refuted` / `insufficient`，不设跨 H 总分，不把局部支持外推为普遍有效。具体问题、模型/版本、样本、逐格预测、局部支持及否决严重度、证据位置与角色在 R2a 登记，对应 R2b 运行前核对完整；共享背景不等于共享结论。

## 4. H 可行性工作量与停点

H1 最多 4 格（1 个清楚问题、2 个预声明机制模型 × 基线/一次条件变化）；H2 最多 2 格（1 个确需澄清的问题，身份/情景与直接路径，同一已知信息）；H3 最多 3 格（1 个封闭抽样框内至多 3 条身份→情景→问题链）。**全部初次评价、最多一次可定位原因的定向复验、最多一个替代方向的一次验证，共享绝对累计上限 9 个结果格。**每个分别尝试的预登记模型—条件格、H2 比较路径或 H3 链均计 1 格；输入不足或中途停止的已尝试单元也计入。各 H 上限分别覆盖归属于该 H 的初评和复验；不得在 H 之间转移未用额度。替代方向的每格计入全局 9 格；如预登记为某个 H 的针对性复验，也同时受该 H 上限约束。若初次评价耗尽 9 格，复验/替代虽在种类上被允许，也没有可用格数；不得另加额度。

**总人时上限为 3 人时（180 人分钟）**，覆盖 H1/H2/H3 的 R2a 预登记、准备、执行、评估和记录，包括获允许的复验/替代。多人同时工作按每人实际投入相加；无人值守的等待不计。逐人记录活动、起止或实际分钟，并累计格数/人时；预登记须为评估和记录留出人时，不得先将额度全部投入执行、再把未评估或未记录输出视为完成。本额度仅用于 H 可行性工作；不计 R1 治理文稿、R3 工具实现或 R4 交付。不含新增付费 API、服务或工具授权。复验与替代是剩余额度内的**可选有界权限**，不是本版授权立即运行；使用前仍须有适用授权、预登记原因/范围/停点及剩余额度。

授权缺失或不明、关键输入缺失、命中预声明否决条件、依据不足、任一适用格数/人时/复验/替代限额到达时，停止受影响单元；无法判断时保留 `insufficient`，不推断成功。若需改变主张或适用范围、证据规则、授权或预算，先暂停受影响范围，形成新版本，由同一维护人作**明确的实质裁决**并留痕；AI 可以提示风险，不能授权或自动扩容。没有可定位修订原因时不启动定向复验；替代方向需由证据支持选路，不为得到肯定结果追加运行。

## 5. 条件工具策略与后继门禁

I-003 在 R1 只固定 D-009/D-015 已选策略：独立 Codex 项目 Skill 候选，由创作者显式调用，提供方法协作流程和一份可导出的单次运行记录；不自动写 canon、不自行运行 H 试验，也不调用外部模型或自动验证。当前候选不授权扩展为数据库、独立脚本、UI、API、治理包安装器或发布系统；这类新增实现范围须由 R3 的 I-006 评估并另行授权，但 I-006 不自行放宽 VP-003/Charter 边界，超出既定边界的变化仍须按愿景治理处理。R3 的 I-006 由同一维护人依据既有实践或 R2 人工方法过程，核对任务/重复步骤、人工成本、预期收益及维护负担，作有理由的分支决定。证据支持工具化时，待方法接口稳定后制作最小 Skill；证据不足或不值得时，记录本轮 no-tool、证据范围与理由、复评触发和责任人。R1 不索取重复使用证据、Skill 名称/路径/精确字段/安装或实现，也不依赖 R4 使用结果。

I-002 控制真实案例使用及 R4 前适配复核；I-005 控制 R2c 证据选路，`insufficient` 不放行 R2d；I-004 控制 R4 交付前独立审计；I-006 只控制 R3 对应分支决策/退出。实际运行、方法工作版、工具实现、交付、收件及验收须以后续事实分别记录。本候选不推进这些门禁或目标状态。
