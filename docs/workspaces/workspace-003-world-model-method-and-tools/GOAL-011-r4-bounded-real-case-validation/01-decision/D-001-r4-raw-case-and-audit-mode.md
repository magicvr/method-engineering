# D-001 · R4 原始输入与外部审计模式

## 用户裁决

2026-10-04，用户确认：

- `修真具体怎么修` 作为正式 R4 真实用例，直接、原文输入方法。
- 方法构建方不得预拆题、预分类或预答；方法自身产生的澄清/停止/条件结果是 R4 测试结果。
- 正式交叉审计由维护者在工作流外调用外部工具完成，不在 AI 工作流内代调用。

## 边界

不写 canon、不替方法解题、不围绕用例定制方法、不实现工具；交付、收件、验收、异议迭代与反馈路由按协议在 S4 执行。外部审计意见在 S5 前由维护者提供并落盘。
