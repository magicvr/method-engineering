# PA4 缺口判定与吸收方案 v0.1

## 总体判断

当前证据不足以把 PA3 的五类关键 unresolved 整体判为已证缺口，更不足以启动原创。推荐采用“局部吸收成熟要素 + 逐项保留关键未知 + 对必要差异设置候选闸门”的方案。所有验证安排均为未来候选，未执行。

## 统一原创闸门

当前没有已满足启动条件的原创点。任何原创候选至少须具备：必要需求明确；调查边界与未知/限制分清；替代检查有结果；继承/有限改造不足可复核；原创范围、可验证输出、反例检查、停止条件明确；用户书面授权执行、资源和责任；相关信息和审计门禁满足。

## 结论

- 五类关键未决均保持“尚未查明”，局部适用限制单列，不互相替代。
- 可先形成轻量接口与手填记录候选，但不提前形成完整工作方法、工具或 R2-W 路线。
- I-010 为 accepted-residual（非 verified）；仅允许 PA4 退出，不能据此冻结 PA5 路线、进入 R2-W 或启动原创。
