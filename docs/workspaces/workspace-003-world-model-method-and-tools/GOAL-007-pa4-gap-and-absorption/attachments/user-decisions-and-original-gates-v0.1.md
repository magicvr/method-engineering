# PA4 用户裁决点与原创闸门 v0.1

## 需用户裁决的候选点

1. **客观问题边界**：世界状态、角色认知事实、作者审美/价值选择与混合问题如何划分；是否改变需求边界。
2. **诊断触发**：是否保持 §10 严格顺序、采用多标签、放宽或收紧新建模触发。
3. **最低充分性**：是否把“最低充分机制模型”解释为“最低充分裁决模型、机制表示按问题选择”。
4. **版本影响/创作回接**：是否允许自动失效/重裁、作品事实晋升、跨模型状态权威或工具实现。
5. **H3 必要性**：身份—情景冷启动采样是否为必要需求；是否要另行授权旧 H 实验或有界验证。

## 当前原创闸门

以上都不是已满足启动条件的原创点。任何原创候选必须同时具备：

- 必要需求明确；
- 调查边界与未知/限制分清；
- 替代检查有实际结果；
- 继承/有限改造不足可复核；
- 原创范围、输出、反例、停止条件明确；
- 用户书面授权执行、资源和责任；
- 相关信息和审计门禁满足。

## 当前结论

I-010 为 accepted-residual（非 verified）；仅允许 PA4 退出，不能据此冻结 PA5 路线、进入 R2-W 或启动原创。S04-C 残余和 H3-SEM-001 不覆盖这些新增未知。
