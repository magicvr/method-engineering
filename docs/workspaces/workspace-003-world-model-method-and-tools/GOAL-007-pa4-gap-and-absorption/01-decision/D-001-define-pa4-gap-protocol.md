# D-001 · PA4 缺口与吸收协议

## 决定

以 PA3 映射矩阵和关键 unresolved 为输入，逐项登记：必要需求、状态（尚未查明/已发现适用限制）、调查边界、替代检查、证据、继承/有限改造不足、吸收方案、差异风险、验证安排、原创范围/停止条件和授权门禁。

## 状态规则

- `尚未查明`：没有足够证据判断理论是否覆盖或适配，不能当缺口。
- `已发现适用限制`：有来源范围/前提或比较证据支持某映射不适用，但仍不自动证明需要原创。
- `吸收/有限改造`：保留来源，明确差异、风险和验证安排。
- `原创闸门`：只有必要需求、替代检查、继承/有限改造不足、范围/停点、授权/审计门禁均明确时，才可提出原创候选；执行仍需用户裁决。

## 停止与授权

发现关键 unresolved、证据冲突、需新增来源/费用/实验/原创时暂停受影响范围并回流用户；不得自动扩容或把未决写成缺口。S04-C 全文残余、H3-SEM-001 和旧 H 门禁继续有效。
