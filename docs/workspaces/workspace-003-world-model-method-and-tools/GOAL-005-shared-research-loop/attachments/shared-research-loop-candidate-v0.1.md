# S1/S2 共享外部研究闭环 · 候选 v0.1

> **状态：draft / design-baseline-accepted。** 创作者接受本候选作为 shared research core 的设计基线；它仍不是已接入 S1/S2 的正式方法，也未通过调用试跑验证。与 v0.17.0、W2 v0.4 或未来 S2 的具体版本接入，另行裁决。

## 1. 定位：按需调用的共享子过程

研究闭环帮助当前宿主处理**可能需要外部资料**的未知。它不是所有未知必须机械跑完的固定阶段，也不取代 S1 的规则 E/F/G、S2 的模型构建与验证、创作者裁决或目标世界求解。

外部研究是获取依据的一种方式；「谁对未知负责、谁有裁定权」是另一条分类轴。研究可给宿主提供可追溯证据与候选解释，不能因找到一份相关资料就自动改变问题结构、模型或当前目标世界事实。

## 2. 未知类型、owner 与外部研究适配性

| 未知类型 | 主要 owner / 裁定权 | 外部研究可以提供 | 外部研究不能代替 |
|---|---|---|---|
| 创作者取舍 | 创作者拥有意图、偏好和最终选择权 | 可选方案、现实先例、后果、风险与取舍依据 | 推断创作者偏好或替创作者选择 |
| S1 问题结构解释未决 | AI 可分析并生成候选；当前方法按既定协作权责由创作者决定是否准入结构 | 候选问题、解释、关系、反例、边界；已有术语或分类可供发现线索 | 把外部 taxonomy、行业分类或来源用语自动升级为当前问题结构 |
| 目标世界客观事实或机制未知 | 目标世界的建模与裁定 owner 依当前工作约定确定；S2 需对目标对象适用性负责 | 现实机制、参数、约束、观测资料、已有模型及其条件 | 证明来源对象与目标世界相同，或以现实常数无条件替代目标对象参数 |
| 纯推理缺口 | 当前分析者/宿主推理过程 | 若推理依赖的某个前提缺失，可针对该前提研究 | 用搜索替代已有前提上的推理；将推理尚未完成误报成资料未知 |
| 资料不可得、不可观测或无法区分 | 当前问题 owner 维护未知及后续动作；裁定权依未知影响而定 | 可访问性线索、观测限制、可行代理指标、研究边界 | 把没有找到资料等同于对象不存在，或抹掉未决状态 |

研究可适配性需单独判断：若问题的答案可能由公开、可定位的资料改变，且资料的对象与用途有可说明的关联，适合尝试外部研究。若决策属于创作者取舍，研究至多支持选择；若属于纯推理，应先推理并指出缺失前提；若未知只能由目标世界内部求解或观察得到，外部资料只能提供机制或模型参考，不能替代目标对象验证。

## 3. 进入条件：先把未知变成有界研究任务

启动一次研究至少要说明：

1. **未知是什么**：当前哪些信息已知、哪些仍不确定；不要把假设或推论写成事实。
2. **影响何处**：它可能改变哪个问题判断、问题结构、模型、参数、约束或下一步。
3. **owner 与裁定权**：谁负责取得/维护信息，谁决定是否据此改变宿主结构或结论。
4. **研究理由**：外部信息为何可能改变当前下一步；若没有缺失前提，先走推理而非搜索。
5. **可回答的研究问题**：以问题或主张表达本轮需要查明什么；过宽时先收窄。若暂不能精确化，可以做一次有明确目的和边界的 reconnaissance，用来缩窄问题，不可将它变成无限探索。
6. **当前用途的足够标准**：什么证据结果足以支持宿主作出下一步判断；这不是对目标结论本身的自动准入标准。

缺任一关键项时，先澄清或记录为待定，不直接进入无边界搜索。对创作者取舍，先把需创作者选择的选项写清，不把研究任务伪装成客观查证。

## 4. 研究问题、来源策略与边界

对本轮问题选定来源类型和选择理由。例如：定义/规范问题优先查权威文本；具体参数查原始测量、数据集或方法文档；机制问题查直接研究、技术说明或可复现模型；术语和来源发现可先用综述或次级资料。来源选择应对应研究问题，不能只因容易搜到就采用。

在开始收集前，给本轮研究写清：

- 搜索域、目标对象/时期/版本等边界；
- 计划尝试的来源类别及其理由；
- 与影响和风险相称的时间、查询范围或工作量上限；
- 何时回看问题是否已足够回答、是否需要改写来源策略；
- 何种结果触发停止、保留未知或请求裁定。

上限和检查点随问题的重要性、后果与可得来源调整；本候选**不规定固定来源数量、轮数或统一时长**。重要主张可要求强于普通主张的来源质量或相互独立的支持，但多个网页不等于多个独立来源；应检查它们是否互相转引同一原始来源。

## 5. 逐主张评价证据并留出处

对会影响结论的每个主张分别记录，而不是只给整个来源打一个总分。最少核对：

- 来源身份、可复查定位信息（链接、文档标题与章节/页码、数据集字段/版本等）；版本、发布日期/访问日期仅在会影响复查或含义时记录；
- 来源实际支持的具体主张与支持依据（原文、数据、方法、观察或推导）；明确来源没有支持什么；
- 对当前问题而言的质量判断及理由，例如来源权威性、方法透明度、数据适切性、时效性或可复现性；
- 来源独立性和转引关系，已知的相互矛盾或反证；
- 适用限制、不确定性、测量定义、样本或情境条件。

只在能复查且确实支撑该主张的范围内引用。来源的权威称号、搜索排名或数量不能替代主张级评价；低质量或间接来源可作线索，但应标明其用途和限制。

## 6. 适用性与迁移边界

凡把来源用于不同对象，都要分别记录：来源研究/观测的**源对象**与当前**目标对象**是什么、二者关键差异、为何认为可迁移、迁移成立的条件，以及哪些内容不能外推。差异可能涉及定义、规模、制度、环境、机制、时间、测量口径、单位或模型假设。

若迁移理由不足，来源仍可作为候选机制或类比，不能写成目标对象事实。发现来源不等于证明其适用于目标对象；适用性主张需回交宿主的相应准入或验证步骤。

## 7. 综合：分开陈述、推论与待验证主张

综合结果至少分成三栏：

1. **来源陈述**：来源直接写明或数据直接显示什么，并链接到证据记录。
2. **AI 推论**：由若干来源、假设或类比推得什么；标明推理链、假设和信心限制，不伪装成来源原话。
3. **目标对象待验证主张**：若要把结论用于目标世界/目标模型，需要验证什么、由谁验证。

综合还要呈现支持证据、重要反证/冲突、来源覆盖范围与剩余不确定性，并只给出本轮资料所能支持的有界结论。它向宿主提出「可考虑的变化」或「现有证据不足以支持变化」，不自行改写宿主结构，不替创作者裁定，也不关闭宿主的未知项或阶段门禁。

## 8. 回交宿主：S1 与 S2 的最小 adapter 契约

研究子过程共用上述输入、证据记录、综合与停止规则；输出形态依宿主而异。以下是**待接入的接口契约**，不是对当前方法版本的修改。

### S1 adapter（候选问题结构）

输出可供审阅的候选问题/解释、关系或依赖、反例与边界，连同每个候选的来源主张、目标对象适用性、推论和限制。每个候选须能回指当前原问及其影响；外部分类只作候选来源。

之后仅回交给现有 S1 方法依次处理：

1. Rule E 判断候选是否达到准入条件；来源出现不等于准入，反例也须检查其前提是否适用于当前目标。
2. Rule F 为已讨论项确定问题/未知归属及 owner/下一步状态。
3. Rule G 判断候选对 coverage、收束或残余的影响，并按既有规则作局部/全局处理。

研究子过程不另造专用子问题拆解法，也不替 E/F/G 预判准入。把文献中的完整 taxonomy 填进问题图不构成结构发现本身。

### S2 adapter（机制、参数、约束与既有模型）

输出可作为机制假设、参数取值/范围、约束、已有模型或观测方式依据的主张，并附来源、推理、假设、单位/定义、范围、适用条件、迁移理由和限制。随后交给 S2 现有模型构建与验证过程，检查目标对象适用性、模型一致性及所需观测/推导。

资料可支持模型选择或参数先验，不自动证明模型对当前目标世界有效。不得静默把现实常数当作目标世界参数，也不得把借来的既有模型当作目标对象的验证结果。

对 v0.17.0、W2 v0.4 或未来 S2 的具体章节、规则、表单和门禁如何修改，须另行审阅并裁决；本候选不指定落盘位置或改写方案。

## 9. 有界结局与停止

本轮研究记录可采用下列结局之一：

- **足以支持当前下一步**：证据与约定的当前用途相称；重要反证/适用性问题已处理或显式带出；没有仍可能改变这一下一步的必要未知。此状态只表示研究交回宿主的资料达到本轮用途，不自动代表宿主问题已解决、模型有效或门禁通过。
- **部分回答 / 证据不足**：现有资料仅支持部分主张，或证据强度/适用性不足；标明缺口和剩余未知。
- **证据冲突**：可信来源对关键主张不一致；描述差异、来源独立性和可能的口径原因，交回宿主处理。
- **未找到 / 不可访问**：在已记录的搜索域与边界内未找到合用来源，或资料无法访问；保留“尚未查到/无法访问”的认识状态。
- **问题需重述 / 外部研究不适用**：原问题不可研究、把推理或创作者取舍误作事实查询，或所需事实只能由目标对象内部产生；重述、回到相应 owner 或停止外部研究。

达到下列条件时，可停止本轮并交回宿主判断：本轮足够标准已满足；主要证据可复查且对结论的重要反证与迁移限制已处理；没有仍可能改变当前下一步的必要未决研究问题。若努力上限已到、来源不可得或继续同类搜索的边际收益已低于其成本，也应停止，但将结局记为不足、未找到或不可访问，并保留未知及 owner/下一动作。

“在本次搜索范围内没有找到”只描述搜索结果，不证明资料或对象不存在。若要主张某物不存在，需另有明确的对象域、判定标准、可覆盖的观测/穷尽方法与适用证据；普通搜索未发现不能承担此证明。不存在对所有任务通用的“搜索完毕”判据。

## 10. 紧凑研究记录字段

每轮按问题规模裁剪记录，至少能重建以下链条：

| 字段组 | 最小内容 |
|---|---|
| 研究身份 | Research ID、日期、研究 owner、宿主/目标对象 |
| 未知与用途 | 未知类型与问题、影响的判断/模型/门禁、当前下一步用途、裁定权 |
| 研究边界 | 研究问题、足够标准、搜索域、来源策略及理由、努力上限与检查点 |
| 证据主张 | 每条主张、来源身份与 locator、版本/日期（适用时）、来源实际支持依据 |
| 评价 | 质量/独立性判断理由、转引关系、限制、反证与矛盾 |
| 适用性 | 源对象与目标对象差异、迁移理由、条件及不可外推范围 |
| 综合和回交 | 来源陈述、AI 推论、待验证主张分栏；结论/信心限制；建议的宿主处理 |
| 宿主处理 | S1 的 E/F/G 处理或 S2 的模型构建/验证结果；准入/验证由宿主记录，不由研究记录代替 |
| 剩余未知 | 未回答项、状态、owner、next action、复查日期或触发条件；结局/停止理由 |

无需为每个条目另建一套治理实体；可附在现有未知登记或执行记录中，只要出处、适用边界、宿主处理与剩余未知可被复查。记录长度和来源数量按用途与风险调整。

**治理门禁接口（条件触发，不是每轮研究的固定步骤）**：若研究揭示影响目标治理门禁的新未知，研究记录不能替代该目标自己的 P-005 信息需求登记，也不能据研究记录直接清除门禁。应在对应目标的权威登记处另行记录该未知的级别（`required` / `non-blocking`）、受影响门禁、最晚需要阶段、验证/收集动作、状态；若延期，还要记录延期理由、责任人和复核日期或触发条件。研究记录可链接该信息项并承载证据与研究过程；宿主仍按 P-005 判断信息门禁。若本轮没有识别出影响治理门禁的新未知，则无需为每次研究重复填写这些字段或启动 P-005 登记。

## 11. 最小运行主线

按需运行，可合并或回返其中步骤：

**识别未知与 owner → 定义研究问题和当前用途的足够标准 → 选择来源并设定边界 → 收集并逐主张评价证据 → 检查适用性与迁移 → 综合并区分来源陈述/推论/目标待验证项 → 回交宿主准入或模型验证 → 登记剩余未知并停止或按新问题再开一轮。**

研究输出通过 Rule E/F/G 或 S2 现有模型验证回到宿主；它不是另一套决定问题结构、目标事实或创作者偏好的方法。进入下一轮时，应有明确未决项和新研究问题，不能仅以“还有资料可查”为理由无限续跑。
