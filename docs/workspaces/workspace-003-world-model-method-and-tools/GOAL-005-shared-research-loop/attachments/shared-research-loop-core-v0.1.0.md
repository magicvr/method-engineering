# Shared Research Core · 候选 v0.1.0

> 本文件将创作者接受的 [研究闭环设计基线](shared-research-loop-candidate-v0.1.md) 拆出为单一共享语义组件。接受的是研究过程设计；本文件仍未接入 S1/S2 方法，未被调用试跑验证。记录结构见 [共享研究记录 schema](shared-research-record-schema-v0.1.0.md)，host-specific 回流契约分别见 [S1 adapter](s1-research-adapter-v0.1.0.md) 和 [S2 adapter](s2-research-adapter-v0.1.0.md)。

## 1. 职责与权责边界

Core 是可由不同宿主共同调用的按需外部研究过程，唯一持有未知分类/研究适配性、研究问题、来源策略、证据评价、迁移、综合、有界停止和剩余未知登记等研究语义。

Core 不拥有 S1/S2 的子流程、问题结构准入、coverage、模型结论、创作者取舍或目标世界事实裁决权。找到来源不会自动改变宿主结构或模型。来源评价与研究停止语义不得由 adapter 各自复制。

## 2. 未知类型、owner 与研究适配性

| 未知类型 | 主要 owner / 裁定权 | 外部研究可提供 | 外部研究不可代替 |
|---|---|---|---|
| 创作者取舍 | 创作者 | 可选方案、现实先例、后果与风险 | 推断偏好或替创作者选择 |
| 问题结构解释未决 | S1 按其现有规则与协作权责处理 | 候选问题/解释、关系、反例、边界、术语线索 | 把外部 taxonomy 自动升级为当前问题结构 |
| 目标世界客观事实或机制未知 | 目标世界的建模与裁定 owner；S2 对目标对象适用性负责 | 现实机制、参数、约束、观测资料、已有模型及条件 | 证明来源对象等同目标对象，或以现实常数无条件替代目标参数 |
| 纯推理缺口 | 当前分析者/宿主 | 研究缺失前提的资料 | 用搜索替代已有前提上的推理 |
| 资料不可得、不可观测或无法区分 | 问题 owner 维护未知；裁定权按影响确定 | 可访问性线索、观测限制、代理指标 | 把未找到资料说成对象不存在 |

只有当外部信息可能改变当前下一步，且对象与用途关联可说明时，才进入资料研究。创作者取舍由研究提供依据而非结论；纯推理先行；目标世界内部事实仍须由目标对象求解或观测，外部资料只能提供机制/模型参考。

## 3. 入口：定义一个有界研究任务

开始资料收集前，应能指出：

1. 未知的具体表述，以及已知、假设和推论之间的区别；
2. 未知可能影响的问题判断、结构、模型、参数、约束或下一步；
3. 信息 owner 与最终裁定权；
4. 外部资料可能改变当前下一步的理由；
5. 本轮可研究的问题/主张；问题尚未形成时，只允许做一次有明确目的和上限的 reconnaissance 以缩窄问题；
6. 本轮用途的足够标准，即什么资料结果能供宿主继续判断。

关键项不足时先记录缺项或澄清，不做无边界搜索。不得将需要创作者选择的取舍伪装成客观事实检索。

## 4. 来源策略与工作边界

来源类别应对应研究问题：规范/定义优先权威文本；参数查原始测量、数据集或方法文档；机制查直接研究、技术说明或可复现模型；综述/二手资料可先用于术语和来源发现。不能仅因容易搜到而采用来源。

收集前写明搜索域、对象/时期/版本边界、计划尝试的来源类别与理由、与影响/风险相称的工作量上限、回看检查点、停止或重述条件。Core 不设固定来源数、轮数或统一时长；高影响主张可要求更强或相互独立的依据。多个网页若转引同一原始来源，不算多份独立支持。

## 5. 证据评价与出处

对每条会影响结论的主张单独评价：来源身份和可复查定位；来源实际支持的内容及其支持依据；当前问题下的质量判断和理由；来源间独立性、转引与冲突；来源限制、定义、方法、测量口径、样本与情境条件。版本/日期在影响复查或含义时记录。

权威称号、搜索排名和来源数量不能替代主张级评价。低质量或间接来源可以作线索，但须标明用途与局限；不得引用超出来源实际支持范围的结论。

## 6. 适用性与迁移

将来源用于不同对象时，记录源对象、目标对象、关键差异、迁移理由、成立条件及不可外推内容。差异可涉及定义、尺度、制度、环境、机制、时间、测量口径、单位或模型假设。

迁移依据不足时，来源只能作为候选机制或类比，不能写成目标对象事实。来源被找到不证明它适用于目标对象；最终适用性由对应宿主检查。

## 7. 综合与输出

综合至少分开呈现：

1. **来源陈述**：来源直接写明或数据直接显示什么；
2. **AI 推论**：由来源、假设或类比推得什么，注明推理链、假设和信心限制；
3. **目标对象待验证主张**：将结论用于目标世界或模型前需要谁验证什么。

同时呈现支持依据、重要反证/冲突、来源覆盖范围和剩余不确定性。Core 只给有界的研究结论，指出可供宿主考虑的变化或证据不足，不直接改写宿主结构/模型，也不关闭宿主未知项和门禁。

## 8. 有界结局、停止与剩余未知

每轮结局从以下类别中选取并说明：

- `sufficient-for-next-step`：证据与当前用途相称；重要反证和迁移问题已处理或带出；无仍可能改变此下一步的必要研究未知。它不表示宿主问题已解决、模型有效或门禁已通过。
- `partial-or-insufficient`：资料只回答部分问题，或证据/适用性不足；记录缺口和剩余未知。
- `conflicting-evidence`：关键主张有可信来源相冲突；说明口径、独立性和冲突点，交宿主处理。
- `not-found-or-inaccessible`：在记录的搜索域内未找到可用资料，或资料无法访问；维持“尚未查到/无法访问”。
- `restate-or-not-researchable`：问题实际需要重述、推理、创作者取舍或目标世界内部求解；交回相应 owner 或停止外部研究。

满足当前足够标准、关键证据可复查、重要反证/迁移限制得到处理且无可能改变下一步的必要研究未知时，可以停止并回交。到达工作量上限、资料不可得或继续同类搜索边际收益过低时也应停止，但不得伪记为充分回答；保留正确的不足/未找到结局及 owner/下一动作。

“在本次搜索范围内没有找到”不证明资料或对象不存在。要主张不存在，需另有明确对象域、判定标准与足以覆盖该域的观测/穷尽方法；普通搜索未发现不承担此证明。

开启下一轮须有明确剩余未知和新的研究问题，不能只以“还有资料可查”为由续跑。

## 9. 共用记录与宿主回交

研究任务、证据主张、评价、迁移、综合、停止理由和剩余未知的共用记录字段见 [shared schema v0.1.0](shared-research-record-schema-v0.1.0.md)。Core 将记录包交给对应 adapter；S1/S2 的调用映射与回流目的地分别由各自 adapter 决定，宿主按照原有规则裁决。

若研究揭示影响目标治理门禁的新未知，研究记录不替代目标自身 P-005 信息需求登记；由目标治理 owner 在权威登记处记录门禁、级别、责任人、收集动作和延期复核要求。没有出现此类门禁未知时，不机械启动 P-005 登记。

## 10. 最小运行主线

**识别未知与 owner → 定义有界研究问题和用途标准 → 选择来源并设边界 → 收集并逐主张评价 → 检查迁移 → 综合来源陈述/推论/目标待验证项 → 经宿主 adapter 回交原裁决或验证链 → 登记剩余未知并停止或带着新问题另开一轮。**
