# D-009 · 授权进入 S1 research-loop host 正式集成候选

创作者在已接受的组件设计基线、S1 试跑设计与窄接口候选基础上，选择「进入正式集成」。据此允许形成一个从 GOAL-004 冻结 S1 v0.16.1 派生的独立集成方法候选 v0.16.2，并对完整方法文件进行只读独立复核。

本决定允许形成和审阅候选，**不等于创作者接受 v0.16.2 为 S1 host 基线，也不授权执行任何外部研究调用或实际试跑**。试跑仍须先固定 host、core、schema、adapter 修订身份，并另行获得执行授权。接受的 core、schema、S1/S2 adapters 与 v0.16.1、v0.17.0、run-10、Probe 1 均保持不变。
