# D-012 · 接受 run-01 为有效试跑样本并裁定后续审查边界

## 创作者裁决

创作者接受 run-01 为有效试跑样本，但**不整体接受当前 Rule E/F/G 回流裁定**，并要求保留原运行记录、不重写 [run-01](../attachments/s1-independent-call-trial-run-01.md)。Core outcome `sufficient-for-next-step` 被接受；本轮 Shared Research Core / Schema / S1 Adapter 的调用、研究留痕、来源评价、迁移边界、有界停止与剩余未知登记作为正证据保留。R-03「供水中断」语义边界作为有效 S1 研究产物保留，继续未决。

## 限制与未裁定项

1. **发现污染**：初始上下文与查询已出现储水、备用供电、重力供水、停电时长等具体机制。因此 run-01 不能证明 research loop 能自主发现这些机制；它只能作为“给定搜索方向后能够可靠取证、评价并回灌”的证据。后续若做 blind trial，应移除这些机制名称。
2. **Rule E 回流暂不接受为已验证**：外部证据支持某条件会影响原问，与目标世界中该条件实际为真，是不同主张。前者可能足以支持把“该条件是否成立”作为待答问题节点纳入 S1；后者仍不能仅凭类比或间接外部资料认定；该条件在目标系统中的值或客观结果可交 B3/S2 求解。此次裁决不预先决定问题节点的准入边界。

## 下一步与授权边界

下一步先审查“外部证据支持候选问题准入”与“外部证据证明目标世界事实”的边界，再决定是否需要最小接口修正或另跑一次干净的 S1 blind trial。当前决定**不授权**修改 shared core/schema/adapter/host，也不授权再次研究调用；若审查后建议这些动作，须另行裁决。未重开 Probe 1、run-10、全局 coverage search 或父层案例结论。
