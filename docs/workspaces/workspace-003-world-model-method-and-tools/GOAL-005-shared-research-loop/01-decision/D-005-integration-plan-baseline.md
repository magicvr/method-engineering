# D-005 · 接受版本化接入方案作为边界与顺序基线

创作者接受 [接入方案 v0.2](../attachments/shared-research-loop-integration-plan-v0.2.md) 作为后续 shared component 边界与流程顺序基线。该决定确认集中落点与 shared component 候选修订标识（已由 D-003 具体记录）、两宿主最小调用/回流接口、共用冻结 core/schema、S1 与 S2 分开试跑及分别验证各自 host 回流。

本决定不授权改写 S1/S2 方法正文、不接受试跑结果、不选择试跑案例；S1/S2 正式 host 版本号和具体插入点仍待可用基线。四份拆分组件候选按计划另行形成并复核；只有经后续授权的 host 集成才可修改对应方法版本。
