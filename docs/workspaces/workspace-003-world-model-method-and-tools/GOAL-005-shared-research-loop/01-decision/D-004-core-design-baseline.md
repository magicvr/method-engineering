# D-004 · 接受 shared research core 候选作为设计基线

创作者接受 [共享研究闭环候选 v0.1](../attachments/shared-research-loop-candidate-v0.1.md) 作为 shared core 的设计基线。其基本闭环为：识别未知与 owner → 定义有界研究问题和当前用途标准 → 选择适当来源并限制范围 → 收集并逐主张评价证据 → 检查适用性/迁移 → 综合并区分来源陈述、AI 推论和目标待验证主张 → 回交宿主判断 → 登记剩余未知并停止或明确开启新问题。

接受范围是研究过程语义的设计基线，含“外部分类不自动成为宿主结构”“资料未找到不等于对象不存在”“迁移理由与适用边界须留痕”“research core 不代替宿主裁决”等边界。它不是经验验证结论，不表示已接入任何 S1/S2 方法版本，也不授权编辑宿主方法或运行调用试跑。
