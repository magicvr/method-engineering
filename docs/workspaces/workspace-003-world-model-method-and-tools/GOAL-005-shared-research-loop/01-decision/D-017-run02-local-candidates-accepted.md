# D-017 · 接受 run-02 两项局部 B3 候选并保留当前粒度

## 创作者裁决

创作者分别裁决：

1. **B3-1 服务路径、设施状态与故障范围**：接受并保留当前粒度。该项合并 run-02 候选 1（路径/设施状态/故障范围）与候选 2（泵站/处理/供电依赖）；后者作为实际系统存在时的条件调查内容，不另立节点。
2. **B3-2 应急/非管网交付的物流覆盖与时序**：接受并保留当前条件粒度。是否实际使用 emergency 或 non-piped delivery 是该求解项首先要回答的适用性问题；只有答案确认使用时，才进入对运输、分发点、覆盖与时序的后续调查。创作者接受的是条件问题结构，不是该供水模式为真的事实。

完整问题文本与 Rule F.2 四字段见 [已裁决的 run-02 局部回流](../attachments/s1-run02-return-reconciliation-v0.1.0.md)。household storage 候选仍未准入，保持未知。

- 本裁决只接受 run-02 形成的两个局部候选节点及其当前粒度；不确认任何目标社区机制、组件、故障、应急交付或家庭储水事实。
- 两项 B3 的 F.2 四字段及 F.3 resolution owner / 下一阶段状态均已齐备，可作为局部内容完整的 S2 求解项；具体目标事实仍待后续调查或建模。

- A-003 的两项 MINOR 仍保留在原独立审计记录中；本决定不改写或关闭该记录。研究样本接受与结构裁决均不接受 S1/S2 方法、Core、Schema 或 Adapter 的一般版本基线。
