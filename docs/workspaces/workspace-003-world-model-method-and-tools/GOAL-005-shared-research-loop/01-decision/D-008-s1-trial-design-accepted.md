# D-008 · 接受 S1 research-loop 独立调用试跑设计基线

创作者接受 [S1 research-loop 独立调用试跑设计 v0.1](../attachments/s1-independent-call-trial-design-v0.1.md) 为设计基线，前提是完成以下唯一修改：在 §3 删除会提示研究方向的具体配置实例，改为不预设任何具体系统配置、故障缓解机制或固定子问题清单；其余设计不变。接受后案例仍是待执行的合成案例，不是 GOAL-002 W4 / `I-402` 真实案例证据。

创作者确认计划工作量边界为 45 分钟；若执行环境不能可靠按墙钟计时，使用查询数、来源数、检查点和停止理由形成可复核预算。试跑须继续遵循已接受的 integration plan：先另行授权并形成窄 S1 host 集成候选，再审阅、固定实际 host 身份，之后才可另行授权试跑执行。

创作者明确授权下一步**形成并审阅**一个基于冻结 v0.16.1 的窄 S1 host 集成候选；这不授权直接启动研究调用或试跑，不允许修改已接受的 core、schema 或 adapter，也不改写 v0.16.1、v0.17.0、run-10 或 Probe 1 案例结论。
