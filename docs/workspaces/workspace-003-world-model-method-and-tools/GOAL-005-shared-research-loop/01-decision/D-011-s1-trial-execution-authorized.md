# D-011 · 授权执行一次 S1 research-loop 独立调用试跑

创作者在同步裁决中选择“授权执行（推荐）”，授权按已接受的 [S1 试跑设计 v0.1](../attachments/s1-independent-call-trial-design-v0.1.md) 与 [绑定包 v0.1.0](../attachments/s1-independent-call-trial-binding-v0.1.0.md) 执行**一次**有界 S1 research-loop 独立调用。该授权仅覆盖绑定包内的单一合成案例、单一研究问题、来源策略、查询/来源上限、检查点、用途标准与停止条件。

本决定不授权第二次调用、S2 试跑、Probe 1、开放式 coverage search、方法或组件编辑，也不把试跑结果预先视为证据采纳、结构接受、方法验证、handoff-ready 或目标答案。研究回流仍须由 S1 按现有 Rule E/F/G 处理；创作者对候选池及未决归属的决定保留待裁。
