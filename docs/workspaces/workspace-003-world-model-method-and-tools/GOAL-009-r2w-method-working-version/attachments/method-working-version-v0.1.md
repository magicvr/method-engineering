# R2-W · 方法工作版 v0.1

## 0. 性质与证据边界

本文件是人工、条件化、可停止/拒答的方法工作版草案，不是实际运行记录、有效性证明或交付放行。它沿用受限 R2-W 路线和 PA2/PA3/PA4/PA5 的局部证据，不新增来源、真实案例、实验、工具或原创。PA5 纸面检查为 20 单元、14 pass、0 fail、6 uncertain；pass 不等于实际可用性验证。六项 uncertain（B03/B05/B08/B13/B17/B20）必须保留。

## 1. 目的、适用与排除

目的：面对有边界的世界模型裁决问题，帮助人工执行者固定原问、条件、输出契约，按需求 §10 顺序检查，区分信息不足、作者待决、条件不满足与有界能力缺口候选，描述已有能力或局部模型候选，保留来源、条件、证据、不确定与拒答边界，并把条件结果或未决事项返回创作者。

适用：创作者负责设定与最终取舍；对象、范围、所求结果、时空参照可说明；世界规则、状态、角色认知可区分；来源/权限可核对；输出契约可说明；操作者接受人工检查、条件回答或拒答。

排除：不替作者补定设定或审美取舍；不把条件可行写成作品已发生；不提供通用客观性、保真拆分或冲突优先级；不承诺诊断穷尽、发现完备、全局最小、自动版本管理、H2 可靠性或 H3 冷启动充分性；不运行旧 H 实验；不新增来源、实验、原创、工具、真实案例或外部交付。

## 2. 角色

- 创作者：提供/确认设定、状态、认知依据和原问，决定创作取舍及是否采用结果。
- 方法执行者：按流程检查，登记依据、版本、限制和停止原因，不替作者或用户裁决。
- 用户/维护人：裁决需求变化、冲突、残余和新增授权。
- 独立审计者：按指定范围核对追溯和门禁，不替执行者完成方法。

## 3. 流程

0. 建立问题记录：原问、来源、对象、条件、时空参照、输出契约；区分事实/假设/推断/作者待决。必要上下文或授权不足即暂停。
1. §10-1 裁决边界：识别可裁决、条件化、返回作者部分；未定设定不补定（B03）；不能确认保真拆分则停止原问（B05）。
2. §10-2 已有能力：记录查找范围、别名/人工复核；分别检查命中、适用、可解、输出达标；无结果不等于能力不存在。
3. §10-3 状态：列所需输入/状态快照/时空/认知依据；不编造状态；补状态后回访；不预设独立状态层。
4. §10-4 组合：核对对象、单位、共享量、条件、假设、输出语义和分支；无依据冲突时停止（B08）；子问可解不自动综合原问（B20）。
5. §10-5 精度：比较输出要求、输入精度、表示分辨率、近似；不伪造精度；粗化输出必须作为修改后问题回访。
6. 汇总去向：已有条件答案、待信息、待裁决、有界能力缺口候选；未完成检查不等于失败，全部未解决不等于已证缺机制。
7. 能力/局部模型候选：写输入、状态、输出、条件、假设、表示、机制组织（条件性）、拒答边界；固定问题下局部充分即可，不声称全局最小；需新增来源/原创/实验/工具/真实案例时停止并返回用户。
8. 检查、登记与回接：核对字段/接口/语义/版本；区分文档核对、纸面证据和未执行检查；依赖不明不复用旧裁决；返回条件结果或拒答，不自动晋升作品事实。

## 4. 两项手填结构

- [模型条目最小结构](model-entry-structure-v0.1.md)：步骤 2、7、8 使用，记录身份/版本、查询/别名、输入/状态/时空、输出/条件/假设/表示、规则/机制组织、来源/改造、检查证据/未验证、拒答、依赖/变更/回接。

两项结构为人工记录载体，不建立第二套状态源或自动系统。

## 5. 六项残余

| 项目 | 处理 | 停止/拒答 | 复审触发 | 不得外推 |
|---|---|---|---|---|
| B03 作者未定设定 | 仅列条件说明，原问保持未决 | 不替作者补定 | 作者设定/授权假设/用途改变 | 条件答案不是无条件事实 |
| B05 保真拆分不明 | 保留原问、拆分理由、共同条件与遗漏 | 停止原问整体裁决 | 作者澄清评价依据/子问关系 | 子问答案不表示原问已回答 |
| B08 未裁决冲突 | 记录冲突双方、条件、版本和影响 | 阻断受影响裁决/组合/建模 | 获得适用依据或书面裁决 | 顺序/先命中不是优先级规则 |
| B13 跨实例复用 | 只标已检查范围和未验证范围 | 不保证非补丁/稳健复用 | 新实例/条件改变/扩大复用前 | 有限实例不证明全局最小 |
| B17 依赖不明旧裁决 | 标待复核，阻断复用 | 不自动宣布全部失效 | 依赖/版本/缓存澄清或足够复核 | 记录未出现依赖不等于无依赖 |
| B20 H2 综合 | H2 仅可选提示，保留共同条件与分支 | 无依据时停止整体答案 | 原问/条件澄清或另行授权 | 子问可解不保证原问可解 |

共同复审：外部交付前、真实案例使用前、证据冲突、新证据、拟复用旧 H 实验或扩大 R2-W 承诺时。

## 6. 版本、证据与变更

人工绑定方法版本、条目版本、规则/条件/状态/时空、组合依赖、输出语义和检查/回接记录。变更记录旧版/新版、理由、已知影响、影响未知、待复核和复核结果；旧裁决原位保留。不得把计划写成执行、字段齐全写成可运行、内部一致写成领域有效、残余接受写成 verified。
