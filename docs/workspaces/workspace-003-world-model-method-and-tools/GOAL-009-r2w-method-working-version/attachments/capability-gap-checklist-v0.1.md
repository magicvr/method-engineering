# 能力缺口判定清单 v0.1

人工填写，空白不表示通过或不存在；未知、未检查、不适用分别注明原因。

| 字段 | 填写说明 |
|---|---|
| 记录标识/日期/填写人 | 人工区分记录及责任 |
| 原问与来源 | 保留原文、来源位置、使用依据 |
| 澄清问题/子问 | 与原问并列，说明改变、遗漏和对应关系 |
| 对象/用途/范围 | 处理对象、用途和排除范围 |
| 条件/状态/时空参照 | 规则、状态快照、时间/空间；未知单列 |
| 事实/假设/推断/作者待决 | 分开标注性质和依据 |
| 输出契约 | 输出含义、精度、条件或可能集合 |
| 方法/条目版本 | 固定实际采用或候选版本 |
| 查找与替代检查范围 | 目录、别名、人工复核、补状态、组合、较粗表示等 |
| 五项检查记录 | §10-1～§10-5 逐项记录：检查信息/缺失、依据/版本、已做动作、结果、未解决原因、停止/待决、回访条件 |
| 交叠与回访 | 什么改变后回到哪一步，哪些结论需复核 |
| 汇总与去向 | 条件答案、待信息、待裁决、有界缺口候选；保留限制 |
| 停止/拒答范围 | 不能回答的是原问整体还是部分，停止理由 |
| 步骤 8A：反补丁检查 | 条件内其他实例（如可用）、条件外反例/对照、偶然依赖分别记录；每项填所需输入/缺失、比较对象/变化条件、拟做/已做动作、输出/证据类型/限制、不能判断时的停止原因/范围、下一责任/复审触发、执行状态。无实例/反例不得宣称非补丁；B13 uncertain |
| 步骤 8A：范围/敏感性检查 | 假设一致性、边界条件、参数/条件变化、表示或计算分辨率分别记录（表示与计算分辨率再分开）；每项填上述输入、比较、动作、输出、停止、责任/复审与状态。逻辑后果不等于领域有效性 |
| 步骤 8B：版本/旧裁决回接 | 原问/契约及方法/条目/规则/条件/状态版本、组合依赖、旧版/旧裁决对照、变更与已知影响/影响未知、待复核旧记录、所需输入、拟做/已做复核动作、输出/未执行、条件结果/未决/拒答回接包及作者待决、停止原因/范围、下一责任/复审触发、执行状态；依赖不明阻断受影响复用，B17 uncertain |
| 下一责任与复审 | 作者/执行者/用户；所需决定或信息；复审触发 |

汇总占位：原问；当前只支持；尚不支持；五项完成范围；下一步责任；本记录不证明的边界。

步骤 8A/8B 的详细动作见 [方法工作版](method-working-version-v0.1.md) 对应子步骤。执行状态逐项填未执行/未知/已执行/不适用及理由；空白不表示通过，未执行不填通过结论。本轮仅补字段与指导，实际检查、旧裁决复核及回接均未执行；拟做动作不是已做证据。
