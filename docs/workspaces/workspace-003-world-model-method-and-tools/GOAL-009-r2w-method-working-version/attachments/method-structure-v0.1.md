# R2-W 方法结构与字段规格 v0.1

## 目的与适用边界

形成人工、条件化、可拒答的世界模型裁决方法工作版。适用于创作者负责设定与最终取舍的有边界问题；输入、条件、输出契约可核对；不足时停止、返回作者或拒答。不承诺诊断穷尽、发现完备、全局最小、自动版本管理、H2 可靠性或 H3 冷启动充分性。

## 角色与责任

- 创作者：提供/确认设定、状态、原问；决定创作取舍与是否使用结果。
- 方法执行者：按流程检查、登记证据/版本/限制，不替作者补定或作创作裁决。
- 用户/维护人：裁决需求变化、冲突、残余和新增授权。
- 独立审计者：按指定范围核对追溯与门禁，不替执行者完成方法。

## 流程骨架

0. 建立问题记录：原问、来源、对象、条件、时空参照、输出契约；区分事实/假设/推断/作者待决。
1. §10-1 核对裁决边界：可裁决、条件化、返回作者；未定设定不补定。
2. §10-2 查找已有能力：目录/别名/人工复核；命中、适用、可解、达标分开。
3. §10-3 检查状态：所需输入/状态快照；补状态后回访。
4. §10-4 检查组合：接口、条件、共享量、分支；冲突无依据时停止。
5. §10-5 检查精度：输出要求、输入精度、表示分辨率、近似；不伪造精度。
6. 汇总去向：已解决、待信息/待裁决、有界能力缺口候选；未完成检查不等于失败。
7. 能力描述与局部模型候选：固定查询、条件、输出、表示、拒答边界；不声称全局最小。
8. 人工登记与回接：版本/依赖/检查证据；条件结果或拒答；不自动成为作品事实。

## 能力缺口判定清单字段

- 原问/对象/条件/输出要求/版本
- §10 五项顺序、检查依据、检查信息是否具备
- 结果、未解决原因、信息不足与能力不足区别
- 查找范围、替代检查、交叠/回访条件
- 最终去向、作者/用户待决事项

## 模型条目最小结构字段

- 条目身份/版本、用途、查询/别名
- 输入、状态、时空参照
- 输出含义、适用条件、假设、表示
- 必要规则/关系；机制表示时的实体、活动、组织
- 来源要素、有限改造差异、检查证据、未验证范围
- 不确定、失败、拒答条件
- 组合依赖、变更影响、旧裁决待复核

## 停止/拒答规则

未定设定、不能确认保真拆分、未裁决冲突、依赖不明、必要输入/权限不足、需新增来源/实验/原创/工具/费用/真实案例时停止受影响范围并返回作者/用户。拒答不必然是失败，但不能据此宣称真实闭环成功。

## 六项残余

B03、B05、B08、B13、B17、B20 必须逐项保留在流程、结构、限制和复审触发中；不得把纸面检查写成实际验证。

## 内部核对计划

S2/S3 完成后，核对：文档结构一致性；§10/§13 覆盖；两项结构字段可填；来源/有限改造/限制/未决/责任可追溯；六项残余未被掩盖；R3/R4 输入和未放行门禁清楚。内部核对不替代独立审计或真实使用验证。
