# A-002 · R2-W 退出独立审计

> 来源：独立 REVIEWER（只读）。本条目按原意见落盘，保留 REJECT 与 required 判定；编排器响应另见索引与后续复审，不覆盖本条。

## Findings

### MAJOR

**F-01 · §13-6/§13-7 的流程覆盖不足，且四项覆盖映射指向不存在的步骤。建议 WORKER 整改，整改后复审。**

- **位置**
  - GOAL-009 `attachments/requirements-coverage-v0.1.md:26–30`
  - `attachments/method-working-version-v0.1.md:41`，以及 §5、§6、§8
  - `attachments/model-entry-structure-v0.1.md:28–29`
- **证据**
  - 覆盖矩阵将 §13-6、§13-7 指向“步骤 8A”，将 §13-9、§13-10 指向“步骤 8B”；实际工作版只有步骤 **0～8**，没有定义 8A/8B。
  - 实际步骤 8 仅要求核对字段、接口、语义、版本，区分证据类型，处理未知依赖并回接结果。
  - 对 §13-6，工作版保留了 B13 的未验证声明，但没有描述如何检查对当前实例的偶然依赖、如何选择条件内其他实例或条件外反例。
  - 对 §13-7，矩阵写了“分开一致性/边界/变化/分辨率”，但工作版和模型条目结构没有对应的分项检查安排。通用“检查证据”“未验证范围”字段可以记录结果，却不足以指导这些检查。
  - 上游 PA3 `attachments/mapping-matrix-v0.1.md` 已明确提出条件内实例、条件外反例，以及假设一致性、边界、参数敏感性、计算分辨率的分开安排；Root 沿用的 R1 v0.6.4 §2 要求可照着执行的步骤、输入、输出与停止点。
- **影响**
  - **有 15 行映射不等于 15 项真实覆盖。** 当前无法确认 §13-6/§13-7 已形成可操作的方法描述；另外两项虽有版本与回接正文承接，映射定位仍不成立。
  - E-003 和 A-001 关于“每项均有工作版位置”“未发现实质缺口”的结论因此过强，不能直接作为 S4 退出依据。
- **建议纠正**
  - 明确定义检查与登记/回接子步骤，或改为引用实际存在的章节。
  - 为反补丁及范围/敏感性检查补充最小人工指导：所需输入、比较对象或变化条件、检查动作、输出记录、不能判断时的停止与下一责任。
  - **只补方法描述，不要求本轮运行检查**；保持 B13 uncertain、实际验证未执行，不增加案例、实验或授权。
  - 同步映射、结构字段及核对意见，再独立复审。当前作为 **required**，阻断 S4 退出。
