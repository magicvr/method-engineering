## 对照成功标准

VP-003 的方法构想是：作者能判断现有模型能否回答，识别所缺为状态、组合、精度或机制，以最低充分机制模型补足，并走完「发现缺口 → 构建模型 → 注册能力 → 完成裁决 → 检查 → 返回创作」。判据 2 要求工作版覆盖 §10 次序和 §13 十项指导，并显式写出适用条件、限制与未决；判据 4 的真实问题检验属于后续交付，不是本目标。v0.1.1 写明意图和判据不变，实现上停止自行推导机制基础理论。

根目标 R2-W 的退出行（`00-meta.md`、D-021）是：按 PA5 冻结路线形成版本化方法，覆盖 §10/§13 与两项手填结构，逐项标流程、证据范围、未验证和下一责任。同一决定另写明沿用 R1 的创作者主责与 AI 可选协助、建议与裁定分离、手填结构与逐项映射契约。PA1 C-01、C-04、C-05 把这些标为最终方法的内容基线。GOAL-008 路线冻结的前置也写「R1 既有需求/授权/停止约束继续有效」，同时授权把机制表示保持为非必需、把最低充分保持为未证明的工作检查目标。

## Findings

### A-004-F-001 · 可执行工作版未写入根目标仍沿用的责任边界与排除边界

- **级别**：required
- **严重度**：中
- **关联**：根目标沿用的 R1 内容基线 C-01、C-04、C-05、C-08；不是新的信息未知项
- **证据**
  - [R1 v0.6.4 §1](../../GOAL-001-world-model-method-and-tools/attachments/R1-freeze-proposal-v0.6.4.md) 规定创作者运行方法并作最终裁决；AI 可提示、追问、建议候选、解释、提供反例与检查、整理材料；建议和裁定分开留痕；AI 不代作结论。同节排除需求 §12 十一项，并把世界状态、角色所知、观众所知分开。§2 把「创作者决策点、AI 可协助形式及不得越界的界线」列为工作版最少内容。
  - [D-021](../../GOAL-001-world-model-method-and-tools/01-decision/D-021-prior-art-driven-implementation-reframe.md) 在 R2-W 退出行之外，单独保留上述继承。根目标 `00-meta.md` 的现行路线说明使用同一句。
  - [约束迁移矩阵](../../GOAL-004-pa1-baseline-and-source-plan/attachments/constraint-migration-matrix-v0.1.md) 将 C-01、C-04、C-05 标为内容基线：C-01 进入最终方法的适用对象与责任边界；C-04 保留 §12 排除；C-05 要求 R2-W 检查点含创作者决策与 AI 边界。C-08 沿用「AI 建议和创作者裁定分别标示」。
  - [路线冻结](../../GOAL-008-pa5-information-closure-and-route-freeze/attachments/route-freeze-v0.1.md) 前置写明 R1 既有需求、授权和停止约束继续有效。其非目标节没有声明取消 AI 边界或 §12 排除。
  - [方法工作版 §1–§2](../attachments/method-working-version-v0.1.md) 写了创作者负责设定与最终取舍，执行者不替作者裁决，角色认知可区分。适用与排除、角色、两项结构均未写 AI 可以做什么、不可以做什么，也未列出 §12 十一项。对 GOAL-009 `attachments/` 检索「AI」「§12」「剧情」「BDI」「模拟器」无命中。清单把事实、假设、推断、作者待决分开，没有建议与裁定两栏。
- **影响**
  - 只按工作版操作的人看不到已冻结的协助边界。文本沉默可以被看成禁止协助，也可以被看成协助不受限制。两种读法都偏离 D-014 之后的 R1 §1。
  - 工作版的排除列表比根目标的需求边界窄。叙事方法、角色决策、自动编剧、完整世界模拟器和固定软件架构没有出现在可执行排除项里。这与 VP-003「方法对象是世界模型裁决」以及「不建设产品化服务」的边界同类，但是工作版自己没有把门关住。
  - 创作者主责、停止/拒答和六项残余已经写明。本项不否定这些成果，也不把未运行真实闭环算作失败。
- **建议纠正**
  - 在工作版角色节和两项结构中写入 R1 §1 已有的 AI 边界：可提示、追问、建议、解释、反例、检查和整理；建议与创作者裁定分栏；AI 不代作结论、不授权、不扩容；没有 AI 也可以运行。
  - 在排除节列入 §12 十一项，并保持世界状态、角色所知、观众所知分开。不新增案例、实验、工具或来源。
  - 这是把已有决定抄入可执行文本。本意见建议走 fixed。若要让工作版继续保持沉默，须由用户书面 user-overruled，并写明范围。I-010 的残余接受不能代替这一项。

### A-004-F-002 · §13-10 的创作取舍记录，以及 v0.6.4 模型条目字段名，仍比冻结落点更具体

- **级别**：recommended
- **严重度**：低
- **证据**
  - R1 v0.6.4 §2 的 §13-10 要求说明由谁承接、如何回交，以及后续创作裁决如何记录纳入、弃用或修改。模型条目须承接问题类、现有模型不足、前提/现实参考、状态输入、机制输出、范围、精度、组合、拒绝条件、反例/条件变化、版本和创作者裁定。
  - 工作版步骤 8B 已把回接包交给作者，并写明作者决定创作取舍、采用与否未知时不得晋升作品事实。覆盖矩阵把 §13-10 标为 unresolved，限制是未证明消费接口和创作效果。条目字段按路线冻结落点实现；机制组织保持条件性，与「不承诺机制表示必需」一致。
  - 工作版和模型条目没有「纳入 / 弃用 / 修改 / 未决定」记录槽，也没有使用「问题类、现有模型不足、前提/现实参考」这些字段名。
- **影响**
  - 不阻断步骤 8B 作为纸面回接。A-003 对 8A/8B 最小指导的通过结论仍然成立。
  - 缺口在于：unresolved 指的是 PA3 处置，读者仍可能把「作者决定创作取舍」当成已经写明纳入、弃用、修改的判断记录。字段名差异则可能被当成 v0.6.4 §2 的模型条目句子已被路线冻结取代，但 GOAL-009 没有单独留下这条收窄。
- **建议纠正**
  - 在回接字段增加创作者的纳入、弃用、修改或未决定，并写明方法不代作该选择。
  - 或者在决策中写明：R2-W 模型条目以 GOAL-008 路线冻结的落点为准，v0.6.4 §2 的十二类字段名不再逐项强制；机制表示继续可以标为不适用。未记录前，不要把两套字段清单看成已经同一。

## 与既有意见的异同

- A-001 认为方法正文没有实质缺口。本意见同意残余、门禁和「未验证」没有被写成有效；不同意「责任与适用边界已经完整」。
- A-002 F-01 指出当时不存在 8A/8B。该缺口已由 E-004 补上，A-003 允许按 fixed 闭合。本意见不重开 F-01，也不改 A-002 的原 verdict。
- A-003 的 scope 是 F-01 闭合与 S4 退出可行性，没有审 AI 边界、§12 排除或 VP 闭环的阶段划分。本意见与 A-003 不冲突：8A/8B 的最小指导仍可核对；新增的是构想对照上的 required。
- 本意见不把 progress 100% 或 S1～S4 的完成标记当作边界已满足的证据。

## 结论 + 建议给编排器/用户的下一步

**conditional。**

工作版符合 VP-003 对本阶段的构想，也符合 reframe 之后的受限 R2-W：它是可停止的人工方法，覆盖 §10 次序和 §13 的处理位置，用局部、有限改造的模型候选代替自行推导的机制理论，并把未运行的检查、六项残余和 R3/R4 门禁留在明处。它还没有满足根目标仍沿用的适用与责任基线。

建议 `/govern` 响应 A-004-F-001，优先 fixed：把已冻结的 AI 边界和 §12 十一项写入工作版与两项结构。不要在本项未合法闭合时确认 GOAL-009 done 或根目标 R2-W 检查点。F-002 可同轮吸收，或另作字段名收窄记录。本意见不授权真实案例、工具、原创或外部交付。
