# GOAL-009 · R2-W 方法工作版与内部核对

## 概述

承接 Root R2-W 和 GOAL-003 的受限 R2-W 路线冻结，形成版本化人工方法工作版及两项可手填结构（能力缺口判定清单、模型条目最小结构）。覆盖需求 §10/§13、适用条件、步骤/输入/输出/停止点、证据/版本追溯、限制/未决/责任和逐项映射。本目标不运行真实案例、不实现工具、不启动原创或实验，不交付 R4。

## 非目标

- 不声称方法或理论已实际有效；纸面检查不是真实使用验证。
- 不新增来源、真实案例、实验、原创、外部执行或工具。
- 不关闭 I-002/I-004/I-006，不改变 I-010 残余，不恢复旧 H。
- 不替 R3/R4 放行或交付。

## 成功标准

- [ ] 形成版本化方法工作版，覆盖 §10/§13、适用/排除条件、步骤、输入/输出/停止点和作者决策点。
- [ ] 形成两项可手填结构，并明确字段、用途和与流程的对应。
- [ ] 形成 §10/§13、来源/有限改造、限制/未决、证据范围、下一责任的逐项映射。
- [ ] 内部核对可区分文档一致性、纸面证据与实际未验证内容；六项残余不被掩盖。
- [ ] 交接 R3/R4 所需输入与未放行门禁；阶段审计无开放 required finding。
